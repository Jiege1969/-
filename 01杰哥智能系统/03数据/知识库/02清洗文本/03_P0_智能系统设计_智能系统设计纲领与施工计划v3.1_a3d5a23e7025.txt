# 01杰哥智能系统设计纲领与施工计划v3.1

生成日期：2026-04-30

## 定位

01杰哥智能系统是整个【杰哥智能化系统】的基础智能底座，负责模型、知识库、n8n、Redis、Qdrant、智能体大脑测试服务和基础执行器。

## 当前状态

已确认的新系统基础服务包括：
- v3 Ollama容器和模型资源池。
- v3 Redis。
- v3 n8n隔离实例和未激活工作流导入件。
- 知识库检索增强链路。
- 智能体大脑测试服务。

## 设计原则

1. 基础能力下沉到01系统，子系统不得重复部署同类基础组件。
2. 模型调用按任务路由，不把一个模型用于所有任务。
3. n8n是逻辑编排中心，真实启用和真实发送必须受闸口控制。
4. 知识库优先本地预演和人工确认，再进入正式使用。
5. 资源占用受控，不能让基础服务影响电脑正常使用。

## 当前施工重点

1. 模型路由和Ollama稳定性。
2. 知识库本地入库和问答预演。
3. n8n隔离导入、未激活工作流和受控刷新。
4. 为股票研究系统提供稳定基础能力。

## 后续计划

1. 完善模型资源池健康检查和任务路由。
2. 把知识库能力开放给股票、本职工作、内容处理。
3. 完善n8n工作流导入件的验收和回滚。
4. 与00总管开工上下文联动，让每次施工前能读取当前基础服务状态。

## 旧资料与基础设施口径

旧 D 盘根目录智能系统路径已经作废并清理，不再作为 WSL2 / Docker Desktop 运行底座口径、脚本输入或系统搭建依据。

当前 v3 基础服务只认 `D:\杰哥智能化系统\01杰哥智能系统` 下的配置、数据、日志和验收报告。任何旧资料只允许先提炼经验，再删除原件，不能把旧路径、旧容器名、旧挂载或旧端口带入当前施工。
