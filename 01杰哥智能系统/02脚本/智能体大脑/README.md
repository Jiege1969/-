# 智能体大脑脚本目录

## 定位

本目录属于 `01杰哥智能系统`，负责模型路由、任务识别、中台能力、知识检索、工作流规划和跨系统只读适配。

## 接口脚本说明

以下脚本名称含业务词，但它们不是业务系统主逻辑：

- `股票研究接口.py`
- `视频制作接口.py`
- `本职工作接口.py`
- `税收业务接口.py`

这些脚本是跨系统只读适配层，只负责读取、汇总或路由 `02杰哥扩展系统` 的业务输出。它们不得承载业务主逻辑，不得写业务正式数据，不得触发企业微信真实发送，不得触发 n8n 正式执行，不得调用券商接口，不得自动交易。

## 边界

1. 模型能力由本目录调度，但业务事实和业务证据仍归对应业务系统管理。
2. 需要写正式业务数据时，必须回到对应业务系统的受控入口。
3. 需要外发消息时，必须经过企业微信助手和总管闸口。
4. 需要升级模型或运行时，必须遵守版本锁定和影子验证规则。
