# 任务队列设计

创建日期：2026-04-26

## 一、定位

任务队列用于隔离即时任务和长任务。

企业微信入口不能被大模型长推理、批量股票筛选、视频转写等任务阻塞。

## 二、任务类型

| 类型 | 示例 | 策略 |
|---|---|---|
| 即时任务 | 普通问答、系统状态 | 同步返回 |
| 中等任务 | 单股分析、短文总结 | 可同步，可降级 |
| 长任务 | 批量选股、视频转写、知识库入库 | 后台队列 |
| 定时任务 | 日报、周报、健康报告 | n8n 触发 |

## 三、第一阶段实现建议

第一阶段可用 Redis 记录任务状态。

后续如任务复杂度上升，再引入专门队列组件。

## 四、状态流转

```text
created
  ↓
queued
  ↓
running
  ↓
success / failed / canceled
```

## 五、输出策略

长任务收到后，企业微信先回复：

```text
已收到，任务已进入后台处理。
```

任务完成后，通过统一消息出口推送结果。
