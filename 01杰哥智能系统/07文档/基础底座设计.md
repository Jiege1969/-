# 01杰哥智能系统基础底座设计

创建日期：2026-04-26

## 一、定位

01杰哥智能系统是 v3 的基础底座。

它负责提供通用能力，不承载股票、视频、本职工作等具体业务逻辑。

## 二、核心能力

1. 统一入口：企业微信、本地 API、后续 Web 控制台。
2. 智能体大脑：任务识别、工具路由、模型路由。
3. 模型服务：统一调用 Ollama，后续可扩展 vLLM。
4. 模型路由：根据任务类型选择 7B、14B、30B、32B、代码、视觉、金融模型。
5. 数据服务：PostgreSQL、Redis、知识库。
6. 工作流中心：n8n 负责定时、编排、推送和 Webhook。
7. 统一消息出口：所有主动推送统一出口。
8. 任务队列：长任务排队，避免阻塞企业微信即时回复。

## 三、边界

01 可以做：

- 提供模型能力。
- 提供数据能力。
- 提供消息能力。
- 提供调度能力。
- 提供权限和治理能力。

01 不做：

- 不直接写股票策略。
- 不直接写视频脚本业务。
- 不直接写本职工作专用流程。
- 不直接生成某个业务模块的专属数据表，除非作为公共数据能力。

## 五、稳定原则

1. 基础组件优先稳定，再接业务。
2. 大模型调用必须经过模型路由。
3. 主动推送必须经过统一消息出口。
4. 长任务必须队列化。
5. 所有基础服务必须有健康检查。
