# 智能体大脑 API 契约

创建日期：2026-04-26

## 一、定位

智能体大脑负责任务识别、模型路由、工具路由和结果整理。

## 二、接口

### GET /健康

用途：健康检查。

### POST /思考

用途：处理统一消息。

请求示例：

```json
{
  "请求ID": "uuid",
  "来源": "wecom",
  "用户": "jiege",
  "内容": "帮我总结这个文档",
  "上下文": {}
}
```

返回示例：

```json
{
  "请求ID": "uuid",
  "任务类型": "知识库问答",
  "执行方式": "同步",
  "模型": "qwen3:14b",
  "工具": "knowledge_base",
  "回复": "这是总结结果..."
}
```

### POST /任务识别

用途：只做任务识别，不执行任务。

返回示例：

```json
{
  "任务类型": "股票研究",
  "置信度": 0.92,
  "建议执行方式": "同步"
}
```

## 三、边界

1. 大脑可以路由任务，但不应承载业务细节。
2. 股票、视频、本职工作、内容处理由各自业务服务处理。
3. 大脑调用模型必须经过模型路由器。
4. 大脑发消息必须经过统一消息出口。
