# 01智能系统轻量任务契约适配包

生成时间：2026-05-05  
适用范围：`D:\杰哥智能化系统\01杰哥智能系统`  
运行原则：学 OpenClaw/Hermes 的任务编排、能力路由、回执闭环逻辑，不引入原件、不复制原实现、不调用真实外部服务。

## 目标

本适配包用于说明 01智能系统如何在轻量、只读、dry_run 的边界内处理标准任务单：

- 读取标准任务单 JSON。
- 路由到模型/中台能力标签。
- 保持 dry_run，真实动作关闭。
- 规划 SQLite影子台账、Redis影子映射和 n8n干跑。
- 输出 receipt 作为本地验收回执。

## 标准任务单读取

标准任务单必须是 JSON object。最小必填字段如下：

- `task_id`：任务唯一编号。
- `schema_version`：任务单版本，例如 `standard_task.v1`。
- `source`：来源系统、通道、接收时间。
- `intent`：任务类别、动作、描述。
- `input`：输入类型、输入引用、摘要。
- `routing_hint`：期望能力、备用能力、模型标签、中台标签。
- `dry_run`：必须为 `true`。
- `safety`：必须声明 `real_action_allowed=false` 以及外部服务、正式库、券商接口、自动交易关闭。
- `receipt_required`：必须为 `true`。

读取流程：

1. 本地读取 JSON 文件，不监听端口、不发网络请求。
2. 解析字段并校验必填项。
3. 若 `dry_run != true`，直接阻断。
4. 若 `safety.real_action_allowed != false`，直接阻断。
5. 若任务要求触发 n8n、企业微信、正式库、券商接口、自动交易或真实模型接口，直接阻断。

## 模型/中台能力路由

路由只产出“选择结果”和“计划回执”，不调用真实模型接口。

| 输入信号 | 路由用途 | dry_run行为 |
| --- | --- | --- |
| `intent.category` | 判断任务类型 | 选择能力标签 |
| `intent.action` | 判断执行意图 | 生成计划动作 |
| `routing_hint.preferred_capability` | 优先能力 | 选择中台标签 |
| `routing_hint.model_family_label` | 模型族标签 | 只记录标签，不调用模型 |
| `safety.risk_level` | 风险门禁 | 高风险真实动作阻断 |

模型路由约束：

- `shadow_model_router` 只能返回模型族标签、提示词配置标签、降级标签。
- 禁止 `call_real_model_api`。
- 禁止把 prompt 发给外部模型供应商。
- 禁止 streaming 或任何真实推理调用。

中台能力路由约束：

- `local_contract_parser`：本地解析标准任务单。
- `shadow_knowledge_lookup`：只生成知识检索计划，不查正式向量库。
- `n8n_dry_run_shadow`：只生成 n8n干跑计划，不触发工作流。
- `unified_message_shadow`：只生成消息回执，不发企业微信。

## SQLite影子台账

SQLite影子台账是计划结构，不连接正式库、不写正式库。

建议字段：

- `task_id`
- `route_label`
- `dry_run`
- `status`
- `blocked_reason`
- `receipt_id`
- `created_at`

本轮包仅声明台账计划，验证脚本不会创建 SQLite 文件。

## Redis影子映射

Redis影子映射是计划结构，不连接真实 Redis、不写真实 Redis。

建议 key：

```text
shadow:task:{task_id}
```

建议 value：

- `route_label`
- `capability`
- `dry_run`
- `receipt_id`
- `ttl_seconds`

本轮包仅声明映射计划，验证脚本不会连接 Redis。

## n8n干跑

n8n 仅允许 dry_run：

- `mode=dry_run`
- `trigger_allowed=false`
- `workflow_execution_allowed=false`
- `webhook_call_allowed=false`

receipt 中可记录“本应选择哪个 n8n 干跑标签”，但不能触发真实 n8n。

## receipt输出

receipt 是任务处理后的本地回执。最小字段：

- `receipt_id`
- `task_id`
- `dry_run`
- `status`
- `selected_route`
- `shadow_writes`
- `external_calls`
- `blocked_actions`
- `evidence`
- `created_at`

硬性要求：

- `external_calls` 必须为空数组。
- `shadow_writes.sqlite.formal_db_write` 必须为 `false`。
- `shadow_writes.redis.real_redis_write` 必须为 `false`。
- 所有阻断的真实动作必须列入 `blocked_actions`。
- `evidence` 只能引用本地文件、字段和校验结论。

## 安全边界

允许：

- 读取本地 JSON/Markdown。
- 本地解析和字段校验。
- 生成影子 SQLite 台账计划。
- 生成影子 Redis 映射计划。
- 生成 n8n 干跑计划。
- 生成 receipt 样例和验收证据。

禁止：

- 触发 n8n。
- 调用企业微信真实发送接口。
- 连接或写入正式库。
- 连接或写入正式向量库。
- 调用真实模型接口。
- 调用券商接口。
- 自动交易。
- 下单。
- 发送真实外部网络请求。
