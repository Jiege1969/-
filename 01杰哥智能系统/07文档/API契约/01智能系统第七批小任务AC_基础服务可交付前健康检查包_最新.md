# 01智能系统第七批小任务AC：基础服务可交付前健康检查包

- 生成时间：2026-05-05 13:21:30
- 执行模式：local_shadow_health_check_only
- 交付门禁：pre_delivery_manual_acceptance
- 安全边界：不调用真实外部API，不触发 n8n，不发企业微信真实消息，不写正式库，不调用券商接口，不自动交易，不触碰本职工作系统。

## 检查项
### AC-H01 API契约
- 目标：交付前确认请求字段、响应字段、枚举、dry_run 和安全边界字段齐全。
- 通过规则：request_fields、response_fields、error_codes、safety_boundary 均存在且字段含义明确。
- 失败降级：返回 AC_CONTRACT_MISMATCH，阻断交付，列入人工补契约清单。
### AC-H02 错误码
- 目标：交付前确认成功、契约不一致、错误码缺口、知识检索降级、日志缺失、异常未处理、安全边界违规均有固定错误码。
- 通过规则：所有错误码具备 status、severity、delivery_gate、message。
- 失败降级：返回 AC_ERROR_CODE_GAP，阻断交付。
### AC-H03 降级
- 目标：证据不足、系统异常、字段缺失、越权真实动作时只返回固定降级语，不补写索引，不调用外部服务。
- 通过规则：每个阻断或降级错误码都有固定 message 和 fallback_action。
- 失败降级：返回 AC_ERROR_CODE_GAP 或 AC_EXCEPTION_UNHANDLED。
### AC-H04 知识检索联动
- 目标：健康检查能读取本地知识检索索引口径，并在证据不足时降级。
- 通过规则：health_check_item 中记录 knowledge_query_id、evidence_ids、evidence_count。
- 失败降级：返回 AC_KNOWLEDGE_LINK_DEGRADED，进入人工复核，不编造证据。
### AC-H05 日志字段
- 目标：交付前确认每个检查项都能产出可追踪日志字段。
- 通过规则：每条样本日志包含 REQUIRED_LOG_FIELDS 全量字段。
- 失败降级：返回 AC_LOG_FIELD_MISSING，阻断交付。
### AC-H06 异常处理
- 目标：本地异常、字段缺失、证据不足、安全边界违规都能转入降级或阻断路径。
- 通过规则：异常矩阵覆盖 contract_missing、no_evidence、local_exception、safety_violation。
- 失败降级：返回 AC_EXCEPTION_UNHANDLED，硬阻断。

## API契约
- 影子端点：POST /shadow/v1/intelligence/base-service/health-check
- 请求字段：request_id、caller、health_scope、knowledge_query、dry_run、safety_boundary
- 响应字段：request_id、status、error_code、health_result、degrade_message、fallback_action、log_fields、knowledge_link、safe_to_show_user、requires_human_review、external_effect、formal_store_write

## 错误码与降级
- OK：status=ok；severity=info；gate=pass；基础服务健康检查通过，可进入后续人工准入评审。
- AC_CONTRACT_MISMATCH：status=blocked；severity=error；gate=stop；API 契约字段或枚举不一致，本轮阻断交付，请先补齐契约。
- AC_ERROR_CODE_GAP：status=blocked；severity=error；gate=stop；错误码或固定降级语缺口未闭合，本轮阻断交付。
- AC_KNOWLEDGE_LINK_DEGRADED：status=degraded；severity=warning；gate=manual_review；知识检索联动证据不足，本轮只允许返回降级说明和人工复核提示。
- AC_LOG_FIELD_MISSING：status=blocked；severity=error；gate=stop；日志字段缺失，无法形成可追踪交付证据，本轮阻断交付。
- AC_EXCEPTION_UNHANDLED：status=blocked；severity=critical；gate=stop；异常处理路径未覆盖或可能外扩真实动作，本轮硬阻断。
- AC_SAFETY_BOUNDARY_VIOLATION：status=blocked；severity=critical；gate=stop；安全边界未闭合，本轮只保留本地 dry_run 记录并要求人工复核。

## 知识检索联动
- 模式：local_readonly_index_reference
- 证据字段：knowledge_query_id、evidence_ids、evidence_count、degrade_reason
- 无证据策略：返回 AC_KNOWLEDGE_LINK_DEGRADED，不编造证据，不补写索引，不调用外部检索。

## 日志字段
- trace_id、request_id、service_name、operation、health_check_item、status、error_code、degrade_reason、fallback_action、knowledge_query_id、evidence_ids、evidence_count、safe_to_show_user、requires_human_review、external_effect、formal_store_write、latency_ms、timestamp

## 异常处理矩阵
- contract_missing：detect_at=request_validation；error_code=AC_CONTRACT_MISMATCH；fallback=block_delivery_and_request_contract_fix；external_effect=none
- no_evidence：detect_at=knowledge_link_check；error_code=AC_KNOWLEDGE_LINK_DEGRADED；fallback=return_degraded_message_and_manual_review；external_effect=none
- local_exception：detect_at=health_check_runtime；error_code=AC_EXCEPTION_UNHANDLED；fallback=block_delivery_keep_local_trace；external_effect=none
- safety_violation：detect_at=safety_boundary_guard；error_code=AC_SAFETY_BOUNDARY_VIOLATION；fallback=hard_block_and_manual_review；external_effect=blocked

## 样本
- AC-S01 健康通过：status=ok；error_code=OK；fallback=none
- AC-S02 知识检索证据不足降级：status=degraded；error_code=AC_KNOWLEDGE_LINK_DEGRADED；fallback=return_degraded_message_and_manual_review
- AC-S03 日志字段缺失阻断：status=blocked；error_code=AC_LOG_FIELD_MISSING；fallback=block_delivery_and_fix_log_schema
- AC-S04 安全边界异常阻断：status=blocked；error_code=AC_SAFETY_BOUNDARY_VIOLATION；fallback=hard_block_and_manual_review
