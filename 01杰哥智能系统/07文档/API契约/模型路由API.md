# 模型路由 API 契约

创建日期：2026-04-26

## 一、定位

模型路由 API 负责根据任务类型和系统资源选择模型。

## 二、接口

### POST /模型/选择

请求示例：

```json
{
  "任务类型": "深度分析",
  "是否需要代码能力": false,
  "是否需要视觉能力": false,
  "是否长任务": true,
  "优先级": "P1"
}
```

返回示例：

```json
{
  "模型": "qwen3:30b",
  "执行方式": "队列",
  "降级模型": "qwen3:14b",
  "原因": "深度分析任务，当前显存允许"
}
```

### POST /模型/调用

用途：统一调用模型。

请求示例：

```json
{
  "模型": "qwen3:14b",
  "提示词": "请总结以下内容...",
  "参数": {
    "temperature": 0.3
  }
}
```

## 三、记录字段

每次模型调用应记录：

1. 请求ID。
2. 任务类型。
3. 模型名。
4. 输入长度。
5. 输出长度。
6. 耗时。
7. 成功或失败。
8. 失败原因。
