# 统一消息出口 API 契约

创建日期：2026-04-26

## 一、定位

统一消息出口负责所有主动推送。

业务模块不得私自调用企业微信接口。

## 二、接口

### POST /消息/发送

请求示例：

```json
{
  "请求ID": "uuid",
  "目标": "wecom",
  "用户": "jiege",
  "优先级": "P1",
  "消息类型": "text",
  "内容": "股票分析报告已完成"
}
```

返回示例：

```json
{
  "状态": "已发送",
  "请求ID": "uuid",
  "渠道": "wecom"
}
```

### POST /消息/合并发送

用途：合并低优先级消息，避免刷屏。

## 三、消息优先级

| 优先级 | 含义 | 策略 |
|---|---|---|
| P0 | 严重故障 | 立即发送 |
| P1 | 任务完成 | 正常发送 |
| P2 | 日报周报 | 定时发送 |
| P3 | 系统日志 | 默认不主动发送 |

## 四、边界

统一消息出口不负责业务分析，只负责发送和记录。
