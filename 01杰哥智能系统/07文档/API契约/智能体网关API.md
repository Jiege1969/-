# 智能体网关 API 契约

创建日期：2026-04-26

## 一、定位

智能体网关负责统一入口。

网关不做复杂业务判断，只负责接收、鉴权、格式统一、转发、记录。

## 二、接口

### GET /健康

用途：健康检查。

返回示例：

```json
{
  "服务": "智能体网关",
  "状态": "正常",
  "时间": "2026-04-26 18:00:00"
}
```

### POST /消息

用途：统一消息入口。

请求示例：

```json
{
  "来源": "wecom",
  "用户": "jiege",
  "消息类型": "text",
  "内容": "分析一下贵州茅台",
  "请求ID": "uuid"
}
```

返回示例：

```json
{
  "状态": "已受理",
  "请求ID": "uuid",
  "回复模式": "同步或异步",
  "回复": "任务已收到"
}
```

## 三、边界

1. 网关不直接调用大模型。
2. 网关不直接写业务数据库。
3. 网关不直接发起股票分析、视频处理等业务逻辑。
4. 网关只调用智能体大脑。
