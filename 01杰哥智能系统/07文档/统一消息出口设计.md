# 统一消息出口设计

创建日期：2026-04-26

## 一、定位

统一消息出口负责所有面向用户的主动推送。

任何业务模块不得私自调用企业微信接口。

## 二、目标

1. 统一推送格式。
2. 统一限流。
3. 统一优先级。
4. 统一失败重试。
5. 统一日志记录。
6. 支持消息合并，避免刷屏。

## 三、消息来源

1. 股票研究系统。
2. 视频制作系统。
3. 本职工作系统。
4. 内容处理系统。
5. 运维守护。
6. n8n 定时任务。
7. 进化系统审核提醒。

## 四、消息等级

| 等级 | 类型 | 推送策略 |
|---|---|---|
| P0 | 严重故障 | 立即推送 |
| P1 | 任务完成 | 正常推送 |
| P2 | 日报周报 | 定时推送 |
| P3 | 系统日志 | 默认不主动推送 |

## 五、第一阶段原则

第一阶段只设计，不接管当前企业微信链路。

正式接管前必须确认：

1. 当前企业微信入口。
2. 当前公网转发链路。
3. 当前密钥位置。
4. 推送失败兜底策略。
