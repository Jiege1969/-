# 智能体大脑测试服务说明

## 定位

本服务是 `杰哥智能化系统v3` 第一阶段的最小可运行大脑，只用于验证新系统的任务识别、模型路由和接口契约。

当前服务不接管旧系统生产流量，不调用企业微信，不写入旧数据库，不停止或重启任何生产容器。

## 已验证结果

2026-04-26 已验证：

- `/health` 返回正常。
- `/任务识别` 可将财报、估值类输入识别为 `股票研究`。
- `/模型/选择` 可将代码脚本类输入路由至 `qwen3-coder:30b`，兜底至 `qwen3:30b`。
- `/思考` 已接入 Ollama 受控推理，默认读取 `127.0.0.1:19134`，支持超时降级。
- 自动验证脚本已覆盖真实推理，并要求模型答复非空。

## 已发现经验

Windows PowerShell 5 对 UTF-8 无 BOM 脚本和管道中文内容存在误读风险。后续 PowerShell 启动脚本尽量采用 ASCII 自发现路径，接口验证脚本使用 Unicode 转义或 Python 文件方式执行。

## 推理边界

- 默认最大输出为 256 token，上限为 1024 token。
- 默认超时时间为 180 秒。
- 高风险任务只返回识别和路由结果，不自动调用模型。
- 当前只调用本机 Ollama，不调用云端模型。
- 对 Qwen3 等推理型模型，过低的输出上限可能导致答复为空；正式任务默认不低于 256。

## 规则治理

任务识别关键词和模型路由规则已从代码剥离到 `智能体大脑规则.json`。后续新增股票、视频、本职工作等任务类型时，优先修改配置，再验证服务行为。

提示词模板已从代码剥离到 `提示词模板.json`。后续任务风格调整优先改配置，再跑总体验收。

能力注册已从代码剥离到 `能力注册表.json`。当前只生成能力计划，不直接调用外部业务工具。

知识库接口当前只读取索引清单，支持状态查询和元数据检索；尚未接入全文解析、向量化或数据库写入。

工作流接口当前只生成 n8n 工作流计划，不实际触发 n8n。

股票研究接口当前只读取股票研究系统本地计划和报告，不联网、不抓行情、不调用券商接口。

视频制作接口当前只读取视频制作系统本地计划、脚本草稿和分镜计划，不处理真实媒体、不上传、不发布。

本职工作接口当前只读取办公材料计划和草稿框架，不读取真实涉密资料、不自动发送。

税收业务接口当前只读取税种分类索引和业务处理计划，不抓取政策、不读取真实涉税资料、不替代正式税务判断。
