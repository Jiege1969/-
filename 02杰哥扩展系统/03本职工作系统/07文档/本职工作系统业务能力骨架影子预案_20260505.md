# 本职工作系统业务能力骨架影子预案

生成日期：2026-05-05

预案性质：影子预案，只做结构设计、证据要求和低风险施工清单；不读取真实涉密资料，不生成正式文档，不写正式业务库，不触发 n8n，不发送企业微信，不修改总管口径。

## 一、总边界

1. 只允许写入本模块影子产物、草稿产物、验收产物或文档。
2. 正式成文前必须人工确认事实依据、引用来源、收件范围和输出版本。
3. 企业微信、n8n、统一消息出口均保持禁用态，除非后续有单独人工确认、总管闸口、执行窗口和许可令。
4. 不读取真实涉密资料；如需真实资料，只能先登记资料索引和脱敏样例要求。
5. 不覆盖正式文档，不自动上传，不跳过人工确认。
6. 继承股票自动交易屏蔽硬闸门：任何股票相关意图只允许研究分析，不允许券商接口、下单、撤单、自动交易、交易委托、明确买卖建议、仓位建议、目标价。

## 二、能力骨架

| 能力层 | 影子能力 | 输入 | 输出 | 当前准入 |
| --- | --- | --- | --- | --- |
| A1 任务入口 | 办公材料任务登记 | 材料类型、主题、用途、期限、人工确认人 | 任务计划影子记录 | 可设计，不接企业微信真实入口 |
| A2 模板匹配 | 按材料类型匹配章节骨架 | 材料类型、场景、现有模板 | 草稿框架 | 可扩展为影子模板库 |
| A3 事实证据卡 | 登记事实依据、来源、时间、责任人 | 人工提供的非涉密摘要或脱敏索引 | 证据卡影子清单 | 可设计，不读取真实资料 |
| A4 草稿生成 | 生成本地草稿框架或草稿片段 | 任务计划、模板、证据卡 | 本地草稿 | 仅 dry-run，不生成正式文档 |
| A5 风险审查 | 检查事实缺失、涉密风险、外发风险 | 草稿与证据卡 | 风险清单 | 可只读检查 |
| A6 人工确认 | 形成确认单 | 草稿、证据卡、风险清单 | 人工确认单 | 可影子预案，不替代审批 |
| A7 状态摘要 | 汇总材料链路状态 | 门禁、预检、草稿、确认单 | 状态摘要 | 已有基础能力 |
| A8 外部联动 | 企业微信/n8n/统一消息出口 | 人工许可、总管闸口、窗口、许可令 | 正式外发或工作流动作 | 当前不准入 |

## 三、可追溯证据要求

每一份草稿或影子材料至少需要以下证据字段：

| 字段 | 要求 | 阻断条件 |
| --- | --- | --- |
| `材料编号` | 唯一编号，建议包含日期、材料类型、序号 | 缺失则不得进入人工确认 |
| `材料类型` | 汇报、方案、总结、纪要、通知、台账之一，或新增类型影子登记 | 未登记类型不得生成正式草稿 |
| `用途场景` | 说明用于内部参考、会议讨论、汇报准备等 | 用途为正式外发时必须 STOP |
| `事实依据摘要` | 人工提供或脱敏后的事实点列表 | 无事实依据不得输出结论性表述 |
| `来源路径或来源说明` | 可是本地脱敏索引、人工备注、公开材料链接摘要 | 来源不明不得标注为事实 |
| `资料敏感级别` | 非涉密、内部、敏感、涉密候选 | 敏感或涉密候选不得自动读取 |
| `引用时间` | 证据形成或采集时间 | 时间缺失时需标记“待复核” |
| `人工确认人` | 负责确认事实、口径、发布范围的人 | 缺失不得进入正式成文 |
| `风险提示` | 事实缺口、口径不确定、涉密风险、外发风险 | 高风险未处理不得进入下一步 |
| `输出级别` | 影子、草稿、人工确认、正式 | 当前只允许影子和草稿 |

## 六、准入和 STOP 条件

准入条件：

1. 只写本模块。
2. 只做影子数据、草稿、报告、验收。
3. 不触发外部链路。
4. 有可回滚的新增文件清单。
5. 通过本模块安全边界检查。

立即 STOP 条件：

1. 需要读取真实涉密资料。
2. 需要覆盖正式文档。
3. 需要企业微信真实发送。
4. 需要触发 n8n。
5. 需要写正式业务库。
6. 需要改总管口径或放行最终闸口。
7. 出现股票交易、券商接口、下单、自动交易、交易建议、仓位建议、目标价等意图。

## 七、影子验收口径

影子施工完成后，验收报告必须至少回答：

1. 新增文件是否全部在 `D:\杰哥智能化系统\02杰哥扩展系统\03本职工作系统` 内。
2. 是否未修改既有配置、脚本、正式数据和总管文件。
3. 是否未运行企业微信、n8n、外部联网、正式库写入、正式文档输出。
4. 是否保留本地生成门禁、正式输出禁用态、R03 dry-run 冻结状态。
5. 是否继承股票自动交易屏蔽硬闸门。
6. 是否有清晰的人工确认和证据追溯要求。

## 八、预案结论

本职工作系统下一步适合走“影子骨架优先”：先补模板索引、证据卡、人工确认单和只读验收规则，再决定是否改脚本。当前不具备正式外发、正式成文、真实资料读取、n8n 触发或企业微信真实发送条件。
