# 本职工作证据卡模板说明

- 生成日期：2026-05-05
- 任务编号：第三批小任务H
- 执行模式：shadow_only
- 适用范围：02杰哥扩展系统/03本职工作系统

## 证据卡必填字段

| 字段 | 说明 | 降级要求 |
| --- | --- | --- |
| 事项 | 待处理或已处理的本职工作事项名称 | 事项不清时只登记为线索 |
| 来源 | 事项依据的来源渠道或本地引用路径 | 来源不明时不得形成确定结论 |
| 可信度等级 | 按公共组件识别的来源等级，如S1-S6或待判定 | 未识别时列为待复核，不得直接形成正式材料 |
| 来源类型 | 官方、学术、主流媒体、商业门户、本地材料等来源类别 | 类别不明时只登记为线索 |
| 来源用途边界 | 当前来源在本职工作场景中只能支撑事实、背景、线索还是正式依据候选 | 用途边界不清时不得扩大使用 |
| 是否需要反向追溯 | 是否必须追到原始文件、正式通知、会议纪要或人工登记材料 | 需要追溯但未完成时只能进入待复核 |
| 是否可作正式依据候选 | 当前来源是否具备进入正式材料依据链的候选资格 | 否或不明时只能作背景、线索或待复核材料 |
| 责任人 | 当前责任人或复核人 | 无人确认时填待确认 |
| 时间 | 事项发生、接收或记录时间 | 时间缺失时列入待复核 |
| 附件路径 | 支撑附件的本地绝对路径列表 | 为空时必须降级为待复核线索 |
| 结论 | 基于证据可得出的结论 | 证据不足时只能输出降级结论 |
| 待复核 | 仍需人工确认的字段或风险 | 不得留空 |

## 离线样本

1. 本职事项证据卡：字段齐全，附件路径指向本地门禁证据，只允许进入人工复核。
2. 缺附件降级：附件路径为空，结论降级为待复核线索，不得生成正式材料。

## 公共来源判断接入

本系统复用 `D:/杰哥智能化系统/02杰哥扩展系统/00公共组件/01配置/信息来源可信度分层规则.json` 与 `D:/杰哥智能化系统/02杰哥扩展系统/00公共组件/02脚本/信息来源智能鉴别器.py`。本职工作场景中，S1来源可作为正式依据候选，但仍需结合内部流程、附件原件、责任人和时间确认；S3-S5来源可作为事实背景、公开报道、线索或材料补充，不得替代正式通知、制度原文或人工确认材料。

## 安全边界

- 不生成正式办公材料。
- 不写正式库、旧系统、数据库或向量库。
- 不发送企业微信真实消息。
- 不触发 response_url、Webhook 或 n8n。
- 不调用券商接口，不自动交易，不下单。
