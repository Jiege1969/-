# 本职工作系统设计

创建日期：2026-04-26

## 一、定位

本职工作系统服务用户日常工作。

它应基于知识库、模型路由和工作流，帮助处理资料、计划、总结、报告和流程。

## 二、第一阶段能力

1. 工作资料问答。
2. 文档摘要。
3. 报告草稿。
4. 工作计划。
5. 复盘总结。

## 三、第二阶段能力

1. 固定格式报告生成。
2. 周报月报。
3. 工作流程提醒。
4. 常用材料模板。
5. 与企业微信指令联动。

## 四、依赖

| 能力 | 来源 |
|---|---|
| 知识库 | 01主系统 |
| 模型路由 | 01主系统 |
| 工作流 | 01主系统 n8n |
| 推送 | 01主系统统一消息出口 |

## 五、边界

本模块不保存通用知识库底座，只保存本职工作相关配置和资料索引。
