# 01股票研究系统

## 定位

本模块负责股票研究相关业务。

股票研究是 v3 的业务模块之一，不是主系统本体。

## 规划能力

1. 单股分析。
2. 批量筛选。
3. 技术指标。
4. 行业和概念强度。
5. 新闻和研报摘要。
6. 图片报告。
7. 企业微信推送。

## 依赖

1. 模型服务由 `01杰哥智能系统` 提供。
2. 消息出口由 `01杰哥智能系统` 提供。
3. 定时任务由 `01杰哥智能系统` 的 n8n 提供。

## 公共来源可信度机制

股票系统复用 `D:/杰哥智能化系统/02杰哥扩展系统/00公共组件/01配置/信息来源可信度分层规则.json` 与 `D:/杰哥智能化系统/02杰哥扩展系统/00公共组件/02脚本/信息来源智能鉴别器.py`。同一来源先按公共规则识别可信度，再按股票场景限定用途：交易所、监管机构、法定披露平台和上市公司公告优先作为正式证据候选；主流媒体、网易、新浪、东方财富等可作为行情、事件、舆情或转载线索，但不能替代公告、财报和监管披露。

所有前台结论仍只作研究参考，不构成买卖建议，不连接券商接口，不自动交易。
