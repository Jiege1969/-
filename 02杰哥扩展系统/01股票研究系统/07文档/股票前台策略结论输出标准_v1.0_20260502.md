# 股票前台策略结论输出标准 v1.0

版本：v1.0  
日期：2026-05-02  
适用范围：股票助手企业微信回复、单股查询、持仓诊断、每日推荐摘要。  

## 一、核心原则

股票系统采用“后台深度分析，前台策略结论”的呈现方式。

后台可以保留复杂计算、技术指标、财务指标、行业强度、复盘账、学习账本等材料；前台面向使用者时，只呈现能直接理解和使用的判断：当前判断、建议策略、参考位置、风险观察线、主要风险、下一步。

前台不再默认堆叠 MACD、RSI、均线明细、财务字段清单。详细数据保留在标准报告和后台账本中，供点击查看、复盘学习和规则优化使用。

## 二、前台固定判断词

- 重点推荐
- 常规推荐
- 观察等待
- 继续持仓观察
- 降低关注
- 离场观望
- 风险复核

说明：这些词是研究辅助结论，不代表自动交易指令。系统不连接券商接口，不自动下单。

## 三、每日推荐输出

每日输出必须区分三类：

- 推荐股票：条件达标，可以重点参考。
- 观察股票：方向值得看，但条件不足。
- 暂不关注：信号弱或风险高，不在前台重点展示。

### 有达标推荐时

模板：

```text
杰哥，您好！根据系统分析，今日推荐以下 X 只股票供您重点参考：

1. 股票名称(代码)：重点推荐/常规推荐
建议策略：一句话说明为什么值得看。
参考位置：等待趋势、行业强度和资金活跃度继续配合；若信号转弱则降为观察。
主要风险：一句话说明主要缺口或风险。

可观察股票：
1. 股票名称(代码)：观察等待。方向值得看，但当前条件尚未完全达到推荐标准。

【温馨提醒】：点击股票名称查看详细报告
```

### 无达标推荐时

模板：

```text
杰哥，您好！根据系统分析，今日暂未发现完全符合推荐条件的股票。

当前更适合观察的方向：行业A、行业B、行业C。

可观察股票：
1. 股票名称(代码)：观察等待。短线活跃，但中期趋势仍需确认。
2. 股票名称(代码)：观察等待。行业强度较好，但资金持续性仍需确认。

建议：今日以观察为主，等待评分、行业强度和资金活跃度同时改善后，再进入推荐名单。

【温馨提醒】：点击股票名称查看详细报告
```

## 四、单股查询输出

用户问“分析某股票”时，前台第一屏不先讲公司介绍，也不先讲技术指标。

### 4.1 企业微信短答模板

用户在企业微信问单股时，系统必须替用户把后台分析翻译成“可观察、可复核、可执行”的条件，不能把“承接、放量、证据补齐”等半成品词抛给用户。

标准模板：

```text
股票名称(代码)
当前判断：重点推荐/常规推荐/观察等待/风险复核 ⭐⭐⭐⭐⭐；强度：X/5
现价：XX.XX元

操作策略：不追高；只看承接区或转强线是否达标。

关注条件：价格回到XX.XX元-XX.XX元后不跌破XX.XX元；收盘或当前价重新站上XX.XX元，视为承接成立。

转强条件：当天收盘价或当前实时价高于XX.XX元；更稳妥看连续2个交易日收盘价都高于XX.XX元，同时近5日成交活跃度达到平时的1.10倍以上。

成交标准：成交活跃就是近5日成交活跃度达到平时的1.10倍以上；明显活跃就是达到平时的1.30倍以上。当前X.XX倍，达到/未达到活跃标准。

风险线：跌破XX.XX元，或跌回XX.XX元下方且量比5日低于1.10，转为谨慎观察。

结论：只等两个信号：一是承接区XX.XX元-XX.XX元按标准成立；二是站上XX.XX元且量比5日达标。

补充核验：系统会继续核验公告、财报和行业信息；当前前台先按价格和成交量条件执行观察。

图文详情：http://43.167.210.211/wecom-bot/message?ask=分析股票名
```

量化参数以 `01配置/股票前台输出标准_v2.json` 中 `单股短答模板.量化标准` 为准：

- 承接区上沿比例：承接价 × 1.01
- 成交活跃：量比5日 ≥ 1.10
- 明显活跃：量比5日 ≥ 1.30

禁止话术：

- `按观察线跟踪`
- `回落承接`
- `有承接`
- `成交量保持活跃`
- `重点看承接和放量`
- `证据仍需补齐`
- `承接和成交量持续性`
- `聊天先给结论`
- `详细证据保留在后台图文报告`
- `最终由你人工判断`

### 4.2 详情页模板

```text
股票名称(代码)
当前判断：观察等待/常规推荐/风险复核。

建议策略：短线有什么变化，中期是否确认，适合重点研究还是等待。

参考位置：若回落到 XX 元附近企稳，且量能不明显萎缩，可提高关注；若站稳 XX 元附近，则继续观察强度。

风险观察线：若跌破 XX 元，建议转为离场观望。

主要风险：行业周期、利润波动、公告财报或资金持续性等。

结论：一句话收束。

【温馨提醒】：点击股票名称查看详细报告
```

## 五、持仓诊断输出

用户问“我持有/持仓某股票还能不能拿”时，前台按持仓诊断模板回复。

模板：

```text
股票名称(代码) 持仓诊断
当前判断：继续持仓观察/降低关注/离场观望。

理由一句话：趋势、资金、行业和风险线的综合判断。

持仓策略：若价格维持在 XX 元上方，可继续按量化价格线观察；若站稳 XX 元且近5日成交活跃度达到平时的1.10倍以上，可提高研究优先级。

离场观察线：若有效跌破 XX 元，建议转为离场观望。

后续条件：重新站上关键均线并保持资金活跃，可恢复积极关注；若观察线跌破且行业转弱，风险扩大。

结论：一句话收束。

【温馨提醒】：点击股票名称查看详细报告
```

## 八、2026-05-04 融合升级补充规则

本补充规则用于把原报告的完整骨架和新讨论形成的前台结论标准合并使用。

原则不是推翻原报告，而是取长补短：

- 原报告的公司、行业、财务、资金、风险、后续跟踪结构继续保留，作为后台完整分析层和详情页材料。
- 原报告中的留白不再直接展示给用户，而是转成数据抓取任务、待核验项或可信度降级原因。
- 技术分析继续在后台计算，前台只输出能被复盘的条件。
- 企业微信只发结论短文，但关键价格、天数、成交额阈值必须写清楚。

### 8.1 微信短文固定为 6+1 段式

```text
【股票名称】一句话结论。

逻辑：行业逻辑 + 公司卡位 + 当前主要矛盾。

财务：用最少数字说明财务支持/部分支持/不支持。

观察条件：观察区间 + N个交易日内至少M天收盘条件 + 成交额阈值实际金额。

转强条件：连续N天收盘站上转强线 + 成交额阈值实际金额。

失败条件：风险线 + 跌破观察区后的修复期限 + 降级处理。

风险：最大风险和不适合的配置方式。
```

### 8.2 所有模糊词必须改写为可验证条件

| 模糊词 | 必须改写成 |
|---|---|
| 稳住 | 未来N个交易日内至少M个交易日收盘不低于某价 |
| 有承接 | 价格条件 + 成交额阈值 + 风险线未跌破 |
| 放量 | 成交额高于截至昨日近N日均额的具体倍数和具体金额 |
| 转强 | 连续N个交易日收盘站上转强线，且成交额满足阈值 |
| 继续观察 | 观察什么、观察几天、什么条件升级或降级 |

成交额基准统一为：

```text
截至昨日、不含当天的近5个交易日平均成交额。
```

示例：

```text
观察条件：138-139元区域，未来3个交易日内至少2天收于138元以上；
若出现下跌日，当日成交额不得超过截至昨日近5日均额的1.2倍。
当前近5日均额：XX亿元，1.2倍阈值：XX亿元。
```

### 8.3 数据缺失时必须降级

以下字段缺失时，微信短文不得输出强结论：

- 近三年营收、净利润及增速。
- 最新季度营收和净利润。
- 毛利率、净利率、ROE。
- 经营现金流净额。
- PE、PB或行业估值对比。
- 当前价、观察区、风险线、转强线。
- 截至昨日近5日平均成交额和阈值金额。

处理方式：

```text
关键数据缺失，结论可信度降级；仅可输出“观察草稿”或“暂不关注”，不得写“重点推荐”。
```

### 8.4 华虹公司短文样例

本样例只作为格式样例，正式生成时必须使用系统最新抓取数据。

```text
【华虹公司】可观察，不追高。

逻辑：公司是特色晶圆代工企业，具备8英寸+12英寸产线和功率器件卡位，受益半导体国产化和行业复苏；但当前利润弹性弱，估值已经偏高。

财务：2025年营收172.91亿元，归母净利3.77亿元，净利率约2.18%，ROE约0.85%。收入改善，但盈利效率偏低，暂不支持重仓价值配置。

观察条件：138-139元区域，未来3个交易日内至少2天收于138元以上；若出现下跌日，当日成交额不得超过截至昨日近5日均额的1.2倍。当前近5日均额：XX亿元，1.2倍阈值：XX亿元。

转强条件：连续2天收于152.28元以上，且单日成交额不低于截至昨日近5日均额XX亿元。

失败条件：收盘跌破132.54元；或跌破138元后2个交易日内不能重新收回138元，本轮观察失败。

风险：PE超600倍，盈利能力尚未匹配估值，只适合观察，不适合重仓长期配置。
```
- 不把后台未核验信息说成已确认事实。
- 有缺失数据时必须用“待核验”“待接入”“需继续观察”等词说明。
