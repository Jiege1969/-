# 股票通用分析判断机制 v1.0

生成时间：2026-05-10

## 一、定位

这套机制是股票系统所有分析判断的上位规则。它不只服务【杰哥推荐】，也服务单股问答、行业判断、L3评分、企业微信前台短答、本地图文报告和后续复盘。

核心思想很简单：方法不在多，在精；指标不按数量投票，而按场景、主次和证据层级发挥作用。

## 二、总原则

1. 先判断问题类型和市场环境，再选择分析方法。
2. 指标必须说明自己擅长什么、不擅长什么、适合什么环境。
3. 主指标决定结论方向，辅助指标只负责确认、解释和提示边界。
4. 风险闸门可以否决结论，辅助指标不能越级推荐。
5. 牛市、熊市、震荡市下，同一指标的权重可以不同。
6. 前台只投影结论、观察条件、风险边界和证据完整度。
7. 全系统只输出研究判断，不输出买卖、下单、仓位、收益承诺。

## 三、证据法阶

| 层级 | 名称 | 作用 |
|---|---|---|
| 宪法层 | 安全边界与硬门槛 | 决定能不能给高优先级结论 |
| 法律层 | 主分析方法 | 决定本次分析的主方向 |
| 规章层 | 辅助指标与解释证据 | 确认、解释、降权、提示缺口 |
| 案例层 | 复盘学习与人工反馈 | 修正阈值和权重，但不自动改正式规则 |

法阶关系必须固定：低层证据不能推翻高层门槛。比如短期放量、题材热度、指标共振，都不能推翻失败对照、数据缺口、行业高拥挤或安全边界。

## 四、通用分析顺序

1. 对象解析：明确股票、行业、问题类型和输出场景。
2. 数据抓取：先读本地正式产物，再读影子产物，必要时只读补证。
3. 环境识别：判断市场强弱、行业顺逆风、拥挤度和风险状态。
4. 方法选型：按问题类型选择主方法，而不是机械套全部指标。
5. 智能选择：调用 `股票指标智能选择与方法切换规则_v1.0.json`，按客观环境匹配指标能力画像和方法组合。
6. 主辅分配：把指标分为主指标、辅助指标、降权指标、否决指标。
7. 证据排序：按宪法层、法律层、规章层、案例层形成判断。
8. 结论生成：输出研究分层、置信度、观察条件和风险边界。
9. 前台投影：把后台证据链压缩成用户能读懂的短答。
10. 复盘学习：按周期回填表现、偏差、失效原因和人工反馈。

## 五、市场环境改变指标主次

### 强势市或牛市

主指标：趋势资格、相对强度排名、行业龙头、失败对照距离。

风险闸门：行业拥挤度、短期过热、失败样本相似度、横截面排名不靠前。

平衡规则：满足条件股票会变多，所以不能机械放大推荐榜；必须提高重点门槛，只保留方法分和横截面分位同时靠前的对象。

### 震荡市或中性市

主指标：强势结构、回踩不破、趋势资格、行业动态强度、失败对照距离。

辅助指标：VCP波动收缩、周线确认、量能持续性。

平衡规则：重点看个股是否独立强于市场和行业，避免只追普涨带来的假强势。

### 弱势市或熊市

主指标：风险闸门、流动性、趋势硬门槛、相对抗跌。

辅助指标：反弹量能、短期形态、事件催化。

平衡规则：不强行凑名单，多数对象只能进入观察或暂缓；重点候选必须更稀缺。

### 事件驱动

主指标：事件事实、影响路径、兑现程度、风险反证。

辅助指标：价格确认、成交活跃、行业扩散。

平衡规则：先确认事件真实性和影响路径，再看技术确认；不能只凭题材热度给强结论。

### 长期研究

主指标：基本面质量、产业趋势、竞争位置、现金流、估值边界。

辅助指标：技术位置、资金活跃、短期情绪。

平衡规则：长期研究不因短期走势好就升级，技术指标只负责时点和风险提示。

## 六、指标角色

| 指标组 | 擅长 | 默认角色 |
|---|---|---|
| 趋势与均线 | 识别中长期趋势阶段 | 主指标或核心门槛 |
| 量能与换手 | 确认突破、承接、拥挤 | 确认指标或风险闸门 |
| 行业与市场宽度 | 识别板块共振和市场环境 | 环境主指标 |
| 失败对照 | 识别高分失败形态 | 核心刹车 |
| 基本面与财务 | 判断长期质量和证据完整度 | 主指标或证据缺口 |
| 估值 | 判断长期回报边界和透支风险 | 辅助指标或风险闸门 |
| 事件与政策 | 解释催化和预期变化 | 场景主指标或待核验证据 |

## 七、输出要求

后台每一次完整分析都应保存这些字段：分析对象、问题类型、市场环境、对象阶段、本次主分析方法、本次主指标、本次辅助指标、本次降权或否决指标、证据法阶、研究结论、置信度、证据缺口、观察条件、风险边界、复盘任务。

前台可以压缩，但不能丢掉三件事：结论、为什么、风险边界。

## 八、学习机制

系统要长期记录：哪些主指标有效，哪些辅助指标误导，哪些市场环境下权重应该改变。复盘对象包括重点研究对象、观察验证对象、高分但被刹车对象、前台判断偏离对象和人工反馈对象。

复盘只生成修正建议，不自动改正式规则。连续证明有效的规则，必须经总管确认后升级。
