# 环境自适应三级漏斗推荐引擎 v1.0

生成时间：2026-05-10

## 定位

本引擎是影子推荐能力，不替换正式前台。它把现有的行业归因、杰哥推荐分析方法v1、失败对照、风险刹车和指标智能选择结果，统一汇总为一张推荐列表。

目标不是生成长篇分析报告，而是输出：

- 当前市场状态和状态概率
- 当前判断线权重
- 优先行业、结构活跃行业、暂缓行业
- 重点关注个股
- 观察验证个股
- 暂缓个股
- 切换原因和复盘任务

## 总流程

```text
数据可信层
  -> 环境状态识别
  -> 判断线权重调度
  -> 市场环境漏斗
  -> 行业筛选漏斗
  -> 行业内个股筛选漏斗
  -> 个股独立强度校验
  -> 风险结论上限
  -> 推荐列表输出
```

## 三层漏斗

第一层：市场环境  
只决定宽严、风险预算、重点候选数量上限，不直接推荐个股。

第二层：行业筛选  
行业层独立评分，筛出顺风行业、结构活跃行业、逆风行业和失败集中行业。

第三层：行业内个股筛选  
在行业内部比较个股，不让行业贝塔掩盖个股量价缺陷。

## 关键原则

1. 不是推翻原系统，而是把原系统放进更高层调度。
2. 行业和个股分开评分。
3. 市场状态用概率和权重平滑，不硬切。
4. 风险不是普通指标，而是结论上限。
5. v1.0 只做规则法和影子运行，复盘稳定后再考虑接前台。
