# 2000只标准大股票池主动研究执行方案

生成日期：2026-04-30

## 一、结论

2000只股票池是股票研究系统的标准大股票池，不是远期可选上限。它的根本作用不是每天给出大量推荐，而是通过足够大的市场样本持续观察、验证、复盘和提炼规律，逐步提升系统分析准确度。

系统必须坚持：2000只做盘后轻扫描，少量候选进入深度分析，最终只把3-5只精选通过企业微信推送给用户。

## 二、核心逻辑

股票研究系统的闭环为：

`2000只标准大股票池 -> 盘后轻扫描 -> 分层评分 -> 5-10只重点关注对象 -> 深度分析 -> 3-5只精选推送 -> 信号账本 -> T+1/T+3/T+5验证 -> 经验提炼 -> 规则优化`

这条链路的重点是“分析准确度持续提升”，不是“每天输出越多越好”。

## 三、分层规模

| 层级 | 规模 | 作用 | 大模型使用 |
|---|---:|---|---|
| 标准大股票池 | 2000只 | 市场观察、规律学习、候选筛选、复盘样本积累 | 不逐只调用 |
| 试运行池 | 300只 | 验证数据源、行业覆盖、批处理稳定性 | 不逐只调用 |
| 核心样本池 | 800-1000只 | 代表性市场样本、规律提炼、候选池输入 | 不逐只调用 |
| 候选研究池 | 20-50只 | 进入研究候选，生成摘要和证据包 | 可少量调用 |
| 深度分析池 | 5-10只 | 盘后重点分析对象 | 可调用 |
| 精选推送池 | 3-5只 | 22:00前企业微信推送 | 可调用 |

## 四、日常时间线

| 时间 | 动作 | 输出 |
|---|---|---|
| 16:00-18:00 | 对2000只标准大股票池做盘后日线级轻扫描 | 行情快照、技术指标、分层评分 |
| 18:00-19:30 | 从扫描结果筛选5-10只重点关注对象 | 候选研究池 |
| 19:30-21:30 | 对候选样本做深度分析 | 研究依据、风险、参考位、星级强度 |
| 22:00前 | 企业微信主动推送3-5只精选 | 按推荐强度从高到低排列 |
| 次日及后续 | T+1/T+3/T+5验证 | 信号成败、偏差原因、经验样本 |

## 五、入池标准

2000只标准大股票池由以下来源组合形成：

1. 沪深主要指数成分，保证市场代表性。
2. 行业龙头与细分龙头，保证产业结构覆盖。
3. 高活跃成交股票，捕捉资金热点。
4. 财务质量较好股票，保留基本面底座。
5. 主题事件异动股票，捕捉阶段性机会。

评分权重沿用 `动态样本池规则.json`：

- 行业代表性：25
- 流动性成交额：20
- 市值与龙头地位：15
- 财务质量：15
- 技术活跃度：10
- 事件题材热度：10
- 历史信号有效性：5

## 六、硬件边界

当前硬件边界：CPU 8核、内存64GB、显存24GB。系统必须遵守：

1. 盘中不扫2000只。
2. 2000只不逐只生成长报告。
3. 2000只不逐只调用大模型。
4. 大模型只处理候选研究池、深度分析池和重点关注池。
5. 每批默认100只，批间暂停，失败降级记录，不阻塞全链路。

## 七、主动推送规则

企业微信主动推送必须克制：

1. 每日精选推送3-5只。
2. 只推强信号、强风险、状态变化和明确研究价值对象。
3. 推送内容按研究信号强度、评分、趋势质量、风险扣分、证据完整度排序。
4. 所有推送必须声明：信息分析，不是收益承诺，不构成强制买卖建议。
5. 严禁自动交易、券商接口、自动下单。

## 八、进化要求

每条推送都必须进入信号账本，记录：

- 触发时间
- 股票代码和名称
- 当时价格
- 评分和星级
- 触发依据
- 风险说明
- 后续T+1/T+3/T+5表现
- 判断是否有效
- 偏差原因

每周提炼一次：

- 哪些指标组合有效
- 哪些是假信号
- 哪些行业或市场环境下规则失效
- 哪些规则需要降权或增强
