# 股票分析报告 v2 融合升级执行标准

版本：v2.1  
日期：2026-05-04  
所属系统：02杰哥扩展系统 / 01股票研究系统  
状态：已纳入后续施工标准

## 一、定位

本标准不是推翻原股票分析报告，而是在原报告优秀骨架上做融合升级。

原报告保留：

- 公司基本概况。
- 行业与宏观分析。
- 财务数据分析。
- 主营业务与核心逻辑。
- 技术与资金分析。
- 风险提示。
- 后续跟踪要点。

升级重点：

- 留白字段转为数据抓取任务、待核验项或可信度降级原因。
- 技术指标退到后台，不在微信端堆指标。
- 前台输出只给结论、依据、观察条件、转强条件、失败条件和风险。
- 所有观察条件必须有价格、天数、成交额阈值和失败处理。
- 每份微信短文都要能进入复盘账，成为可验证样本。

## 二、三层输出机制

### 1. 后台完整分析层

用途：详情页、完整报告、学习教材、复盘账。

必须保留：

- 行业景气判断与来源。
- 公司卡位与主营业务。
- 近三年财务与最新季度财务。
- 毛利率、净利率、ROE、经营现金流。
- PE、PB、行业估值对比或历史分位。
- 当前价、观察区、风险线、转强线。
- 截至昨日近5日平均成交额、20日均额或成交活跃对比。
- 数据缺失项、待核验项和来源状态。

允许保留在后台但不直接推送：

- MACD、RSI、KDJ、均线细节。
- 行业强度计算过程。
- 资金活跃度计算过程。
- 模型审稿记录。
- 判断复盘账、验证结果账、经验候选账。

### 2. 研究判断层

用途：形成系统内部结论和复盘账字段。

固定回答五个问题：

| 问题 | 允许结论 |
|---|---|
| 值不值得关注 | 优先关注 / 可观察 / 暂不关注 / 放弃 |
| 逻辑来自哪里 | 行业 / 公司 / 财务 / 资金 / 技术 / 事件 |
| 财务是否支持逻辑 | 支持 / 部分支持 / 不支持 / 数据不足 |
| 估值是否透支预期 | 合理 / 偏高 / 严重高估 / 数据不足 |
| 什么条件证明对或错 | 成功条件 / 失败条件 / 验证周期 |

研究判断层必须输出：

- 关注级别。
- 核心逻辑。
- 财务支持度。
- 估值状态。
- 结论可信度：高 / 中 / 低。
- 验证周期：T+3 / T+5 / T+20 / 财报后。
- 成功条件。
- 失败条件。
- 数据缺失降级说明。

### 3. 微信输出层

用途：企业微信和手机端第一屏。

固定为 6+1 段式：

```text
【股票名称】一句话结论。

逻辑：行业逻辑 + 公司卡位 + 当前主要矛盾。

财务：最少数字验证财务支持/部分支持/不支持。

观察条件：观察区间 + N个交易日内至少M天收盘条件 + 成交额阈值实际金额。

转强条件：连续N天收盘站上转强线 + 成交额阈值实际金额。

失败条件：风险线 + 跌破观察区后的修复期限 + 降级处理。

风险：最大风险和不适合的配置方式。
```

微信端可以短，但不能省掉关键数字。

## 三、最小数据集

缺少以下任一关键字段时，报告不得输出强推荐结论：

| 类别 | 字段 |
|---|---|
| 行业 | 行业景气判断、行业判断来源 |
| 财务 | 近三年营收、净利润及增速 |
| 财务 | 最新季度营收、净利润 |
| 财务 | 毛利率、净利率、ROE |
| 财务 | 经营现金流净额 |
| 估值 | PE、PB、行业均值或历史分位 |
| 市场 | 当前价、观察区、风险线、转强线 |
| 成交 | 截至昨日近5日平均成交额、观察阈值、转强阈值 |

降级规则：

- 财务核心数据缺失：结论可信度降为低，关注级别不得高于可观察。
- 最新季度缺失：必须写“最新季度待核验”，不得写盈利趋势已经确认。
- 估值对比缺失：不得写估值合理。
- 成交额阈值缺失：不得写放量、资金配合、有承接。
- 行业来源缺失：行业景气只能写待核验。
- 利润下滑原因缺失：必须写“利润下滑主因待核验”。

## 四、量化条件统一语法

### 1. 时间窗口

统一格式：

```text
未来N个交易日内至少M个交易日满足条件。
连续N个交易日满足条件。
```

### 2. 成交额基准

统一定义：

```text
截至昨日、不含当天的近5个交易日平均成交额。
```

不得使用含当天的均额作为当天阈值，避免循环定义。

### 3. 观察成立

标准格式：

```text
观察区间为A-B元。未来3个交易日内至少2个交易日收盘价不低于A元；
若出现下跌日，当日成交额不得超过截至昨日近5日均额的1.2倍。
当前近5日均额为X亿元，1.2倍阈值为Y亿元。
```

### 4. 转强确认

标准格式：

```text
连续2个交易日收盘价高于转强线C元；
且单日成交额不低于截至昨日近5日均额X亿元。
```

### 5. 失败条件

标准格式：

```text
收盘跌破风险线D元，本轮观察失败；
或收盘跌破观察区下沿A元后，未来2个交易日内不能重新收回A元，观察等级下调。
```

### 6. 弱势震荡

可选补充：

```text
若观察区承接后5个交易日内仍不能站上中间验证位E元，降低观察优先级。
```

中间验证位可由系统按观察区上沿和转强线之间的中位数生成。

## 五、模糊表达禁用

以下词不能单独出现：

- 稳住。
- 有承接。
- 放量。
- 转强。
- 资金配合。
- 继续观察。
- 风险加大。
- 估值较高但可以关注。

替代规则：

| 模糊词 | 替代表达 |
|---|---|
| 稳住 | N日M次收盘不破某价 |
| 有承接 | 价格条件 + 成交额阈值 + 风险线未跌破 |
| 放量 | 成交额高于截至昨日近N日均额的具体倍数和金额 |
| 转强 | 连续N日收盘站上某价，且成交额满足阈值 |
| 继续观察 | 观察什么、几天内验证、什么结果升级或降级 |

## 六、华虹公司样例

本样例只作为表达格式样例，正式生成时必须使用系统最新抓取数据。

```text
【华虹公司】可观察，不追高。

逻辑：公司是特色晶圆代工企业，具备8英寸+12英寸产线和功率器件卡位，受益半导体国产化和行业复苏；但当前利润弹性弱，估值已经偏高。

财务：2025年营收172.91亿元，归母净利3.77亿元，净利率约2.18%，ROE约0.85%。收入改善，但盈利效率偏低，暂不支持重仓价值配置。

观察条件：138-139元区域，未来3个交易日内至少2天收于138元以上；若出现下跌日，当日成交额不得超过截至昨日近5日均额的1.2倍。当前近5日均额：XX亿元，1.2倍阈值：XX亿元。

转强条件：连续2天收于152.28元以上，且单日成交额不低于截至昨日近5日均额XX亿元。

失败条件：收盘跌破132.54元；或跌破138元后2个交易日内不能重新收回138元，本轮观察失败。

风险：PE超600倍，盈利能力尚未匹配估值，只适合观察，不适合重仓长期配置。
```

## 七、复盘闭环接入

每一条微信短文都必须能转成复盘记录：

- 原始结论。
- 判断主因。
- 财务支持度。
- 估值状态。
- 观察条件。
- 转强条件。
- 失败条件。
- 验证周期。
- 证据完整度。
- 用户反馈。
- 后续验证结果。

验证结果不得由系统自动确认，必须进入待人工确认或复盘确认流程。

## 八、安全边界

- 本标准只用于股票研究分析。
- 不连接券商接口。
- 不自动交易。
- 不输出自动买入、自动卖出、下单、撤单、调仓指令。
- 不承诺收益。
- 不把“可观察”写成“必须操作”。

## 九、实施顺序

1. 先作为规则和模板纳入配置、文档、验收。
2. 再选择华虹公司或历史样本做影子样板。
3. 再改微信短文生成器。
4. 再接入详情页。
5. 最后接入推荐列表和复盘账自动字段。
