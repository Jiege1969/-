# 股票指标智能选择与方法切换规则 v1.0

生成时间：2026-05-10

## 一、要解决的问题

指标多不是问题，方法多也不是问题。真正的问题是：当前客观环境下，谁有主要解释权，谁只能辅助，谁必须降权，谁能直接否决。

因此系统要做的不是堆指标，而是智能选择、及时切换、保留解释、事后复盘。

## 二、核心原则

1. 客观情况决定使用什么分析方法。
2. 每类指标都有天生局限，局限也意味着它的优点和缺点都很突出。
3. 主导指标决定结论方向，辅助指标负责确认和解释。
4. 市场环境、行业状态、股票阶段、问题类型变化时，主辅指标也要变化。
5. 切换要及时，但不能频繁摇摆。
6. 风险闸门不参与平均分，直接决定结论上限。
7. 分析不是单一方法组合，必须由市场、行业、个股、趋势、量价、风险多条判断线并行完成。
8. 最终落脚点是行业以及行业中值得关注的个股，不是市场状态本身。

## 三、理论底座

这套机制借鉴六类思想：

| 来源 | 借鉴点 | 系统落地 |
|---|---|---|
| 统筹优化/运筹学 | 多目标约束决策 | 先过硬约束，再做指标排序 |
| 多准则决策MCDA | 指标能力画像和适配度 | 按问题、市场、阶段、数据质量、失效风险打分 |
| 市场状态切换 | 市场状态不同，权重不同 | 强势、震荡、弱势、事件、长期研究分别选方法 |
| 控制论 | 及时响应但防止摇摆 | 滞后确认、阈值差、冷却期、P0紧急通道 |
| 统计学习/时间序列验证 | 防过拟合、防未来函数 | 走步复盘，按当时已知数据验证 |
| 实战经验 | 指标优缺点都突出 | 每个指标组写明擅长、局限、失效环境 |

## 四、七层技术核心架构

| 层级 | 名称 | 职责 | 输出 |
|---|---|---|---|
| 第1层 | 数据可信层 | 检查数据存在、新鲜度、样本量和偏差 | 数据质量分、证据缺口 |
| 第2层 | 客观环境层 | 识别市场、行业、股票阶段和事件状态 | 市场状态、行业状态、股票阶段 |
| 第3层 | 指标能力层 | 匹配指标擅长、局限和失效风险 | 指标适配分、失效风险 |
| 第4层 | 方法组合层 | 选择强趋势、突破、回踩、防守、事件、长期组合 | 当前方法组合、备选组合 |
| 第5层 | 主辅排序层 | 划分主导、辅助、降权、否决指标 | 指标角色 |
| 第6层 | 结论约束层 | 用证据法阶和风险闸门限制结论上限 | 结论上限、置信度 |
| 第7层 | 复盘学习层 | 验证主导指标和方法组合是否有效 | 有效性评分、修正建议 |

## 五、落地结构

```text
市场环境判断
  -> 行业强弱判断
  -> 行业内个股筛选
  -> 个股趋势阶段判断
  -> 量价承接判断
  -> 风险刹车判断
  -> 行业及行业中值得关注个股
  -> 前台结论投影
  -> 复盘学习修正
```

## 六、多层分析任务矩阵

| 判断线 | 回答问题 | 主导指标 | 输出 |
|---|---|---|---|
| 市场环境判断 | 当前环境偏强、震荡、弱势还是事件扰动 | 市场宽度、指数趋势、候选强弱分布、成交活跃度 | 市场状态、方法宽严、候选数量上限 |
| 行业强弱判断 | 哪些行业顺风、逆风、高拥挤 | 行业动态强度、强势过度代表、失败过度代表、行业内强势占比 | 顺风行业、结构活跃行业、逆风行业 |
| 行业内个股筛选 | 行业内哪些个股真正强 | 强势相似度、失败对照距离、相对行业强度、方法分位 | 行业内重点、观察、暂缓 |
| 个股趋势阶段判断 | 个股处于趋势延续、突破、回踩、过热还是破位 | 趋势与均线、第二阶段模板、周线趋势、250日位置 | 趋势阶段、可信度、观察条件 |
| 量价承接判断 | 上涨是否有成交承接 | 成交额20_60比、量比、成交量波动率、成交额波动率 | 承接状态、量能可信度 |
| 风险刹车判断 | 是否必须限制结论上限 | 失败对照、最大回撤、行业失败集中、数据缺口 | 结论上限、降级原因、复盘任务 |

这张矩阵是本规则的核心。任何单一“当前方法组合”都只能代表某个场景下的默认组合，不能代表完整分析系统。

## 七、数学化定义

```text
状态变量 S = 市场状态 + 行业状态 + 股票阶段 + 事件状态 + 数据质量
决策变量 A = 方法组合 + 主导指标 + 辅助指标 + 降权指标 + 否决指标
目标函数 = 最大化解释力、稳定性、时效性、复盘有效性
硬约束 = 安全边界、数据有效性、失败对照P0、重大风险反证、结论上限
软约束 = 指标冗余、样本数量、行业拥挤、市场状态不稳定、近期误判率
```

这意味着：系统不是问“哪个股票指标满足最多”，而是问“在当前状态S下，选择哪个动作A最合理”。

## 八、指标能力画像

| 指标组 | 擅长 | 局限 | 默认角色 |
|---|---|---|---|
| 趋势与均线 | 趋势方向和强弱阶段 | 滞后，反转初期慢 | 主导或硬门槛 |
| 量能与换手 | 突破确认、承接、拥挤 | 易被一日异动污染 | 确认主导或风险闸门 |
| 相对强度 | 候选池内排序和独立强弱 | 普涨牛市区分度下降 | 排序主导 |
| 行业与市场宽度 | 顺逆风和市场环境 | 高拥挤时变成风险 | 环境主导 |
| 失败对照 | 防止高分假象 | 只能防错，不能证明机会 | 永久核心刹车 |
| 波动与回撤 | 风险、整理、VCP | 低波动不必然安全 | 辅助或风险闸门 |
| 基本面与财务 | 长期质量 | 更新慢、短线解释弱 | 长期主导 |
| 估值 | 回报边界和透支风险 | 题材期短期弱 | 辅助或风险闸门 |
| 事件与政策 | 催化和逻辑变化 | 核验难、易透支 | 场景主导 |

## 九、方法组合

### 强趋势延续组合

主导：趋势与均线、相对强度、失败对照。

辅助：量能与换手、行业与市场宽度、波动与回撤。

适用：市场不是弱势市，股票趋势资格较高，失败对照距离足够。

### 放量突破确认组合

主导：量能与换手、趋势与均线、相对强度。

辅助：行业与市场宽度、波动与回撤。

适用：突破信号出现，量能同步，行业不逆风。

### 回踩不破组合

主导：趋势与均线、波动与回撤、量能与换手。

辅助：行业与市场宽度、相对强度。

适用：前期趋势成立，回撤受控，量能未恶化。

### 弱势防守组合

主导：失败对照、波动与回撤、流动性风险、趋势与均线。

辅助：相对强度、量能与换手。

适用：弱势市、市场宽度弱、风险样本增多。

### 事件驱动核验组合

主导：事件事实、影响路径、风险反证、价格确认。

辅助：量能、行业扩散、趋势位置。

适用：出现政策、公告、产业事件或突发消息。

### 长期质量组合

主导：基本面与财务、产业趋势、估值、风险反证。

辅助：技术位置、资金活跃、行业环境。

适用：长期研究、单股深度、L3评分。

## 十、综合汇总规则

汇总顺序：

1. 市场环境判断决定宽严。
2. 行业强弱判断决定优先研究方向。
3. 行业内个股筛选决定候选对象。
4. 个股趋势阶段判断决定是否具备可研究结构。
5. 量价承接判断决定结构可信度。
6. 风险刹车判断决定结论上限。

排序原则：

1. 先行业后个股：先找顺风或结构活跃行业，再找行业内强个股。
2. 先风险后加分：失败对照和数据缺口先决定上限，再看趋势和量能加分。
3. 先相对后绝对：市场环境不同，绝对分数不直接可比，必须看横截面分位。
4. 先结构后表达：后台完成多线判断后，前台只投影结论。

## 十一、组合质量标准

1. 互补性：组合要覆盖趋势、量能、环境、风险，不允许全是同类指标。
2. 低冗余：高度同源指标合并为指标组，不重复投票。
3. 时效匹配：短线和事件用快指标，长期研究用慢指标。
4. 失效可识别：每个组合必须知道自己在什么环境下容易失效。
5. 可复盘：保留当时环境、指标角色和结论。
6. 可投影：后台复杂，前台仍能压缩成结论、观察条件、风险边界。

## 十二、选择算法

适配分由七部分组成：

```text
适配分 =
问题适配 * 0.25
+ 市场适配 * 0.25
+ 股票阶段适配 * 0.20
+ 数据质量 * 0.15
+ 时效 * 0.10
- 失效风险 * 0.15
- 冗余惩罚 * 0.10
```

系统每次只选1到3组主导指标、2到5组辅助指标。多个同类指标不能重复投票，要先合并成指标组。

## 十三、切换机制

触发条件：

- 市场状态切换。
- 行业顺逆风切换。
- 行业拥挤度显著升高。
- 股票阶段从趋势延续变为破位、过热或回撤扩大。
- 事件事实出现或消失。
- 复盘证明原主导指标连续失效。

确认条件：

- 普通切换需要连续2个观察周期满足条件。
- P0风险、数据缺口、安全边界、失败对照立即生效。
- 强转弱反应要快，弱转强需要更多确认。

防摇摆：

- 新主导指标适配分比旧主导指标高10分以上，才普通切换。
- 切换后至少保留一个观察周期，除非出现P0风险。
- 每次切换必须记录旧方法、新方法和原因。

## 十四、复盘验证

验证原则：

1. 只能用当时已知数据生成结论，禁止未来函数。
2. 按时间顺序走步复盘，不能只看静态全样本。
3. 成功和失败样本都要保留，避免幸存者偏差。
4. 参数和阈值只生成修正建议，不自动改变正式规则。

验证窗口：5日、20日、60日、120日。

评价指标：方向有效率、相对行业超额、最大回撤、趋势保持率、误判类型、主导指标贡献、辅助指标是否误导。

## 十五、还需要系统补充的能力

1. 数据质量评分：数据少、过旧、缺失时自动降权。
2. 冗余控制：同类指标合并，避免重复投票。
3. 结论上限：硬门槛失败时，辅助指标再多也不能升级。
4. 学习闭环：复盘主导指标是否真的有效。
5. 解释输出：后台保留完整选择理由，前台只投影结论。
