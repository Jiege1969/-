# 研究决策复盘闭环蓝图

生成时间：2026-04-30 10:01:48

## 一、核心逻辑

系统推荐、用户判断、市场验证、复盘归因、规则优化、再次推荐。

## 二、四本账

| 账本 | 保存位置 | 作用 |
|---|---|---|
| 系统判断账 | 03数据/10复盘闭环/01系统判断账 | 还原系统当时为什么推荐，便于判断系统逻辑是否有效。 |
| 人工决策账 | 03数据/10复盘闭环/02人工决策账 | 学习用户的判断风格和决策依据。 |
| 结果验证账 | 03数据/10复盘闭环/03结果验证账 | 用市场结果验证系统判断和人工判断。 |
| 经验提炼账 | 03数据/10复盘闭环/04经验提炼账 | 把一次判断沉淀为可复用经验，反哺股票系统和总进化系统。 |

## 三、归因矩阵

- 系统正确用户正确：强化该模式，进入有效经验候选。
- 系统正确用户错误：下次同类场景提高提醒强度，但仍需人工确认。
- 系统错误用户正确：提炼用户判断逻辑，进入规则优化候选。
- 系统错误用户错误：标记为失败样本，查找数据、指标、环境或突发事件原因。

## 四、反馈入口

- 确认L4：股票名称或代码，原因
- 继续观察：股票名称或代码，原因
- 暂不关注：股票名称或代码，原因
- 无价值：股票名称或代码，原因
- 系统看错：股票名称或代码，原因
- 我判断错了：股票名称或代码，原因

## 五、进化边界

允许：
- 生成经验候选
- 生成权重调整建议
- 生成提示词优化建议
- 生成下次提醒策略
- 进入03进化系统待提炼样本

禁止：
- 未经复盘直接修改正式规则
- 单个样本直接改变权重
- 自动升级到L4以上
- 自动买入或卖出
- 绕过人工确认发送交易建议
