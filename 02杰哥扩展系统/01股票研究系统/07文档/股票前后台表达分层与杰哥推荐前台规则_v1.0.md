# 股票前后台表达分层与杰哥推荐前台规则 v1.0

> 层级：子系统规则 / 股票研究系统  
> 状态：当前执行  
> 固化时间：2026-05-10  
> 适用范围：杰哥私人股票分析顾问、杰哥推荐、企业微信股票摘要、单股图文详情页、股票分析报告生成。

## 一、核心原则

后台按标准判断，前台按使用者需要表达。

股票系统可以在后台计算长期成长质量、行业共振、量价结构、资金活跃度、强势样本相似度、失败样本对照、财报质量和证据缺口；但前台不得把后台判断过程机械展开成固定章节。

前台只展示本轮使用者需要看到的结果、关键理由、验证条件和证据边界。

## 二、后台与前台的分工

| 层级 | 作用 | 展示要求 |
|---|---|---|
| 后台分析标准 | 用于评分、过滤、准入、复盘和证据链 | 可以复杂，保留在台账、图文详情、后台报告和复盘材料 |
| 前台摘要 | 用于企业微信首页、杰哥推荐首页 | 必须简洁，只给结果、名单、方向和边界 |
| 单股详情页 | 用于点击股票后的完整图文报告 | 复用新系统股票分析范本，按需展示关键章节 |
| 按需展开 | 用户单独询问长期成长、财报、指标、样本相似度时 | 再展开对应后台依据，不默认全部展示 |

## 三、长期成长质量的定位

长期成长质量主要用于股票池、候选池和持续跟踪资格判断，不是杰哥推荐首页必须展示的内容。

执行规则：

1. 长期成长质量可以作为样本池准入、候选池过滤和杰哥推荐后台加权依据。
2. 长期成长质量不得机械出现在每份前台摘要和每个单股详情页中。
3. 只有当用户明确询问长期成长质量，或长期成长质量是本次结论的关键原因时，才在前台展开。
4. 如果长期成长质量影响推荐结论，前台应转化为自然语言判断，不直接搬运后台框架。

示例：

```text
错误表达：
六、长期成长质量框架
- 雷达结论：长期成长观察
- 技术成熟度：...
- TAM/终局市场：...

正确表达：
该股具备持续跟踪价值，但当前量价条件未满足，暂不进入杰哥推荐。
```

## 四、杰哥推荐首页规则

杰哥推荐首页是推荐摘要和可点击入口，不是分析过程展示页。

固定结构：

```text
【杰哥推荐】
时间：YYYY.MM.DD

【重点关注】X只
1. 股票名称(代码)：星级
   【行业】行业名称

【观察股票】Y只
1. 股票名称(代码)：星级
   【行业】行业名称

【关注方向】
1. 【行业A】上行
2. 【行业B】修复
3. 【行业C】活跃

【证据边界】
未人工核验的信息仍按待核验处理。
本消息为研究摘要，不构成投资建议，不作为买卖指令。
```

首页禁止默认展示：

- 后台指标计算过程。
- 长期成长质量框架。
- 财报详细字段。
- 技术指标明细。
- 强势样本相似度细项。
- 失败样本对照明细。
- “最终由你人工判断”等甩锅式表达。

## 五、单股详情页规则

单股详情页复用新系统股票分析范本，以图文报告形式展示。它可以包含：

- 结论。
- 操作策略或研究策略。
- 关注条件。
- 价格观察。
- 为什么这样判断。
- 风险提醒。
- 证据补充。
- 后续跟踪重点。

单股详情页不要求每次固定展示长期成长质量。是否展示由本次问题和结论需要决定。

如果用户从杰哥推荐首页点击进入，详情页应优先解释：

- 为什么进入重点关注或观察股票。
- 当前还缺什么验证条件。
- 价格、成交、行业和风险线如何观察。
- 哪些信息仍待核验。

## 六、分数、星级和状态

杰哥推荐前台的星级必须服务于当前推荐表达，不得出现“五星但回避”这类自相矛盾的首页口径。

执行规则：

1. 首页只展示进入重点关注或观察股票的标的。
2. 当前状态为回避、风险复核或暂不纳入的股票，不进入杰哥推荐首页。
3. 如果需要展示分数，统一使用 100 分制，并与图文报告评分口径保持一致。
4. 星级是前台显示层，不得替代证据、风险和验证条件。
5. 单股详情页可以说明“长期值得研究但当前不进入杰哥推荐”，但首页不展示这类标的。

## 七、表达纪律

前台表达要像报告，不像算法日志。

允许：

- 行业方向与资金活跃度形成共振。
- 走势结构保持强势。
- 当前量价条件未满足，暂不进入杰哥推荐。
- 继续观察成交活跃度和转强线是否有效。

禁止：

- 把后台字段逐项摊开。
- 因为后台有某项指标就强制写入前台。
- 把股票池准入标准机械写成推荐理由。
- 把长期成长质量默认作为推荐首页栏目。
- 输出买入、加仓、卖出、目标价或保证收益。

## 八、安全边界

本规则只约束股票研究表达，不授权真实发送企业微信，不触发 n8n，不调用券商接口，不自动交易。

所有股票内容均为研究摘要或研究报告，不构成投资建议，不作为买卖指令。
