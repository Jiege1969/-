# 股票研究系统设计

创建日期：2026-04-26

## 一、定位

股票研究系统是 v3 的业务模块之一，负责股票数据采集、分析、筛选、报告和推送。

它不自动下单，不承诺收益，不替用户做最终买卖决定。

## 二、第一阶段能力

1. 复用当前新系统已跑通的单股分析服务设计。
2. 支持实时行情。
3. 支持历史 K 线。
4. 支持技术指标。
5. 支持图片报告。
6. 支持企业微信问答。

## 三、第二阶段能力

1. 股票池。
2. 批量筛选。
3. 行业强度。
4. 新闻和研报摘要。
5. 收盘日报。
6. 候选池分层。

## 三点一、旧草案吸收后的核心逻辑

早期《股票智能系统（草案）》中的方向保留，但按当前 v3 架构重落位：

1. 800只核心样本池采用“沪深300 + 中证500”为第一基底，后续扩展为800-1000只核心样本和2000只盘后代表轻扫描。
2. 保留L1-L8八级分层，但L1-L4属于人工确认层，系统默认只自动推荐到L5深度研究池。
3. 保留行业强度、技术面、资金面、AI候选复核四层漏斗。
4. 保留MA、RSI、MACD、成交量指标作为第一批指标内核。
5. 保留多数据源容错思路，公开只读数据优先，缓存和手工CSV兜底。
6. 保留日报与反馈闭环，但企业微信真实发送继续走统一消息出口和人工确认门禁。
7. 暂不做模型微调和交易接口，先用反馈、回测和规则权重优化实现进化。

## 三点二、研究决策复盘闭环

股票研究系统的进化采用“四本账”：

1. 系统判断账：记录系统为什么推荐。
2. 人工决策账：记录用户确认、否定、修改及理由。
3. 结果验证账：记录T+1、T+3、T+5、T+20后的市场表现。
4. 经验提炼账：归因系统与用户判断的对错，沉淀可复用经验。

这套闭环既用于股票系统自身升级，也作为03进化系统可复用的学习样板。系统可以生成经验候选、权重调整建议和提示词优化建议，但不得直接修改正式规则、自动升级到L4以上或生成交易指令。
