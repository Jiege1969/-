## 字段映射

| 后台字段 | 前台字段 | 是否前台展示 | 规则 |
| --- | --- | --- | --- |
| stock_identity | 第一行对象 | 是 | 前台第一行必须输出股票名称和代码，格式为“股票名称（代码）：结论词”。 |
| total_score + conclusion_threshold | 结论词 | 是 | 前台只展示结论词，不展开完整计分过程；分数留在后台。 |
| item_scores.evidence | 主要依据 | 是 | 从后台证据中选择最多3条最能解释结论的依据，禁止平铺全部指标。 |
| item_scores.missing | 关键缺口 | 是 | 只展示P0/P1缺口，并说明它如何限制结论强度和置信度。 |
| confidence | 置信度表达 | 是 | 前台用高/中/低和一句原因表达，不展示模型内部推理。 |
| next_review_date + review_focus | 复核提醒 | 是 | 前台只说明下一次复核看什么，不给买卖、下单、仓位动作。 |
| raw_indicators | 不直接展示 | 否 | K线、MACD、RSI、量比等原始指标只作为后台证据，不在前台堆叠。 |
| calculation_trace | 不直接展示 | 否 | 评分计算过程留在后台验收，不进入企业微信短答。 |
