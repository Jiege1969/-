# 企业微信单股分析短答：用户视角草案

- 所属系统：股票研究系统
- 资产身份：前台输出草案，不是正式配置，不改企业微信入口
- 目标：用户在企业微信问“某某股票怎么样”时，直接得到结论、观察策略、关键条件和风险提醒；后台分析依据只保留为简短理由。
- 边界：只作研究分析，不构成投资建议，不给买卖指令，不连接券商，不自动交易。

## 一、前台输出原则

用户不是来读后台分析过程的。企业微信短答必须做到：

- 第一行明确分析对象。
- 先给结论，不先讲指标。
- 只说用户下一步该观察什么，不展开后台计算过程。
- 技术指标、政策事件、市场风格、财报缺口只作为“为什么”的简短理由。
- 证据不足时直接降级，不把缺口写成一大段。
- 不使用“放量、承接、转强”等黑话，除非同时给出具体价格和成交标准。
- 不输出买入、卖出、仓位、下单、目标收益。

## 二、标准短答结构

```text
分析对象：股票名称（代码）

结论：暂不建议关注 / 可纳入观察 / 重点关注
一句话：用一句人话说明为什么。

现在怎么处理：
- 当前不追 / 可放入观察池 / 等确认后再提高优先级
- 只看X个信号：价格、成交、风险线

观察条件：
- 价格条件：站上/守住/回到某个明确区间
- 成交条件：成交活跃达到某个明确倍数或金额
- 时间条件：连续N天或未来N个交易日内满足

风险线：
- 跌破某价格，或跌回某区间且成交不足，观察降级

为什么这样判断：
- 技术：一句话
- 基本面/资金：一句话
- 政策/行业：一句话
- 市场环境：一句话

证据缺口：
- 只列1-3个最关键缺口

说明：仅供研究参考，不构成投资建议，不作为买卖指令。
```

## 三、云南锗业示例短答

```text
分析对象：云南锗业（sz002428）

结论：暂不建议关注。
一句话：政策主题有支撑，但价格和成交还没确认转强，财报和行业价格证据也没补齐。

现在怎么处理：
- 当前不追，先放观察池。
- 只看三个信号：能否守住78.79-79.58元、能否站上86.83元、成交能否明显活跃。

观察条件：
- 价格回到78.79-79.58元附近后，不跌破75.58元。
- 若要转强，需站上86.83元；更稳妥看连续2个交易日收在86.83元上方。
- 成交活跃度至少达到近5日平时水平的1.10倍；当前约1.08倍，暂未达标。

风险线：
- 跌破75.58元，本轮观察降级。
- 跌回78.79元下方且成交仍不活跃，也降级观察。

为什么这样判断：
- 技术：当前仍是观察等待，未站上转强线。
- 基本面/资金：市盈率较高，财报关键指标还没结构化接入。
- 政策/行业：锗出口管制对云南锗业有政策支撑，但不能单独构成强结论。
- 市场环境：市场风格数据仍是partial，只能作为低置信参考。

证据缺口：
- 财报关键指标未完整接入。
- 锗价格、公告、解禁减持仍待核验。
- 全市场风格数据还未达到confirmed。

说明：仅供研究参考，不构成投资建议，不作为买卖指令。
```

## 四、前台不应出现的内容

- 大段 MACD、RSI、均线、K线过程。
- 大段政策原文。
- 大段评分公式。
- “建议买入”“建议卖出”“加仓”“减仓”“目标价”。
- “政策利好所以重点关注”这类单因子强结论。
- “承接明显”“放量转强”但不给具体价格和成交标准。

## 五、后台保留但前台压缩的内容

- L3分项评分。
- 政策事件强度、暴露度、衰减因子。
- 市场风格计算过程。
- 财报/资金字段完整性。
- 复盘和证据链。

前台只拿这些内容生成“结论、观察条件、风险线、关键理由、证据缺口”。
