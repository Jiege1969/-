# 02扩展系统 n8n低风险转正式前门禁包

- 生成时间：2026-05-05 14:03 +08:00
- 小任务：并行小任务F
- 范围：企业微信、知识库、内容、视频、税收只读五条扩展线
- 执行边界：只定义门禁，不导入、不启用、不触发任何 n8n workflow
- 当前结论：真实发送、正式库写入、真实媒体转换、税务正式判断继续关闭

## 总门禁

| 门禁项 | 状态 | 说明 |
| --- | --- | --- |
| n8n workflow 导入 | 关闭 | `workflow_import=false`，本包不生成可导入执行件 |
| n8n workflow 启用 | 关闭 | `workflow_enable=false`，不得激活任何 workflow |
| n8n workflow 触发 | 关闭 | `workflow_trigger=false`，不得调用 webhook 或 API |
| 企业微信真实发送 | 关闭 | 白名单仅为候选审查范围，不构成发送许可 |
| 正式库写入 | 关闭 | 知识库、内容库、税务库、向量库均不得写入 |
| 真实媒体转换 | 关闭 | 视频仅允许分镜、素材清单和参数预览 |
| 税务正式判断 | 关闭 | 税收线仅允许只读核验和人工复核清单 |

## 五条业务线门禁

| 业务线 | 白名单口径 | 回滚口径 | 仍禁止动作 |
| --- | --- | --- | --- |
| 企业微信 | 候选企业、候选复核人、预览消息类型；消息上限为 0 | 保持禁用、作废审批、撤销候选白名单 | 真实发送、response_url、群机器人 webhook、正式队列写入 |
| 知识库 | 只读来源引用、引用预览、去重预览 | 废弃影子映射和 receipt，不删除用户资料 | 正式知识库写入、向量库写入、外部检索 API |
| 内容 | dry_run 样例文档、差异预览、策略预览 | 丢弃预览批次，不覆盖、不移动、不删除源文件 | 正式内容库写入、发布、定时发布、真实文档转换 |
| 视频 | 样例素材引用、分镜预览、参数预览 | 作废预览任务，不进入渲染队列，不删除素材 | 转码、剪辑、渲染、字幕封面成品、发布 |
| 税收只读 | 脱敏样例、只读凭证引用、人工复核清单 | 作废复核清单，不改税务凭证和正式库 | 正式税务判断、申报建议、自动申报、税务 API |

## 禁止动作总表

- 禁止导入、启用、激活、触发 n8n workflow。
- 禁止调用 n8n webhook、企业微信 webhook、response_url、外部税务 API、外部渲染服务。
- 禁止读取或写入真实凭据。
- 禁止企业微信真实发送。
- 禁止写正式知识库、正式内容库、正式税务库、向量库或正式消息队列。
- 禁止真实媒体转码、剪辑、渲染、字幕封面成品生成和发布。
- 禁止税务正式判断、申报建议和自动申报。
- 禁止移动、删除、覆盖用户源文件。
