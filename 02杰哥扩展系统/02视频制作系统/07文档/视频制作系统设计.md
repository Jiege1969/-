# 视频制作系统设计

创建日期：2026-04-26

## 一、定位

视频制作系统负责音视频材料处理和视频内容生产辅助。

## 二、第一阶段能力

1. 音频转文字。
2. 视频提取音频。
3. 字幕整理。
4. 视频内容摘要。
5. 口播文案生成。

## 三、第二阶段能力

1. 分镜脚本。
2. 素材标签。
3. 标题和封面文案。
4. 多平台文案适配。
5. 项目归档。

## 四、依赖

| 能力 | 来源 |
|---|---|
| 语音识别 | 当前新系统语音识别服务设计 |
| 文案生成 | 01主系统模型路由 |
| 长任务 | 01主系统任务队列 |
| 素材索引 | 01主系统知识库 |
| 结果推送 | 01主系统统一消息出口 |

## 五、稳定要求

视频转写属于长任务，默认进入后台队列。

不得阻塞企业微信即时响应。
