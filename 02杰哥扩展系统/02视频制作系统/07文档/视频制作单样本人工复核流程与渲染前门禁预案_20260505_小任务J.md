# 视频制作单样本人工复核流程与渲染前门禁预案

- 生成日期：2026-05-05
- 小任务：第四批并行小任务J
- 适用范围：`D:\杰哥智能化系统\02杰哥扩展系统\02视频制作系统`
- 本轮性质：从只读盘点/影子预案推进到单样本人工复核流程预案；不转码、不剪辑、不渲染、不生成字幕、不生成封面、不发布。

## 一、流程目标

本预案只允许把 1 个素材登记样本、1 个脚本分镜样本、1 张人工复核单和 1 个真实渲染阻断样本串成可人工检查的闭环。人工复核只判断字段完整性、引用路径、授权/用途状态和风险提示，不代表真实渲染、发布、外发或正式库写入放行。

## 二、单样本流程

| 阶段 | 输入 | 人工复核字段 | 允许输出 | 禁止动作 |
| --- | --- | --- | --- | --- |
| V1 素材登记 | 人工占位素材描述 | 来源、授权、用途、引用路径 | 素材登记 JSON | 读取、复制、移动、删除真实素材 |
| V2 脚本分镜 | 素材登记样本 | 脚本准确性、分镜完整性、风险提示 | 脚本分镜 JSON | 真实剪辑、转码、渲染、字幕生成 |
| V3 人工复核 | 素材登记与脚本分镜 | 复核人、复核时间、最终复核结论、回滚字段 | 人工复核单 JSON | 自动放行真实渲染或发布 |
| V4 渲染前门禁 | 人工复核单 | 阻断原因、允许替代动作、回滚字段 | 真实渲染阻断 JSON | 调用剪辑软件、渲染器、封面生成器、发布工具 |

## 三、前门禁规则

出现以下任一情况，真实渲染必须保持阻断：

1. 请求真实转码、剪辑、渲染、字幕生成、封面生成或发布。
2. 请求触发 n8n、Webhook、企业微信真实发送、平台发布或外部上传。
3. 请求写正式库、旧系统、数据库、向量库或跨系统业务目录。
4. 请求调用券商接口、行情接口、自动交易或账户操作。
5. 引用路径缺失、授权状态缺失、人工复核字段缺失或回滚字段缺失。
6. 人工复核结论试图直接放行真实渲染、发布或外发。
