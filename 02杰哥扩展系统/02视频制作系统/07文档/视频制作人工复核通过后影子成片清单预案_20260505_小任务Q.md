## 一、预案目标

本预案把“人工复核通过”限定为影子层状态，只允许输出可人工检查的成片清单字段、阻断原因、降级说明和回滚字段。任何复核通过候选都不得自动升级为真实媒体制作、发布、外发或正式库写入。

## 二、影子清单字段

| 字段组 | 必填字段 | 说明 |
| --- | --- | --- |
| 基础字段 | 样本类型、生成日期、小任务、样本编号、场景、引用路径 | 引用路径必须是本地绝对路径 |
| 关联字段 | 关联人工复核单、关联脚本分镜、关联素材登记或关联渲染阻断样本 | 只引用现有文本/JSON样本，不读取或处理真实媒体 |
| 复核字段 | 复核状态、复核人、复核时间、复核说明 | 复核通过只允许进入影子清单 |
| 清单字段 | 影子片名、影子版本、影子输出占位符、清单状态、可交付性 | 输出占位符必须声明不生成真实媒体文件 |
| 禁用字段 | 真实渲染、真实转码、真实剪辑、生成字幕、生成封面、自动发布 | 全部必须为 false |
| 回滚字段 | 可回滚、回滚触发条件、回滚方式、回滚影响、回滚负责人 | 回滚只影响影子预案，不处理真实媒体 |
| 安全字段 | 外部动作禁用、安全边界 | 明确不触发n8n、企业微信、正式库、券商接口、自动交易和本职工作系统 |
