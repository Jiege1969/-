# 视频制作系统影子施工预案

生成日期：2026-05-05

适用范围：`D:\杰哥智能化系统\02杰哥扩展系统\02视频制作系统`

预案性质：影子预案，只描述低风险下一步队列，不执行真实媒体处理，不运行剪辑软件，不触发 n8n，不发送企业微信，不触碰股票自动交易。

## 一、总原则

1. 只允许在视频制作系统目录内新增盘点、预案、验收类文档。
2. 下一步施工前先确认工作区无人正在改同一文件，不回滚、不覆盖他人修改。
3. 所有脚本运行前必须确认是否会写入 `03数据` 或 `04日志`；只读任务不得运行会生成新数据的脚本。
4. 真实媒体、剪辑软件、转码、上传发布、企业微信真实发送、n8n 触发、股票自动交易接入全部保持关闭。

## 三、建议的影子流程

1. 静态盘点：只读目录、配置、脚本、最新 JSON 摘要，不运行任何业务脚本。
2. 能力地图：把现有能力分为计划、候选、匹配、主题化、门禁、禁用态、状态摘要。
3. 风险标记：标出所有 `subprocess.run` 链式调用点和所有 `write_text/mkdir` 写入点。
4. 放行评审：只在人工确认后，才允许运行会写入 `03数据` 或 `04日志` 的脚本。
5. 真实媒体隔离：真实媒体处理必须另开审批，不得混入当前文本预演链路。
6. 发布隔离：发布和通知动作必须保持人工确认，不得由视频制作系统自动发出。

## 四、运行前检查清单

若未来需要运行任何视频制作脚本，先逐项确认：

- 是否仍在 `D:\杰哥智能化系统\02杰哥扩展系统\02视频制作系统` 范围内。
- 是否会写入 `03数据` 或 `04日志`，以及是否允许本次写入。
- 是否会因依赖缺失自动调用其他脚本。
- 是否读取 `04内容处理系统`，以及该读取是否只读。
- 是否明确不会复制、移动、删除、覆盖或转码原素材。
- 是否明确不会调用剪辑软件或生成真实媒体。
- 是否明确不会触发 n8n 或发送企业微信。
- 是否明确不会接入股票自动交易、行情、券商或下单链路。

## 五、升级施工的最小放行条件

在允许从影子预案进入实际施工前，建议至少满足：

1. 素材登记台账存在，且每个素材有来源和授权状态。
2. 内容处理系统索引存在，且候选生成脚本不需要自动补生成外部索引。
3. 门禁开关继续显示真实渲染、自动发布、n8n、企业微信为 false。
4. 状态摘要安全边界继续显示 `接入交易: false`。
5. 有单独渲染放行单，且默认不放行。
6. 有发布前人工确认表，且默认不发布。

## 六、硬闸门继承

股票自动交易屏蔽硬闸门在本预案中优先级最高。任何后续自动化、通知、状态摘要或跨系统桥接，只要出现交易、行情、券商、下单、自动交易关键词，必须立即停留在影子状态，不进入执行。
