# 局部修正闭环影子器

- 生成时间：2026-05-08 09:39:18
- 真实系统触发：否

## 内容

### 定位
- 把“改开头、换语气、保留后半段、换声音”等自然语言修正请求，转成可追溯、可复核、可回滚的影子修正闭环。

### 闭环步骤
-
  - 步骤：
    - 接收修正指令
  - 输入：
    - 用户自然语言，例如“第三句不像我，改得松弛一点”。
  - 输出：
    - 最近指令、目标对象、待确认项。
  - 真实系统触发：
    - False
-
  - 步骤：
    - 定位修改范围
  - 输入：
    - 脚本草案、分镜草案、用户描述。
  - 输出：
    - 目标片段、锁定片段、允许修改片段。
  - 真实系统触发：
    - False
-
  - 步骤：
    - 生成修正建议
  - 输入：
    - 目标片段、修改方向、去AI感要求。
  - 输出：
    - 最多三条候选修正建议和人工确认点。
  - 真实系统触发：
    - False
-
  - 步骤：
    - 人工复核
  - 输入：
    - 候选修正建议、原文、改动理由。
  - 输出：
    - 通过、退回、局部再改、驳回。
  - 真实系统触发：
    - False
-
  - 步骤：
    - 沉淀经验
  - 输入：
    - 人工选择和修改原因。
  - 输出：
    - 进化候选，不直接写正式规则库。
  - 真实系统触发：
    - False

### 修正类型
- 语气修正：更口语、更克制、更年轻、更沉稳。
- 结构修正：换开头、压缩中段、强化结尾。
- 内容修正：增加真人细节、减少空泛金句、补充知识增量。
- 分镜修正：换画面氛围、补镜头节奏、标注素材授权缺口。
- 包装修正：音色、字幕、滤镜、BGM 偏好登记。

### 锁定规则
- 人工已确认片段默认锁定，后续局部修正不得覆盖。
- 用户明确说“只改第三句”时，其他句子进入锁定片段。
- 若修正会影响合规、原创性或平台规范，必须退回待人工复核。

### 输出卡片字段
- 任务ID：
  - 绑定视频工厂任务单。
- 会话ID：
  - 绑定聊天终端会话。
- 最近指令：
  - 用户最后一句修正指令。
- 目标对象：
  - 脚本、标题、分镜、声音、字幕、封面、发布文案。
- 目标片段：
  - 待修改句子或段落。
- 锁定片段：
  - 不得被本次修正覆盖的内容。
- 修正方向：
  - 用户想要的语气、风格或信息变化。
- 候选建议：
  - 影子建议，待人工确认。
- 风险提示：
  - 合规、素材、平台、原创性、AI标识等问题。
- 人工复核状态：
  - 待确认。
- 真实系统触发：
  - False
