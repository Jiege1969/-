# 大模型接入前置条件清单

- 生成时间：2026-05-08 09:30:54
- 真实系统触发：否

## 内容

### 目的
- 在真实接入DeepSeek、通义千问等模型前，先固定安全、配置、日志和人工复核前置条件。

### 前置条件
- 模型供应商、用途、费用和调用范围已由总管确认。
- API Key 不写入脚本和任务单，只允许放在受控配置或环境变量。
- 模型输出只能写入草案、建议、待复核问题，不得直接写放行清单。
- 模型不得读取真实账号、Cookie、平台后台或素材密钥。
- 模型生成内容必须再次经过 compliance_check 和人工复核。
- 模型输出必须保留来源、时间、输入摘要、修改轮次。
- 企业微信输入只作为消息来源，不等于真实发送放行。

### 未来适配器接口草案
- 输入：
  - 会话ID
  - 任务ID
  - 用户指令
  - 当前草案摘要
  - 锁定片段
  - 门禁状态
- 输出：
  - 意图分类
  - 建议回复
  - 草案修订建议
  - 待用户确认项
  - 风险提示
- 禁止输出：
  - 真实发布命令
  - 真实渲染命令
  - 账号凭证
  - 跳过门禁建议
