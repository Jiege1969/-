# 轮次012 视频工厂总控层系统健康运行检查清单

> 用途：固定视频工厂总控层的安全底线和日常巡检口径。  
> 适用范围：轮次012任务生成、合规检查、草案生成、渲染适配器、发布适配器、放行清单、归档。

- [ ] 门禁检查函数 `compliance_check()` 是否在 `generate_task()` 中被自动调用。
- [ ] 所有任务单的 `允许真实渲染` 是否默认为 `false`。
- [ ] 所有任务单的 `允许自动发布` 是否默认为 `false`。
- [ ] 所有任务单的 `允许调用外部素材API` 是否默认为 `false`。
- [ ] 渲染适配器是否包含随机限速逻辑，范围为 `30-120` 秒。
- [ ] 渲染适配器限速注释是否明确为“节奏控制/防误触”，而不是规避平台风控。
- [ ] 发布适配器是否有 AI 标识确认提醒：`请确认已在发布平台勾选“内容由AI生成”`。
- [ ] 所有外部调用（MoneyPrinterTurbo、PostBot、MoneyPrinterPlus 等）是否都只保留在适配器内部的 `# TODO` 占位处。
- [ ] 外部工具调用处是否都有异常捕获和日志记录。
- [ ] 风控关键词库是否独立在 `01配置\视频工厂合规规则.json` 中，且可直接修改。
- [ ] 高风险内容是否在 `draft_generator.py` 草案生成阶段被二次合规门禁阻断。
- [ ] 成语故事类主题是否强制要求 `古今结合举例` 段落。
- [ ] 经典语录类主题是否强制要求 `古今结合举例` 段落。
- [ ] 发布适配器注释是否使用安全措辞：`仅支持人工确认后的本地浏览器辅助操作，严禁刷量、批量骚扰、规避平台限制`。
- [ ] 生成放行与发布放行是否拆分为两个独立清单。
- [ ] 未在生成放行清单中标记 `放行` 的任务，渲染适配器是否拒绝执行。
- [ ] 未在发布放行清单中标记 `放行` 的任务，发布适配器是否拒绝执行。
- [ ] 任务状态是否使用标准化枚举值：`预演中 | 待人工复核 | 复核通过 | 生成放行 | 已生成待预览 | 发布待确认 | 发布放行 | 已发布 | 已驳回`。
- [ ] 企业微信会话字段是否保留：`会话来源`、`会话ID`、`最近指令`、`等待用户确认项`。
- [ ] 草案文件末尾是否附加完整《创作者自查清单》。
- [ ] 每次任务生成是否同步生成 `archive` 归档副本。
- [ ] 每次草案生成是否同步生成 `archive` 归档副本。
- [ ] 每次适配器运行是否同步生成放行清单快照和日志文件。
- [ ] 轮次012所有产物是否只写入 `03数据\18轮次012视频工厂总控层`，不污染 R010/R011。
- [ ] 真实渲染、自动发布、n8n、企业微信真实外发是否仍保持未放行状态。

## 日常巡检建议

1. 每次修改词库后，至少运行 TC02、TC03、TC04 三类用例。
2. 每次接入真实渲染命令前，先确认生成放行清单与发布放行清单仍然分离。
3. 每次接入发布工具前，先确认 AI 标识提醒、人工确认和日志回写仍然存在。
4. 任一检查项失败时，应暂停真实执行链路，只允许本地预演。
