# 轮次012 发布路径打通方案

> 结论：第一条真实发布桥梁选择 `social-auto-upload CLI`。  
> 当前状态：发布路径已接入 `publisher.py` 配置层，但真实发布默认关闭，需人工完成账号登录、视频文件路径、放行清单和 AI 标识确认后再启用。

## 1. 方案选择

| 方案 | 结论 | 原因 |
| --- | --- | --- |
| PostBot | 保留为人工同步/兜底 | PostBot 更像 Chrome 扩展，不适合作为 `publisher.py` 直接命令行调用入口。 |
| social-auto-upload | 首选桥梁 | 当前提供 `sau` 命令行，适合由 Python 在本地放行后调用；支持抖音、快手、小红书、B站等平台。 |
| MoneyPrinterPlus | 后续规模化备选 | 更偏完整项目，不适合作为轮次012第一条最小发布桥梁。 |
| AiToEarn | 暂不首选 | 引入 API Key/服务端/MCP 能力，和当前本地门禁优先原则不完全贴合。 |

- 适配器：`D:\杰哥智能化系统\02杰哥扩展系统\02视频制作系统\02脚本\发布适配器\publisher.py`

## 3. 当前安全默认值

`视频发布桥梁配置.json` 中：

```json
"启用真实发布": false
```

这意味着：

- 已经打通 `publisher.py -> social-auto-upload CLI` 的命令构建路径。
- 但默认不会执行真实发布命令。
- 即使发布清单标记为 `放行`，也只会写入“桥梁未启用”的日志和结果回写。

## 4. 发布清单建议字段

后续真实发布时，建议将发布清单表格扩展为包含以下字段：

```markdown
| 任务ID | 生成状态 | 发布放行状态 | 放行时间 | 放行人 | 视频文件 | 标题 | 简介 | 标签 | 平台 | 账号 | B站分区ID | 发布结果 |
```

其中：

- `视频文件`：真实成片本地绝对路径。
- `平台`：可填 `B站`、`抖音`、`小红书`、`快手`，多个平台用逗号分隔。
- `账号`：social-auto-upload 中已登录配置的账号名。
- `B站分区ID`：B站发布需要分区参数，默认配置为 `249`。

## 5. 真实启用前置条件

1. 已安装并验证 `social-auto-upload`。
2. 本机 `sau` 命令可用。
3. 已通过 `sau login <platform> --account <account>` 或工具文档要求完成本地账号登录。
4. 发布清单中视频文件存在。
5. 发布清单中 `发布放行状态` 已人工改为 `放行`。
6. 执行 `publisher.py` 时必须确认已在平台标识 AI 生成内容。
7. 配置中人工改为 `"启用真实发布": true`。

测试成功后，再逐步扩展到小红书、抖音、快手。不要一开始全平台发布。

## 7. 安全底线

- 生成放行不等于发布放行。
- 发布前必须人工预览成品。
- 发布前必须确认 AI 生成内容标识。
- 仅支持人工确认后的本地浏览器辅助操作，严禁刷量、批量骚扰、规避平台限制。
- 任一工具登录失效、验证码、平台规则变化或账号异常时，应立即回退到手动发布。
