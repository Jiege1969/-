# 税收可交付前只读验收包说明

- 生成日期：2026-05-05
- 对应数据包：`03数据\25税收可交付前只读验收包`
- 文档性质：交付前只读验收说明，不是税务意见

## 一、目的

本说明用于交接“税收可交付前只读验收包”。该包把上一阶段的来源候选和人工复核要求收束为交付前检查材料，重点确认政策来源候选、人工复核单、不可判断边界、禁写正式库和回滚字段是否齐备。

## 二、验收闭环

```text
政策来源候选
-> 人工复核单
-> 不可判断边界标注
-> 禁写正式库检查
-> 回滚字段确认
-> 只读验收报告
```

## 三、本轮产物

- `税收可交付前政策来源候选清单_最新.md`
- `税收可交付前人工复核单_最新.md`
- `税收可交付前不可判断边界清单_最新.md`

- `税收可交付前只读验收包说明.md`

## 四、固定边界

当前阶段只做本地只读验收，不触发 n8n，不发企业微信真实消息，不写正式政策库、正式知识库、向量库或业务库，不调用券商接口，不自动交易，不给正式税务适用判断，不给正式申报建议，不触碰本职工作系统。

## 五、交接要求

1. 后续任何交付评审必须先检查人工复核人、复核时间、只读确认和回滚字段。
2. 政策来源候选只表示材料来源进入人工视野，不表示政策有效或适用。
3. 不可判断边界必须随材料一起交接，不能被摘要删除。
4. 回滚字段缺失时不得交付。
5. 如需正式政策库、知识库、向量库或业务库写入，必须另走人工审批和正式流程，本包不放行。
