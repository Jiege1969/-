# 官方来源智能鉴别通用规则

- 生成日期：2026-05-07
- 适用范围：税收业务系统。本文件仅约束税收系统内部来源治理；跨系统通用化应回到上位母本，不由税收目录单独定义。
- 文件性质：来源治理与证据链通用规则，不是税务意见

## 一、核心原则

系统应当具备信息来源智能鉴别能力。国家税务总局、各级地方税务局、财政、政府公报等官方或权威站点，不应简单一律推给人工复核来源真假。学术性权威网站、国家级部门和单位、中央级主流媒体、大型商业门户等，也应按可信度和用途边界分层处理，而不是简单二分为可信或不可信。

人工复核的价值应集中在高风险判断上：

- 时效链：是否废止、修改、尚未生效、存在过渡期。
- 附件链：附件、表单、填报说明是否下载、解析、哈希留痕。
- 地方边界：地方口径适用地区、上位文件关系、能否外推。
- 业务事实：具体主体、期间、交易、凭证、申报状态是否满足条件。
- 结论边界：是否会形成正式申报建议、正式投资建议、正式合同意见或其他高风险结论。

## 二、可信度分层

| 等级 | 来源类型 | 例子 | 可以做什么 | 不能做什么 |
| --- | --- | --- | --- | --- |
| S1 | 国家官方与法定发布来源 | 国家税务总局、各级地方税务局、财政部、国务院、中国政府网、全国人大、政府公报 | 可作为政策、法规等正式依据来源候选 | 不能跳过时效、附件、地方边界和业务适用复核 |
| S2 | 国家级部门、事业单位与权威公共机构 | 国家统计局、央行、市场监管总局、工信部、发改委、中科院、社科院等 | 可作为事实、统计、监管背景、专业背景来源 | 不能替代税务、法律、监管正式原文 |
| S3 | 学术权威与专业数据库 | 高校、研究院、学术数据库、专业期刊平台 | 可作为研究观点、理论背景、学术证据 | 不能替代官方政策、公告、法规或业务复核 |
| S4 | 中央级主流媒体与权威新闻机构 | 新华社、人民网、央视网、中国经济网、中国日报等 | 可作为公开事实、政策传播、舆情和新闻线索 | 不能单独作为正式政策依据 |
| S5 | 大型商业门户与高公信力公共平台 | 网易、新浪、腾讯、搜狐等 | 可作为线索、转载入口、舆情和公共信息提示 | 必须反向追溯到官方、学术或原始权威来源后才能进入正式证据链 |
| S6 | 普通第三方、自媒体、论坛和未知来源 | 个人号、论坛、培训材料、来源不明网页 | 仅作检索线索或人工排查对象 | 默认不得进入正式证据链 |

## 三、机器负责的部分

系统应自动完成以下工作：

| 能力 | 说明 |
| --- | --- |
| 域名识别 | 识别官方根域、子域、栏目和最终跳转链接 |
| 来源分级 | 标记国家官方、地方官方、国家级权威机构、学术权威、权威媒体、商业门户、附件、非官方 |
| 字段抽取 | 抽取标题、文号、发布机关、发布日期、文件时效、来源链接 |
| 路径登记 | 保存原文路径、解析文本路径、元数据路径、下载时间和哈希 |
| 异常识别 | 对来源不可追溯、标题机关矛盾、字段缺失、附件未解析进行阻断或降级 |

## 四、人工负责的部分

人工不重复做系统已经能稳定判断的官网身份确认。人工重点复核：

| 复核对象 | 说明 |
| --- | --- |
| 时效关系 | 文件是否仍可作为当前依据，是否被修改、废止、替代 |
| 地方口径 | 是否只适用于特定省、市、地区或特定办理场景 |
| 上位依据 | 地方文件、问答、解读是否能关联正式上位文件 |
| 业务适用 | 具体企业、个人、交易、期间、凭证是否满足适用条件 |
| 输出风险 | 是否越界形成正式税务意见、正式申报建议或其他高风险建议 |

## 五、税收系统特别规则

| 来源 | 智能鉴别口径 | 使用边界 |
| --- | --- | --- |
| 国家税务总局政策法规库 | 自动标记为中央官方正式来源 | 仍需核验时效、附件和适用期间 |
| 国家税务总局官网 | 自动标记为中央官方或官方辅助来源 | 解读、问答不得单独替代正式依据 |
| 各级地方税务局官网 | 自动标记为地方官方来源 | 必须保留适用地区，不得泛化为全国口径 |
| 地方财政、地方政务公开 | 可标记为地方官方候选来源 | 必须核验机关、地区、栏目和上位文件 |
| 学术权威和专业数据库 | 可标记为研究辅助来源 | 可辅助理解，不得替代税收政策原文 |
| 中央级主流媒体 | 可标记为权威媒体来源 | 可作为线索和传播材料，不得单独作为正式政策依据 |
| 网易、新浪等商业门户 | 可标记为公共传播来源 | 必须反向追溯原始权威来源 |
| 第三方转载、自媒体、培训材料 | 低可信或未知来源 | 只能作为检索线索，必须反向找到官方原文 |

## 六、通用状态

| 状态 | 含义 | 后续动作 |
| --- | --- | --- |
| 官方来源已核验 | 系统已确认来源身份可信 | 进入官方证据库或候选队列 |
| 地方官方来源已核验 | 系统已确认地方官方身份 | 进入地方口径候选，并标注地区 |
| 可信来源已识别 | 系统已识别学术、媒体或门户等来源层级 | 按用途边界进入辅助证据、线索或待追溯队列 |
| 元数据待补全 | 来源可信但字段、附件或时效不完整 | 进入待补证区 |
| 人工复核待确认 | 涉及业务适用或正式结论 | 进入人工复核区 |
| 非官方阻断 | 来源不可追溯或非官方 | 不入正式证据链 |

## 七、禁止事项

- 不得把官方来源自动鉴别等同于正式业务结论。
- 不得把地方官方口径自动泛化为全国通用口径。
- 不得用政策解读、问答、培训资料单独支撑正式结论。
- 不得把网易、新浪等商业门户上的转载内容直接当成政策原文。
- 不得把学术研究观点当成官方执行口径。
- 不得绕过网站访问限制、验证码、登录权限或频率限制。
- 不得未经人工确认输出正式申报、正式税务意见或其他高风险建议。

## 八、结论

来源身份和可信度由系统智能鉴别，业务结论由人工复核把关。系统的目标不是把所有资料都推给人工，也不是把所有大网站都当成正式依据，而是让每类来源进入它应该进入的位置。
