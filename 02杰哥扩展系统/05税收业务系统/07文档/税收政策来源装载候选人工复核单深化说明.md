# 税收政策来源装载候选人工复核单深化说明

- 生成日期：2026-05-05
- 对应数据包：`03数据\24税收政策来源装载候选人工复核单深化`
- 文档性质：候选资料人工复核单深化说明，不是税务意见

## 一、目的

本说明用于把“正式来源装载前门禁”之后的资料，进一步约束为必须人工复核的装载候选。复核单重点检查复核人、复核时间、来源、文号、时效、附件、结论和回滚字段，避免候选资料绕过人工责任链进入正式库。

## 二、复核闭环

```text
装载前门禁候选
-> 人工复核单建档
-> 复核人和时间确认
-> 来源、文号、时效、附件核验
-> 结论和回滚字段确认
-> 完整复核候选/降级待补证/阻断
```

## 三、四个样本

| 样本 | 输出 | 说明 |
| --- | --- | --- |
| 完整复核候选 | 完整复核候选 | 字段齐备，只能进入后续正式装载评估，不直接写正式库 |
| 缺复核人阻断 | 阻断 | 复核人姓名或完成时间为空，人工责任链不完整 |
| 时效不明降级 | 降级待补证 | 施行日期、适用期间、文件时效待核验，不得作当前适用依据 |
| 正式申报建议阻断 | 阻断 | 用户要求正式申报建议、节税方案或自动申报时阻断 |

## 四、固定边界

当前阶段不触发 n8n，不发企业微信真实消息，不写正式政策库、正式知识库、向量库或业务库，不调用券商接口，不自动交易，不给正式税务适用判断，不给正式申报建议，不触碰本职工作系统。
