# 税收人工入口资料下载器说明

## 作用

用户填一个国家税务总局、政策法规库或财政部税政司的官方入口网址，脚本自动识别页面里的政策网页和附件，先生成待下载清单。

默认只生成清单，不下载。

## 使用命令

最省事的方式：

1. 先生成网址填写文件。

```powershell
python D:\杰哥智能化系统\02杰哥扩展系统\05税收业务系统\02脚本\生成税收人工入口网址填写模板.py
```

2. 打开并填写：

```text
D:\杰哥智能化系统\02杰哥扩展系统\05税收业务系统\03数据\11人工入口下载器\入口网址_请填写.txt
```

3. 一键生成待下载清单：

```powershell
python D:\杰哥智能化系统\02杰哥扩展系统\05税收业务系统\02脚本\税收人工入口资料清单一键生成.py
```

4. 生成逐项下载选择模板：

```powershell
python D:\杰哥智能化系统\02杰哥扩展系统\05税收业务系统\02脚本\生成税收人工入口资料下载选择模板.py
```

5. 打开同目录的 `税收人工入口资料下载选择模板_最新.json`，把需要下载条目的 `选择下载` 从 `false` 改成 `true`。

6. 走下载闸口。没确认或没勾选时，只生成申请单，不下载：

```powershell
python D:\杰哥智能化系统\02杰哥扩展系统\05税收业务系统\02脚本\税收人工入口资料下载闸口.py
```

确认且已勾选后，才允许小批量下载：

```powershell
python D:\杰哥智能化系统\02杰哥扩展系统\05税收业务系统\02脚本\税收人工入口资料下载闸口.py --confirm-download YES --max-files 5
```

也可以直接在命令里传网址：

更稳妥的下载方式是先走闸口。未确认时只生成申请单：

## 安全边界

- 只允许官方白名单域名。
- 默认不下载，只生成清单。
- 非官方域名会在联网前被拒绝。
- 下载闸口要求“确认参数 + 选择模板勾选”双条件。
- 选择模板必须匹配当前清单入口网址，避免拿旧勾选下载新清单。
- 下载只进入预演目录。
- 不写正式政策目录。
- 不写向量库。
- 不触发 n8n。
- 不发送企业微信。
- 不自动标记正式依据。
