# 研发费用税收正式政策链接入口径预案说明

- 生成日期：2026-05-05
- 对应数据包：`03数据\22研发费用企业所得税证据链补齐预案`
- 文档性质：研发费用税收问答证据链标准说明，不是正式税务意见

## 目的

本说明把研发费用加计扣除方向从“找到资料”收束为“可追溯证据链”。后续系统只能基于官方来源、正式依据、本地路径、引用关系和人工复核字段输出答案草案；当证据不足时必须降级或不可回答。

## 入口径

1. 正式依据优先：国家税务总局政策法规库、财政部官网、国务院/中国政府网、全国人大法律法规入口。
2. 官方解释辅助：政策解读、政策指引、办税指南、公开问答和案例只用于理解和风险提示。
3. 关联材料留痕：附件、表单、地方口径、修改废止关系必须作为关系边，不得单独支撑结论。
4. 非官方材料拦截：第三方文章、培训课件、搜索摘要只能作为检索线索。

## 三种输出

| 状态 | 条件 | 输出 |
| --- | --- | --- |
| 可回答 | 有全文有效正式依据，本地原文/解析文本/元数据路径齐备，阻断项可说明 | 答案草案、正式依据、引用路径、人工复核项 |
| 需降级 | 有官方材料但正式依据、时效、事实或附件字段不完整 | 降级语、补证清单、人工复核字段 |
| 不可回答 | 官方依据缺失、事实严重不足、用户要求正式申报建议或越界 | 不可回答语、安全边界、人工处理事项 |

## 固定边界

当前阶段不做法律或税务最终适用判断，不给正式申报建议，不自动接企业微信，不触发 n8n，不写正式库或向量库，不调用券商接口，不自动交易。
