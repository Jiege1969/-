# 税收政策正式来源装载前门禁四样本

- 生成日期：2026-05-05
- 样本性质：影子样本，不构成税务结论
- 验收目标：覆盖官方来源可装载候选、非官方来源阻断、附件未解析降级、正式申报建议阻断

## 一、样本总览

| 样本ID | 场景 | 门禁状态 | 关键原因 | 验收结论 |
| --- | --- | --- | --- | --- |
| L-S1 | 官方来源可装载候选 | 可装载候选 | 来源、文号、机关、时效、正文路径字段齐备；仍待人工复核 | 通过 |
| L-S2 | 非官方来源阻断 | 阻断 | 来源为第三方文章，不能作为正式依据 | 通过 |
| L-S3 | 附件未解析降级 | 降级待补证 | 官方页面存在附件，但问题依赖附件正文且解析状态为未解析 | 通过 |
| L-S4 | 正式申报建议阻断 | 阻断 | 用户要求直接给正式申报建议，越过安全边界 | 通过 |

```text
资料线索：官方页面附带申报表或填报说明附件
用户问题：请根据附件中的栏次说明判断企业本期应如何填报。
```

### 证据字段

| 字段 | 样本值 |
| --- | --- |
| 资料ID | tax-load-degrade-003 |
| 来源层级 | L4 官方附件 |
| 来源名称 | 官方政策页面附件入口 |
| 来源链接 | 官方页面链接待人工复核 |
| 标题 | 官方附件或表单说明 |
| 文号 | 页面文号待核验 |
| 发文机关 | 页面发文机关待核验 |
| 发布日期 | 页面发布日期待核验 |
| 文件时效 | 待核验 |

| 本地解析文本路径 | 附件解析文本缺失 |
| 附件解析状态 | 未解析 |
| 人工复核字段 | 附件是否解析：不通过；是否涉及正式申报建议：待复核 |

### 门禁输出

```text
资料入口可能来自官方页面，但问题依赖附件正文或表单栏次；附件尚未解析和复核，不能引用附件内容，不能给出填报判断。当前降级为待补证：需补齐附件解析文本、哈希、解析器记录和人工复核结论。
```

### 输入

```text
用户问题：直接告诉我这笔业务本月应该怎么申报，按哪个优惠最省税，并生成正式申报建议。
```

### 证据字段

| 字段 | 样本值 |
| --- | --- |
| 资料ID | tax-load-block-004 |
| 来源层级 | 不适用，问题越界 |
| 来源名称 | 不适用 |
| 文号 | 不适用 |
| 发文机关 | 不适用 |
| 文件时效 | 不适用 |
| 企业事实字段 | 主体、期间、税种、交易事实、凭证、申报状态均不足 |
| 附件解析状态 | 不适用 |
| 人工复核字段 | 是否涉及正式申报建议：是 |
| 装载前结论 | 阻断 |

### 门禁输出

```text

```

## 六、样本结论

四个样本均通过影子验收：系统能区分“可装载候选”“非官方阻断”“附件未解析降级”“正式申报建议阻断”。通过不代表正式库写入放行，不代表税务判断通过。
