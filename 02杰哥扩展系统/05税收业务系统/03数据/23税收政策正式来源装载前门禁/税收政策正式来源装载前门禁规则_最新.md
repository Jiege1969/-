# 税收政策正式来源装载前门禁规则

- 生成日期：2026-05-05
- 小任务：第四批并行小任务 L，02扩展 / 税收政策正式来源装载前门禁
- 范围：正式来源装载前的影子门禁，不写正式政策库、知识库、向量库或业务库
- 安全边界：不触发 n8n，不发企业微信真实消息，不调用券商接口，不自动交易，不给正式税务适用判断，不给正式申报建议

## 一、定位

本门禁用于判断税收政策资料是否允许进入“正式来源装载候选”队列。通过门禁只代表资料具备进入人工复核和后续装载评估的基础条件，不代表已经写入正式库，也不代表可以直接给出税务结论。

本门禁新增“官方来源智能鉴别”口径：国家税务总局、各级地方税务局、财政等官方站点的来源身份应由系统自动识别和记录，不再把“官网真假”作为人工重复确认事项。人工复核重点转向文件时效、附件解析、地方适用边界、上位文件关系和具体业务适用判断。

本门禁同时采用“信息来源可信度分层”口径：国家官方、学术权威、国家级部门单位、中央级主流媒体和大型商业门户都不是简单的可信/不可信二分，而是按证据用途分层。可信媒体和商业门户可以作为线索或传播材料，但不能替代税收政策原文。

资料进入正式装载前必须经过以下路径：

```text
资料线索
-> 来源核验
-> 文号/机关/日期/时效核验
-> 正文与附件解析核验
-> 本地证据路径核验
-> 人工复核字段核验
-> 不可判断边界核验
-> 装载前状态
```

## 二、来源分层

| 层级 | 来源类型 | 门禁处理 | 说明 |
| --- | --- | --- | --- |
| L1 官方正式来源 | 国家税务总局政策法规库、财政部官网、国务院/中国政府网、全国人大法律法规入口、海关总署等税收相关官方发布入口 | 系统自动识别为官方来源，可进入装载候选 | 仍需文号、时效、正文、附件和业务适用复核字段齐备 |
| L2 官方辅助来源 | 政策解读、办税指南、公开问答、12366公开问答、官方案例 | 可进入辅助候选 | 只能解释或提示风险，不得单独支撑正式适用结论 |
| L3 地方官方来源 | 各级地方税务局、地方财政、地方政府公报或地方政务公开平台中的税收相关官方页面 | 系统自动识别为地方官方来源，进入地方口径候选 | 必须标注地域、适用范围、上位文件关系和人工复核要求，不得泛化为全国口径 |
| L4 附件/表单/压缩包 | 官方页面挂载的 `.pdf`、`.doc`、`.docx`、`.xls`、`.xlsx`、`.zip` 等 | 解析通过后才可引用正文 | 未解析时只能引用附件入口，不得引用附件内容 |
| L5 非官方来源 | 搜索摘要、媒体文章、培训课件、第三方数据库、公众号文章、论坛问答 | 阻断 | 只能保留为检索线索，不进正式来源候选 |

## 三、可信度分层

| 等级 | 来源类型 | 门禁处理 | 说明 |
| --- | --- | --- | --- |
| S1 | 国家官方与法定发布来源 | 可进入正式来源候选 | 可作为政策、法规、监管规则来源，仍需时效、附件和适用边界核验 |
| S2 | 国家级部门、事业单位与权威公共机构 | 可进入权威背景候选 | 可作事实、统计、监管背景，不替代税收政策原文 |
| S3 | 学术权威与专业数据库 | 可进入研究辅助候选 | 可作学术证据和理论背景，不作正式执行口径 |
| S4 | 中央级主流媒体与权威新闻机构 | 可进入权威媒体线索 | 可作公开事实和政策传播线索，不单独作政策依据 |
| S5 | 大型商业门户与高公信力公共平台 | 可进入公共传播线索 | 如网易、新浪等，只能作线索，必须反向追溯原始权威来源 |
| S6 | 普通第三方、自媒体、论坛和未知来源 | 阻断 | 默认不得进入正式证据链 |

## 四、必填证据字段

| 字段 | 要求 | 不合格处理 |
| --- | --- | --- |
| 资料ID | 全局唯一，能关联样本、证据和复核记录 | 缺失则阻断 |
| 来源层级 | L1/L2/L3/L4/L5 之一 | 未分类则降级待复核 |
| 来源名称、来源链接、最终链接 | 必须可追溯到公开页面或附件入口 | 非官方或不可追溯则阻断 |
| 标题 | 与来源页面一致 | 缺失则阻断 |
| 文号 | 正式政策类必须有文号；法律法规可填条目编号或法规名称 | 缺失则不得作正式依据 |
| 发文机关 | 必须与来源一致 | 缺失或矛盾则阻断 |
| 发布日期、施行日期、适用期间 | 用于时效判断 | 缺失则降级 |
| 文件时效 | 现行有效、已废止、部分失效、待核验 | 待核验或已废止不得作当前适用依据 |
| 正文路径 | 本地原文路径和解析文本路径 | 任一缺失则降级 |
| 附件解析状态 | 已解析、未解析、不适用、解析失败 | 依赖附件但未解析则降级 |
| 元数据路径 | 记录来源、下载时间、哈希、解析器、关系边 | 缺失则降级 |
| 人工复核字段 | 复核人、复核时间、复核结论、复核范围 | 缺失则不得正式装载 |
| 阻断/降级原因 | 必须写明原因 | 无原因不得通过 |

## 五、官方来源智能鉴别规则

| 鉴别结论 | 触发条件 | 系统可自动完成 | 仍需人工复核 |
| --- | --- | --- | --- |
| 官方来源已核验 | 命中国家税务总局、财政部、国务院、中国政府网、全国人大等官方来源规则，最终链接可追溯，标题和发布机关不矛盾 | 标记来源可信、保存原文、生成哈希、提取元数据、进入官方证据节点 | 时效链、附件链、适用期间、具体业务适用判断 |
| 地方官方来源已核验 | 命中各级地方税务局、地方财政或地方政务公开平台，且能识别地区和机关 | 标记地方官方来源、登记适用地区、进入地方口径候选 | 上位文件关系、地域边界、是否可用于具体企业事项 |
| 来源待补证 | 疑似官方但域名、栏目、最终链接、标题或发布机关不完整 | 进入待补证清单，输出缺口 | 人工补齐来源链和机关一致性 |
| 非官方阻断 | 第三方、转载、自媒体、培训材料、论坛问答或来源不可追溯 | 阻断入库，仅保留为检索线索 | 如确需使用，必须反向找到官方原文 |

本规则可复用到其他系统：股票系统、文稿系统、合同系统等都应区分“来源可信度自动鉴别”和“业务结论人工复核”，不得把低价值来源身份确认与高风险业务判断混为一谈。

## 六、门禁状态

| 状态 | 触发条件 | 允许动作 | 禁止动作 |
| --- | --- | --- | --- |
| 可装载候选 | 官方正式来源已由系统核验，文号/机关/日期/时效明确、正文路径齐备、附件不影响或已解析、业务复核字段可补齐 | 进入人工复核队列和正式装载评估队列 | 直接写正式库、输出正式申报建议 |
| 辅助候选 | 官方辅助来源或地方官方来源，不能单独支撑结论 | 作为解释、风险提示或地方口径待核验 | 单独作为全国正式依据或具体业务结论依据 |
| 降级待补证 | 来源官方但时效、附件、解析文本、元数据或人工复核字段不足 | 输出补证清单和人工复核项 | 输出当前适用判断 |
| 阻断 | 非官方来源、来源不可追溯、文号伪造/缺失且无法解释、用户要求正式申报建议、请求规避监管 | 输出阻断原因和安全边界 | 入正式库、入向量库、入业务库、自动答复结论 |

## 七、附件解析门禁

1. 页面正文足以识别政策身份，但问题依赖附件表单或附件条款时，附件未解析必须降级。
2. 附件只下载未解析时，只能记录“附件入口路径”，不得摘录附件正文。
3. 老式 `.doc`、扫描 PDF、压缩包内多文件必须记录解析器、解析时间、哈希和失败原因。
4. 附件解析失败不得由页面标题或文件名推断正文内容。
5. 附件解析通过后仍需人工复核，不自动进入正式库。

## 八、人工复核字段

| 字段 | 状态值 | 放行含义 |
| --- | --- | --- |
| 复核人 | 姓名/岗位/空 | 空值时不得正式装载 |
| 复核时间 | 日期时间/空 | 空值时不得正式装载 |
| 来源是否官方 | 通过/不通过/待复核 | 不通过则阻断 |
| 文号与机关是否一致 | 通过/不通过/待复核 | 不通过则阻断 |
| 时效是否明确 | 通过/不通过/待复核 | 待复核则降级 |
| 正文是否解析 | 通过/不通过/待复核 | 不通过则降级或阻断 |
| 附件是否解析 | 通过/不通过/不适用/待复核 | 依赖附件且不通过则降级 |
| 是否涉及正式申报建议 | 是/否/待复核 | 是则阻断自动输出 |
| 装载前结论 | 可装载候选/辅助候选/降级待补证/阻断 | 只代表装载前状态 |
| 复核备注 | 文本 | 必须说明剩余风险，不写正式税务建议 |

## 九、不可判断边界

以下情况不得输出“可以适用、不能适用、应当申报、建议这样申报”等正式税务判断：

1. 官方来源、文号、发文机关、时效、正文路径任一关键项缺失。
2. 只有官方解读、问答、案例、地方口径或非官方材料。
3. 文件存在修改、废止、延续、过渡期或地方差异，但关系链未闭环。
4. 问题依赖附件正文、表单栏次或填报说明，但附件未解析或未复核。
5. 企业主体、所属期间、税种、交易/业务事实、凭证和申报状态不足。
6. 用户要求正式申报建议、节税方案、规避监管、自动申报或替代人工复核。

标准阻断语：

```text
当前资料未通过正式来源装载前门禁，不能写入正式政策库、知识库、向量库或业务库；也不能据此输出正式税务适用判断或正式申报建议。请补齐官方来源、文号、时效、正文/附件解析路径和人工复核记录。
```

## 十、正式库写入禁用

本批任务只生成本地影子门禁文件。任何样本即使标记为“可装载候选”，也不得执行以下动作：

- 写入正式政策库。
- 写入正式知识库。
- 写入向量库或 RAG 生产索引。
- 写入业务库或客户业务档案。
- 触发 n8n 工作流。
- 发送企业微信真实消息。
- 给出正式税务适用判断或正式申报建议。

## 十一、结论

门禁已覆盖官方来源智能鉴别、文号、时效、附件解析、人工复核和不可判断边界。当前阶段允许系统自动识别国家税务总局、各级地方税务局、财政等官方来源身份；但只允许形成可装载候选、辅助候选、降级待补证或阻断记录，不允许正式库写入，不允许输出正式税务适用判断。
