# 研发费用业务事实采集模板

- 生成时间：2026-05-07 21:13:45
- 模板状态：draft
- 字段数量：27
- 必填字段数量：17
- 用途：供研发费用加计扣除涉税业务分析前人工补充事实，不形成正式税务结论。

## 字段

- [必填] 主体信息 / 企业名称：确认纳税主体。
- [必填] 主体信息 / 纳税人识别号：与申报主体、辅助账、留存资料匹配。
- [必填] 主体信息 / 纳税人类型：确认是否为居民企业、是否查账征收。
- [必填] 主体信息 / 适用地区：识别是否需要地方口径或主管税务机关复核。
- [必填] 期间信息 / 所属年度：匹配政策适用期间和申报期间。
- [必填] 期间信息 / 申报场景：区分预缴、汇算清缴、追溯享受或更正申报。
- [必填] 项目事实 / 研发项目名称：建立项目级判断对象。
- [必填] 项目事实 / 项目研发目标：核验是否具有明确研发目标。
- [必填] 项目事实 / 拟突破核心技术：核验技术不确定性和创新性。
- [必填] 项目事实 / 研发组织形式：核验系统组织形式和研发团队情况。
- [选填] 项目事实 / 研发成果或阶段成果：辅助判断项目结果和资料闭环。
- [选填] 项目事实 / 是否存在专家鉴定：有争议或政策要求时作为人工复核依据。
- [必填] 费用信息 / 研发费用总额：采集金额口径，但本模板不测算税额。
- [选填] 费用信息 / 人员人工费用：匹配研发费用归集范围。
- [选填] 费用信息 / 直接投入费用：匹配研发费用归集范围。
- [选填] 费用信息 / 折旧费用：匹配研发费用归集范围。
- [选填] 费用信息 / 无形资产摊销：匹配研发费用归集范围。
- [选填] 费用信息 / 其他相关费用：核验限额和归集口径。
- [选填] 特殊事项 / 委托研发情况：核验委托研发、境外委托和关联方资料。
- [选填] 特殊事项 / 合作或集中研发情况：核验费用分摊和项目归属。
- [必填] 排除事项 / 是否涉及不适用行业：核验行业限制。
- [必填] 排除事项 / 是否涉及不适用活动：核验常规升级、直接应用、简单改变等排除情形。
- [必填] 资料清单 / 研发支出辅助账：确认留存备查资料。
- [必填] 资料清单 / 项目立项资料：确认研发活动证据链。
- [必填] 资料清单 / 费用归集明细：确认费用和生产经营费用是否分别核算。
- [必填] 资料清单 / 留存备查资料目录：支撑后续人工复核。
- [选填] 资料清单 / 主管税务机关沟通记录：识别地方口径或争议处理。

## 放行规则

- 必填字段未补齐时，不得生成适用判断。
- 政策链仍为pending_review时，只能生成待复核分析草案。
- 金额字段只采集事实口径，不自动测算可扣除金额或税额影响。
- 项目创新性、技术不确定性和费用归集准确性必须人工复核。
