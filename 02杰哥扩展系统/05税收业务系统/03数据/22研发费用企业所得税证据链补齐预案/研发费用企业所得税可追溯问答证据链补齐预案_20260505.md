## 现状判断

1. 正式依据库已有 2 条全文有效正式依据：

   - `7d75b41b84bca341`：国家税务总局关于优化企业所得税年度纳税申报表的公告，国家税务总局公告2025年第1号。
2. 问题包中 `tax-q-001` 和 `tax-q-003` 可形成答案草案，但仍保留人工复核和附件解析阻断提示。
3. 主要缺口不在网页正文，而在附件：申报表和填报说明为老式 `.doc`，现阶段只有轻量字符串抽取，不能正式回填。

### 研发费用加计扣除问答链

研发费用方向当前仍是“正确降级”的状态：

1. 答案草案样板 `tax-draft-002` 明确可信度为低，不能判断当前是否可以享受。
2. 已有辅助材料包括研发费用加计扣除项目鉴定案例、第二辑、政策执行指引、财税〔2015〕119号关联页面等，但当前均因时效缺失、资料类别为关联材料、未人工复核等原因不能支撑当前适用判断。
3. 异常待核验区存在 `3832f81db81178ce_研发费用加计扣除项目鉴定案例（第三辑）.元数据.json`，其阻断原因为文件时效缺失；该材料可用于案例学习和风险点拆解，不能作为正式依据。
4. 当前最核心缺口是“全文有效正式政策链”和“适用条件证据字段”没有形成可追溯闭环。

## 目标证据链形态

建议把每个可回答问题固化为以下链路：

`问题ID -> 问题包规则 -> 正式依据候选 -> 本地原文/解析文本/元数据 -> 证据节点 -> 关系边 -> 答案草案 -> 人工复核单 -> 输出状态`

每条证据至少保留：

- 证据ID、资料ID、资料类别、标题、文号、发文机关、发布日期、施行日期、文件时效。
- 来源名称、来源链接、最终链接、下载时间、原文哈希、本地原文路径、本地解析文本路径、本地元数据路径。
- 是否可作当前适用依据、阻断原因、关联证据ID列表、人工复核状态。
