# 研发费用税收正式政策链接入口径预案

- 生成日期：2026-05-05
- 小任务：E，研发费用税收方向正式政策链补齐预案
- 范围：只读/影子标准，不写正式库，不形成法律或税务最终适用判断
- 安全边界：不触发 n8n，不发企业微信真实消息，不调用券商接口，不自动交易，不写向量库、正式知识库或正式政策库

## 一、定位

本预案只定义研发费用加计扣除问答进入正式政策链时的证据入口径。系统未来回答此类问题时，只能输出“可追溯答案草案、降级说明或不可回答说明”，不能替代税务机关、律师、税务师或企业申报责任人作出正式适用判断。

合格链路必须满足：

```text
问题原文 -> 场景拆解 -> 官方来源清单 -> 正式政策候选 -> 本地原文/解析文本/元数据 -> 证据字段 -> 引用路径 -> 人工复核 -> 输出状态
```

| S2 官方解释 | 国家税务总局政策解读、政策指引、办税指南、财政部/科技部相关公开解读 | 解读、指引、口径说明 | 解释正式依据含义，不能单独支撑当前适用结论 | 仅作辅助证据 |
| S3 官方问答/案例 | 税务总局公开问答、12366公开问答、项目鉴定案例 | 问答、案例、场景样本 | 用于识别风险点、事实字段和常见误区 | 不得替代正式依据 |

## 三、证据字段标准

### 1. 政策证据卡字段

| 字段 | 必填 | 用途 | 不合格处理 |
| --- | --- | --- | --- |
| 证据ID/资料ID | 是 | 串联问题、证据、引用路径 | 缺失则不入链 |
| 资料类别 | 是 | 区分正式依据、解释、问答、附件、关联材料 | 未分类则进入待核验 |
| 标题、文号、发文机关 | 是 | 确认政策身份 | 任一缺失不得作当前适用依据 |
| 发布日期、施行日期、文件时效 | 是 | 判断时间口径 | 时效缺失或已废止则降级 |
| 来源名称、来源链接、最终链接 | 是 | 支撑可追溯来源 | 非官方来源不得作依据 |
| 原文哈希、下载时间 | 是 | 留痕防篡改 | 缺失则仅作候选 |
| 本地原文路径、解析文本路径、元数据路径 | 是 | 本地复核入口 | 路径缺失则不能生成可复核答案草案 |
| 适用税种、主题关键词 | 是 | 绑定研发费用/企业所得税场景 | 缺失则不能自动匹配问题 |
| 是否可作当前适用依据 | 是 | 输出状态闸门 | false 时只能解释或降级 |
| 阻断原因 | 是 | 说明不能回答的原因 | 无阻断原因不得直接通过 |
| 关联证据ID列表 | 建议 | 串联解释、附件、废止修改关系 | 缺失则引用路径不完整 |

### 2. 研发费用事实字段

| 字段 | 目的 | 人工复核要求 |
| --- | --- | --- |
| 企业主体、所属期间、税种 | 确定问题范围 | 确认是否为企业所得税研发费用事项 |
| 研发项目名称、项目目标、技术不确定性 | 判断是否进入研发活动事实核验 | 系统不得自行认定创新性 |
| 费用类型、费用归集方式、辅助账 | 映射加计扣除费用范围 | 需人工核对原始凭证与辅助账 |
| 行业限制、负面活动、委托/合作/集中研发 | 判断是否触发特殊规则 | 缺失则降级 |
| 留存备查资料、项目鉴定材料、成果证明 | 支撑复核闭环 | 缺失则不得形成当前适用判断 |
| 地方口径、主管税务机关沟通记录 | 识别地区差异 | 仅能提示需核验，不自动替代正式依据 |

## 四、引用路径标准

每个答案草案必须展示最短可复核路径：

```text
问题ID
-> 正式依据ID/候选ID
-> 来源链接/最终链接
-> 本地原文路径
-> 本地解析文本路径
-> 本地元数据路径
-> 关系边：解释/问答/案例/附件/修改/废止/地方补充
-> 人工复核单
```

引用路径输出规则：

1. 正式依据必须排在解释、问答、案例之前。
2. 案例和指引只能标注为“解释/风险提示”，不得写成结论来源。
3. 附件正文未正式解析时，只能引用附件入口，不引用附件内容。
4. 已废止、已修改、时效缺失材料必须带阻断原因。
5. 问题依赖具体企业事实时，引用路径后必须跟“待补事实字段”。

## 五、不可判断边界

以下任一情况命中时，系统不得输出“可以享受/不能享受/应当申报”等结论：

1. 没有全文有效正式依据，或正式依据的文号、时效、来源、正文路径缺失。
2. 只有政策解读、执行指引、问答、案例、培训材料或第三方材料。
3. 企业事实字段缺失，尤其是项目技术不确定性、费用归集、辅助账、所属期间、留存备查材料。
4. 需要地方税务口径、项目鉴定或主管税务机关确认，但本地链路没有复核结果。
5. 政策存在修改、废止、延续、比例调整或行业限制，但关系链未闭环。
6. 附件为老式 `.doc` 且正式解析器未接入，问题又依赖附件正文或表单字段。
7. 用户要求正式申报建议、节税方案、法律/税务最终判断或规避监管口径。

标准不可回答语：

```text
未找到可复核的全文有效正式依据，且关键事实或人工复核字段不足；当前不能形成可追溯答案草案，也不能给出正式税务适用判断。
```

## 六、人工复核字段

| 字段 | 状态值 | 说明 |
| --- | --- | --- |
| 复核人 | 姓名/岗位/空 | 空值时不得进入正式问答链 |
| 复核时间 | 日期时间/空 | 空值时仅为影子样本 |
| 来源是否官方 | 通过/不通过/待复核 | 校验来源白名单 |
| 正式依据是否全文有效 | 通过/不通过/待复核 | 校验时效与废止修改关系 |
| 适用期间是否匹配 | 通过/不通过/待复核 | 校验所属期间 |
| 企业事实是否齐备 | 通过/不通过/待复核 | 校验研发事实字段 |
| 附件是否正式解析 | 通过/不通过/不适用/待复核 | 校验附件正文可用性 |
| 地方口径是否需要核验 | 需要/不需要/待复核 | 不自动推断地方差异 |
| 是否可输出答案草案 | 可回答/需降级/不可回答 | 只控制草案状态 |
| 复核结论摘要 | 文本/空 | 不写正式申报建议 |

## 八、输出状态规则

## 九、本轮结论

本轮仅补齐研发费用税收方向的正式政策链接入口径预案。当前研发费用加计扣除仍不得形成“能否享受”的正式或当前适用判断；必须先补齐全文有效正式依据、修改废止关系、适用期间、企业事实字段和人工复核记录。
