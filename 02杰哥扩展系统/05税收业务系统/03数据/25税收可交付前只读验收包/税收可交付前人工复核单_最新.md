# 税收可交付前人工复核单

- 生成日期：2026-05-05
- 表单性质：交付前只读人工复核单
- 使用边界：用于人工验收政策来源候选、证据链、不可判断边界和回滚字段，不产生正式税务判断

## 一、复核单主表

| 字段 | 填写要求 | 缺失处理 |
| --- | --- | --- |
| 复核单编号 | `AG-TAX-RO-YYYYMMDD-序号` | 阻断 |
| 关联候选编号 | 对应政策来源候选清单编号 | 阻断 |
| 复核人姓名 | 真实人工复核人，不得由系统代填 | 阻断 |
| 复核人岗位 | 税务、财务、法务、业务或其他人工岗位 | 阻断 |
| 复核开始时间 | 精确到分钟 | 阻断 |
| 复核完成时间 | 精确到分钟 | 阻断 |
| 来源级别 | A1、A2、A3、B1、C1 | 空值阻断，C1 阻断 |
| 来源链接复核 | 可追溯、不可追溯、待补证 | 不可追溯阻断，待补证降级 |
| 文号复核 | 一致、不一致、无文号待说明、待补证 | 不一致阻断，待补证降级 |
| 时效复核 | 现行、废止、部分废止、待核验 | 待核验降级，不得作当前适用判断 |
| 附件复核 | 无附件、已解析、待解析、解析失败 | 待解析或解析失败降级 |
| 正式申报建议检查 | 未涉及、涉及 | 涉及时阻断 |
| 不可判断边界 | 必填，说明不能自动判断事项 | 空值降级 |
| 只读确认 | 必须填写“已确认只读，不写正式库” | 空值阻断 |
| 回滚字段确认 | 回滚触发条件、目标、责任人、记录路径齐备 | 空值阻断 |
| 复核结论 | 通过、降级待补证、阻断 | 空值阻断 |

## 二、复核结论枚举

| 结论 | 含义 | 后续处理 |
| --- | --- | --- |
| 通过 | 字段齐备且未触发阻断；只代表可交付前验收材料完整 | 进入人工交付评审，不写正式库 |
| 降级待补证 | 来源、时效、附件、边界或证据链存在待补事项 | 补齐证据后重新复核 |
| 阻断 | 非官方来源、来源不可追溯、人工责任链缺失、正式申报建议越界或正式库写入风险 | 不得交付为可用依据 |

## 五、硬性边界

- 人工复核单不能替代税务专业意见。
- 复核通过不能解释为正式政策适用判断。
- 复核通过不能解释为正式申报建议。
- 复核通过不能自动触发正式库写入。
- 复核通过不能触发 n8n、企业微信真实消息、券商接口或自动交易。
