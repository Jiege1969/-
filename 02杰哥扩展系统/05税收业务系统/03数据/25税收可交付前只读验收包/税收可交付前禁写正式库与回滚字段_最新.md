# 税收可交付前禁写正式库与回滚字段

- 生成日期：2026-05-05
- 文件性质：只读验收安全约束
- 适用范围：税收可交付前验收包内的候选资料、人工复核单、边界清单、验收报告

## 一、禁写对象

| 对象 | 禁写要求 | 验收动作 |
| --- | --- | --- |
| 正式政策库 | 不得新增、修改、删除正式政策条目 | 只记录候选和复核状态 |
| 正式知识库 | 不得新增问答、解释、政策解读或业务口径 | 只记录不可判断边界 |
| 向量库 | 不得嵌入、重建、追加索引或刷新召回库 | 只登记本地路径，不做向量化 |
| 业务库 | 不得写入企业、申报、税额、客户、工单正式数据 | 只写影子验收材料 |
| 自动化系统 | 不得触发 n8n、企业微信真实消息、券商接口或自动交易 | 只做本地文件验收 |

## 二、禁写检查点

1. 产物路径必须位于允许写入范围内。
2. 文件名必须体现只读、候选、复核、边界、验收或回收，不得命名为正式库条目。
3. 表格字段不得包含可执行写库指令、接口调用地址、真实发送标志或自动交易参数。
4. 任何“通过”结论都必须附带“不写正式库”的限定。
5. 回收报告必须列明未触发 n8n、未发企业微信真实消息、未调用券商接口、未自动交易、未触碰本职工作系统。

## 三、回滚字段

| 字段 | 必填 | 说明 |
| --- | --- | --- |
| 回滚编号 | 是 | `AG-TAX-RB-YYYYMMDD-序号` |
| 关联候选编号 | 是 | 对应政策来源候选编号 |
| 关联复核单编号 | 是 | 对应人工复核单编号 |
| 回滚触发条件 | 是 | 来源失效、文号错误、时效变化、附件解析失败、人工复核不通过、越界输出、误写风险 |
| 回滚目标 | 是 | 候选清单、复核单、边界清单、验收报告或交接说明 |
| 回滚动作 | 是 | 撤回候选、降级待补证、标记阻断、补充说明、作废影子条目 |
| 回滚责任人 | 是 | 必须为人工责任人，不得由系统代填 |
| 回滚时间 | 是 | 精确到分钟 |
| 回滚原因 | 是 | 用事实描述，不写税务结论 |
| 回滚前状态 | 是 | 通过、降级待补证、阻断、待复核 |
| 回滚后状态 | 是 | 降级待补证、阻断、作废、待复核 |
| 回滚记录路径 | 是 | 只能指向影子验收路径，不得指向正式库 |

## 四、回滚样例

| 回滚编号 | 关联候选编号 | 触发条件 | 回滚动作 | 回滚后状态 |
| --- | --- | --- | --- | --- |
| AG-TAX-RB-20260505-001 | AG-TAX-CAND-20260505-001 | 时效待核验 | 降级待补证 | 降级待补证 |
| AG-TAX-RB-20260505-002 | AG-TAX-CAND-20260505-002 | 附件待解析 | 不引用附件正文 | 降级待补证 |
| AG-TAX-RB-20260505-003 | AG-TAX-CAND-20260505-005 | 非官方来源 | 标记阻断 | 阻断 |

## 五、越界处置

如发现任何材料被误用于正式库、正式申报建议、自动化发送或业务库写入，应立即：

1. 标记相关候选为阻断。
2. 在回滚字段中记录触发条件和责任人。
3. 作废相关交付前验收结论。
4. 只保留影子记录用于追溯。
5. 交由人工负责人处理，不自动修复正式库。
