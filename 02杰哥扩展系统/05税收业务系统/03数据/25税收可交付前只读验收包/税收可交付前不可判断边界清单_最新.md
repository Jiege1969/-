# 税收可交付前不可判断边界清单

- 生成日期：2026-05-05
- 清单性质：交付前只读边界清单
- 核心原则：凡不能由已登记证据直接支持的事项，一律标注不可判断、降级或阻断，不输出正式税务适用判断或正式申报建议

## 一、不可判断事项

| 边界编号 | 不可判断事项 | 触发条件 | 处理方式 |
| --- | --- | --- | --- |
| AG-TAX-BND-001 | 当前是否仍然有效 | 文件时效、废止关系、修订关系未核验 | 降级待补证，不作现行有效判断 |
| AG-TAX-BND-002 | 是否适用于特定企业 | 缺少企业行业、规模、资格、地区、纳税身份、业务事实 | 阻断正式适用判断 |
| AG-TAX-BND-003 | 是否适用于特定纳税期 | 适用期间、申报期、政策过渡期不明确 | 降级待补证 |
| AG-TAX-BND-004 | 申报表栏次和填报口径 | 缺少官方申报表说明或附件未解析 | 降级，不引用栏次 |
| AG-TAX-BND-005 | 优惠资格是否满足 | 缺少资质证书、备案、研发项目、人员、合同、票据、账册等事实证据 | 阻断正式判断 |
| AG-TAX-BND-006 | 税额测算是否可用于申报 | 缺少完整账务、发票、纳税申报表、税率、扣除比例、历史申报记录 | 阻断正式申报建议 |
| AG-TAX-BND-007 | 地方口径能否泛化 | 来源为地方官方文件或地方办税指南 | 只限登记地域，不得泛化 |
| AG-TAX-BND-008 | 官方问答能否替代条文 | 来源为问答、解读、新闻稿、办税指南 | 只能辅助说明，不作唯一正式依据 |
| AG-TAX-BND-009 | 附件正文是否可引用 | 附件待解析、解析失败、哈希缺失或未人工复核 | 降级，不引用附件正文 |
| AG-TAX-BND-010 | 用户请求是否越界 | 用户要求正式申报建议、节税方案、自动申报、代办申报 | 阻断，只输出人工处理事项 |

## 二、输出模板

```text
当前材料仅完成只读验收登记。
以下事项不可自动判断：
1. [填写不可判断事项]
2. [填写证据缺口]
3. [填写需人工复核或补证动作]

因此，本材料不构成正式税务适用判断，不构成正式申报建议，不触发正式库写入。
```

## 三、降级与阻断口径

| 类型 | 使用场景 | 输出限制 |
| --- | --- | --- |
| 降级待补证 | 证据可能补齐，但当前不足以支撑交付 | 只列补证事项，不输出结论 |
| 阻断 | 来源不合格、责任链缺失、请求越界或正式写入风险 | 停止交付，不进入后续评审 |
| 只读通过 | 字段、来源、复核、回滚均齐备 | 只代表验收材料完整，不代表正式适用 |

## 四、禁止表达

- 禁止表达“该政策一定适用”。
- 禁止表达“可以按此申报”。
- 禁止表达“建议采用某某申报方案”。
- 禁止表达“系统已写入正式库”。
- 禁止表达“已自动完成申报或通知”。
