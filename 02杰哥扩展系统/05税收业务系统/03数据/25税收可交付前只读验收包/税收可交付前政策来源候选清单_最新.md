# 税收可交付前政策来源候选清单

- 生成日期：2026-05-05
- 适用阶段：可交付前只读验收
- 清单性质：来源候选登记，不构成正式政策库、知识库、向量库或业务库写入
- 输出边界：只做候选来源、证据路径、人工复核状态和阻断条件记录，不给正式税务适用判断或正式申报建议

## 一、候选来源分级

| 来源级别 | 候选范围 | 只读验收要求 | 可交付前状态 |
| --- | --- | --- | --- |
| A1 官方正式来源 | 国家税务总局、财政部、国务院及具有正式发文权限的机关公开发布的政策文件 | 必须记录标题、文号、发文机关、发布日期、施行日期、适用期间、原文链接、本地原文路径、哈希、抓取时间 | 可进入人工复核，不直接写正式库 |
| A2 官方附件来源 | A1 文件附带的附件、表格、解读附件、申报表说明 | 必须记录附件名称、所属主文件、附件链接、附件解析状态、附件哈希、附件复核结论 | 附件未解析或复核失败时降级 |
| A3 地方官方来源 | 省市税务机关、财政部门公开发布的地方执行口径或办理材料 | 必须记录地域、发布机关、是否上位文件引用、适用地域边界 | 只能作为地方候选，不得泛化到全国 |
| B1 官方辅助来源 | 官方问答、办税指南、政策解读、新闻稿 | 必须标注辅助性质，不得替代正式政策条文 | 可辅助人工理解，不作为唯一正式依据 |
| C1 非官方来源 | 媒体、公众号、论坛、第三方数据库、培训材料、企业内部总结 | 必须标注非官方，不进入正式来源候选 | 阻断 |

## 二、候选字段

| 字段 | 必填 | 验收规则 |
| --- | --- | --- |
| 候选编号 | 是 | 采用 `AG-TAX-CAND-YYYYMMDD-序号`，不可重复 |
| 来源级别 | 是 | 只能填写 A1、A2、A3、B1、C1 |
| 来源名称 | 是 | 填写发布机关或来源站点名称 |
| 政策标题 | 是 | 与原文标题一致，不得人工改写为结论 |
| 文号 | A1/A3 必填 | 缺文号时降级为待补证；确无文号需人工说明 |
| 发文机关 | 是 | 与文号机关、网站来源一致；矛盾时阻断 |
| 发布日期 | 是 | 以原文公开日期为准 |
| 施行日期 | 是 | 不明确时降级，不得输出当前适用判断 |
| 适用期间 | 是 | 不明确时降级，不得推断纳税期适用 |
| 文件时效 | 是 | 现行、废止、部分废止、待核验；待核验时降级 |
| 原文链接 | 是 | 记录可追溯链接；跳转链接需记录最终链接 |
| 本地原文路径 | 是 | 只读登记，路径不得指向正式库 |
| 解析文本路径 | 否 | 未解析时标注待解析，不得引用解析正文 |
| 元数据路径 | 是 | 记录来源、抓取、哈希、复核状态 |
| 附件清单 | 否 | 有附件必须列明；依赖附件但未解析时降级 |
| 人工复核状态 | 是 | 待复核、复核通过、复核不通过、降级待补证、阻断 |
| 不可判断边界 | 是 | 记录不能自动判断的原因 |
| 回滚记录路径 | 是 | 记录候选撤回、降级、纠错的影子路径 |

## 四、候选进入交付前验收条件

1. 来源可追溯，原文链接、本地原文路径、元数据路径齐备。
2. 文号、机关、发布日期、施行日期、适用期间、文件时效完成初核。
3. 附件依赖关系明确，未解析附件不得被正文引用。
4. 人工复核状态不为空，复核责任链可追踪。
5. 不可判断边界和回滚记录路径已填写。
6. 明确未写正式政策库、知识库、向量库或业务库。

## 五、阻断规则

- 非官方来源阻断。
- 来源链接不可追溯阻断。
- 文号机关与发布机关矛盾阻断。
- 施行日期、适用期间、文件时效不明时降级。
- 附件依赖但附件未解析或复核失败时降级。
- 用户要求正式申报建议、节税方案或自动申报时阻断。
- 任何候选不得绕过人工复核直接写正式库。
