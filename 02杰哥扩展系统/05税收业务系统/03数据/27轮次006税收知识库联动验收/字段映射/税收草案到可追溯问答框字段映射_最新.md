```text

```

## 二、字段映射

---

## 三、税收特有字段

以下字段是税收业务特有，不能丢失，也不能被知识库通用摘要吞掉：

| 字段 | 原因 |
|:---|:---|
| 适用税种 | 影响资料范围和适用口径 |
| 企业事实条件是否齐备 | 决定是否能进入人工判断 |
| 正式依据是否全文有效 | 决定是否具备草案基础 |
| 是否存在已修改或废止文件 | 决定时效风险 |
| 附件是否已解析 | 申报表、填报说明常依赖附件 |
| 地方口径是否需要核验 | 税收适用可能存在地方差异 |
| 能否形成当前适用判断 | 只能人工复核，不由系统自动判断 |
