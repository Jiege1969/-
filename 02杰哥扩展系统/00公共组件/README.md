# 扩展系统公共组件说明

## 定位

本目录存放 02 扩展系统可复用的公共能力，不归属于某一个具体业务助手。它服务于股票、视频、文稿、税收、知识库、企业微信助手等扩展场景。

## 可放内容

- 公共数据结构、公共校验逻辑、公共模板片段。
- 多个扩展子系统共用的轻量工具。
- 只读验收、影子验证、回执整理等通用材料。
- 信息来源可信度分层、来源智能鉴别、证据链通用治理规则。

## 不可放内容

- 不放正式密钥、个人隐私原文、券商交易能力。
- 不放某一个业务系统独占的脚本；独占脚本应回到对应子系统。
- 不直接触发 n8n 正式执行、企业微信真实发送或外部交易接口。

## 维护要求

新增文件必须说明用途、触发方式、安全边界和验收口径。公共组件被两个以上子系统引用后，应在本目录或总管文档中登记依赖关系。

## 已纳入公共能力

- `01配置\信息来源可信度分层规则.json`：S1-S6 信息来源可信度分层和各业务系统适配原则。
- `02脚本\信息来源智能鉴别器.py`：离线判断 URL 来源等级、用途边界和是否需要反向追溯。
- `02脚本\验证信息来源可信度分层规则.py`：公共来源判断机制验收脚本。
- `07文档\信息来源可信度判断通用规则.md`：跨业务系统通用说明。
