# 企业微信接入设置说明

## 定位

企业微信接入设置负责把企业微信消息转入本地智能系统，并把系统结果按安全口径返回给用户。它是交互入口，不是业务中枢。

## 当前口径

当前主用方式为公网 URL 回调。历史长连接仅保留为停用记录，不作为主链路自动启动。

## 目录职责

- `01配置`：机器人身份、路由表、通道口径和权限边界。
- `02脚本`：回调入口、消息路由、助手分发、格式化回复和影子验证。
- `03数据`：路由影子报告、回执记录、验收结果。
- `04日志`：请求、响应、异常和安全阻断记录。
- `07文档`：机器人设置、故障排查、接口说明和交接材料。

## 安全边界

默认不发送正式群发消息，不主动触发外部业务动作。真实发送、n8n 正式执行、券商接口、删除数据等操作必须有单独准入和证据。

## 维护要求

新增机器人必须登记角色、入口 URL、路由目标、允许指令、禁止动作和回退方式。任何长连接恢复都必须先经过总管批准并更新当前口径。

## 运维入口

- 服务启停与健康检查见：`07文档\企业微信接入设置运维速查.md`
- 杰哥视频助理轮次012命令见：`07文档\杰哥视频助理轮次012指令速查卡.md`
- 视频助理状态变更类命令必须走 `/wecom/video-assistant`，通用 `/command` 只保留预演路由。
