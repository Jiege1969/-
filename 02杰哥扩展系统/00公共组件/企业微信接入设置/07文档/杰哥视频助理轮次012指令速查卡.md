# 杰哥视频助理轮次012指令速查卡

> 入口：`/wecom/video-assistant`  
> 本机测试：`http://127.0.0.1:19310/wecom/video-assistant?text=你的指令`  
> 公网口径：`http://43.167.210.211/wecom/video-assistant`  
> 安全边界：不真实发送企业微信、不触发n8n、不绕过人工复核、不自动真实渲染、不自动发布。

## 从想法到草案

| 你在企业微信里说 | 系统动作 | 安全状态 |
| --- | --- | --- |
| `视频想法：我想聊聊为什么人过30，交朋友就变成了一种奢侈` | 生成轮次012任务单、脚本草案、分镜草案 | 只做本地预演 |
| `查看草案` | 返回最新脚本草案和分镜草案摘要 | 不渲染、不发布 |
| `生成草案` | 基于最新任务单重新生成草案 | 不渲染、不发布 |

## 人工复核与生成放行

| 你在企业微信里说 | 系统动作 | 安全状态 |
| --- | --- | --- |
| `复核通过 VF-YYYYMMDD-001` | 将任务单状态改为复核通过 | 不渲染 |
| `驳回 VF-YYYYMMDD-001 原因：不够像我` | 将任务单状态改为已驳回，并记录原因 | 不渲染 |
| `生成放行 VF-YYYYMMDD-001` | 写入视频生成放行清单 | 不直接渲染 |
| `渲染环境修复清单` | 生成 MoneyPrinterTurbo / ImageMagick 前置环境修复建议 | 不启用真实渲染 |
| `应用渲染配置建议` | 将已验证的 MoneyPrinterTurbo / ImageMagick 路径写回配置 | 强制保持真实渲染关闭 |
| `生成预检 VF-YYYYMMDD-001` | 检查 MoneyPrinterTurbo、ImageMagick、Chrome 和生成放行状态 | 不渲染 |
| `最终启用真实渲染 VF-YYYYMMDD-001 我确认启用真实渲染` | 执行最终真实渲染启用门禁 | 只开关配置，不直接渲染 |
| `执行生成适配器 VF-YYYYMMDD-001` | 调用本地生成适配器；真实渲染未启用时只记录日志 | 当前不真实渲染 |

## 重要提醒

- 通用 `/command` 入口只做视频制作预演，不执行轮次012状态变更。
- 状态变更类指令必须走 `/wecom/video-assistant`。
- 真实渲染必须先通过 MoneyPrinterTurbo / ImageMagick / Chrome / 生成放行清单预检。
- 真实发布必须先通过视频文件、账号登录、发布放行、AI标识和最终启用门禁。
