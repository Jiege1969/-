## 巡检项

| 检查项 | 预期 |
| --- | --- |
| 19310 端口状态 | 127.0.0.1:19310 存在监听进程 |
| 19302 端口状态 | 只记录端口监听状态，不请求股票业务接口 |
| /health | 状态正常，n8n 口径为“检查项可读，真实触发关闭” |
| 工作秘书税收输入1 | `税收业务：软件产品即征即退需要准备哪些资料` 返回 `【税收分析助手-待复核草案摘要】`，事项为 `软件产品增值税即征即退` |
| 工作秘书税收输入2 | `税收业务：帮我查一下增值税法的依据` 返回 `【税收分析助手-待复核草案摘要】`，事项为 `增值税法依据` |
| 工作秘书税收输入3 | `税收业务：研发费用加计扣除需要准备哪些资料` 返回 `【税收分析助手-待复核草案摘要】`，事项为 `研发费用加计扣除` |
| 系统管家股票职责分流 | `/wecom/system-manager` 收到 `分析天齐锂业` 应转交股票助手或股票专家 |
| 工作秘书股票职责分流 | `/wecom/work-secretary` 收到 `分析天齐锂业` 应转交股票助手或股票专家 |
| 视频助理系统职责分流 | `/wecom/video-assistant` 收到 `系统现在进度多少` 应转交系统管家 |
| 股票旧口径 | 回复不得出现 `重点推荐`、`常规推荐`、`买入研究信号`、`卖出研究信号`、`加仓`、`减仓`、`满仓`、`清仓`、`仓位` |
| 视频真实渲染门禁 | `生成预检 VF-20260508-005` 和最终真实渲染门禁应保持 `blocked` |
| 视频真实发布门禁 | `发布预检` 应保持 `blocked` |
| real_send | 所有 19310 样例均应为 `false` |
| 触发 n8n | 所有 19310 样例均应为 `false` |

## 红线

- 不真实发送企业微信。
- 不接 n8n。
- 不请求 19302 股票业务接口，只确认端口状态。
- 不接券商、不交易。
- 不登录电子税务局、不接财税软件。
- 不修改总管面板。
- 不修改一键接续包。
- 不重载 19310/19302；如发现需要重载，仅登记为“需总管确认”。
