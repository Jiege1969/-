# 企业微信单样本真实发送前最终人工确认包说明

- 生成日期：2026-05-05
- 任务编号：第六批小任务W
- 所属系统：02杰哥扩展系统/00公共组件/企业微信接入设置
- 对应数据：`03数据/17真实发送前最终人工确认包`
- 执行模式：final_manual_confirmation_package_only_no_send

## 本轮目标

本轮生成企业微信单样本真实发送前的最终人工确认包字段，覆盖白名单、消息预览、回滚、监控、人工确认人、确认时间和禁发条件，并输出 5 个离线样本用于验收。

## 确认包口径

| 模块 | 口径 |
| --- | --- |
| 白名单 | 必须命中用户、助手、场景、消息类型和单样本上限；不命中立即禁发 |
| 消息预览 | 人工确认前只能生成预览，不允许携带 response_url/Webhook/n8n 可执行链路 |
| 回滚 | 任一禁发条件命中即 block_all，并保持不发送状态 |
| 监控 | 只做离线发送前检查，external_call_count 必须为 0，real_send_attempted 必须为 false |
| 人工确认人 | 必须由真实人工确认人手工填写，不由样本伪造 |
| 确认时间 | 必须由人工确认时手工填写；本轮样本使用 PENDING 或 BLOCKED 标记 |
| 禁发条件 | 白名单、预览变更、外部触发、正式写入、券商接口、自动交易、人工确认缺失均为硬阻断 |

## 五个样本设计

| 样本 | 目标 | 预期 |
| --- | --- | --- |
| W-001 | 验证白名单命中且预览完整时的最终确认字段 | 不发送，等待人工确认人和确认时间 |
| W-002 | 验证白名单不命中 | block_all 禁发 |
| W-003 | 验证消息预览含交易指令 | block_all 禁发 |
| W-004 | 验证人工确认人或确认时间缺失 | block_all 禁发 |
| W-005 | 验证 response_url/Webhook/n8n 标记 | block_all 禁发，且不触发外部链路 |

## 使用说明

该确认包不是发送授权，也不是自动发送入口。即使样本 W-001 字段完整，也仍处于 pending_human_confirmation 状态；只有真实人工确认人在正式流程中填写确认人和确认时间后，才可进入后续人工审核流程。本轮交付不包含后续发送执行。

## 安全边界

- 不真实发送企业微信。
- 不触发 response_url/Webhook。
- 不触发 n8n。
- 不写正式库、正式向量库、旧系统或本职工作系统。
- 不调用券商接口。
- 不自动交易、下单或撤单。
- 不改动发送配置、正式白名单或生产路由。
