# 企业微信灰度监控读取与回滚演练说明

- 生成日期：2026-05-05
- 任务编号：第五批小任务S
- 所属系统：02杰哥扩展系统/00公共组件/企业微信接入设置
- 对应数据：`03数据/16灰度监控读取与回滚演练样本`
- 执行模式：shadow_only_offline_read

## 本轮目标

本轮只形成企业微信灰度监控读取与回滚演练样本，覆盖监控读取、失败阈值、回滚动作和审计记录。所有样本均为离线 shadow 样本，不真实发送企业微信，不触发 response_url/Webhook/n8n，不写正式库。

## 演练口径

| 模块 | 口径 |
| --- | --- |
| 监控读取 | 只读取本地离线样本字段，read_mode 固定为 offline_shadow_snapshot_only |
| 失败阈值 | failure_count 达到 2 进入预警，达到 3 触发回滚；response_url/Webhook/n8n 等硬边界阈值为 0 |
| 回滚动作 | block_all、冻结灰度样本窗口、停止扩量、要求人工复核、写离线审计 |
| 审计记录 | 每个样本必须有 audit_record_id、decision、block_reason、created_at、created_by |

## 五个样本

| 样本 | 目标 | 预期 |
| --- | --- | --- |
| S-001 正常shadow | 白名单命中、字段完整、无外部触发 | 只保留影子读取，不回滚 |
| S-002 失败阈值预警 | failure_count 达到预警阈值 2 | 冻结扩量并人工复核，不进入真实发送 |
| S-003 回滚触发 | failure_count 达到回滚阈值 3 | block_all 并记录离线审计 |
| S-004 response_url请求阻断 | 读取到 response_url_present=true | block_all，不调用 response_url/Webhook |
| S-005 n8n请求阻断 | 读取到 n8n_requested=true | block_all，不触发 n8n |

## 安全边界

- 企业微信真实发送保持禁用。
- response_url、Webhook、n8n 保持禁用。
- 只写入 `03数据/16灰度监控读取与回滚演练样本`、`07文档` 和固定回收报告。
- 不写正式库、正式向量库、旧系统或本职工作系统。
- 不调用券商接口，不自动交易，不下单，不撤单。

## 使用说明

本产物用于人工检查灰度监控读取字段和回滚演练字段是否齐备，不是执行器，不是发送器，不构成任何真实放量、自动化调用或交易授权。
