> 生成时间：2026-05-08 06:39:18 +08:00

## 一句话定位

企业微信接入层只回答三件事：

```text
消息从哪里来 -> 应该转给谁 -> 什么动作不能做
```

它不回答：

```text
这个业务应该怎么判断、怎么决策、怎么最终执行
```

## 允许职责

| 类别 | 可以做什么 | 边界 |
|---|---|---|
| 通讯接入 | 登记企业微信 URL、Token/AESKey 引用、回调路径、端口 | 不直接暴露密钥，不替业务系统做判断 |
| 路由转发 | 根据机器人终端和消息类型转到对应业务系统 | 不新增业务 if/else，不改业务结论 |
| 安全闸门 | 统一拦截真实发送、n8n、交易、自动发布、真实税务办理等动作 | 禁令只能收紧，不能绕过 |
| 日志追溯 | 记录入口、路由、预演状态、异常和回滚边界 | 不写正式业务结论库 |
| 健康检查 | 检查入口是否可用、路由是否能预演、配置是否可解析 | 不启动或重启正式服务 |
| 兜底澄清 | 无法识别时提示澄清或转人工 | 不擅自替用户做业务选择 |

## 禁止职责

| 禁止项 | 原因 | 应回到哪里 |
|---|---|---|
| 判断股票买卖、仓位、交易动作 | 涉及投资决策和交易边界 | 股票研究系统 + 人工判断 |
| 判断税务适用、金额、申报路径 | 涉及正式税务意见和办理风险 | 税收业务系统影子分析 + 人工复核 |
| 判断视频是否可发布 | 涉及平台发布、素材授权和外发风险 | 视频制作系统复核链路 |
| 判断系统总体进度和施工优先级 | 会与总管系统抢权 | 00杰哥系统总管 |
| 自动触发 n8n、企业微信真实发送、服务重启 | 属真实系统动作或外发 | W2/W3 暂停确认 |
| 维护另一套机器人业务职责最终解释权 | 会变成第 6 个业务中枢 | 各业务系统自己的登记口径 |
