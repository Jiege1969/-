# 企业微信单样本灰度前置预案说明

- 生成日期：2026-05-05
- 任务编号：第三批小任务H
- 执行模式：shadow_only
- 适用范围：02杰哥扩展系统/06企业微信助手系统

## 前置预案范围

本预案只生成灰度条件、白名单字段、回滚字段和监控字段。它不是发送器，不调用企业微信接口，不触发 response_url、Webhook 或 n8n。

## 字段清单

| 类别 | 字段 | 要求 |
| --- | --- | --- |
| 灰度条件 | 单样本模式 | 仅允许 1 条离线样本进入前置判定 |
| 灰度条件 | 白名单命中 | 发送对象、机器人标识、场景编号必须全部命中 |
| 灰度条件 | 人工复核 | 只产出允许/阻断判定，不代替人工发送 |
| 白名单字段 | allowed_user_ids | 仅保留 shadow_user_only |
| 白名单字段 | allowed_bot_keys | 仅保留 shadow_bot_only |
| 白名单字段 | allowed_scene_ids | 仅保留 H_SINGLE_SAMPLE_PRECHECK |
| 白名单字段 | allow_real_send | 固定为 false |
| 白名单字段 | allow_response_url | 固定为 false |
| 白名单字段 | allow_n8n | 固定为 false |
| 回滚字段 | rollback_mode | 固定为 block_all |
| 回滚字段 | rollback_trigger_fields | 包含白名单未命中、样本超量、真实发送请求、response_url、Webhook、n8n、人工复核缺失、监控异常 |
| 监控字段 | send_attempt_count | 必须为 0 |
| 监控字段 | external_call_count | 必须为 0 |
| 监控字段 | real_send_requested | 必须为 false |
| 监控字段 | response_url_present | 必须为 false 才能允许前置 |
| 监控字段 | n8n_requested | 必须为 false |

## 离线样本

1. 企业微信单样本允许前置：白名单命中，只允许进入人工复核前置，不允许真实发送。
2. 企业微信真实发送阻断：出现真实发送或 response_url 请求时立即回滚到 block_all。

## 安全边界

- 不真实发送企业微信消息。
- 不触发 response_url、Webhook 或 n8n。
- 不调用券商接口，不自动交易，不下单。
- 不写正式库、旧系统、数据库或向量库。
