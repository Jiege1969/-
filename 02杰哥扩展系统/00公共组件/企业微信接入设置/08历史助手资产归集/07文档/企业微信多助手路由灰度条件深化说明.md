# 企业微信多助手路由灰度条件深化说明

本说明对应 `03数据/13多助手路由灰度条件深化` 的离线产物。

## 本轮结论

多助手统一路由只允许继续影子验证，不允许正式放量。股票单人受控发送证据不能复用为总管助手、知识库助手、进化规则助手或默认兜底助手的真实发送授权。

## 五类助手

- 股票助手：只分析不交易；交易意图优先拦截。
- 总管助手：只读总管确认来源；不改进度口径。
- 知识库助手：必须带证据片段和引用路径；证据不足则降级。
- 进化规则助手：只生成候选规则草案；不自动固化。
- 默认兜底助手：只追问一次；不自动学习归档。

## 禁止事项

- 不真实发送企业微信。
- 不触发 Webhook 或 n8n。
- 不调用券商接口。
- 不自动交易或下单。
- 不写正式库、正式向量库、旧系统或总管正式口径。
