# 企业微信多助手灰度监控与回滚字段深化说明

- 生成日期：2026-05-05
- 任务编号：第四批小任务N
- 所属系统：02杰哥扩展系统/06企业微信助手系统
- 对应数据：`03数据/15多助手灰度监控与回滚字段深化`
- 执行模式：shadow_only

## 本轮结论

企业微信多助手灰度继续保持影子验证。本轮只补齐白名单、样本计数、失败阈值、回滚触发和审计记录字段，不扩大为真实发送，不触发 response_url/Webhook/n8n。

## 深化字段

| 类别 | 字段 | 要求 |
| --- | --- | --- |
| 白名单 | whitelist_id、allowed_user_ids、allowed_bot_keys、allowed_scene_ids、allowed_message_types、allowed_sample_count | 全部命中才允许进入人工复核前置 |
| 样本计数 | sample_count、sample_count_limit、current_sample_count | 超过上限立即阻断 |
| 失败阈值 | whitelist_miss_max、sample_count_over_limit_max、response_url_present_max、n8n_requested_max、external_call_count_max | 任一阈值触发即回滚 |
| 回滚触发 | rollback_mode、rollback_trigger_policy、rollback_trigger_fields、rollback_action | 默认 block_all，只记录阻断原因 |
| 审计记录 | audit_record_id、decision、block_reason、rollback_mode、external_call_count、created_at | 只写离线审计记录 |

## 回滚策略

回滚模式固定为 `block_all`。以下任一条件出现，即阻断该样本并记录审计：

- 白名单不命中。
- 样本数超过 allowed_sample_count。
- 请求真实发送企业微信。
- 携带或请求 response_url/Webhook。
- 请求 n8n。
- 外部调用次数大于 0。
- 写正式库、正式向量库或旧系统。
- 缺少人工复核标记。
- 监控字段缺失或异常。

## 样本覆盖

| 样本 | 覆盖目标 | 预期 |
| --- | --- | --- |
| N-001 允许前置 | 白名单命中、样本计数正常、失败阈值为 0 | 只允许进入人工复核前置 |
| N-002 白名单不命中 | whitelist_miss | 阻断并 block_all |
| N-003 超样本数 | sample_count_over_limit | 阻断并 block_all |
| N-004 response_url阻断 | response_url_present | 阻断并 block_all，不触发 |
| N-005 n8n阻断 | n8n_requested | 阻断并 block_all，不触发 |

## 禁用项

- 企业微信真实发送：禁用。
- response_url：禁用。
- Webhook：禁用。
- n8n：禁用。
- 正式库和正式向量库：禁用。
- 券商接口、自动交易、下单：禁用。
- 本职工作系统：不触碰。
