## 三、内容处理特有字段

以下字段必须保留，不能被知识库通用摘要吞掉：

| 字段 | 原因 |
|:---|:---|
| 原文路径 | 决定能否追溯来源 |
| 来源说明 | 决定是否允许生成草案 |
| 授权状态 | 决定是否能用于发布或复用 |
| 目标用途 | 决定改写风格和风险 |

| 是否允许真实转换 | 默认 false，需另行审批 |
