## 四、输入边界

允许输入：

1. `03数据\01素材入口` 内的本地素材文件。
2. `01配置` 内的本模块配置文件。
3. `03数据` 内上游已经生成的索引、计划、预演、门禁和状态摘要文件。

限制输入：

1. 不直接读取正式业务库或旧系统库作为处理输入。
2. 不接入税收业务数据。
3. 不接收 n8n webhook、企业微信回调、外部 HTTP 推送作为自动输入。
4. 未经人工登记的股票、交易、账户、券商接口、买卖信号类内容不得进入自动处理链路。

## 五、输出边界

允许输出：

1. `03数据\02登记索引`：素材索引 JSON。
2. `03数据\03批处理计划`：批处理计划 JSON。
3. `03数据\04转换预演`：转换预演 JSON。
4. `03数据\05本地转换门禁`：门禁与禁用态检查 JSON。
5. `03数据\06状态摘要`：状态摘要 JSON/Markdown。
6. `04日志`：验收日志 JSON。
7. `07文档`：盘点报告、影子预案、验收报告。

禁止输出：

1. 覆盖、删除、移动、改写任何源素材或真实业务文档。
2. 写入正式库、旧系统或跨系统业务目录。
3. 外发转换结果。
4. 触发 n8n。
5. 真实发送企业微信。
6. 生成或传递可触发股票自动交易的指令、webhook、脚本、账号接口参数或买卖执行信号。

## 六、股票自动交易屏蔽硬闸门继承

本系统继承股票自动交易屏蔽硬闸门，作为高于内容处理任务的全局约束：

1. 涉及股票、证券、账户、券商、买入、卖出、止盈、止损、仓位、自动下单、量化交易、交易 webhook、交易 API 的内容，默认进入人工复核，不进入自动处理和外发链路。
2. 本系统不得生成、改写、排版或转发用于自动下单的结构化指令。
3. 本系统不得把内容处理结果连接到 n8n、券商接口、交易脚本、企业微信自动推送或任何可导致交易执行的通道。
4. 即使素材本身通过格式校验，只要命中交易执行意图，也必须阻断真实处理，仅允许形成本地只读风险登记。
