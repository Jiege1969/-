# 内容处理系统设计

创建日期：2026-04-26

## 一、定位

内容处理系统负责通用文本、图文、报告和多平台内容处理。

## 二、第一阶段能力

1. 长文摘要。
2. 改写润色。
3. 结构化提纲。
4. 报告整理。
5. 图文报告文案。

## 三、第二阶段能力

1. 多平台发布格式适配。
2. 海报文案。
3. 视频文案联动。
4. 图片理解辅助。
5. 图片生成联动。

## 四、依赖

| 能力 | 来源 |
|---|---|
| 模型路由 | 01主系统 |
| 知识库 | 01主系统 |
| 视频素材 | 02视频制作系统 |
| 推送 | 01主系统统一消息出口 |

## 五、边界

内容处理系统不直接管理企业微信和模型服务。
