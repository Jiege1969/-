# P2_REAL_MATERIAL_INTAKE_GATE_001 真实材料接入分流门

- 生成时间：2026-05-09
- 所属阶段：P2-S4
- 所属层级：扩展系统孵化区横向能力
- 状态：只读分流门，不是自动处理入口

## 一、目的

当用户后续提供真实脱敏材料时，系统必须先经过本分流门，再进入税收、本职工作、视频或共享政策证据影子入口。分流门的职责不是生成业务结论，而是判断材料能不能进入影子、进入哪条影子线、是否必须暂停等待人工确认。

## 二、分流字段

| 字段 | 要求 |
|:---|:---|
| material_id | 待生成 |
| source_type | 用户提供 / 官方公开 / 历史样例 / 人工经验 / 待核验 |
| source_path_or_url | 待填写；不主动扫描未指定目录 |
| authorization_status | 已授权 / 仅参考 / 禁止使用 / 待确认 |
| sensitivity | 无敏感 / 财务 / 人事 / 合同 / 客户 / 素材版权 / 账号 / 待判 |
| desensitized_status | 已脱敏 / 未脱敏 / 不适用 / 待确认 |
| target_line | tax / office_work / video_production / shared_policy_evidence / pause |
| can_enter_shadow | 是 / 否 / 待确认 |
| human_review_required | 是 |
| next_allowed_action | 登记资料 / 生成待复核草案 / 只记录缺口 / 暂停 |

## 三、分流规则

| 条件 | 结果 |
|:---|:---|
| 未授权、禁止使用、来源不清 | `target_line=pause`，只记录缺口 |
| 含财务、人事、合同、客户、账号等敏感内容且未脱敏 | `target_line=pause`，只记录脱敏缺口 |
| 请求申报、开票、退税、交易、审批、上传、发布、外发 | `target_line=pause`，进入红线阻断 |
| 税收政策或涉税业务分析材料 | 进入 `TAX_DAILY_INTAKE_002`，不得直接生成正式税务意见 |
| 制度、流程、台账字段、办公资料 | 进入 `OFFICE_SHADOW_002`，不得连接真实办公系统 |
| 脚本、分镜、素材授权、平台规范 | 进入 `VIDEO_P2_REVIEW_CHAIN_NEXT_001`，发布门禁保持关闭 |
| 政策依据候选或公开政策来源 | 进入 `P2_SHARED_POLICY_READONLY_NEXT_001`，不得替代业务线判断 |

## 四、禁止动作

- 不触发 n8n。
- 不发送企业微信。
- 不写正式库。
- 不主动扫描用户未指定目录。
- 不复制真实敏感资料。
- 不申报、不开票、不退税。
- 不交易、不调用券商接口。
- 不连接 OA、ERP、财务、人事系统。
- 不渲染、不上传、不发布视频。

```powershell

```

检查通过后，仍只能进入对应影子入口卡；没有人工复核前不得声明正式能力。
