# 共享政策证据只读调用样例通用模板

> 版本：v1.0  
> 日期：2026-05-07  
> 资产身份：扩展系统内部政策证据只读调用样例模板  
> 风险等级：W1  
> 边界：模板，不是生产接口，不接 n8n，不外发，不写库。  

## 一、用途

本模板用于后续新增业务线或新场景时，快速生成“只读调用政策证据”的影子样例。

它解决的问题是：调用方可以读取证据，但不能把证据直接写成业务结论；必须保留来源、层级、状态、风险和禁止用途。

## 二、样例头部

```text
# 共享政策证据只读调用样例 {SYSTEM} {编号}：{主题}

> 版本：v1.0
> 日期：YYYY-MM-DD
> 资产身份：{业务系统}只读政策证据调用影子样例
> 风险等级：W1
> 边界：只读样例，不写库，不外发，不接 n8n，不触发真实业务动作。
```

## 三、调用输入

| 字段 | 内容 |
|:---|:---|
| requesting_system | 待填 |
| query_intent | 待填 |
| topic_keywords | 待填 |
| expected_evidence_level | 待填 |
| source | 待填 |
| business_context | 可脱敏填写；没有则写待补 |

## 四、只读证据返回

| 字段 | 内容 |
|:---|:---|
| evidence_id | 待填 |
| title | 待填 |
| document_number | 待填或无 |
| issuing_authority | 待填 |
| evidence_level | 必填；未知则写待补 |
| validity_status | 必填；未知则写 pending_review |
| source_url | 官方链接或无 |
| source_path | 本地来源路径 |
| extracted_conditions | 适用条件摘录或待补 |
| topic_tags | 待填 |
| risk_flags | 必填；没有风险也要说明无已知风险但待复核 |

## 五、业务内解释

| 字段 | 内容 |
|:---|:---|
| allowed_use | 证据可用于什么 |
| forbidden_use | 证据不能用于什么 |
| output_state | draft / pending_review / evidence_ready / human_reviewed |
| review_questions | 人工复核问题 |
| next_action | 下一步补证据、补资料或复核 |

## 六、禁止事项

- 不把证据写成正式结论。
- 不省略 evidence_level。
- 不省略 validity_status。
- 不把 pending_review 写成 confirmed。
- 不写入、覆盖、删除政策库或业务库。
- 不触发 n8n、企业微信、外发、发布、交易或审批。

## 七、验收标准

| 验收项 | 标准 |
|:---|:---|
| 只读 | 只读取证据，不写库 |
| 保真 | 保留来源、层级、状态 |
| 不越权 | 不生成正式结论 |
| 可复核 | 有 review_questions |
| 可接续 | 有 next_action |
