# P2-S13 影子入口填写差异预览规则

> 状态：只读差异预览规则，不是写入器。
> 日期：2026-05-09
> 边界：不读取真实材料，不写影子入口，不触发外部动作。

## 目的

P2-S12 已确认 4 份候选可以进入人工填写讨论。P2-S13 只生成填写差异预览，让人工看到目标入口哪些字段可能被填写、哪些字段必须保持不变、哪些字段仍然需要等待真实脱敏材料。

## 硬规则

- 只允许读取 P2-S12 闸口预演样例和目标入口空白 JSON。
- 只允许输出差异预览包。
- 不允许覆盖目标入口。
- 不允许把占位建议当成真实材料。
- 不允许生成正式业务结论。
- 不允许触发 n8n、企业微信、正式库或任何真实业务动作。

## 差异类型

| 类型 | 含义 |
|:---|:---|
| `candidate_placeholder` | 可由人工基于真实脱敏材料填写，目前仅生成占位建议 |
| `must_remain_false` | 红线或正式能力字段必须保持 false |
| `must_remain_pending` | 仍需待复核、待人工确认或待补 |
| `must_not_change` | 系统身份、编号、边界字段不得改变 |

## 通过条件

- 只为 `fill_candidate_gate_pass` 的候选生成差异预览。
- 暂停或红线阻断项不得生成业务入口差异。
- 所有差异必须 `preview_only=true`。
- 所有差异必须 `write_target_entry=false`。
- 所有红线字段必须保持 false。
