# 影子底座统一人工闸口清单

> 版本：v1.0
> 状态：人工闸口草案，不是自动审批规则
> 边界声明：不接 n8n，不接企业微信，不写正式库，不触发真实业务动作。

## 1. 必须人工确认的动作

| 类别 | 触发动作 | 处理 |
|:---|:---|:---|
| 正式开工 | 从影子样例进入正式业务系统 | 暂停，重新执行开工五问 |
| 真实系统接入 | OA、ERP、电子税务局、发布平台、企业微信 | 暂停，人工确认 |
| 外发发布 | 发送、推送、报送、发布、上传、通知 | 暂停，人工确认 |
| 写正式库 | 写业务库、账本、正式台账、生产配置 | 暂停，人工确认 |
| 批量处理 | 批量读取、批量删除、批量转换、批量渲染 | 暂停，先做R0审计 |
| 敏感资料 | 财务、人事、合同、客户、素材版权、账号信息 | 暂停，确认授权和脱敏 |

## 2. 各业务线特殊闸口

| 业务线 | 特殊闸口 |
|:---|:---|
| 税收业务 | 申报、退税、备案、开票、登录电子税务局、给出确定金额 |
| 本职工作业务 | 提交审批、盖章、报送、发送正式材料、读取真实办公系统 |
| 视频制作业务 | 读取真实素材、剪辑、转码、渲染、生成字幕/封面/配音、发布 |

## 3. 闸口输出格式

```text
人工闸口提醒
- 触发动作：
- 初判风险：
- 涉及业务线：
- 必须确认：
- 可继续做的影子动作：
```

## 4. 可继续做的动作

- 需求澄清。
- 只读核查公开资料。
- 草案整理。
- 待补项标注。
- 脱敏样例结构设计。

## 5. 禁止绕行

- 不能把“影子”写成“正式可用”。
- 不能把“设计草案”变成“生产脚本”。
- 不能把“用户授权”当成长期通用授权。
