## 用途

当用户要求“生成视频”“出片”“开始渲染”时，本卡用于检查真实渲染放行前还缺什么，而不是直接执行渲染。

## 缺口字段

| 字段 | 要求 | 缺口处理 |
|---|---|---|
| 任务ID | 必须明确 | 缺失则澄清 |
| 脚本草案版本 | 必须人工确认 | 未确认则退回文案门禁 |
| 分镜草案版本 | 必须人工确认 | 未确认则退回分镜门禁 |
| 素材授权证明 | 必须完整 | 缺失则阻断 |
| 音色/配音授权 | 必须确认 | 未确认则阻断 |
| 字幕/画幅参数 | 必须明确 | 缺失则待补 |
| 生成放行状态 | 必须已单独放行 | 未放行则不能谈真实渲染 |
| 真实渲染放行状态 | 必须已单独放行 | 未放行则保持待确认 |
| 失败回滚路径 | 必须存在草案回退路径 | 缺失则待补 |

## 输出结论

- 真实渲染放行缺口已关闭：只代表可交总管判断是否进入 W3。
- 真实渲染放行缺口未关闭：保持待人工复核。
- 命中素材或授权阻断：不得进入真实渲染。
