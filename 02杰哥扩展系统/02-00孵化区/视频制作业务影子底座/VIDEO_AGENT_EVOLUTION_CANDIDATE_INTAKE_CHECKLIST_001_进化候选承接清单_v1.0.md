# VIDEO_AGENT_EVOLUTION_CANDIDATE_INTAKE_CHECKLIST_001_进化候选承接清单_v1.0

> 资产身份：视频创作智能体影子层进化候选承接清单
> 阶段：W1/R0
> 状态：候选清单，不是正式规则升级
> 边界：只列候选，不写正式规则库，不覆盖旧经验。

## 使用场景

当人工回执、修正流转或红线登记中出现可复用经验时，使用本清单判断是否可以进入进化候选。进入候选不代表已验证，更不代表正式规则。

## 承接字段

| 字段 | 示例值 | 说明 |
|:---|:---|:---|
| 候选ID | `VAI-EVO-CAND-0000` | 影子候选编号 |
| 来源类型 | 待填写 | 人工回执/修正流转/红线登记/复盘 |
| 来源文件 | 待填写 | 仅引用影子目录文件 |
| 可复用经验摘要 | 待填写 | 简短摘要 |
| 适用场景 | 待填写 | 例如开场优化、素材授权、AI标识、平台规范 |
| 不适用场景 | 待填写 | 避免过度泛化 |
| 证据数量 | 待填写 | 单案例/多案例 |
| 人工复核状态 | `pending_review` | 未复核不得升级 |
| 多案例验证状态 | `not_started` | 未验证不得升级 |
| 升级建议 | `keep_as_candidate` | 默认保持候选 |

## 升级限制

1. 单案例经验只能进入候选池。
2. 未经多案例验证不得升级正式规则。
3. 候选经验不得跨系统直接复用到税务、股票或其他业务线。
