# VIDEO_AGENT_PRE_PUBLISH_BLOCKER_CLOSE_CONDITION_001 发布前阻断关闭条件清单 v1.0

- 资产类型：阻断关闭条件清单
- 施工等级：W1/R0
- 适用范围：发布前阻断项、四件套缺口、多平台差异检查缺口
- 状态：草案

## 目的

定义发布前阻断项什么时候可以在影子层关闭，防止“有人回复了”就被误判为“可以发布”。

## 关闭条件

| 阻断类型 | 关闭条件 | 关闭证明 | 关闭后状态 | 是否自动发布 |
|---|---|---|---|---|
| 成品预览未复核 | 成品预览复核回执为通过 | 回执编号 | preview_review_passed_shadow | 否 |
| AI 标识未确认 | AI 标识确认回执为已确认 | 回执编号 | ai_label_confirmed_shadow | 否 |
| 素材授权缺失 | 授权证明回执为通过且已归档 | 回执编号 | material_authorized_shadow | 否 |
| 发布放行缺失 | 发布放行确认回执为放行 | 回执编号 | publish_release_confirmed_shadow | 否 |
| 平台规则缺失 | 平台规则复核完成 | 复核记录编号 | platform_rule_checked_shadow | 否 |
| 多平台检查未完成 | 每个平台均有独立检查回执 | 回执清单 | platform_checks_complete_shadow | 否 |
| 红线阻断 | 总管明确解除或改为可复核缺口 | 总管判断记录 | manager_review_required | 否 |

## 固定规则

1. 阻断关闭只代表影子阻断项关闭，不代表真实发布。
2. 关闭证明必须可追溯到回执或总管判断记录。
3. 任一关闭证明缺失，阻断项保持开启。
4. 红线阻断不能由业务线自行关闭。

## 边界

本清单不关闭真实系统任务、不写正式库、不触发发布。
