# VIDEO_AGENT_CLARIFICATION_TEMPLATE_001 澄清问题模板

> 版本：v1.0  
> 生成时间：2026-05-08 09:55:00 +08:00  
> 资产身份：视频创作智能体 W1/R0 澄清问题模板  
> 风险等级：W1/R0  
> 边界声明：只定义无法判断或高风险输入时的澄清问题模板，不调用模型 API，不接企业微信真实消息，不启动服务，不生成真实媒体，不发布，不触发 n8n。

## 为什么不能用现有文件扩展

意图路由表已经列出“无法判断时澄清一次”，但没有规定澄清问题怎么写、问什么、问到什么程度。澄清问题模板需要单独存在，防止系统在信息不足时连环追问，或在高风险指令下直接执行。

## 它让系统更会做什么

- 更会在信息不足时只问最关键的一问。
- 更会把高风险指令转成门禁确认，而不是执行。
- 更会把用户的含混表达变成可进入会话状态契约的字段。
- 更会避免连续追问造成体验负担。

## 澄清场景

| 场景 | 触发条件 | 澄清问题模板 | 后续路由 |
|:---|:---|:---|:---|
| 目标不清 | 只有主题，没有用途或平台 | 这条视频你更想做成“知识讲解、故事演绎、观点评论”哪一种？ | 会话状态契约 |
| 平台不清 | 没有目标平台 | 目标平台先按哪个来设计：B站、抖音、小红书、视频号，还是先不定平台？ | 会话状态契约 |
| 修改范围不清 | 只说“改一下” | 你想优先改标题、开头、正文、分镜、旁白，还是整体风格？ | 局部修正契约 |
| 素材风险 | 涉及真人、品牌、音乐、影视片段 | 这些素材是否有授权，是否可以只先做文字分镜不读取素材？ | 素材授权门禁 |
| 生成风险 | 用户要求“直接生成” | 先确认：当前只做生成预检，不真实渲染，可以吗？ | 生成放行门禁 |
| 发布风险 | 用户要求“直接发” | 先确认：这句话只进入发布预检，不会自动发布，可以吗？ | 发布放行门禁 |
| 多意图冲突 | 同时要求改稿、生成、发布 | 我先处理哪一步：改稿、生成预检，还是发布预检？ | 意图路由 |

## 规则

1. 每次最多澄清一个问题。
2. 问题必须能把输入转成一个或多个契约字段。
3. 命中生成、发布、素材、平台账号、企业微信真实外发或 n8n 时，澄清只进入门禁，不执行动作。
4. 用户不回答时，保持 `pending_clarification`，不继续推进。
