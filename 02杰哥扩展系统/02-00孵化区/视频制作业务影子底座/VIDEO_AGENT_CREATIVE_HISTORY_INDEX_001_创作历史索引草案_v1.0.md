# VIDEO_AGENT_CREATIVE_HISTORY_INDEX_001 创作历史索引草案

> 生成时间：2026-05-08 09:55:00 +08:00  
> 资产身份：视频创作智能体 W1/R0 创作历史索引草案  
> 风险等级：W1/R0  
> 边界声明：只定义会话、草案、复核、门禁和进化候选之间的索引字段；不写向量库，不接真实 LLM 记忆库，不读取真实素材，不改正式视频系统脚本，不触发渲染、发布、企业微信真实外发或 n8n。

## 为什么不能用现有文件扩展

现有索引文件记录“有哪些资产”，轮次012链路快照记录“一个任务走到了哪里”。创作历史索引要记录跨会话、跨草案、跨复核回执、跨进化候选的关系，属于视频智能体记忆前的结构化底座，不能和资产总索引或单任务状态快照混在一起。

## 它让系统更会做什么

- 更会记住用户前后几次创作草案之间的关系。
- 更会追踪某个想法如何变成脚本、分镜、复核和候选经验。
- 更会在后续对话中只读参考历史，而不是直接覆盖旧草案。
- 更会把“可复用经验”保持在候选层，等待多案例验证。

## 索引字段

| 字段 | 类型 | 必填 | 说明 |
|:---|:---|:---:|:---|
| 历史索引ID | string | 是 | 创作历史索引唯一编号 |
| 会话ID | string | 是 | 对应会话状态契约中的会话ID |
| 用户想法摘要 | string | 是 | 脱敏后的原始想法摘要 |
| 关联任务ID | string | 否 | 如 VF-YYYYMMDD-001 |
| 关联草案ID | list | 是 | 文案、分镜、标题、封面等草案编号 |
| 关联复核包ID | list | 是 | 人工复核工作包或清单编号 |
| 关联回执ID | list | 是 | 人工回执、修正验收回执编号 |
| 关联候选经验ID | list | 是 | 进化候选编号 |
| 当前阶段 | string | 是 | idea / draft / review / revision / candidate / archived |
| 可复用标签 | list | 是 | 主题、平台、风格、结构等标签 |
| 不可复用原因 | list | 是 | 版权、素材授权、平台规则、质量不足等 |
| 只读引用路径 | list | 是 | 历史文件路径，只读引用 |
| 待人工确认项 | list | 是 | 需要人工决定是否继续使用的内容 |

## 使用规则

1. 索引只保存关系和摘要，不保存真实素材、凭据、平台账号或隐私信息。
2. 历史记录只能作为只读参考，不得自动覆盖当前草案。
3. 候选经验未通过多案例验证前，不得进入正式规则。
4. 命中版权、隐私、平台规则或授权不清时，必须进入待人工确认项。
