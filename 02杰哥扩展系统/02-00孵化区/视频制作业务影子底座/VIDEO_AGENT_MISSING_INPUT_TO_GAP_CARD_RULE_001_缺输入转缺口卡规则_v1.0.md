# VIDEO_AGENT_MISSING_INPUT_TO_GAP_CARD_RULE_001 缺输入转缺口卡规则 v1.0

- 资产类型：连续施工规则
- 施工等级：W1/R0
- 适用范围：视频制作线连续自动施工
- 状态：草案

## 规则目的

当缺少关键上下文时，不把“缺输入”当成停工理由；如果缺口可以被结构化表达，就自动转为缺口卡、待复核问题或占位模板。

## 转换表

| 缺少内容 | 自动转换产物 | 是否继续施工 |
|---|---|---|
| 缺用户原始想法 | 输入条件缺口卡 | 是 |
| 缺平台规则链接 | 平台规则待复核问题卡 | 是 |
| 缺素材授权 | 素材授权缺口卡 | 是 |
| 缺成品预览 | 成品预览待复核卡 | 是 |
| 缺 AI 标识确认 | AI 标识确认回执模板 | 是 |
| 缺发布平台选择 | 发布目标缺口卡 | 是 |
| 缺真实账号或 Cookie | 红线阻断登记 | 否，不实施 |
| 缺真实 API Key | 红线阻断登记 | 否，不实施 |

## 固定边界

缺口卡只能表达“还缺什么”和“需要谁复核”，不能自动补真实账号、真实素材、真实配置或平台授权。
