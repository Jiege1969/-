# VIDEO_AGENT_PRE_PUBLISH_GATE_FINAL_OVERVIEW_001 发布前门禁最终总览卡 v1.0

- 资产类型：门禁总览卡
- 施工等级：W1/W2 低风险影子施工
- 适用范围：视频发布前最终人工门禁总览
- 状态：草案

## 目的

把发布前所有关键门禁放到一张卡里，供人工复核时一眼判断“为什么还不能发布”或“是否可以提交总管判断”。该卡不执行发布。

## 总览门禁

| 门禁 | 必要证明 | 当前默认状态 | 未通过处理 |
|---|---|---|---|
| 生成放行 | 生成放行清单或回执 | 待确认 | 回到生成放行复核 |
| 真实渲染放行 | 渲染放行清单或回执 | 待确认 | 回到渲染放行复核 |
| 成品预览 | 成品预览复核回执 | 待确认 | 回到成品预览复核队列 |
| AI 标识 | AI 标识确认回执 | 待确认 | 回到发布合规复核队列 |
| 素材授权 | 素材授权证明回执 | 待确认 | 回到素材授权复核队列 |
| 多平台检查 | 每个平台独立检查回执 | 待确认 | 回到平台差异复核 |
| 发布放行 | 发布放行确认回执 | 待确认 | 回到门禁一致性复核 |
| 红线扫描 | 红线阻断登记为空或已由总管处理 | 待确认 | 保持阻断 |

## 判断规则

1. 任一门禁待确认，发布保持阻断。
2. 任一红线未处理，发布保持阻断。
3. 所有门禁齐备也不自动发布，只能进入“待总管或人工最终确认”状态。
4. 多平台发布必须逐平台判断，不能用全局通过替代逐平台通过。

## 输出口径

```text
发布前门禁总览：未通过。
阻断门禁：[列出]
下一步：[对应复核队列]
真实系统触发：否。
```

## 边界

本总览卡只做人工复核视图，不连接平台、不发企业微信、不调用发布工具。
