# VIDEO_AGENT_REDLINE_ALTERNATIVE_ACTION_TEMPLATE_001_红线阻断后替代影子动作模板_v1.0

> 资产身份：视频创作智能体影子层红线替代动作模板
> 阶段：W1/R0
> 状态：替代动作模板，不是红线豁免
> 边界：阻断真实动作后，只允许转为影子草案、复核清单或回传记录。

## 使用场景

当用户请求命中真实生成、真实发布、企业微信外发、读取凭据、读取真实素材或改正式入口等红线时，系统不能执行原请求，只能提供低风险替代影子动作。

## 替代动作表

| 红线请求 | 禁止动作 | 允许替代影子动作 |
|:---|:---|:---|
| 直接生成视频 | 生成、渲染、转码、剪辑 | 生成待复核脚本/分镜/素材缺口清单 |
| 直接生成配音/字幕/封面 | 调用 TTS、字幕、封面工具 | 生成文案草案、字幕文本草案、封面文案方向 |
| 直接发布平台 | 上传、发布、改发布配置 | 生成发布前待复核问题清单 |
| 企业微信外发 | 真实发送消息 | 生成待发送文本草案和人工确认项 |
| 提供账号/密钥/webhook | 读取、保存、使用凭据 | 记录凭据风险并提示改为人工配置 |
| 读取真实素材目录 | 访问素材路径 | 登记“存在素材待授权”，生成授权待补字段 |
| 修改正式入口/端口/脚本 | 改服务、端口、正式路由 | 生成总管判断请求和影子对齐回传 |

## 输出要求

1. 先说明红线已阻断。
2. 再说明未触发真实系统。
3. 只给替代影子动作。
4. 不诱导用户提供密钥、账号或真实素材。
