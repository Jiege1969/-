# VIDEO_AGENT_WECOM_HUMAN_REVIEW_REFUSE_EXECUTION_REPLY_001 企业微信人工复核后仍不同意执行回执样例

- 版本：v1.0
- 日期：2026-05-08
- 所属业务线：视频制作系统
- 所属层级：W1/W2 影子回执样例
- 当前状态：草案
- 终端角色：杰哥视频助理

## 1. 适用场景

当视频线人工复核后仍不同意生成、渲染或发布时，本回执用于向用户说明拒绝原因，并给出下一步可做的低风险修正。

## 2. 输入样例

```text
复核后不同意发布，先别发。
```

## 3. 回执样例

```text
杰哥，收到。

任务已登记为“人工复核后不同意执行”。我不会继续生成、渲染、上传或发布。

当前建议先处理复核意见：
1. 如果是文案问题，进入局部修正文案；
2. 如果是素材授权问题，补素材来源和授权证据；
3. 如果是平台规范问题，重新做平台待补字段核对；
4. 如果是合规问题，保持阻断并记录复核原因。

本次没有触发真实渲染、真实发布、企业微信真实外发或 n8n。
```

## 4. 状态建议

| 字段 | 建议值 |
|---|---|
| 当前状态 | 人工复核后不同意执行 |
| 下一步允许动作 | 局部修正/补授权/补平台规范/保持阻断 |
| 自动渲染 | 否 |
| 自动发布 | 否 |
| 真实外发 | 否 |

## 5. 边界声明

本样例只定义回执文本，不发送企业微信，不调用企业微信接口，不修改公共接入配置。

本样例不调用真实模型、不读取真实素材、不渲染、不上传、不发布、不触发 n8n。
