# VIDEO_AGENT_WECOM_COMMAND_REPLY_SAMPLE_001 企业微信命令回执占位样例 v1.0

- 资产类型：回执占位样例
- 施工等级：W1/R0
- 适用范围：企业微信作为输入输出终端的影子对话设计
- 状态：草案

## 定位

本样例只描述“杰哥视频助理”未来可能返回给用户的文本结构，不接企业微信接口，不真实发送消息，不触发 n8n。

## 输入样例

```text
发布 VF-20260508-003 到小红书和视频号
```

## 回执样例

```text
已收到发布指令草案：VF-20260508-003。

当前只完成影子检查，不能进入真实发布。

阻断项：
1. 发布放行清单未确认。
2. 平台 AI 生成内容标识未人工确认。
3. 素材授权证明未归档。
4. 成品预览未完成人工复核。

可执行的下一步：
请先补齐发布放行、AI 标识确认、素材授权和成品预览复核。
```

## 其他命令占位

| 用户命令类型 | 影子回执动作 | 是否真实执行 |
|---|---|---|
| 生成视频 | 返回生成放行缺口 | 否 |
| 渲染视频 | 返回真实渲染放行缺口 | 否 |
| 发布视频 | 返回发布放行缺口 | 否 |
| 查看状态 | 返回影子任务状态摘要草案 | 否 |
| 修改文案 | 返回局部修正草案和待复核项 | 否 |

## 边界

- 不调用企业微信接口。
- 不发送真实消息。
- 不接 n8n。
- 不连接真实发布工具。
- 不读取真实账号或 Cookie。
