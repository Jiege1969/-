# VIDEO_AGENT_STATUS_QUERY_GAP_CARD_001 状态查询缺口卡

> 业务线：视频制作业务影子底座
> 层级：W1/R0
> 状态：影子缺口卡，不是真实查询接口
> 日期：2026-05-08

## 目的

当用户通过未来企业微信入口或人工输入询问“任务到哪了”“还缺什么”“能不能发布”时，若影子任务信息不足，使用本卡记录缺口，不编造任务状态。

## 缺口字段

| 字段 | 说明 |
|:---|:---|
| `shadow_task_id` | 影子任务编号 |
| `query_text` | 脱敏后的查询内容 |
| `requested_status_type` | 进度/缺口/复核/发布门禁/关闭状态 |
| `known_status` | 已知影子状态 |
| `missing_status_fields` | 缺失状态字段 |
| `evidence_pointer` | 可追溯影子文件 |
| `reply_boundary` | 回执边界说明 |
| `next_shadow_action` | 下一步影子动作 |

## 缺口处理规则

- 无影子任务编号时，返回需要提供编号或上下文。
- 无状态记录时，返回“无可追溯状态记录”，并建立缺口。
- 涉及发布许可时，只返回门禁状态，不写成许可。
- 涉及真实企业微信发送状态时，只返回“影子未接真实发送”。

## 边界

本卡不查询真实服务、不查询真实企业微信、不查询真实任务库、不触发 n8n。
