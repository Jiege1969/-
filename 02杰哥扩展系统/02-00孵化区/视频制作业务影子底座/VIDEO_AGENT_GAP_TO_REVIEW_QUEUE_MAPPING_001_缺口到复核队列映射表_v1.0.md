# VIDEO_AGENT_GAP_TO_REVIEW_QUEUE_MAPPING_001 缺口到复核队列映射表 v1.0

- 资产类型：映射表
- 施工等级：W1/R0
- 适用范围：视频制作影子任务的缺口分流
- 状态：草案

## 目的

把“缺什么”自动映射到对应的人工复核队列，避免缺口卡生成后无人承接，也避免系统因为缺资料停在等待确认。

## 映射表

| 缺口类型 | 进入队列 | 队列责任 | 输出物 | 是否允许真实动作 |
|---|---|---|---|---|
| 主题表达不清 | 内容复核队列 | 人工编辑 | 选题澄清问题 | 否 |
| 文案风格不匹配 | 内容复核队列 | 人工编辑 | 局部修正建议 | 否 |
| 成语/语录原创性不足 | 原创性复核队列 | 人工编辑 | 古今结合补写问题 | 否 |
| 平台规则缺失 | 平台规范复核队列 | 发布负责人 | 平台规则待补清单 | 否 |
| 素材授权缺失 | 素材授权复核队列 | 素材负责人 | 授权证明待补清单 | 否 |
| AI 标识未确认 | 发布合规复核队列 | 发布负责人 | AI 标识确认回执 | 否 |
| 成品预览未确认 | 成品预览复核队列 | 人工复核人 | 预览验收回执 | 否 |
| 生成/渲染/发布放行冲突 | 门禁一致性复核队列 | 总控复核人 | 放行冲突处理意见 | 否 |
| 真实账号/Cookie/API Key 缺失 | 红线阻断登记 | 总管判断 | 红线阻断记录 | 否 |

## 输出规则

1. 每个缺口至少进入一个复核队列。
2. 同一缺口可同时进入多个队列，但必须标注主责任队列。
3. 进入红线阻断登记的事项不得自动转为真实执行。
4. 队列输出只能是问题、回执、草案或阻断记录。
