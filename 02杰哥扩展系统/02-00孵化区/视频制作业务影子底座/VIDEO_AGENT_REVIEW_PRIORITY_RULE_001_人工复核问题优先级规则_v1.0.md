> 资产身份：视频制作线 W1/R0 人工复核问题优先级规则  
> 风险等级：低风险  
> 边界声明：只定义复核排序，不替代人工判断。

## 用途

当影子工厂输出多个待复核问题时，本规则用于排序，保证高风险合规和放行问题优先处理。

## 优先级

| 优先级 | 问题类型 | 处理原则 |
|---|---|---|
| P0 | 合规高风险、封建迷信、绝对化医疗、焦虑贩卖 | 先阻断，再给替代建议 |
| P0 | 素材授权、肖像隐私、音乐版权缺口 | 未关闭前不进真实渲染 |
| P0 | 发布放行、AI标识、平台规则缺口 | 未关闭前不进发布 |
| P1 | 主题同质化、去AI感不足、原创性不足 | 进入局部修正 |
| P1 | 分镜不匹配、节奏不清、画幅不明确 | 进入分镜修正 |
| P2 | 标题口吻、字幕风格、配音偏好 | 进入风格调整 |
| P2 | 复盘经验、模板沉淀 | 进入进化候选 |

## 排序规则

1. P0 问题未关闭时，不处理 P1/P2 的执行类请求。
2. 发布相关 P0 优先于风格优化。
3. 素材授权缺口优先于画面美观。
4. 多个 P0 并存时，先处理合规和授权，再处理平台发布。
