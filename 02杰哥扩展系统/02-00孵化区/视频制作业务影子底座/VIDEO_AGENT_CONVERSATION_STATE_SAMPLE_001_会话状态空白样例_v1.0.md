# VIDEO_AGENT_CONVERSATION_STATE_SAMPLE_001_会话状态空白样例_v1.0

> 资产身份：视频创作智能体影子层会话状态样例
> 阶段：W1/R0
> 状态：空白样例，不是真实会话记录
> 边界：不接真实 LLM、不接向量库、不读取真实素材、不触发企业微信真实发送。

## 样例用途

用于演示一个视频创作请求进入影子层后，系统应如何记录会话状态。该样例只做字段占位，供后续待复核草案、三候选输出和澄清问题模板引用。

## 会话状态字段

| 字段 | 示例值 | 说明 |
|:---|:---|:---|
| 会话ID | `VAI-SESSION-0000` | 影子样例编号，不对应真实用户会话 |
| 输入来源 | `manual_shadow_input` | 人工录入的影子输入，不是企业微信真实消息 |
| 用户原始想法摘要 | 待填写 | 只写脱敏摘要，不保留敏感原文 |
| 当前意图 | 待路由 | 新建任务/局部修正/澄清/生成预检/发布预检/复盘进化 |
| 任务阶段 | `draft_intake` | draft_intake / clarification_needed / option_draft / human_review_pending |
| 关联资料 | 待填写 | 只允许引用影子目录内资料卡或公开规则来源卡 |
| 素材授权状态 | 待核验 | 未核验前不得进入生成或发布讨论 |
| 平台规范状态 | 待核验 | 未核验前不得输出可发布结论 |
| 当前输出类型 | 待定 | 澄清问题/三候选草案/复核清单/回执摘要 |
| 置信度 | `low` | 空白样例默认低置信度 |
| 待人工复核项 | 待填写 | 所有生成、素材、发布、原创性、AI标识问题均需人工复核 |
| 红线命中 | `none_in_sample` | 样例未命中红线；真实输入需重新扫描 |
| 下一步动作 | `manual_review_or_clarification` | 只能进入澄清或人工复核 |

## 禁止推导

1. 不得把本样例解释为真实用户画像或长期记忆。
2. 不得把样例字段自动写入正式任务系统。
3. 不得因字段齐全而放行生成、渲染、上传或发布。
