# VIDEO_AGENT_TOTAL_CLOSURE_READING_ORDER_001_VAI001至VAI035总收口阅读顺序_v1.0

> 业务线：视频制作业务影子底座
> 阶段：W1/R0
> 日期：2026-05-08
> 资产身份：视频创作智能体影子阅读顺序卡，不是正式视频制作系统入口。

## 用途

本卡用于在接续 VAI-001 至 VAI-035 阶段资产前，给施工者一个固定阅读顺序和放行状态核对口径。

它只组织影子资料读取，不读取真实素材，不调用模型、TTS、渲染器、发布器、企业微信或 n8n。

## 为什么单独建立

VAI-001 至 VAI-035 已经形成多层资产：契约、样例、检查、红线、成熟度、手工试运行、回传和总收口。旧文件各自解决局部问题，但没有一张卡明确“接续时先读什么、读完能做什么、不能误判为什么”。

本卡不改旧文件，只把接续顺序抽出来，避免后续施工者从某一张放行或验收文件直接跳到真实生成、真实渲染、发布或企业微信外发。

## 放行状态一致性检查

| 用户或文件状态 | 可继续做的低风险动作 | 必须保持阻断的动作 |
|:---|:---|:---|
| 创意已确认 | 生成或修订文本草案、澄清缺口 | 真实渲染、发布、外发 |
| 文案已确认 | 进入分镜草案或局部修正验收 | 生成视频、配音、字幕、封面 |
| 分镜已确认 | 检查素材授权字段、平台规格字段 | 读取真实素材目录、剪辑或转码 |
| 素材授权待补 | 登记缺口和人工复核问题 | 真实渲染、发布 |
| AI标识待补 | 登记平台合规提示 | 绕过平台标识要求 |
| 生成放行待讨论 | 进入渲染缺口卡核对 | 自动调用 MoneyPrinterTurbo、HappyHorse 或 Qwen-TTS |
| 真实渲染未放行 | 只登记缺口 | 真实渲染、配音、字幕、封面生成 |
| 成片预览未形成 | 只登记预览缺口 | 发布、外发 |
| 发布放行未形成 | 进入发布前门禁缺口卡 | PostBot、平台登录、上传、发布 |
| 企业微信回执草案已形成 | 本地留存草案或交给人工复制 | 企业微信真实发送、n8n webhook |

## 一票阻断

命中以下任一项时，本线只登记阻断，不继续实施：

- 请求真实渲染、真实剪辑、配音、字幕、封面或成片生成。
- 请求平台登录、上传、发布或 PostBot 调用。
- 请求企业微信真实发送、n8n、Webhook 或服务重启。
- 请求读取真实素材、账号凭据、Token、AESKey 或密钥。
- 请求把影子验收、人工回执或总收口直接升级为正式规则。
