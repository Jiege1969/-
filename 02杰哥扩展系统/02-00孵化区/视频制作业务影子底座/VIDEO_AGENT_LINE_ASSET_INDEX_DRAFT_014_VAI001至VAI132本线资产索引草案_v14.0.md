## 5. 当前关键链路

```text
人工复核发现问题
→ 允许局部修正
→ 填写局部修正记录
→ 登记局部修正问题队列
→ 输出影子修正草案
→ 修正后回到人工复核
→ 高频问题进入进化候选映射
→ 候选继续人工复核或提交总管判断
→ 不自动进入生成、渲染、上传、发布
```

## 6. 当前边界

- 本索引只服务视频制作业务影子底座，不进入正式视频制作系统。
- 局部修正问题队列只登记待补项，不触发真实模型或真实素材读取。
- 进化候选映射只形成候选，不写正式规则库、不修改总管文件。
- 复核通过不等于生成放行。
- 生成放行、真实渲染放行、发布放行继续拆开。
- 企业微信相关资产均为样例，不代表真实外发。
- MoneyPrinterTurbo、ImageMagick、n8n、上传和发布均未调用。
