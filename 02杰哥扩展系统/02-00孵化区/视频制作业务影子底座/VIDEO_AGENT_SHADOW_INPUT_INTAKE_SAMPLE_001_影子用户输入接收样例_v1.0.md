# VIDEO_AGENT_SHADOW_INPUT_INTAKE_SAMPLE_001_影子用户输入接收样例_v1.0

> 资产身份：视频创作智能体影子层输入接收样例
> 阶段：W1/R0
> 状态：空白样例，不是企业微信真实入口
> 边界：不接公共企业微信配置、不读取凭据、不发送消息、不启动服务。

## 样例用途

用于演示“杰哥工作秘书”或其他入口转来的用户问题，在未接真实企业微信前如何手工登记为影子输入。该样例仅提供字段，不代表路由已上线。

## 输入接收字段

| 字段 | 示例值 | 说明 |
|:---|:---|:---|
| 输入记录ID | `VAI-INPUT-0000` | 影子输入编号 |
| 来源终端 | `manual_shadow_terminal` | 手工录入，不是企业微信真实终端 |
| 来源消息ID | 待填写 | 不保存真实企业微信消息ID |
| 接收时间 | 待填写 | 手工填写 |
| 用户问题脱敏摘要 | 待填写 | 不保存手机号、账号、素材路径、个人隐私 |
| 是否包含素材路径 | 待核验 | 有则只登记“存在路径”，不读取 |
| 是否要求生成 | 待核验 | 命中则进入人工门禁 |
| 是否要求发布或外发 | 待核验 | 命中则进入阻断 |
| 初步意图 | 待路由 | 参考意图路由分类表 |
| 下一步 | 澄清或人工复核 | 不自动生成 |

## 红线处理

1. 出现真实账号、密钥、素材路径时，只登记风险，不读取内容。
2. 出现“直接生成”“直接发布”“发企业微信”等要求时，进入阻断，不执行。
3. 本文件不修改公共企业微信接入配置，不触发任何真实消息。
