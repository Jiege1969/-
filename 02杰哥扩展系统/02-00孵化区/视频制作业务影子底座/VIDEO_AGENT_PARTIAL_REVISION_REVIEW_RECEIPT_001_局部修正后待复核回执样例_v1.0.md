# VIDEO_AGENT 局部修正后待复核回执样例

- 文件编号：VIDEO_AGENT_PARTIAL_REVISION_REVIEW_RECEIPT_001
- 版本：v1.0
- 生成日期：2026-05-08
- 所属业务线：视频制作业务影子底座
- 适用范围：视频创作智能体影子工厂、企业微信视频助理前台文案草案
- 文档状态：影子草案，待人工复核

## 1. 使用场景

当用户或人工复核人允许进行低风险局部修正，并且系统已生成局部修正草案后，本回执用于提示：

1. 修正已形成影子草案。
2. 修正内容仍需人工复核。
3. 修正通过不等于生成放行、渲染放行或发布放行。
4. 当前不会触发真实模型、真实渲染、真实发布、n8n 或企业微信真实外发。

## 2. 回执样例

```text
杰哥，局部修正草案已经整理好。

本次只处理了你允许修改的部分：
- 修正范围：{允许修正范围}
- 已锁定内容：{锁定内容}
- 输出草案：{输出物名称}

现在状态是：局部修正待复核。

请你重点看三件事：
1. 修改后的表达是否更像你自己的说法；
2. 是否仍有AI感、焦虑感或平台合规风险；
3. 是否同意进入下一道人工门禁。

注意：这不是生成放行，也不是渲染放行，更不是发布放行。没有你的单独确认，我不会进入真实生成、渲染或发布。
```

## 3. 建议结构化字段

| 字段 | 示例 | 说明 |
|------|------|------|
| 回执ID | PRR-20260508-001 | 局部修正复核回执编号 |
| 任务ID | VF-20260508-003 | 对应视频工厂任务 |
| 会话来源 | 企业微信 | 仅表示入口来源，不表示真实外发 |
| 会话ID | shadow-wecom-video-001 | 影子会话标识 |
| 修正范围 | 文案开头、第三段分镜 | 本轮允许改的部分 |
| 锁定内容 | 已确认标题、结尾金句 | 不得误改的内容 |
| 输出物名称 | 局部修正文案草案_001.md | 本轮草案名称 |
| 当前状态 | 局部修正待复核 | 必须回到人工门禁 |
| 禁止动作 | 真实生成、渲染、发布、外发 | 本回执不授权执行 |

## 4. 前台提示原则

- 用“已经整理好草案”而不是“已经完成制作”。
- 用“待复核”而不是“可发布”。
- 用“不会进入真实生成、渲染或发布”明确边界。
- 不承诺平台账号、素材授权、成片效果或发布结果。

## 5. 红线登记

若用户在本回执之后直接说“马上生成”“直接发布”“发到抖音/小红书/视频号”，系统只能登记阻断，并提示需要独立的生成放行、渲染放行和发布放行。
