## 一、栏目定位

| 字段 | 建议值 |
|:---|:---|
| 栏目名称 | 成语一分钟 / 小故事大智慧 / 今天讲个成语 |
| 默认受众 | 小学生及家长 |
| 默认时长 | 30秒或60秒 |
| 默认风格 | 通俗、具体、有故事、有启发，不过度说教 |
| 输出身份 | 待复核文本草案，不是可发布脚本 |

## 二、统一结构

| 顺序 | 模块 | 目的 | 30秒建议 | 60秒建议 |
|:---|:---|:---|:---|:---|
| 1 | 问题钩子 | 让观众立刻知道冲突 | 1句问题 | 1句问题 + 1个反常动作 |
| 2 | 成语点名 | 明确今天讲哪个成语 | 直接点名 | 点名并给一句生活化解释 |
| 3 | 故事进入 | 交代人物、地点、目标 | 1个场景 | 1个场景 + 人物心理 |
| 4 | 冲突发生 | 写出具体动作和错误判断 | 1个关键动作 | 关键动作 + 错误想法 |
| 5 | 结果揭示 | 让观众看到后果 | 1个结果 | 结果 + 人物反应 |
| 6 | 现实启发 | 把故事和生活连接 | 1句启发 | 1句启发 + 1个生活例子 |
| 7 | 人工复核问题 | 保留人工判断入口 | 3项 | 5项 |

## 三、分镜统一格式

| 字段 | 填写要求 |
|:---|:---|
| 镜头编号 | 从1开始连续编号 |
| 画面 | 必须能被人工理解，不写“画面好看” |
| 旁白 | 对应当前镜头，不重复大段正文 |
| 素材状态 | 默认待授权 |
| AI标识 | 默认待确认 |
| 平台规范 | 默认待复核 |

## 四、30秒版本结构

```text
开头钩子：1句
成语释义：1句
故事正文：3段
现实启发：1句
人工问题：至少3个
分镜：4到5个镜头
```

30秒版本必须保留完整故事冲突，不得只保留结论。

## 五、60秒版本结构

```text
开头钩子：1到2句
成语释义：1到2句
故事正文：5段
现实启发：1到2句
人工问题：至少5个
分镜：6到8个镜头
```

60秒版本应补人物心理、错误判断和生活类比，不得机械扩写套话。

## 六、一票否决

- 没有具体成语。
- 没有成语释义。
- 没有人物、动作、冲突、结果。
- 分镜只有空话。
- 直接声称可发布。
- 请求读取真实素材、调用渲染器、触发发布器、发送企业微信或 n8n。

## 七、复用流程

1. 先确认成语、受众、目标时长。
2. 按本结构写影子文本草案。
3. 用 `VIDEO_SCRIPT_QUALITY_ACCEPTANCE_TABLE_001` 做质量验收。
4. 用 `VIDEO_SCRIPT_DURATION_VARIANT_CHECK_001` 检查30秒/60秒差异。
5. 用人工复核回执承接人工意见。
6. 如出现可复用经验，只能进入进化候选，不得直接写正式规则。
