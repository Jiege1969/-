# VIDEO_AGENT_MULTI_PLATFORM_CHECK_FAILURE_REPLY_SAMPLE_001 多平台检查未通过回执样例 v1.0

- 资产类型：回执样例
- 施工等级：W1/R0
- 适用范围：多平台发布前检查未通过时的占位回执
- 状态：草案样例

## 输入场景

用户发出发布命令，但多平台发布前检查显示部分平台仍有标题、封面、AI 标识或平台规则缺口。

## 回执样例

```text
任务 VF-20260508-003 的多平台发布前检查未通过。

已通过平台：
- 暂无

待复核平台：
- 抖音：AI 标识未确认，封面未确认
- 小红书：标题风格待复核，素材说明未确认
- 视频号：平台规则未核对

当前结论：
不能进入真实发布，也不能一键全平台发布。

下一步：
已转入发布合规复核队列、平台文案复核队列、素材授权复核队列。

真实系统触发：否。
```

## 固定规则

1. 回执必须逐平台列出问题。
2. 不能把部分平台通过表述成全部平台可发。
3. 未通过项必须映射到复核队列。
4. 本样例不发送企业微信、不执行发布。
