# VIDEO_AGENT_WECOM_FINAL_CONFIRMATION_MISSING_MATERIAL_REPLY_001 企业微信最终确认待补材料回执样例 v1.0

- 资产类型：企业微信占位回执样例
- 施工等级：W1/W2 低风险影子施工
- 适用范围：最终人工确认前发现材料缺失时
- 状态：草案样例，不真实外发

## 输入场景

用户询问或尝试确认发布，但最终确认质量检查发现材料缺失。

## 回执样例

```text
任务 VF-20260508-003 当前不能进入最终人工确认。

待补材料：
1. 发布前门禁最终总览记录
2. 发布前阻断汇总记录
3. 小红书平台独立检查回执
4. 素材授权证明回执

已转入：
- 门禁一致性复核队列
- 平台差异复核队列
- 素材授权复核队列

下一步：
请先补齐上述材料。补齐后仍只进入人工最终确认，不会自动发布。

真实系统触发：否。
```

## 固定规则

1. 回执必须列出具体待补材料。
2. 回执必须列出复核队列。
3. 回执必须说明“补齐后仍不自动发布”。
4. 本样例不调用企业微信接口、不发送真实消息、不发布。
