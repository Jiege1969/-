# VIDEO_AGENT_WECOM_PUBLISH_COMMAND_REFUSAL_REPLY_001 企业微信发布命令拒绝回执样例 v1.0

- 资产类型：企业微信占位回执样例
- 施工等级：W1/R0
- 适用范围：用户通过企业微信发出发布命令但发布条件不齐时
- 状态：草案样例，不真实外发

## 输入命令样例

```text
发布 VF-20260508-003 到抖音、小红书、视频号
```

## 拒绝回执样例

```text
已收到发布命令草案：VF-20260508-003。

当前不能进入真实发布。

原因：
1. 发布放行清单未确认。
2. 成品预览未完成人工复核。
3. 平台 AI 生成内容标识未确认。
4. 素材授权证明未归档。

已转入复核队列：
- 发布合规复核队列
- 成品预览复核队列
- 素材授权复核队列

下一步：请先完成人工复核和发布放行。
真实系统触发：否。
```

## 固定拒绝规则

1. 发布放行缺失，必须拒绝。
2. 真实渲染放行缺失，必须拒绝。
3. 成品预览缺失，必须拒绝。
4. AI 标识确认缺失，必须拒绝。
5. 素材授权缺失，必须拒绝。
6. 真实账号、Cookie、API Key、n8n、外发接口等请求出现时，转红线阻断登记。

## 边界

本样例只定义回执文本，不调用企业微信，不触发发布工具，不接 n8n。
