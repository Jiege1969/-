# VIDEO_AGENT_PRE_PUBLISH_GATE_GAP_TO_REVIEW_MAPPING_001 发布前门禁缺口到复核队列映射样例 v1.0

- 资产类型：缺口映射样例
- 施工等级：W1/W2 低风险影子施工
- 适用范围：发布前门禁总览缺口处理
- 状态：草案样例

## 目的

当发布前门禁总览发现缺口时，自动把缺口映射到对应复核队列，避免停在笼统的“发布条件不足”。

## 映射样例

| 门禁缺口 | 映射队列 | 所需输出 | 关闭条件 | 是否真实执行 |
|---|---|---|---|---|
| 生成放行缺失 | 生成放行复核队列 | 生成放行回执 | 回执为放行 | 否 |
| 真实渲染放行缺失 | 渲染放行复核队列 | 渲染放行回执 | 回执为放行 | 否 |
| 成品预览缺失 | 成品预览复核队列 | 成品预览复核回执 | 回执为通过 | 否 |
| AI 标识缺失 | 发布合规复核队列 | AI 标识确认回执 | 回执为已确认 | 否 |
| 素材授权缺失 | 素材授权复核队列 | 素材授权证明回执 | 回执为通过且已归档 | 否 |
| 多平台检查缺失 | 平台差异复核队列 | 每个平台独立检查回执 | 全平台检查完成 | 否 |
| 发布放行缺失 | 门禁一致性复核队列 | 发布放行确认回执 | 回执为放行 | 否 |
| 红线阻断存在 | 红线阻断登记 | 总管判断记录 | 总管明确解除或转为可复核缺口 | 否 |

## 固定规则

1. 每个缺口必须有复核队列和所需输出。
2. 缺口关闭条件必须可追溯。
3. 缺口关闭不等于真实发布。
4. 红线缺口不能由视频线自行关闭。

## 边界

本样例不创建真实队列、不分派真实人员、不触发企业微信或发布。
