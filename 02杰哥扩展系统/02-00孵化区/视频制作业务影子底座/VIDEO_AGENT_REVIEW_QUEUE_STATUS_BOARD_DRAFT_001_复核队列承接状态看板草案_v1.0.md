# VIDEO_AGENT_REVIEW_QUEUE_STATUS_BOARD_DRAFT_001 复核队列承接状态看板草案 v1.0

- 资产类型：看板草案
- 施工等级：W1/R0
- 适用范围：视频制作影子复核队列
- 状态：草案，不连接真实看板或数据库

## 目的

把缺口到复核队列的承接状态放到一张影子看板里，便于人工知道哪些问题已经分派、哪些仍阻断、哪些可以关闭影子任务。

## 看板字段

| 字段 | 说明 |
|---|---|
| queue_id | 复核队列编号 |
| queue_name | 复核队列名称 |
| primary_owner | 主责任人或角色 |
| pending_count | 待处理数量，占位字段 |
| blocked_count | 红线阻断数量，占位字段 |
| latest_task_id | 最近任务编号，占位字段 |
| latest_gap_type | 最近缺口类型 |
| next_shadow_action | 下一步影子动作 |
| real_system_triggered | 必须为否 |

## 边界

- 不创建真实看板。
- 不连接数据库。
- 不外发企业微信。
- 不触发 n8n。
- 不自动分派真实人员任务。
