# VIDEO_AGENT_SHADOW_STATUS_ENUM_MAPPING_001_影子状态枚举对照表_v1.0

> 资产身份：视频创作智能体影子状态枚举对照表
> 阶段：W1/R0
> 状态：状态对照表，不是真实状态机

## 状态枚举

| 状态 | 含义 | 可进入下一步 | 禁止误解 |
|:---|:---|:---|:---|
| `intake_pending` | 等待脱敏输入 | 接收提示模板 | 不是已接入真实入口 |
| `intake_checked` | 已完成脱敏和红线检查 | 澄清或三候选 | 不是生成放行 |
| `clarification_needed` | 缺关键字段 | 一个澄清问题 | 不是拒绝服务 |
| `option_draft_ready` | 可形成三候选文本草案 | 人工复核 | 不是脚本定稿 |
| `human_review_pending` | 等待人工复核 | 人工回执 | 不是发布前批准 |
| `revision_pending` | 等待修正 | 修正流转样例 | 不是自动改稿 |
| `redline_blocked` | 命中红线 | 阻断登记和替代影子动作 | 不是总管批准 |
| `shadow_closed` | 影子任务可关闭 | 关闭条件清单 | 不是关闭真实任务 |
| `evolution_candidate_pending` | 经验可入候选 | 进化候选承接 | 不是正式规则 |

## 使用原则

1. 状态只用于影子层手工试运行。
2. 状态变化必须记录到状态日志。
3. 任何状态都不自动放行生成、渲染、发布或外发。
