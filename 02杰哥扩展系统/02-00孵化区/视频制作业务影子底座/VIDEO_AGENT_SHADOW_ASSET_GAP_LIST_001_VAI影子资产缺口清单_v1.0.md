## 当前缺口

| 缺口 | 影响 | 处理 |
|:---|:---|:---|
| 缺真实脱敏视频想法样例 | 无法填写完整试运行样例 | 等用户人工提供脱敏想法后填入模板 |
| 缺平台发布规格细项 | 不能判断可发布性 | 继续保持待核验，不输出发布结论 |
| 缺素材授权明细 | 不能进入生成讨论 | 只登记素材待授权字段 |
| 缺人工回执实例 | 无法沉淀真实复核经验 | 等人工填写后再进入进化候选 |
| 缺多案例验证 | 不能升级规则 | 候选经验保持 pending_review |
| 缺真实企业微信入口授权 | 不能作为真实输入输出终端 | 继续手工影子输入，不改公共配置 |
