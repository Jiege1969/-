> 阶段：W1/R0
> 状态：提示模板，不是真实入口

## 提示模板

请提供一条已经脱敏的视频想法，只需要文字摘要，不要提供账号、手机号、密钥、webhook、完整素材路径、身份证件、客户隐私或未授权素材原文。

建议按以下字段提供：

| 字段 | 示例填写方式 |
|:---|:---|
| 视频主题 | 想表达什么内容 |
| 目标平台 | B站/视频号/抖音/小红书/其他 |
| 目标受众 | 给谁看 |
| 期望风格 | 轻松/严肃/科普/剧情/口播/混剪 |
| 目标时长 | 大致时长 |
| 素材情况 | 有素材但待授权/无素材/只做文案 |
| 禁止内容 | 不希望出现的表达 |
| 期望输出 | 澄清问题/三候选开场分镜文本/复核问题清单 |

## 接收后处理

1. 先做脱敏和红线检查。
2. 字段不足时只问一个关键澄清问题。
3. 字段足够时只能生成待复核文本草案。
4. 命中生成、发布、外发、凭据或真实素材读取时，只登记阻断。
