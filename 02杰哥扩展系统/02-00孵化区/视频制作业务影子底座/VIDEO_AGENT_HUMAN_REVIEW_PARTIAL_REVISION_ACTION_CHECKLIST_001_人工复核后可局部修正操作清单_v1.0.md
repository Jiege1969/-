# VIDEO_AGENT 人工复核后可局部修正操作清单

- 文件编号：VIDEO_AGENT_HUMAN_REVIEW_PARTIAL_REVISION_ACTION_CHECKLIST_001
- 版本：v1.0
- 生成日期：2026-05-08
- 所属业务线：视频制作业务影子底座
- 适用范围：视频创作智能体影子工厂与人工复核链
- 文档状态：影子草案，待人工复核

## 1. 目的

当人工复核不同意执行，但允许继续修改草案时，本清单用于界定哪些动作属于低风险局部修正，哪些动作必须登记阻断。

本清单不接真实模型、不触发真实渲染、不触发真实发布、不读取真实素材、不进行企业微信真实外发。

## 2. 可局部修正范围

| 复核意见类型 | 可执行的影子动作 | 输出物 | 下一道门禁 |
|--------------|------------------|--------|------------|
| 文案语气不符合个人风格 | 仅生成局部修正文案草案，不覆盖正式脚本 | 局部修正文案草案 | 人工再次复核 |
| 金句或表达有AI感 | 生成去AI感改写建议卡，不调用真实模型 | 去AI感改写建议卡 | 人工再次复核 |
| 分镜画面不贴合 | 修订分镜描述和画面需求，不读取素材库 | 局部分镜修正草案 | 素材授权复核 |
| 素材授权不完整 | 生成素材授权缺口清单，不下载素材 | 素材授权待补清单 | 素材来源人工确认 |
| 平台规则不明确 | 生成平台规则待补问题，不登录平台账号 | 平台规则待补问题清单 | 平台规则人工确认 |
| 合规风险待确认 | 生成风险说明和删除建议，不进入执行 | 合规风险处理建议 | 合规人工确认 |

## 3. 必须阻断的动作

| 请求类型 | 处理方式 | 原因 |
|----------|----------|------|
| 直接生成成片 | 登记阻断 | 缺生成放行时不能进入真实渲染 |
| 直接渲染 | 登记阻断 | 渲染放行需独立人工确认 |
| 直接发布 | 登记阻断 | 发布放行需独立人工确认 |
| 读取真实素材库 | 登记阻断 | 素材授权和隐私风险未齐时不能读取 |
| 调用真实模型API | 登记阻断 | 本阶段仅做 W1/R0 影子契约与草案 |
| 触发企业微信真实外发 | 登记阻断 | 当前仅为回执样例，不接公共接入层 |
| 接 n8n 或服务端口 | 登记阻断 | 属于总管和服务链路红线 |

## 4. 建议字段

局部修正记录建议包含以下字段：

| 字段 | 含义 | 是否必填 |
|------|------|----------|
| 任务ID | 对应视频工厂任务单编号 | 是 |
| 复核结论ID | 对应人工复核回执或总管判断回执 | 是 |
| 复核意见摘要 | 人工指出的问题 | 是 |
| 允许修正范围 | 文案、分镜、素材授权问题、平台规则问题等 | 是 |
| 锁定内容 | 已确认不可改动的内容 | 是 |
| 禁止动作 | 明确不能生成、渲染、发布、外发 | 是 |
| 输出物名称 | 本次局部修正生成的影子草案名称 | 是 |
| 下一道门禁 | 修正后必须进入的复核节点 | 是 |

## 5. 状态建议

| 状态 | 说明 |
|------|------|
| 待局部修正 | 人工拒绝执行，但允许影子修正 |
| 局部修正草案已生成 | 已生成草案，未复核 |
| 局部修正待复核 | 等待人工确认是否采纳 |
| 局部修正驳回 | 修正仍不通过 |
| 局部修正采纳 | 人工同意进入下一道门禁，但不代表生成或发布放行 |

## 6. 边界声明

- 本清单只定义影子修正动作。
- 本清单不替代生成放行清单。
- 本清单不替代渲染放行清单。
- 本清单不替代发布放行清单。
- 本清单不授权任何真实账号、平台、接口、服务或数据库操作。
