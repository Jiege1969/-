# VIDEO_AGENT_MANUAL_TRIAL_READINESS_CHECK_001_手工试运行准备度核对卡_v1.0

> 业务线：视频制作业务影子底座
> 编号：VAI-040
> 阶段：W1/R0
> 日期：2026-05-08
> 资产身份：视频创作智能体手工影子试运行准备度核对卡，不是正式视频生成或发布许可。

## 用途

本卡用于判断一次视频创作智能体手工影子试运行是否具备最小准备条件。

它只检查输入、草案、人工复核、回执、红线登记和索引留痕，不调用真实 LLM、TTS、渲染器、发布器、企业微信或 n8n。

## 准备度等级

| 等级 | 含义 | 可继续动作 |
|:---|:---|:---|
| R0-NOT-READY | 缺少基础输入或红线未判定 | 补输入、补缺口、登记阻断 |
| R0-PARTIAL | 输入可读，但复核或回执链不完整 | 生成待复核草案或补复核问题 |
| R0-READY | 输入、草案、复核、回执和红线登记链路齐备 | 进入手工影子试运行 |
| R0-BLOCKED | 命中真实渲染、发布、外发、服务或凭据红线 | 只登记阻断，不实施 |

## 最小准备条件

| 核对项 | 必要字段或证据 | 不满足时动作 |
|:---|:---|:---|
| 输入来源 | 用户人工提供或脱敏样例，不编造真实需求 | 转入脱敏想法接收提示模板 |
| 创作目标 | 讲故事、科普、表达观点、整理素材、发布计划等至少一项 | 生成澄清问题 |
| 平台假设 | B站、视频号、抖音、小红书或待定 | 平台待定时只做通用草案 |
| 受众和风格 | 至少有一个受众或风格线索 | 标为待补，不强行定调 |
| 可修改范围 | 标题、开头、正文、分镜、旁白、封面、发布文案等 | 缺失时只做整体草案 |
| 已确认内容 | 已确认字段和待确认字段分开 | 不得覆盖已确认内容 |
| 平台规范 | 有来源卡或待补字段 | 缺失时不得输出可发布结论 |
| 素材授权 | 授权状态明确或登记待补 | 缺失时不得进入生成放行 |
| AI标识 | 已确认、待确认或不适用 | 待确认时生成合规提示 |
| 人工复核问题 | 至少包含内容、合规、素材、发布四类之一 | 补复核问题清单 |
| 回执承接 | 有人工选择、修改意见、驳回或待补字段 | 补人工回执模板 |
| 红线扫描 | 已扫描真实渲染、发布、外发、n8n、服务、凭据 | 命中则登记阻断 |

## 允许输出

- 待复核文本草案。
- 三候选开场或分镜草案。
- 澄清问题。
- 局部修正建议。
- 平台规范和素材授权缺口。
- 人工复核问题清单。
- 回执草案。
- 进化候选草案。

## 禁止输出

- 可直接发布的成片结论。
- 真实渲染、配音、字幕、封面或剪辑动作。
- 平台登录、上传、发布或 PostBot 指令。
- 企业微信真实发送或 n8n webhook。
- 读取真实素材目录、账号凭据、Token、AESKey 或密钥。
- 把一次影子试运行经验直接写成正式规则。

## 试运行前短句模板

```text
[准备度: R0-READY / R0-PARTIAL / R0-BLOCKED]
[输入: 已脱敏/待补/命中红线]
[可做: 草案/澄清/复核/回执]
[不可做: 渲染/发布/外发/n8n/服务变更]
```

## 当前结论

视频创作智能体可以进入手工影子试运行准备度核对。只有准备度达到 R0-READY 时，才允许进行手工影子试运行；即便 R0-READY，也不代表真实生成、真实渲染、发布或企业微信外发放行。
