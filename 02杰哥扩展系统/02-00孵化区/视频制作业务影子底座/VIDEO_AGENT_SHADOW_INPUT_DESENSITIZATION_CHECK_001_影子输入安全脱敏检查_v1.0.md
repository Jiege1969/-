# VIDEO_AGENT_SHADOW_INPUT_DESENSITIZATION_CHECK_001 影子输入安全脱敏检查

> 业务线：视频制作业务影子底座
> 层级：W1/R0
> 状态：影子检查清单，不是真实内容网关
> 日期：2026-05-08

## 目的

在手工影子试运行或未来企业微信占位输入进入草案链路前，检查输入是否包含真实账号、联系方式、隐私信息、未授权素材路径、真实客户信息或发布平台凭据线索。

## 检查项

| 检查项 | 命中示例 | 影子处理 |
|:---|:---|:---|
| 个人身份信息 | 姓名、手机号、身份证、住址 | 要求脱敏后再进入影子链路 |
| 账号与凭据 | cookie、token、密码、密钥 | 登记红线阻断 |
| 未授权素材路径 | 本地真实素材目录、网盘真实链接 | 转素材授权缺口 |
| 真实客户信息 | 客户名称、合同、报价、隐私素材 | 要求脱敏或人工确认 |
| 真实发布指令 | 直接发布、上传、群发、外发 | 转真实执行请求阻断 |
| 平台敏感操作 | 登录、代发、自动投流 | 登记红线阻断 |

## 输出字段

- `input_check_id`
- `source_input_type`
- `desensitization_status`
- `sensitive_items_detected`
- `required_user_action`
- `redline_hit`
- `next_shadow_action`

## 边界

本清单只检查人工提供的脱敏文本或占位输入，不读取真实企业微信消息、真实素材目录、账号、cookie 或凭据。
