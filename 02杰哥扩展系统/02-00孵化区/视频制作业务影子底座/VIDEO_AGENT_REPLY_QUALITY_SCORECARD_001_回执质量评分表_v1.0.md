# VIDEO_AGENT_REPLY_QUALITY_SCORECARD_001 回执质量评分表

> 业务线：视频制作业务影子底座
> 层级：W1/R0
> 状态：影子评分表，不是真实绩效或发布审核
> 日期：2026-05-08

## 目的

为企业微信占位回执、状态查询回执和人工回执草案提供质量评分框架，确保回执清晰、可追溯、不越界。

## 评分项

| 评分项 | 分值 | 标准 |
|:---|:---|:---|
| 任务识别 | 0-2 | 能否识别影子任务或明确缺口 |
| 状态清晰 | 0-2 | 当前影子状态是否清楚 |
| 证据可追溯 | 0-2 | 是否指向影子资产或脱敏输入 |
| 缺口明确 | 0-2 | 是否列明缺失字段 |
| 边界合规 | 0-2 | 是否避免正式生成、发布、发送措辞 |

## 判定

- 8-10：可进入人工复核。
- 5-7：需要补充字段。
- 0-4：退回缺口卡或红线阻断登记。

## 边界

评分只服务影子质量控制，不代表真实发送许可、发布许可或正式审核结论。
