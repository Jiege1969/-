# VIDEO_AGENT 局部修正后复核结果分流卡

- 文件编号：VIDEO_AGENT_PARTIAL_REVISION_REVIEW_RESULT_ROUTING_CARD_001
- 版本：v1.0
- 生成日期：2026-05-08
- 所属业务线：视频制作业务影子底座
- 文档状态：影子草案，待人工复核

## 1. 目的

局部修正完成并进入人工复核后，本卡用于把复核结果分流到正确状态，避免“修正通过”被误解为“可以生成、渲染或发布”。

## 2. 分流规则

| 复核结果 | 允许进入的下一状态 | 必须生成的记录 | 禁止推导 |
|----------|--------------------|----------------|----------|
| 修正采纳，但仍需补素材授权 | 素材授权待补 | 素材授权待补清单 | 不能推导生成放行 |
| 修正采纳，但平台规则待确认 | 平台规则待补 | 平台规则待补问题清单 | 不能推导发布放行 |
| 修正采纳，进入脚本/分镜人工复核通过 | 复核通过 | 人工复核通过回执 | 不能自动渲染 |
| 修正仍不通过 | 局部修正驳回 | 驳回原因记录 | 不能继续执行 |
| 修正引入新合规风险 | 合规阻断 | 合规风险处理建议 | 不能生成、渲染或发布 |
| 用户要求直接发布 | 发布红线阻断 | 红线阻断记录 | 不能调用发布适配器 |

## 3. 状态迁移边界

```text
局部修正待复核
→ 修正采纳
→ 只能进入复核通过或待补问题
→ 仍需独立生成放行
→ 仍需独立渲染放行
→ 仍需独立发布放行
```

## 4. 必填字段

| 字段 | 含义 |
|------|------|
| 任务ID | 对应视频工厂任务 |
| 局部修正记录ID | 对应本次修正记录 |
| 复核人 | 人工复核人 |
| 复核时间 | 复核发生时间 |
| 复核结果 | 采纳 / 驳回 / 待补 / 合规阻断 |
| 下一状态 | 按分流规则填写 |
| 不得推导事项 | 生成放行、渲染放行、发布放行等 |

## 5. 边界声明

- 本卡不触发真实执行。
- 本卡不替代人工复核回执。
- 本卡不替代生成、渲染、发布三类放行清单。
- 本卡不接真实模型、真实素材、企业微信真实外发、平台账号或 n8n。
