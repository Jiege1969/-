## 用途

本清单用于防止“生成放行”“真实渲染放行”“发布放行”被混用，确保任何真实动作前都停在人工门禁。

## 检查项

| 检查项 | 通过条件 | 未通过处理 |
|---|---|---|
| 生成放行状态 | 已有单独人工生成放行 | 保持脚本与分镜预演 |
| 真实渲染放行状态 | 已有单独人工真实渲染放行 | 不调用执行器 |
| 发布放行状态 | 已有单独人工发布放行 | 不进入发布辅助 |
| 成品预览状态 | 已人工预览通过 | 不进入发布预检 |
| 素材授权状态 | 所有素材授权结论明确 | 阻断真实渲染 |
| AI标识状态 | 逐平台确认 | 阻断发布放行 |
| 平台规则状态 | 逐平台待补字段无阻断 | 保持发布待确认 |

## 一致性规则

1. 生成放行不能推导真实渲染放行。
2. 真实渲染放行不能推导发布放行。
3. 成品预览通过不能推导发布放行。
4. 企业微信口令不能替代任一放行清单。
5. 放行状态冲突时，以更保守状态为准。
