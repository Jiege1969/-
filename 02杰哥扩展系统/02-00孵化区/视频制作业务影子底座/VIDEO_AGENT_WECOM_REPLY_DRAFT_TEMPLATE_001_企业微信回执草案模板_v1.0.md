## 用途

本模板用于把影子工厂的处理结果整理成适合企业微信终端展示的短回执，但当前只写本地草案。

## 回执类型

| 类型 | 触发场景 | 回执重点 |
|---|---|---|
| 任务已接收 | 用户输入新想法 | 任务ID、主题、等待确认项 |
| 草案已生成 | 脚本/分镜草案完成 | 草案路径、人工复核点 |
| 需要澄清 | 意图不清或缺任务ID | 只问一个短问题 |
| 命中阻断 | 合规、素材、AI标识、发布放行缺口 | 阻断原因、替代动作 |
| 待人工复核 | 进入门禁 | 复核清单、下一步选项 |
| 完成影子演练 | 演练闭环完成 | 结果摘要、未触发真实系统 |

## 回执字段

- 会话ID
- 任务ID
- 回执类型
- 摘要
- 待确认项
- 阻断项
- 本地文件路径
- 是否触发真实系统
- 下一步可选指令
