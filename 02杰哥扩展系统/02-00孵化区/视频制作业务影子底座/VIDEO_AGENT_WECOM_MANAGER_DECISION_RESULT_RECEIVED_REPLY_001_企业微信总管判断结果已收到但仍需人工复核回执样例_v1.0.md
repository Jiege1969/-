# VIDEO_AGENT_WECOM_MANAGER_DECISION_RESULT_RECEIVED_REPLY_001 企业微信总管判断结果已收到但仍需人工复核回执样例

- 所属层级：W1/W2 影子回执样例

## 1. 适用场景

当未来总管判断结果被人工带回视频线时，本回执用于提醒用户：结果已在影子层接收，但视频线仍需人工复核，不能据此自动渲染或发布。

## 2. 输入样例

```text
总管已经判断 VF-20260508-003 可以继续复核。
```

## 3. 回执样例

```text
杰哥，收到。

我已按影子接收口径记录：任务 VF-20260508-003 有一条“总管判断结果已带回”的信息。

当前可继续的是视频线人工复核，不是自动渲染或发布。后续仍需要核对：
1. 判断范围是生成、渲染、发布还是只允许继续复核；
2. 是否有单独的生成放行和发布放行；
3. 素材授权、AI 标识、平台规范是否仍有缺口。

本次没有读取总管文件、没有企业微信真实外发、没有触发 n8n、没有渲染或发布。
```

## 4. 状态建议

| 字段 | 建议值 |
|---|---|
| 当前状态 | 总管判断结果已收到-待视频线人工复核 |
| 下一步允许动作 | 生成复核问题清单或最终确认清单 |
| 自动渲染 | 否 |
| 自动发布 | 否 |
| 真实外发 | 否 |

## 5. 边界声明

本样例只定义回执文本，不发送企业微信，不调用企业微信接口，不修改公共接入配置。

本样例不读取总管文件、不写总管、不触发 n8n、不调用真实模型、不读取素材、不渲染、不上传、不发布。
