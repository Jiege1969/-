# VIDEO_AGENT_REVIEW_QUEUE_ESCALATION_RULE_001 复核队列升级规则 v1.0

- 资产类型：复核规则
- 施工等级：W1/R0
- 适用范围：视频制作影子复核队列
- 状态：草案

## 目的

当普通复核队列发现红线、跨系统、真实执行或职责不清时，必须升级为阻断或总管判断，而不是继续在业务线内推进。

## 升级规则

| 场景 | 当前队列 | 升级到 | 处理方式 | 是否实施真实动作 |
|---|---|---|---|---|
| 涉及真实账号、Cookie、API Key | 任意队列 | 红线阻断登记 | 记录阻断原因 | 否 |
| 需要接企业微信公共路由 | 任意队列 | 总管判断 | 生成对齐请求 | 否 |
| 需要接 n8n | 任意队列 | 总管判断 | 生成阻断登记 | 否 |
| 需要真实渲染或发布 | 任意队列 | 门禁一致性复核队列 | 检查三段门禁 | 否 |
| 平台规则无法确认 | 平台规范复核队列 | 发布合规复核队列 | 补规则缺口 | 否 |
| 素材授权无法确认 | 素材授权复核队列 | 红线阻断登记 | 保持不可执行 | 否 |
| AI 标识确认缺失 | 发布合规复核队列 | AI 标识确认待补 | 生成确认回执模板 | 否 |
| 职责归属不清 | 任意队列 | 总控复核人 | 明确主责任队列 | 否 |

## 固定原则

1. 升级不是放行。
2. 总管判断不是业务线自行修改总管文件。
3. 红线阻断登记不是执行许可。
4. 任何升级结果都必须生成回传记录或缺口记录。

## 边界

本规则不创建真实工单、不分派真实人员、不触发真实系统。
