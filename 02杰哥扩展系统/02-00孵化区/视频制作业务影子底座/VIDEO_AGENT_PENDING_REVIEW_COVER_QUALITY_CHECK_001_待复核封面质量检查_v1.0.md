# VIDEO_AGENT_PENDING_REVIEW_COVER_QUALITY_CHECK_001 待复核封面质量检查

> 业务线：视频制作业务影子底座
> 层级：W1/R0
> 状态：影子质量检查，不是真实交付审核
> 日期：2026-05-08

## 目的

检查待复核输出封面是否足够醒目地标注影子身份、人工复核状态、红线状态、缺口和正式执行禁止项。

## 检查项

| 检查项 | 通过标准 |
|:---|:---|
| 影子身份明确 | 必须写明不是正式视频制作系统输出 |
| 复核状态明确 | `review_status` 必须为 `pending_human_review` |
| 正式执行禁止 | `formal_execution_allowed` 必须为 `false` |
| 红线状态明确 | 命中红线时必须列出类别 |
| 缺口明确 | 待补字段必须列明 |
| 人工复核明确 | 待复核项必须列明 |
| 边界声明完整 | 必须说明不生成、不渲染、不发布、不外发 |

## 不合格处理

- 缺影子身份：退回封面模板补齐。
- 出现正式执行许可：转红线阻断回执。
- 缺待复核项：转复核队列空白登记表。

## 边界

本检查不审核真实交付物，不批准发布，不发送企业微信。
