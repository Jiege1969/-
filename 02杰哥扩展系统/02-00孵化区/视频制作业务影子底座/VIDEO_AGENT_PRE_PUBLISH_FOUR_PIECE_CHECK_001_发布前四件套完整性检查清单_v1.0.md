# VIDEO_AGENT_PRE_PUBLISH_FOUR_PIECE_CHECK_001 发布前四件套完整性检查清单 v1.0

- 资产类型：发布前完整性检查清单
- 施工等级：W1/R0
- 适用范围：视频制作影子发布前人工复核链
- 状态：草案

## 目的

发布前至少要同时具备四类人工确认材料：成品预览复核、AI 标识确认、素材授权证明、发布放行确认。任一缺失时，发布命令必须被拒绝并转入待复核。

## 四件套

| 编号 | 材料 | 对应模板/记录 | 缺失后处理 | 是否单独构成发布放行 |
|---|---|---|---|---|
| PPC-001 | 成品预览复核 | 成品预览复核回执模板 | 转成品预览复核队列 | 否 |
| PPC-002 | AI 标识确认 | AI 标识确认回执模板 | 转发布合规复核队列 | 否 |
| PPC-003 | 素材授权证明 | 素材授权证明回执模板 | 转素材授权复核队列 | 否 |
| PPC-004 | 发布放行确认 | 发布放行清单或发布放行回执 | 转门禁一致性复核队列 | 否 |

## 最小通过条件

1. 四件套均有记录编号。
2. 四件套均为人工确认，不是系统自动推断。
3. 四件套均未出现红线阻断。
4. 三段门禁状态一致：生成、真实渲染、发布不得互相替代。
5. 仍需总管或正式系统整合时，只输出待整合提示，不执行发布。

## 拒绝口径

```text
发布前四件套未齐，不能进入真实发布。
缺失项：[列出缺失材料]
下一步：进入对应人工复核队列。
真实系统触发：否。
```

## 边界

本清单只做完整性检查，不连接平台、不调用发布工具、不触发企业微信真实外发。
