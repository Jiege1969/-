# VIDEO_AGENT_REDLINE_BLOCK_REGISTER_001 红线阻断登记簿模板

> 版本：v1.0  
> 生成时间：2026-05-08 10:52:00 +08:00  
> 资产身份：视频制作线 W1/R0 红线阻断登记模板  
> 风险等级：低风险  
> 边界声明：只登记阻断，不实施红线动作。

## 用途

当连续施工遇到真实模型、真实渲染、真实发布、n8n、企业微信真实外发、服务端口、总管文件、公共组件、正式库、真实账号等红线时，本模板用于记录“为什么停在阻断登记”，并自动转向低风险替代动作。

## 登记字段

| 字段 | 说明 |
|---|---|
| 阻断编号 | REDLINE-VIDEO-YYYYMMDD-001 |
| 触发指令 | 用户原始指令或系统候选动作 |
| 命中红线类型 | 模型 / 渲染 / 发布 / n8n / 企业微信外发 / 服务端口 / 越权写入 / 真实账号 |
| 风险说明 | 为什么不能实施 |
| 当前状态 | 已阻断 / 待总管裁定 / 已转低风险替代 |
| 替代影子动作 | 可继续做的字段、模板、缺口卡、自检报告 |
| 是否触发真实系统 | 固定为否 |
| 是否需要总管整合 | 是 / 否 |
| 下一步 W1/R0 候选 | 自动接续的小任务 |

## 替代动作规则

1. 要接真实模型时，改为生成模型接入前置条件清单。
2. 要真实渲染时，改为生成真实渲染放行缺口卡。
3. 要真实发布时，改为生成发布前最终门禁摘要。
4. 要企业微信真实外发时，改为生成企业微信回执草案。
5. 要改总管或公共组件时，改为本线对齐回传记录。

## 自检

- [x] 阻断登记不实施红线动作。
- [x] 替代动作保持 W1/R0。
- [x] 不触发真实系统。
