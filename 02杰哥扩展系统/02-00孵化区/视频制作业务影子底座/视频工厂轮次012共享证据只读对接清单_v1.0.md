## 一、用途

本清单用于把 `02视频制作系统` 轮次012总控层与孵化区已经建立的共享政策证据、平台规范来源卡和素材授权待补字段对齐。

它不是生产接口配置，也不是 n8n 工作流；它只说明：视频工厂在生成本地预演任务单、脚本草案、分镜草案、发布前检查草案时，哪些证据可以只读参考，哪些结论不能输出。

## 五、建议的只读接入步骤

```text
视频工厂本地任务单
-> 读取合规规则中的默认边界和任务状态
-> 读取平台规范来源卡或共享证据样例
-> 生成平台规范/素材授权待复核问题
-> 写入本地对话草案或待复核清单
-> 等待人工复核
```

任何一步需要真实素材目录、剪辑器、渲染器、发布平台账号、企业微信真实发送或 n8n，立即停止并标 W3。
