## 1. 适用场景

当用户通过“杰哥视频助理”表达类似“VF-20260508-003 最终确认材料已补齐”时，本回执用于说明：

1. 系统可以在影子层登记“缺口材料看起来已补齐”。
2. 仍需人工做最终确认。
3. 不自动触发生成、渲染、发布、n8n 或企业微信真实外发。

## 2. 输入样例

```text
VF-20260508-003 最终确认材料已补齐，请继续。
```

## 3. 回执样例

```text
杰哥，收到。

我已按影子检查口径登记：任务 VF-20260508-003 的最终确认缺口材料显示为“已补齐待人工确认”。

当前仍不能自动发布，原因是：
1. 缺口补齐只代表材料进入最终确认队列；
2. 生成放行、渲染放行、发布放行必须拆开；
3. 发布前还需要人工确认 AI 标识、平台规范、素材授权和最终成片预览。

下一步可做的是：生成“最终人工确认待签字清单”或登记“需交回总管判断”的阻断项。

本次没有触发真实渲染、真实发布、企业微信真实外发或 n8n。
```

## 4. 状态写法

| 字段 | 建议值 |
|---|---|
| 任务ID | VF-20260508-003 |
| 当前状态 | 最终确认缺口已补齐待人工确认 |
| 下一步允许动作 | 生成最终人工确认待签字清单 |
| 自动发布 | 否 |
| 真实外发 | 否 |
| 是否需要总管判断 | 仅在命中红线或请求真实执行时需要 |

## 5. 边界声明

本样例只定义回执文本和状态表达，不接入企业微信接口，不发送真实消息，不改企业微信公共接入配置。

本样例不调用真实模型、不读取真实素材、不渲染、不上传、不发布、不触发 n8n。
