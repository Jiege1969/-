# VIDEO_AGENT_CONTINUATION_STATE_CARD_001 连续施工状态卡

> 版本：v1.0  
> 生成时间：2026-05-08 10:52:00 +08:00  
> 资产身份：视频制作线 W1/R0 连续施工状态卡  
> 风险等级：低风险  
> 边界声明：只记录本业务线影子施工的接续状态，不修改总管、不触发企业微信、不接 n8n、不渲染、不发布。

## 用途

本卡用于把“完成一轮后自动进入下一轮”的工作方式固定下来，避免每次完成一份影子产物后停在等待确认状态。

## 状态字段

| 字段 | 说明 |
|---|---|
| 当前施工轮次 | 本业务线内部连续施工轮次编号 |
| 已读总管面板 | 每轮开始是否已只读总管面板 |
| 已读一键接续包 | 每轮开始是否已只读一键接续包 |
| 当前候选任务 | 本轮选择的 W1/R0 小任务 |
| 候选来源 | 影子队列、上一轮下一步建议、缺口卡或人工复核链 |
| 写入范围 | 必须限定在视频制作系统或视频制作业务影子底座 |
| 风险等级 | 低风险 / 需登记阻断 |
| 红线命中 | 是否命中真实模型、真实渲染、真实发布、n8n、真实外发等 |
| 本轮自检结果 | 通过 / 待复核 |
| 本轮回传记录 | 对齐回传记录文件名 |
| 下一轮自动候选 | 完成本轮后自动选择的下一项 |

## 自动接续规则

1. 每轮开始先只读总管面板和一键接续包。
2. 若当前候选可在 W1/R0 内完成，则直接施工。
3. 若候选缺少输入，则转为缺口卡、字段清单、模板或自检报告。
4. 若命中红线，只登记阻断，不实施。
5. 完成一轮后自动选择下一轮候选，不停在“是否继续”。

## 禁止事项

- 不改总管文件。
- 不改公共组件。
- 不改服务端口。
- 不接真实模型。
- 不读取真实素材。
- 不渲染、不上传、不发布。
- 不真实发送企业微信。
