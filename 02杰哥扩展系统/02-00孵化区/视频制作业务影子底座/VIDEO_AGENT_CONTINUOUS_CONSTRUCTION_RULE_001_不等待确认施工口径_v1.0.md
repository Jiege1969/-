# VIDEO_AGENT_CONTINUOUS_CONSTRUCTION_RULE_001_不等待确认施工口径_v1.0

> 资产身份：视频制作业务影子底座连续施工规则卡
> 阶段：W1/R0
> 状态：本线接续口径，不是总管规则、不改正式服务。

## 核心规则

在视频制作业务影子底座内，凡是低风险、可自动完成、只写本线影子目录的施工事项，不再等待用户反复输入“继续”。

## 自动推进条件

| 条件 | 处理 |
|:---|:---|
| 只读总管施工面板和一键接续施工包 | 自动执行 |
| 只在视频制作业务影子底座写入文本或 JSON 草案 | 自动执行 |
| 不触发真实系统、不改正式入口、不读取凭据 | 自动执行 |
| 能通过 JSON 解析和边界扫描验证 | 自动收口 |
| 需要总管吸收但不需要总管立即改配置 | 生成回传记录，不暂停施工 |

## 红线阻断条件

| 红线 | 处理 |
|:---|:---|
| 真实接入企业微信、n8n、发布平台或外部引擎 | 只登记阻断，不实施 |
| 读取或保存账号、密钥、企业微信凭据 | 只登记阻断，不实施 |
| 启动、重启服务或修改端口 19310/19302 | 只登记阻断，不实施 |
| 修改正式视频系统脚本、正式入口或公共组件配置 | 只登记阻断，不实施 |
| 读取真实素材、生成视频、配音、字幕、封面、转码、渲染或发布 | 只登记阻断，不实施 |

## 每轮固定动作

1. 先只读总管施工面板、一键接续施工包和视频线最新总收口。
2. 选择下一项低风险影子施工任务。
3. 只在视频制作业务影子底座内写入资产。
4. 运行 JSON 解析和边界扫描。
5. 更新索引、生成自检和对齐回传。
6. 如无红线，下一轮继续从最新总收口的自动队列推进。

## 输出口径

对外报告应说明“已继续施工”，而不是询问“是否继续”。只有红线事项才说明阻断原因，并把请求交回总管判断。
