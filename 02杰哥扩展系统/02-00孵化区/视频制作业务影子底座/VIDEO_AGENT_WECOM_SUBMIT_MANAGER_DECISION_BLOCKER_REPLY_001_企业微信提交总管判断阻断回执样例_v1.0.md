# VIDEO_AGENT_WECOM_SUBMIT_MANAGER_DECISION_BLOCKER_REPLY_001 企业微信提交总管判断阻断回执样例

- 版本：v1.0
- 日期：2026-05-08
- 所属业务线：视频制作系统
- 所属层级：W1/W2 影子回执样例
- 当前状态：草案
- 终端角色：杰哥视频助理

## 1. 适用场景

当用户通过“杰哥视频助理”要求系统把事项“提交总管判断”时，如果当前视频线窗口没有权限写总管、改路由或真实外发，本回执用于说明：已识别为需总管判断，但本线只登记阻断，不代替总管执行。

## 2. 输入样例

```text
把 VF-20260508-003 提交总管判断，准备发布。
```

## 3. 回执样例

```text
杰哥，已识别：任务 VF-20260508-003 涉及“提交总管判断/准备发布”。

当前视频制作线只能做影子登记，不能直接写总管面板，也不能触发真实发布。

我已生成“需总管判断缺口卡”的影子记录口径。后续需要你在总管对话框中确认，或由总管侧吸收这条回传。

本次没有修改总管文件、没有企业微信真实外发、没有触发 n8n、没有渲染或发布。
```

## 4. 状态建议

| 字段 | 建议值 |
|---|---|
| 当前状态 | 需总管判断-视频线已登记阻断 |
| 用户可见结论 | 已识别需上交，但本线不代办真实提交 |
| 视频线可继续动作 | 输出缺口卡、待复核问题、回执草案 |
| 禁止动作 | 改总管、发企业微信、触发 n8n、发布 |

## 5. 边界声明

本样例只定义回执文本，不发送企业微信，不调用企业微信接口，不修改公共接入配置。

本样例不写总管、不触发 n8n、不调用真实模型、不读取素材、不渲染、不上传、不发布。
