# VIDEO_AGENT_CONTINUOUS_QUEUE_NEXT_001 连续施工下一轮候选队列 v1.0

- 资产类型：影子施工候选队列
- 施工等级：W1/R0
- 适用范围：视频制作线连续自动施工
- 状态：草案

## 队列目的

当用户授权“连续自动施工”后，若当前任务完成但未触发红线，系统不应停在等待确认，而应从本队列中自动选择下一个低风险影子任务继续推进。

## 自动选择原则

1. 优先选择只写入视频制作业务影子底座的任务。
2. 优先补齐人工复核链、状态契约、检查清单、占位样例和回传记录。
3. 遇到真实模型、真实渲染、真实发布、n8n、企业微信真实外发、服务端口、总管文件或公共组件时，只登记阻断。
4. 缺少输入时，自动转为输入条件核对、缺口卡、占位模板或待复核问题清单。

## 停止条件

仅在以下情况暂停并回传阻断：

- 需要改总管或公共组件。
- 需要接真实模型 API。
- 需要读取真实素材或真实账号。
- 需要真实渲染、上传、发布或企业微信真实外发。
- 需要接 n8n、服务脚本或端口。
- 缺少关键上下文且无法通过缺口卡表达。
