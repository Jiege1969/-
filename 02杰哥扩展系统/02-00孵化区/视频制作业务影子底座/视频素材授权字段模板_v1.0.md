# 视频素材授权字段模板

> 版本：v1.0
> 状态：影子字段模板，不读取真实素材
> 边界声明：不读取真实素材，不转码，不剪辑，不渲染，不生成字幕/封面/配音，不发布，不外发，不触发 n8n 或企业微信。

## 用途

用于后续登记用户明确授权的素材范围，避免把样片、参考图、网络素材误当作可用素材。

## 字段模板

| 字段 | 说明 | 状态 |
|:---|:---|:---|
| asset_id | 素材编号 | 待生成 |
| asset_type | 视频 / 音频 / 图片 / 字幕 / 字体 / Logo | 待确认 |
| source | 用户提供 / 自有素材 / 授权素材 / 公开参考 | 待确认 |
| authorization_scope | 可剪辑 / 可发布 / 仅参考 / 禁止使用 | 待确认 |
| owner | 权利方或来源方 | 待补 |
| usage_limit | 使用限制 | 待补 |
| privacy_risk | 是否含个人、客户、地址、账号等敏感信息 | 待判 |
| expiry_date | 授权期限 | 待补 |
| human_review | 人工复核意见 | 待填写 |

## 禁止项

- 不主动读取素材目录。
- 不把公开参考自动视为可商用素材。
- 不把未确认授权素材放入制作方案。
