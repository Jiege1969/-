# VIDEO_AGENT_MANAGER_DECISION_INCOMPLETE_RETURN_GAP_CARD_001 判断结果信息不完整退回缺口卡

- 版本：v1.0
- 日期：2026-05-08
- 所属业务线：视频制作系统
- 所属层级：W1/W2 影子缺口卡
- 当前状态：草案

## 1. 定位

本缺口卡用于处理“总管判断结果已带回，但信息不完整”的情况。

本卡只登记缺口，不退回真实总管、不发送企业微信、不触发任何真实执行。

## 2. 信息不完整判定

| 缺口 | 判定口径 | 默认处理 |
|---|---|---|
| 缺任务ID | 无法绑定视频任务 | 退回补任务ID |
| 缺判断来源 | 无法确认来自总管还是人工口述 | 退回补来源 |
| 缺判断范围 | 未说明生成、渲染、发布、素材、合规或路由 | 退回补范围 |
| 缺执行边界 | 未说明是否允许真实执行 | 默认不允许执行 |
| 缺人工复核要求 | 未说明是否仍需人工复核 | 默认仍需人工复核 |
| 缺放行拆分 | 未拆分生成放行、渲染放行、发布放行 | 不进入发布链 |

## 3. 缺口卡字段

| 字段 | 说明 |
|---|---|
| 缺口卡ID | 视频线本地编号 |
| 关联任务ID | 可为空，若为空必须列为缺口 |
| 原始判断摘要 | 人工带回的判断摘要 |
| 缺失字段 | 从信息不完整判定中选择 |
| 默认阻断结果 | 不执行、不发布、不外发 |
| 需要补充的问题 | 面向人工或总管的问题 |
| 视频线可继续事项 | 只能生成待补问题或复核清单 |

## 4. 样例

| 字段 | 样例 |
|---|---|
| 缺口卡ID | VAI-GAP-RETURN-20260508-001 |
| 关联任务ID | VF-20260508-003 |
| 原始判断摘要 | 总管说可以继续 |
| 缺失字段 | 判断范围、执行边界、放行拆分 |
| 默认阻断结果 | 不渲染、不发布、不外发 |
| 需要补充的问题 | 是继续人工复核，还是允许某一类放行？是否已单独拆分生成/渲染/发布？ |
| 视频线可继续事项 | 生成待补问题清单 |

## 5. 边界声明

本缺口卡不读取总管文件，不写总管，不调用企业微信接口，不修改公共组件。

本缺口卡不调用真实模型、不读取真实素材、不渲染、不上传、不发布、不触发 n8n。
