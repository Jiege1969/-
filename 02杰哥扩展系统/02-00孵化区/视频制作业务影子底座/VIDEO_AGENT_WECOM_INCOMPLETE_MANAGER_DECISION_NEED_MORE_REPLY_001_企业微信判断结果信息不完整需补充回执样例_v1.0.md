# VIDEO_AGENT_WECOM_INCOMPLETE_MANAGER_DECISION_NEED_MORE_REPLY_001 企业微信判断结果信息不完整需补充回执样例

- 版本：v1.0
- 日期：2026-05-08
- 所属业务线：视频制作系统
- 所属层级：W1/W2 影子回执样例
- 当前状态：草案
- 终端角色：杰哥视频助理

## 1. 适用场景

当用户带回一句不完整判断，例如“总管说可以继续”“可以发了”“先按这个走”，但没有明确任务ID、判断范围、放行拆分或执行边界时，本回执用于提示需要补充信息。

## 2. 输入样例

```text
总管说这个可以继续，发吧。
```

## 3. 回执样例

```text
杰哥，我收到这条判断结果，但当前信息还不完整，不能进入生成、渲染或发布。

还需要补齐这几项：
1. 对应的视频任务ID；
2. 总管判断的范围：是继续人工复核、生成放行、渲染放行，还是发布放行；
3. 是否已经单独确认素材授权、AI 标识和平台规范；
4. 是否仍需要视频线最终人工复核。

在这些信息补齐前，我只能登记为“判断结果信息不完整-待补充”，不会触发渲染、发布、企业微信真实外发或 n8n。
```

## 4. 状态建议

| 字段 | 建议值 |
|---|---|
| 当前状态 | 判断结果信息不完整-待补充 |
| 下一步允许动作 | 生成待补问题清单 |
| 自动渲染 | 否 |
| 自动发布 | 否 |
| 真实外发 | 否 |

## 5. 边界声明

本样例只定义回执文本，不发送企业微信，不调用企业微信接口，不修改公共接入配置。

本样例不读取总管文件、不写总管、不触发 n8n、不调用真实模型、不读取素材、不渲染、不上传、不发布。
