# VIDEO_AGENT_ASSET_NAMING_CONFLICT_CHECK_001 影子资产命名冲突检查清单 v1.0

- 资产类型：命名检查清单
- 施工等级：W1/R0
- 适用范围：视频制作业务影子底座新增资产
- 状态：草案

## 目的

连续自动施工时，资产数量增长很快。命名检查用于避免重复编号、同义重复、旧资产被覆盖、影子草案误写成正式文件。

## 检查项

| 编号 | 检查项 | 标准 | 不通过处理 |
|---|---|---|---|
| NC-001 | 前缀唯一 | 新文件前缀不与既有文件冲突 | 改为新编号，不覆盖旧文件 |
| NC-002 | 中英文口径一致 | md 和 json 的资产 ID、版本、主题一致 | 退回修正 |
| NC-003 | 阶段编号连续 | VAI 编号不倒退、不复用 | 改用下一编号 |
| NC-004 | 影子标识明确 | 文件标题或状态含“影子/草案/W1/R0” | 补标识 |
| NC-005 | 不冒充正式入口 | 文件名不包含“正式上线”“正式发布”“正式入口”等误导词 | 改为影子草案 |
| NC-006 | 不覆盖旧资产 | 不删除、不移动、不重写旧资产 | 新增修正版或回传说明 |
| NC-007 | 配对完整 | 关键资产优先 md/json 配对 | 补配对文件 |
| NC-008 | 编码可读 | 文件应为 UTF-8 可读文本 | 新增修正记录，不移动旧文件 |

## 输出

命名冲突出现时，只输出：

- 冲突文件名。
- 冲突类型。
- 建议新文件名。
- 是否需要总管判断。

不直接删除或移动任何旧资产。
