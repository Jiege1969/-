# 视频投稿规格与素材授权待补字段清单

> 版本：v1.0  
> 日期：2026-05-07  
> 资产身份：视频投稿规格与素材授权待补字段影子清单  
> 风险等级：W1  
> 边界：只做字段清单，不读取真实素材，不连接平台账号，不剪辑、不渲染、不上传、不发布、不外发、不接 n8n。  

## 一、用途

本清单用于承接 VIDEO 002 中仍未补齐的投稿规格、分区规则和素材授权缺口。它帮助视频制作系统在生成脚本、分镜、素材清单或发布前检查草案时，明确哪些信息缺失会阻断“可发布/平台合规/版权安全”结论。

## 二、平台规格待补字段

| 字段 | 说明 | 当前状态 | 缺失影响 |
|:---|:---|:---|:---|
| target_platform | 目标发布平台，如B站、视频号、抖音等 | missing | 不知道适用哪套平台规则 |
| content_type | 普通投稿、活动投稿、直播切片、商业宣传、课程等 | missing | 无法判断分区或活动规则 |
| current_rule_url | 当前投稿规范、帮助中心或分区规则链接 | missing | 不能判断规则是否最新 |
| collected_date | 规则采集日期 | missing | 无法控制规则时效 |
| duration_limit | 时长限制 | missing | 不能给剪辑时长建议 |
| resolution_requirement | 分辨率要求 | missing | 不能给导出规格建议 |
| aspect_ratio | 横版、竖版或平台特殊比例 | missing | 不能给画幅规格建议 |
| cover_requirement | 封面尺寸、文字、审核风险 | missing | 不能给封面合规建议 |
| subtitle_requirement | 字幕语言、敏感词、可读性要求 | missing | 不能给字幕交付建议 |
| tag_or_topic_requirement | 活动标签、话题、分区标签 | missing | 不能给投稿信息建议 |

## 三、素材授权待补字段

| 字段 | 说明 | 当前状态 | 缺失影响 |
|:---|:---|:---|:---|
| asset_id | 素材编号 | missing | 不能形成可追溯素材清单 |
| asset_type | 视频、音频、图片、字幕、字体、Logo | missing | 无法判断授权类别 |
| source | 用户提供、自有、授权、公开参考、第三方平台 | missing | 无法判断可用性 |
| authorization_scope | 可剪辑、可发布、仅参考、禁止使用 | missing | 不能进入制作方案 |
| owner | 权利方或来源方 | missing | 无法追溯版权责任 |
| usage_limit | 商用、非商用、平台限制、地域限制 | missing | 无法判断使用边界 |
| privacy_risk | 是否含个人、客户、地址、账号、车牌等敏感信息 | missing | 无法判断脱敏需求 |
| expiry_date | 授权期限 | missing | 无法判断授权是否过期 |
| human_review | 人工复核意见 | missing | 不能升级为可用素材 |

## 四、阻断规则

| 缺口 | 阻断内容 |
|:---|:---|
| 未明确目标平台 | 阻断平台规格建议和发布结论 |
| 未补当前规则链接 | 阻断平台合规结论 |
| 未补素材授权范围 | 阻断素材进入制作方案 |
| 未补隐私风险判断 | 阻断外发、发布、公开展示 |
| 未补人工复核 | 阻断版权安全和可发布结论 |

## 五、可继续输出

- 脚本结构草案。
- 分镜结构草案。
- 平台规范待补清单。
- 素材授权待补清单。
- 发布前人工复核问题。
- 风险提示。

## 六、禁止输出

- 不输出“可发布”。
- 不输出“平台合规已确认”。
- 不输出“版权安全”。
- 不输出“素材可商用”。
- 不触发剪辑、渲染、上传、发布或外发。

## 七、人工复核问题

1. 目标平台和内容类型是什么？
2. 当前使用的投稿规范链接是哪一个，采集日期是什么？
3. 每个素材的来源和权利方是谁？
4. 每个素材是否可剪辑、可发布、可商用、可跨平台使用？
5. 是否包含个人、客户、地址、账号、电话、车牌等敏感信息？
6. 是否需要法务、品牌、客户或平台运营人员复核？
