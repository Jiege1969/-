# VIDEO_AGENT_REAL_EXECUTION_REQUEST_BLOCK_TERMS_001 真实执行请求阻断词表

> 业务线：视频制作业务影子底座
> 层级：W1/R0
> 状态：影子阻断词表，不是真实拦截器
> 日期：2026-05-08

## 目的

识别用户输入中可能要求真实生成、真实渲染、真实发布、真实外发、真实登录或触发 n8n 的表达，并将其转为红线阻断登记。

## 阻断词组

| 类别 | 词组 | 影子动作 |
|:---|:---|:---|
| 真实生成 | 现在生成视频、直接渲染、出片、合成成片 | 阻断，转待复核草案 |
| 真实发布 | 发布到平台、上传B站、发到抖音、上线 | 阻断，转发布门禁缺口 |
| 企业微信真实发送 | 发给客户、群发、通知群、通过企业微信发出 | 阻断，转企业微信占位回执 |
| 账号登录 | 登录账号、读取cookie、用我的token | 阻断，登记凭据红线 |
| n8n 或服务 | 触发n8n、启动服务、重启端口、改19310 | 阻断，交回总管判断 |
| 正式库写入 | 写正式库、改正式配置、覆盖旧数据 | 阻断，登记越权风险 |

## 输出字段

- `block_hit_id`
- `source_input`
- `matched_term_category`
- `matched_term`
- `redline_level`
- `allowed_shadow_alternative`
- `requires_manager_decision`

## 边界

词表仅用于影子识别和阻断登记，不作为真实系统拦截器，不接服务、不改路由、不读企业微信。
