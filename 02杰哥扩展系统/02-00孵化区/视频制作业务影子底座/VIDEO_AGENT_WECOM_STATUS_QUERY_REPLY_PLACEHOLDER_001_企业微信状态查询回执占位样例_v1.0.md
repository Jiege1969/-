# VIDEO_AGENT_WECOM_STATUS_QUERY_REPLY_PLACEHOLDER_001 企业微信状态查询回执占位样例

> 业务线：视频制作业务影子底座
> 层级：W1/R0
> 状态：占位样例，不是真实企业微信回执
> 日期：2026-05-08

## 目的

为未来企业微信“状态查询”类对话预留影子回执格式。该文件不接真实企业微信，不读取凭据，不发送消息。

## 回执占位格式

```text
【影子状态查询回执】
影子任务：{shadow_task_id}
当前状态：{current_shadow_status}
最近动作：{last_shadow_action}
待补字段：{missing_fields}
待人工复核：{human_review_items}
红线状态：{redline_status}
下一步影子动作：{next_shadow_action}

说明：以上为视频制作影子底座待复核信息，不代表正式生成、渲染、发布或外发结果。
```

## 状态查询响应规则

| 查询意图 | 影子响应 |
|:---|:---|
| 查询任务进度 | 返回当前影子状态和最近动作 |
| 查询待补事项 | 返回缺口字段和待复核项 |
| 查询能否发布 | 返回发布门禁状态，不能写成发布许可 |
| 查询企业微信发送状态 | 返回“未接真实发送，仅占位” |
| 查询真实生成结果 | 返回红线阻断说明 |

## 边界

此样例只作为未来对接前的格式草案。真实路由、真实发送、真实消息读取、凭据读取、服务接入和 n8n 流转均不在本线实施。
