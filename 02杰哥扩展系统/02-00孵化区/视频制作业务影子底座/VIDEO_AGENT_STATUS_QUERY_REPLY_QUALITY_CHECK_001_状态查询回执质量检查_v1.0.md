# VIDEO_AGENT_STATUS_QUERY_REPLY_QUALITY_CHECK_001 状态查询回执质量检查

> 业务线：视频制作业务影子底座
> 层级：W1/R0
> 状态：影子质量检查，不是真实发送前审核
> 日期：2026-05-08

## 目的

检查状态查询占位回执是否清晰、可追溯、不越界，防止把影子状态写成正式完成、正式发布或真实企业微信发送状态。

## 质量检查项

| 检查项 | 通过标准 |
|:---|:---|
| 任务可识别 | 有影子任务编号或明确缺口说明 |
| 状态可追溯 | 当前状态可回到影子状态记录 |
| 缺口说清楚 | 缺失字段列明，不编造 |
| 复核说清楚 | 待人工复核项明确 |
| 红线说清楚 | 真实生成、发布、外发请求必须阻断 |
| 语气合规 | 不使用“已发布”“已发送”“已上线”等正式完成措辞 |
| 下一步可执行 | 下一步仅限影子动作或人工复核 |

## 不合格处理

- 无任务编号：转状态查询缺口卡。
- 有正式完成措辞：转回执字段一致性检查。
- 命中真实执行请求：转红线阻断登记。

## 边界

本检查不发送企业微信，不读取真实会话，不调用真实服务。
