## 1. 用途

本队列用于登记局部修正链路中出现的待补问题。它只记录问题、分级、责任归属和下一步门禁，不触发真实模型、真实渲染、真实发布、企业微信真实外发或 n8n。

## 3. 问题类型说明

| 问题类型 | 说明 | 可做动作 | 禁止动作 |
|----------|------|----------|----------|
| 文案 | 表达、语气、AI感、结构问题 | 生成影子修改建议 | 不调用真实模型 |
| 分镜 | 画面逻辑、镜头顺序、具体场景问题 | 生成分镜修正草案 | 不读取素材库 |
| 素材授权 | 来源、授权、隐私和肖像风险问题 | 登记缺口 | 不下载素材 |
| 平台规则 | 标题、标签、AI标识、平台规范问题 | 登记待补项 | 不登录平台账号 |
| 合规 | 焦虑贩卖、绝对化表达、洗稿风险 | 登记阻断或删除建议 | 不进入生成、渲染、发布 |

## 4. 状态枚举

- 待补：问题已登记，尚未处理。
- 处理中：正在生成影子草案或待补清单。
- 已转复核：已生成影子输出，等待人工复核。
- 已阻断：命中红线或高风险，不能继续。
- 已关闭：人工确认问题已处理，但不代表生成、渲染或发布放行。

## 5. 边界声明

- 问题队列不替代任务单。
- 问题队列不替代人工复核回执。
- 问题队列不替代生成、渲染、发布放行清单。
- 问题队列不授权任何真实执行。
