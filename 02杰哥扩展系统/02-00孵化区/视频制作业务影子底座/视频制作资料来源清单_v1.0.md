# 视频制作资料来源清单

> 版本：v1.0
> 状态：影子资料清单，不是正式素材库
> 边界声明：不读取真实素材，不转码，不剪辑，不渲染，不生成字幕/封面/配音，不发布，不外发，不触发 n8n 或企业微信。

| 来源类型 | 示例 | 当前状态 | 使用边界 |
|:---|:---|:---|:---|
| 用户任务说明 | 视频目的、受众、时长、发布平台 | 待用户提供 | 只作需求草案输入 |
| 用户授权素材 | 视频、音频、图片、字幕、品牌素材 | 未接入 | 需用户明确授权目录 |
| 脚本与分镜 | 文案、镜头表、旁白稿 | 待用户提供 | 只做结构整理 |
| 平台规范 | 分辨率、时长、封面比例、字幕规范 | 待补 | 需记录来源和日期 |
| 风格参考 | 公开链接、样片描述、风格关键词 | 待用户提供 | 不等于版权授权 |
| 历史成片复盘 | 已发布视频、复盘记录 | 待用户筛选 | 先脱敏或确认授权 |

## 整理原则

- 先登记来源，不主动扫描素材目录。
- 素材授权不明确时，只记录待补，不进入处理。
- 平台规范需标注来源和适用时间。
- 历史样片只作复盘参考，不自动复制风格或素材。
