# VIDEO_AGENT_WECOM_SUBMIT_HUMAN_CONFIRMATION_REFUSAL_REPLY_001 企业微信提交人工确认拒绝回执样例 v1.0

- 资产类型：企业微信占位回执样例
- 施工等级：W1/W2 低风险影子施工
- 适用范围：用户通过企业微信尝试提交最终人工确认，但门禁材料不齐
- 状态：草案样例，不真实外发

## 输入命令样例

```text
我确认 VF-20260508-003 可以发布
```

## 拒绝回执样例

```text
已收到最终人工确认草案：VF-20260508-003。

当前不能接收为有效最终确认。

原因：
1. 发布前门禁总览记录缺失或未通过。
2. 发布前阻断汇总记录缺失。
3. 多平台检查未全部完成。
4. 素材授权证明未归档。

系统处理：
- 已保持发布阻断。
- 已转入门禁一致性复核队列。
- 未触发真实发布。

下一步：
请先补齐门禁总览、阻断汇总、多平台检查和素材授权证明。

真实系统触发：否。
```

## 固定规则

1. 口头确认不能替代结构化回执。
2. 门禁材料不齐时，必须拒绝最终确认。
3. 拒绝回执必须说明缺哪些材料。
4. 本样例不发送企业微信真实消息，不发布。
