# VIDEO_AGENT_CONVERSATION_STATE_CONTRACT_001 会话状态契约草案

> 版本：v1.0  
> 生成时间：2026-05-08 10:30:00 +08:00  
> 资产身份：视频创作智能体 W1/R0 会话状态字段契约草案  
> 风险等级：W1/R0  
> 边界声明：只定义会话状态字段，不接真实大模型，不写向量库，不修改 `video_factory_chat.py`，不读取真实素材，不渲染，不上传，不发布，不触发 n8n，不企业微信真实外发。

## 定位

本契约用于承接“杰哥视频助理”未来输入的一句话、多轮修改和人工确认结果，让视频制作影子工厂知道当前处于哪一个创作状态。它只服务影子链路，不代表真实会话系统已上线。

## 核心字段

| 字段 | 类型 | 必填 | 说明 |
|---|---|---:|---|
| 会话ID | string | 是 | 本次创作对话的唯一编号 |
| 会话来源 | string | 是 | 默认企业微信，但当前只登记来源，不真实外发 |
| 用户原始想法 | string | 是 | 用户未改写的创作输入，可脱敏 |
| 当前任务ID | string | 否 | 已生成任务单后绑定 |
| 当前创作目标 | string | 是 | 脚本、分镜、标题、封面建议、发布前复核等 |
| 目标平台 | list | 是 | 小红书、抖音、视频号、B站等，未知时填待确认 |
| 目标受众 | string | 是 | 受众画像或待确认 |
| 风格基调 | string | 是 | 温和、纪实、走心、幽默、知识型等 |
| 已确认内容 | list | 是 | 用户已明确确认且不得自动覆盖的内容 |
| 可修改内容 | list | 是 | 用户允许继续局部调整的内容 |
| 等待用户确认项 | list | 是 | 平台、主题、脚本、分镜、素材、AI标识等待确认项 |
| 合规阻断项 | list | 是 | 版权、隐私、平台规则、AI标识、发布风险等 |
| 生成放行状态 | string | 是 | not_requested / pending_human_gate / human_released_for_generation |
| 真实渲染放行状态 | string | 是 | not_requested / pending_human_gate / human_released_for_render |
| 发布放行状态 | string | 是 | not_requested / pending_human_gate / human_released_for_publish |
| 最近指令 | string | 否 | 最近一轮用户输入，用于意图路由 |

## 状态约束

1. `已确认内容` 不得被局部修正自动覆盖。
2. 生成放行、真实渲染放行、发布放行必须拆分。
3. `human_released_for_generation` 不等于 `human_released_for_render`，也不等于 `human_released_for_publish`。
4. 出现素材授权、隐私、平台规则、AI标识缺口时，必须进入 `等待用户确认项` 或 `合规阻断项`。
5. 本契约不得直接驱动模型调用、素材读取、渲染、上传、发布或企业微信外发。
