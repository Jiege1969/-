# 视频制作工作流梳理

> 版本：v1.0
> 状态：影子工作流草案，不是自动化制作流程
> 边界声明：不读取真实素材，不转码，不剪辑，不渲染，不生成字幕/封面/配音，不发布，不外发，不触发 n8n 或企业微信。

## 影子工作流

```text
用户提出视频任务
-> 判断视频类型和目标
-> 登记授权素材与待补资料
-> 拆解脚本/分镜/素材/字幕/封面需求
-> 标注版权、隐私、平台和发布风险
-> 生成待复核制作方案
-> 用户人工确认
-> 后续另行决定是否进入正式制作
```

## 节点说明

| 节点 | 输入 | 输出 | 人工确认点 |
|:---|:---|:---|:---|
| 视频类型判断 | 用户描述 | 视频类型、目标受众、时长草案 | 类型不清时确认 |
| 素材授权登记 | 素材说明、来源、授权边界 | 素材清单草案 | 授权不清时确认 |
| 制作需求拆解 | 文案、分镜、字幕、封面要求 | 需求拆解表 | 风格和版权边界确认 |
| 风险识别 | 素材、平台、发布目标 | 禁止动作、人工闸口 | 涉发布或外发必须确认 |
| 待复核方案 | 已确认资料 | 制作方案草案 | 采用前确认 |
| 经验沉淀 | 人工修正和复盘 | 进化样本候选 | 是否沉淀需确认 |

## 默认禁止动作

- 不读取素材目录。
- 不启动剪辑、转码、渲染、字幕、封面或配音工具。
- 不连接发布平台或企业微信。
- 不上传、发布或外发。
- 不把样片风格当作可复制授权。

## 第一阶段验收

- 每个节点都有输入、输出和人工确认点。
- 工作流明确为影子草案。
- 不包含脚本、计划任务、n8n工作流或真实处理入口。
