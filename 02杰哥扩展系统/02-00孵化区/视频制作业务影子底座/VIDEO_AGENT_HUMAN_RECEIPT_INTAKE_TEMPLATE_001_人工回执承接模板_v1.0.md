# VIDEO_AGENT_HUMAN_RECEIPT_INTAKE_TEMPLATE_001_人工回执承接模板_v1.0

> 资产身份：视频创作智能体影子层人工回执承接模板
> 阶段：W1/R0
> 状态：空白模板，不是正式验收结论
> 边界：只承接人工意见，不升级正式规则、不放行生成或发布。

## 使用场景

当人工对三候选草案、脚本草案、分镜草案、素材授权、平台规范、AI标识或原创性问题给出反馈时，使用本模板承接意见。

## 回执字段

| 字段 | 示例值 | 说明 |
|:---|:---|:---|
| 回执ID | `VAI-HR-0000` | 影子回执编号 |
| 关联输入ID | 待填写 | 对应影子输入记录 |
| 关联会话ID | 待填写 | 对应影子会话状态 |
| 关联候选方案ID | 待填写 | OPTION-A/B/C 或不适用 |
| 人工选择结果 | 待填写 | 选择、退回、合并、重写、阻断 |
| 修改意见 | 待填写 | 仅记录人工意见摘要 |
| 素材授权意见 | 待核验 | 不明确时继续阻断 |
| 平台规范意见 | 待核验 | 不明确时不得发布 |
| AI标识意见 | 待核验 | 需按平台规则复核 |
| 原创性意见 | 待核验 | 不作为自动原创判定 |
| 是否允许继续到下一影子步骤 | 待人工勾选 | 只限影子步骤，不等于生成或发布 |
| 是否形成进化候选 | 待复核 | 需要多案例验证后才可升级 |

## 禁止事项

1. 人工回执不等于正式视频上线许可。
2. 人工选择候选不等于生成、渲染或发布放行。
3. 单次人工意见不得直接写入正式规则库。
