# VIDEO_AGENT_RECEIPT_FIELD_CONSISTENCY_CHECK_001 回执字段一致性检查

> 业务线：视频制作业务影子底座
> 层级：W1/R0
> 状态：影子检查清单，不是真实审计程序
> 日期：2026-05-08

## 目的

检查人工回执、企业微信占位回执、关闭回执和对齐回传记录是否使用一致字段，保证后续追溯时能看清“谁、何时、基于什么、做了什么影子决定”。

## 检查项

| 检查项 | 标准 |
|:---|:---|
| 任务编号一致 | `shadow_task_id` 或关联编号必须可追溯 |
| 状态字段一致 | 不混用正式状态和影子状态 |
| 人工复核字段完整 | 需保留 `human_decision` 或待复核空位 |
| 红线字段完整 | 命中红线时必须写阻断，不写许可 |
| 证据引用完整 | 需指向影子资产或脱敏输入 |
| 时间字段明确 | 回执时间为空时必须标注待填写 |
| 正式边界明确 | 必须声明不代表真实生成、发布或外发 |

## 处理动作

- 字段缺失：转缺口卡。
- 状态冲突：转人工复核队列。
- 出现正式放行措辞：转红线阻断队列。

## 边界

本清单不审计真实系统，不读取真实消息，不写正式审计库。
