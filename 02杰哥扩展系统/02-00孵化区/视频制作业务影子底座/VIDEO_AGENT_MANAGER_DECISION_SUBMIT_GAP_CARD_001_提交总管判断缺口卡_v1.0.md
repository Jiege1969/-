# VIDEO_AGENT_MANAGER_DECISION_SUBMIT_GAP_CARD_001 提交总管判断缺口卡

- 版本：v1.0
- 日期：2026-05-08
- 所属业务线：视频制作系统
- 所属层级：W1/W2 影子缺口卡
- 当前状态：草案

## 1. 定位

本缺口卡用于记录：哪些视频制作线事项已经超出本业务线影子施工权限，需要交回总管对话框判断。

本卡只登记“应交回判断”的理由，不实际修改总管文件，不触发总管服务，不发送企业微信。

## 2. 触发条件

| 触发项 | 是否可由视频线处理 | 建议状态 |
|---|---|---|
| 请求接真实大模型 | 否 | 需总管判断 |
| 请求真实渲染或成片 | 否 | 需总管判断 |
| 请求真实上传或发布 | 否 | 需总管判断 |
| 请求接 n8n | 否 | 需总管判断 |
| 请求企业微信真实外发 | 否 | 需总管判断 |
| 请求改企业微信公共接入配置 | 否 | 需总管判断 |
| 请求改服务端口或重启服务 | 否 | 需总管判断 |
| 请求写正式视频系统、正式库或其他业务线 | 否 | 需总管判断 |
| 请求读取真实账号、Cookie、API Key | 否 | 需总管判断 |

## 3. 缺口卡字段

| 字段 | 说明 |
|---|---|
| 缺口卡ID | 自动或人工编号 |
| 任务ID | 关联视频任务ID |
| 用户原始指令 | 需要保留原话 |
| 命中红线 | 从触发条件中选择 |
| 当前处理方式 | 只登记阻断，不实施 |
| 建议交回对象 | 总管对话框或人工负责人 |
| 视频线可继续事项 | 影子清单、回执、待补问题 |
| 禁止动作 | 真实执行、外发、发布、改配置 |

## 4. 样例

| 字段 | 样例 |
|---|---|
| 缺口卡ID | VAI-GAP-MGR-20260508-001 |
| 任务ID | VF-20260508-003 |
| 用户原始指令 | 把这个视频直接发到抖音和小红书 |
| 命中红线 | 请求真实发布 |
| 当前处理方式 | 已登记阻断，不实施 |
| 建议交回对象 | 总管对话框 |
| 视频线可继续事项 | 生成发布前待复核问题清单 |
| 禁止动作 | 不上传、不发布、不调用发布工具 |

## 5. 边界声明

本缺口卡不向总管写入任何正式记录，不触发企业微信、不触发 n8n、不修改服务、不接真实账号。

本缺口卡不调用 MoneyPrinterTurbo、HappyHorse、Qwen-TTS、PostBot，不读取素材，不渲染，不上传，不发布。
