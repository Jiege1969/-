# 视频制作业务影子底座：开工五问校准

> 版本：v1.0
> 状态：影子底座，不是正式视频制作系统
> 边界声明：不读取真实素材，不转码，不剪辑，不渲染，不生成字幕/封面/配音，不发布，不外发，不触发 n8n 或企业微信。

## 1. 需求

建立视频制作业务的影子底座，用于整理视频任务类型、素材来源、流程节点、风险边界和待复核输出结构。

当前只做方法验证和需求拆解，不提供真实剪辑、真实渲染、自动发布或批量素材处理能力。

## 2. 输入

- 用户明确提供或授权的素材说明、脚本、分镜、字幕、封面需求和发布要求。
- 公开可核验的风格参考、平台规范或技术资料。
- 后续用户指定的本地素材目录。

当前待补：

- 第一批视频类型。
- 可使用素材的授权范围。
- 目标平台和输出规格。
- 用户可接受的人工确认节点。

## 3. 输出

- 视频资料来源清单。
- 视频数据源清单。
- 视频需求草案。
- 视频任务场景拆解。
- 视频影子工作流。

所有输出均为待复核草案，不生成真实视频产物。

## 4. 风险

- 不读取未授权真实素材。
- 不自动转码、剪辑、渲染、配音、字幕生成或封面生成。
- 不发布到任何平台。
- 不外发素材、成片、字幕、封面或账号信息。
- 不把风格参考等同于版权授权。

## 5. 验收

第一阶段只验收影子底座：

- 文件均位于孵化区视频制作业务影子底座目录。
- 每份文件明确影子状态和真实动作禁止边界。
- 不包含脚本、计划任务、n8n工作流或真实素材处理入口。
- 正式视频制作系统开工前必须重新执行扩展系统开工五问。
