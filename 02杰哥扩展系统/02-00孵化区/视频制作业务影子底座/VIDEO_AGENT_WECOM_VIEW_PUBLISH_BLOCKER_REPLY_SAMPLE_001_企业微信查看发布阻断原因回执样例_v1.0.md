# VIDEO_AGENT_WECOM_VIEW_PUBLISH_BLOCKER_REPLY_SAMPLE_001 企业微信查看发布阻断原因回执样例 v1.0

- 资产类型：企业微信占位回执样例
- 施工等级：W1/W2 低风险影子施工
- 适用范围：用户询问“为什么不能发布/查看发布阻断原因”
- 状态：草案样例，不真实外发

## 输入命令样例

```text
查看 VF-20260508-003 发布阻断原因
```

## 回执样例

```text
任务 VF-20260508-003 当前不能进入真实发布。

阻断原因：
1. 成品预览复核未通过或未填写。
2. AI 标识确认回执缺失。
3. 素材授权证明未归档。
4. 小红书、视频号平台检查仍待复核。
5. 发布放行确认回执未填写。

已进入复核队列：
- 成品预览复核队列
- 发布合规复核队列
- 素材授权复核队列
- 平台差异复核队列
- 门禁一致性复核队列

下一步：
请先补齐上述回执。全部补齐后，仍需人工最终确认，不会自动发布。

真实系统触发：否。
```

## 固定规则

1. 回执必须说明不能发布的具体原因。
2. 回执必须列出已进入的复核队列。
3. 回执必须提醒“补齐后仍不自动发布”。
4. 本样例不调用企业微信接口，不发送真实消息。
