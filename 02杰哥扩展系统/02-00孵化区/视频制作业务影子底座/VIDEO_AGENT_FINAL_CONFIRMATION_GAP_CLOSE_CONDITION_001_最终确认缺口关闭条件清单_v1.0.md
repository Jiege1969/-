# VIDEO_AGENT_FINAL_CONFIRMATION_GAP_CLOSE_CONDITION_001 最终确认缺口关闭条件清单

- 版本：v1.0
- 日期：2026-05-08
- 所属业务线：视频制作系统
- 所属层级：W1/W2 影子契约层
- 当前状态：草案
- 适用范围：发布前最终人工确认缺口的关闭判断

## 1. 定位

本清单用于判断“发布前最终确认缺口清单”中的待补材料是否可以在影子层标记为已补齐。

本清单只定义关闭条件，不代表生成放行、渲染放行、发布放行或总管正式裁定。

## 2. 关闭原则

1. 缺口关闭必须有可追溯证据。
2. 红线阻断项不能由视频制作线自行关闭。
3. 任何缺口未关闭时，最终确认状态保持“待补材料”或“待人工复核”。
4. 缺口全部关闭后，只能进入“等待最终人工确认”，不能自动进入发布。

## 4. 不得关闭的情况

- 只有口头说“可以发”，但没有记录任务ID、确认范围和确认人。
- 只有生成放行，没有单独发布放行。
- 只有素材候选，没有素材授权证明或来源说明。
- 平台规范未按平台拆开核对。
- 需要真实模型、真实素材、真实渲染、真实发布、n8n、企业微信真实外发或真实账号配置才能确认。

## 5. 输出要求

关闭判断输出必须包含：

- 任务ID
- 缺口编号
- 是否关闭
- 关闭依据
- 仍需人工确认项
- 是否触发红线
- 下一步允许状态
