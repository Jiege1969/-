# 视频平台规范来源卡模板

> 版本：v1.0
> 状态：影子来源卡模板，不是正式平台规则库
> 边界声明：不读取真实素材，不转码，不剪辑，不渲染，不生成字幕/封面/配音，不发布，不外发，不触发 n8n 或企业微信。

## 用途

用于登记视频平台公开规范或用户提供的发布要求，帮助后续生成待复核视频方案。

## 模板

| 字段 | 内容 |
|:---|:---|
| platform_name | 待补 |
| source_type | 官方规范 / 用户要求 / 历史经验 |
| source_url_or_file | 待补 |
| collected_date | 待补 |
| applicable_content_type | 短视频 / 横版视频 / 直播切片 / 其他 |
| duration_limit | 待补 |
| resolution_requirement | 待补 |
| aspect_ratio | 待补 |
| subtitle_requirement | 待补 |
| cover_requirement | 待补 |
| publish_risk | 待补 |
| review_note | 待复核 |

## 使用边界

- 平台规范可能变化，必须记录采集日期。
- 用户发布要求不得替代平台真实规则。
- 本阶段不连接平台账号、不上传、不发布。
