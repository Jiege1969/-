# VIDEO_AGENT_MULTI_PLATFORM_PRE_PUBLISH_DIFFERENCE_CHECK_001 多平台发布前差异检查草案

> 业务线：视频制作业务影子底座
> 层级：W1/R0
> 状态：影子检查草案，不是真实平台发布配置
> 日期：2026-05-08

## 目的

在不接平台、不读账号、不发布的前提下，列出不同平台发布前可能需要人工复核的差异项，避免把一个平台的口径直接套到另一个平台。

## 差异项

| 差异项 | 复核问题 | 影子处理 |
|:---|:---|:---|
| 标题长度 | 目标平台标题长度是否不同 | 进入平台规范复核 |
| 简介/文案 | 是否需要平台专属简介 | 进入文案复核 |
| 标签 | 标签数量和敏感词要求是否不同 | 进入平台规范复核 |
| 封面 | 封面比例和文字要求是否不同 | 进入封面复核 |
| AI标识 | 是否必须标注 AI 生成或辅助 | 进入 AI 标识复核 |
| 素材授权 | 平台是否要求额外授权证明 | 进入素材授权复核 |
| 发布时间 | 是否存在活动、时段或地区限制 | 进入人工复核 |

## 输出字段

- `platform_difference_check_id`
- `target_platforms`
- `difference_items`
- `missing_platform_rules`
- `human_review_items`
- `release_blocking_items`

## 边界

本草案不接任何平台接口，不生成发布配置，不上传、不发布、不外发。
