# VIDEO_AGENT_STATE_CHANGE_LOG_TEMPLATE_001_影子会话状态变更日志模板_v1.0

> 资产身份：视频创作智能体影子会话状态变更日志模板
> 阶段：W1/R0
> 状态：空白模板，不接数据库
> 边界：只记录状态变化，不接向量库、不接真实会话、不改正式任务。

## 使用场景

当影子会话从输入接收、澄清、三候选草案、人工回执、修正流转或阻断登记之间切换时，用本模板记录状态变化。

## 日志字段

| 字段 | 示例值 | 说明 |
|:---|:---|:---|
| 日志ID | `VAI-STATE-LOG-0000` | 影子日志编号 |
| 会话ID | 待填写 | 对应影子会话 |
| 变更时间 | 待填写 | 人工填写 |
| 变更前状态 | 待填写 | 例如 `option_draft` |
| 变更后状态 | 待填写 | 例如 `human_review_pending` |
| 触发来源 | 待填写 | 澄清回答/人工回执/红线扫描/手工调整 |
| 关联文件 | 待填写 | 仅引用影子目录内文件 |
| 变更原因 | 待填写 | 简短摘要 |
| 是否命中红线 | 待填写 | 是/否 |
| 是否进入人工复核 | 待填写 | 是/否 |

## 限制

1. 本模板不建立数据库。
2. 本模板不代表长期记忆或用户画像。
3. 状态日志不等于正式任务状态。
