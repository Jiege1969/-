# VIDEO_AGENT_SHADOW_TASK_CLOSE_CONDITION_001 影子任务关闭条件清单

> 版本：v1.0  
> 生成时间：2026-05-08 11:12:00 +08:00  
> 资产身份：视频制作线 W1/R0 影子任务关闭条件清单  
> 风险等级：低风险  
> 边界声明：只定义影子任务何时可关闭，不代表正式上线或真实执行完成。

## 用途

本清单用于判断一个视频影子任务是否可以在本地闭环，避免未关闭的合规、授权或放行问题被误判为完成。

## 可关闭条件

| 条件 | 要求 |
|---|---|
| 任务单存在 | 有任务ID和原始输入 |
| 合规检查完成 | 高风险阻断已登记或已关闭 |
| 脚本草案完成 | 有人工复核点 |
| 分镜草案完成 | 有素材需求或授权占位 |
| 待复核问题列明 | P0/P1/P2 已分类 |
| 放行状态明确 | 生成、真实渲染、发布三类状态已拆分 |
| 回传记录生成 | 写明做了什么、风险、是否触发真实系统 |
| 下一步建议存在 | 但不作为等待确认点 |

## 不可关闭条件

- 高风险合规问题未登记。
- 素材授权缺口未列明。
- 发布放行与生成放行混用。
- 真实执行结果被写成影子结论。
- 缺少本轮对齐回传记录。

## 自检

- [x] 只定义影子关闭条件。
- [x] 不声明正式完成。
- [x] 不触发真实系统。
