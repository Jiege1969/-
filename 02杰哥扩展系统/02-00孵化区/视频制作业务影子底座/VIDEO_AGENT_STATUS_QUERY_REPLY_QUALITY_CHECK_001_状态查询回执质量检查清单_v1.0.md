# VIDEO_AGENT_STATUS_QUERY_REPLY_QUALITY_CHECK_001 状态查询回执质量检查清单 v1.0

- 资产类型：质量检查清单
- 施工等级：W1/R0
- 适用范围：企业微信状态查询回执占位样例、命令行状态摘要草案
- 状态：草案

## 目的

状态查询回执不能只回答“处理中”，必须让使用者看清当前卡在哪个门禁、缺什么、谁复核、下一步能做什么，同时明确没有触发真实系统。

## 合格回执要素

| 检查项 | 合格标准 |
|---|---|
| 任务编号 | 明确展示影子任务 ID 或视频工厂任务 ID |
| 当前状态 | 使用影子状态枚举，不使用正式发布状态冒充 |
| 三段门禁 | 分别展示生成放行、真实渲染放行、发布放行 |
| 缺口列表 | 列出素材授权、平台规则、AI 标识、成品预览等缺口 |
| 复核队列 | 标注缺口已进入哪个人工复核队列 |
| 下一步 | 只给影子动作或人工复核动作，不给真实执行命令 |
| 真实系统触发 | 明确写“未触发真实系统” |
| 红线提醒 | 若涉及真实账号、Cookie、API Key、n8n、外发或发布，必须标注阻断 |

## 不合格样例

```text
任务已准备好，可以发布。
```

不合格原因：

- 未说明三段门禁。
- 未说明 AI 标识和素材授权。
- 未说明是否人工预览。
- 把影子状态误说成可发布。

## 合格样例

```text
VF-20260508-003 当前为“发布待确认”。

生成放行：已确认
真实渲染放行：待确认
发布放行：待确认

缺口：
1. 成品预览未完成人工确认。
2. 平台 AI 标识未确认。
3. 素材授权证明未归档。

下一步：进入发布合规复核队列，不触发真实发布。
真实系统触发：否。
```

## 边界

本清单只检查回执文本质量，不连接企业微信，不读取真实任务库，不发送消息。
