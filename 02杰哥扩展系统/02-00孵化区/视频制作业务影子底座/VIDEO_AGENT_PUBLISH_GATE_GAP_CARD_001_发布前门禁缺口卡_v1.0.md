## 用途

当用户说“发吧”“可以发布”“同步到平台”时，本卡用于把发布意图转为发布前缺口检查，不直接执行发布。

## 缺口字段

| 字段 | 要求 | 缺口处理 |
|---|---|---|
| 任务ID | 必须明确 | 缺失则要求澄清 |
| 成品版本 | 必须绑定已预览版本 | 缺失则退回成品预览 |
| 成品预览回执 | 必须为预览通过 | 不是通过则退回复核 |
| 发布放行清单 | 必须单独发布放行 | 未放行则保持发布待确认 |
| 平台列表 | 必须逐平台明确 | 缺失则列待确认平台 |
| AI标识确认 | 必须逐平台确认 | 未确认则阻断 |
| 素材授权结论 | 必须完整 | 缺证据则阻断 |
| 标题标签检查 | 不得焦虑诱导或误导 | 命中则退回修改 |
| 账号授权状态 | 必须人工确认 | 不接真实账号 |

## 输出结论

- 发布前门禁通过：只代表可以交总管判断是否进入真实发布链路。
- 发布前门禁未通过：保持发布待确认。
- 命中一票阻断：退回人工复核。
