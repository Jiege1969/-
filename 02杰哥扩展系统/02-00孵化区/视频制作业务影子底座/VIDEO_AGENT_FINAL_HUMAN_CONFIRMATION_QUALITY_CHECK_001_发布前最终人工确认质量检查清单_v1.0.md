# VIDEO_AGENT_FINAL_HUMAN_CONFIRMATION_QUALITY_CHECK_001 发布前最终人工确认质量检查清单 v1.0

- 资产类型：质量检查清单
- 施工等级：W1/W2 低风险影子施工
- 适用范围：发布前最终人工确认占位回执
- 状态：草案

## 目的

确保最终人工确认不是一句“同意发布”，而是基于门禁总览、阻断汇总、四件套、多平台检查和红线扫描的完整确认。

## 检查项

| 编号 | 检查项 | 合格标准 |
|---|---|---|
| FHC-001 | 任务编号 | 明确填写视频任务编号 |
| FHC-002 | 门禁总览引用 | 引用发布前门禁最终总览记录 |
| FHC-003 | 阻断汇总引用 | 引用发布前阻断汇总记录 |
| FHC-004 | 四件套状态 | 成品预览、AI 标识、素材授权、发布放行均有回执 |
| FHC-005 | 多平台状态 | 每个平台都有独立检查结果 |
| FHC-006 | 红线状态 | 无未处理红线，或已交回总管判断 |
| FHC-007 | 决策口径 | 只能是“提交总管判断/待补/驳回” |
| FHC-008 | 真实系统触发 | 必须为否 |

## 不合格处理

1. 缺门禁总览：退回复核总览补齐。
2. 缺阻断汇总：退回发布前阻断汇总。
3. 缺平台独立检查：退回多平台复核。
4. 出现红线：转红线阻断登记。

## 边界

本检查清单不触发发布，不提交总管，不调用企业微信接口。
