# VIDEO_AGENT_THREE_OPTION_OUTPUT_TEMPLATE_001 三候选开场分镜方案输出模板

> 版本：v1.0  
> 生成时间：2026-05-08 09:55:00 +08:00  
> 资产身份：视频创作智能体 W1/R0 三候选开场/分镜方案输出模板  
> 风险等级：W1/R0  
> 边界声明：只定义三候选文字模板，不生成图片、音频、字幕、封面或视频，不调用模型 API，不读取真实素材，不渲染，不发布，不企业微信真实外发，不触发 n8n。

## 为什么不能用现有文件扩展

现有脚本复核和分镜复核文件面向已经存在的单个草案，强调修正和验收。三候选模板面向创意早期，让系统在未生成正式草案前提供多个可选方向，避免一上来就把一个方案误当成定稿。

## 它让系统更会做什么

- 更会给用户提供多个创意方向，而不是单一路线。
- 更会把开场、分镜、风险和待确认项一起列出。
- 更会把候选方案保持在草案层，不直接进入生成放行。
- 更会让用户选择、组合或要求局部修正。

## 输出结构

每次最多输出 3 个候选方案：

| 字段 | 类型 | 必填 | 说明 |
|:---|:---|:---:|:---|
| 候选方案ID | string | 是 | A / B / C 或唯一编号 |
| 方案定位 | string | 是 | 情绪型、知识型、冲突型、故事型等 |
| 开场5秒 | string | 是 | 文字开场，不生成真实音视频 |
| 核心钩子 | string | 是 | 吸引用户继续看的核心冲突或问题 |
| 分镜摘要 | list | 是 | 3-6 个镜头的文字摘要 |
| 旁白基调 | string | 是 | 旁白风格和语速建议 |
| 适合平台 | list | 是 | 候选平台，不代表发布放行 |
| 素材需求 | list | 是 | 需要哪些素材或授权 |
| 风险点 | list | 是 | 版权、隐私、平台、AI标识等风险 |
| 待人工确认项 | list | 是 | 用户需要选定或确认的事项 |

## 输出规则

1. 三个候选应明显不同，不做同义改写凑数。
2. 每个候选都必须包含风险点和待人工确认项。
3. 用户选择某个候选后，只进入局部修正或草案骨架，不进入生成放行。
4. 候选方案不生成图片、音频、字幕、封面或视频。
