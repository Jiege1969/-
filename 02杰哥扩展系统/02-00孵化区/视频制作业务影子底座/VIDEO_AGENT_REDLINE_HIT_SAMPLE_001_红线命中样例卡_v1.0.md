# VIDEO_AGENT_REDLINE_HIT_SAMPLE_001_红线命中样例卡_v1.0

> 资产身份：视频创作智能体影子层红线命中样例卡
> 阶段：W1/R0
> 状态：空白样例，不是真实阻断事件
> 边界：只记录红线类型和处理口径，不实施红线动作。

## 样例用途

用于演示当用户输入中出现真实生成、真实发布、读取素材、读取凭据、改正式入口等要求时，系统如何登记阻断并回传，而不是执行。

## 红线命中字段

| 字段 | 示例值 | 说明 |
|:---|:---|:---|
| 红线记录ID | `VAI-REDLINE-0000` | 影子样例编号 |
| 关联输入ID | 待填写 | 对应影子输入 |
| 命中类型 | 待填写 | 生成/发布/外发/凭据/真实素材/服务/正式入口 |
| 用户请求摘要 | 待填写 | 脱敏摘要 |
| 风险说明 | 待填写 | 说明为什么不能自动执行 |
| 当前处理 | `blocked_record_only` | 只登记阻断，不实施 |
| 是否触发真实系统 | 否 | 固定为否 |
| 是否需要总管判断 | 是 | 红线事项交回总管 |
| 可替代影子动作 | 待填写 | 例如生成待复核问题清单 |

## 典型红线

| 类型 | 示例 | 处理 |
|:---|:---|:---|
| 真实生成 | 直接生成视频、配音、字幕、封面 | 阻断，改为生成待复核清单 |
| 真实发布 | 直接上传到平台 | 阻断，登记发布前复核问题 |
| 企业微信外发 | 直接发给某人或群 | 阻断，不发送 |
| 凭据风险 | 提供账号、密钥、机器人 webhook | 阻断，不读取、不保存 |
| 真实素材 | 要求读取本地素材目录 | 阻断，只登记“存在素材待授权” |
| 正式入口 | 要求改服务脚本、端口、正式路由 | 阻断，交回总管 |

## 输出口径

命中红线时，不问是否继续执行红线动作；只说明已阻断、已登记、下一步可做影子替代动作。
