# VIDEO_SCRIPT_QUALITY_FIX_CARD_001_成语故事内容质量纠偏卡_v1.0

> 业务线：视频制作业务影子底座
> 阶段：W1/R0
> 日期：2026-05-08
> 资产身份：视频脚本草案质量纠偏卡，不是正式视频生成或发布许可。

## 一、问题

验证发现：视频想法转任务和草案查看流程可用，但“成语故事”类内容质量不足，输出容易停留在通用模板，没有真正写出成语内容。

这不是流程阻断，但属于 P1 内容质量阻断。修复前，视频系统只能声明为“流程可用，内容质量需优化”。

## 二、成语故事脚本最低质量线

成语故事类草案至少包含：

1. 成语名称。
2. 成语释义。
3. 适合短视频的故事梗概。
4. 3 到 5 段脚本正文。
5. 开头钩子。
6. 分镜提示。
7. 结尾启发或反转。
8. 素材授权和平台规范待复核项。
9. 人工复核问题。

## 三、不得输出

- 只给“标题、开头、正文、结尾”的空模板。
- 只说“这里写故事内容”而没有具体故事。
- 只给泛泛建议，不写脚本正文。
- 直接生成可发布结论。
- 触发真实渲染、上传、发布或企业微信外发。

## 四、验收样例

| 输入 | 通过条件 |
|:---|:---|
| 帮我做一个成语故事短视频 | 至少给出一个具体成语、故事梗概和脚本正文 |
| 做一个掩耳盗铃的短视频 | 必须围绕“掩耳盗铃”写具体故事，不得泛化为“某个成语” |
| 成语故事要更适合小学生 | 语言风格应更简单，并保留成语释义和故事 |
| 成语故事要有反转 | 结尾必须有明确反转或现实启发 |

## 五、推荐输出结构

```text
成语：
释义：
适合人群：
开头钩子：
故事脚本：
分镜草案：
素材/合规待复核：
人工复核问题：
```

## 六、边界

- 不真实渲染。
- 不生成配音、字幕或封面。
- 不上传、不发布。
- 不登录平台账号。
- 不触发企业微信真实发送或 n8n。
- 不把草案质量通过视为生成或发布放行。

## 七、业务线接续

下一步可继续 W1/R0：

1. 建立成语故事脚本草案质量验收表。
2. 建立一条“掩耳盗铃”高质量脚本影子样例。
3. 把脚本质量纠偏结果回传给视频线总收口。
