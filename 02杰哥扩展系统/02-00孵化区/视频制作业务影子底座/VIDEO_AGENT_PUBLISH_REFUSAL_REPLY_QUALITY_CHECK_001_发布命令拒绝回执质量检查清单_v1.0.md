# VIDEO_AGENT_PUBLISH_REFUSAL_REPLY_QUALITY_CHECK_001 发布命令拒绝回执质量检查清单 v1.0

- 资产类型：质量检查清单
- 施工等级：W1/R0
- 适用范围：企业微信发布命令拒绝回执、命令行发布阻断回执
- 状态：草案

## 目的

当用户发出“发布”命令但门禁不齐时，回执不能只说“不能发布”，必须说明阻断原因、进入哪个复核队列、下一步如何补齐，并明确未触发真实发布。

## 检查项

| 编号 | 检查项 | 合格标准 |
|---|---|---|
| PRQ-001 | 任务编号 | 回执中明确任务 ID |
| PRQ-002 | 拒绝结论 | 明确写“不能进入真实发布” |
| PRQ-003 | 三段门禁 | 分别列出生成放行、真实渲染放行、发布放行 |
| PRQ-004 | 阻断原因 | 至少列出一个可复核原因 |
| PRQ-005 | 复核队列 | 每个阻断原因映射到人工复核队列 |
| PRQ-006 | 下一步 | 下一步只能是补复核、补授权、补确认或等待人工，不得是发布命令 |
| PRQ-007 | 真实系统触发 | 明确写“否” |
| PRQ-008 | 红线提示 | 真实账号、Cookie、API Key、n8n、外发接口等必须登记阻断 |

## 不合格回执

```text
发布条件不足，请稍后再试。
```

不合格原因：

- 没有任务 ID。
- 没有三段门禁。
- 没有具体阻断原因。
- 没有复核队列。
- 没有说明真实系统是否触发。

## 合格回执最小结构

```text
任务：VF-20260508-003
结论：不能进入真实发布。
阻断：发布放行未确认；成品预览未复核；AI 标识未确认。
复核队列：发布合规复核队列、成品预览复核队列。
下一步：请先完成复核和发布放行。
真实系统触发：否。
```

## 边界

本清单只检查回执文本，不调用企业微信、不调用发布工具、不接 n8n。
