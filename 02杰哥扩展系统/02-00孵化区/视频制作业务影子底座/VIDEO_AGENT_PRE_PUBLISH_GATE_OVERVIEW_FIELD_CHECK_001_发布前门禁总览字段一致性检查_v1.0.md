# VIDEO_AGENT_PRE_PUBLISH_GATE_OVERVIEW_FIELD_CHECK_001 发布前门禁总览字段一致性检查 v1.0

- 资产类型：字段一致性检查
- 施工等级：W1/W2 低风险影子施工
- 适用范围：发布前门禁最终总览卡、发布前阻断汇总回执、多平台检查回执
- 状态：草案

## 目的

确保发布前门禁相关资产使用同一套字段和同一套阻断口径，避免 A 文件显示“可进入发布”，B 文件仍显示“待确认”的状态冲突。

## 必备字段

| 字段 | 含义 | 必须出现的资产 |
|---|---|---|
| task_id | 视频任务编号 | 阻断汇总、企业微信回执、多平台检查回执 |
| gate_name | 门禁名称 | 门禁总览、阻断汇总 |
| gate_state | 门禁状态 | 门禁总览、阻断汇总 |
| required_proof | 必要证明 | 门禁总览、阻断汇总 |
| blocker_reason | 阻断原因 | 阻断汇总、企业微信回执 |
| review_queue | 复核队列 | 阻断汇总、企业微信回执 |
| next_action | 下一步影子动作 | 全部回执类资产 |
| real_system_triggered | 是否触发真实系统 | 全部回执类资产 |

## 状态一致性规则

1. `gate_state` 为 `pending_confirmation` 时，不能出现“可发布”结论。
2. `real_system_triggered` 在本阶段必须为 `false`。
3. 同一任务的多平台检查必须保留逐平台状态，不能压缩成单一全局状态。
4. 红线阻断存在时，`next_action` 只能是阻断登记或总管判断。
5. 发布放行确认缺失时，企业微信回执必须拒绝发布命令。

## 不通过处理

只生成字段缺口清单或状态冲突清单，不修改真实配置、不触发发布、不发送企业微信。
