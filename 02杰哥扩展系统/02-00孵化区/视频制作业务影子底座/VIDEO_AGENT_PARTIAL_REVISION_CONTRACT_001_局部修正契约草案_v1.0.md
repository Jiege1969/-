# VIDEO_AGENT_PARTIAL_REVISION_CONTRACT_001 局部修正契约草案

> 版本：v1.0  
> 生成时间：2026-05-08 10:30:00 +08:00  
> 资产身份：视频创作智能体 W1/R0 局部修正字段契约草案  
> 风险等级：W1/R0  
> 边界声明：只定义局部修正输入输出，不自动改正式草案，不生成成片，不放行生成或发布，不读取真实素材，不触发 n8n 或企业微信真实外发。

## 定位

本契约用于处理“把开头改得更生活化”“第三镜换个画面”“语气更温柔”等局部修改命令。它保护已确认内容，只输出待复核修正建议。

## 修正字段

| 字段 | 类型 | 必填 | 说明 |
|---|---|---:|---|
| 任务ID | string | 是 | 必须绑定已有影子任务 |
| 修改对象 | enum | 是 | 标题、开头、正文、结尾、分镜、旁白、配音、封面、标签 |
| 修改范围 | string | 是 | 第几句、第几镜、第几段或全局 |
| 锁定内容 | list | 是 | 用户已确认、不得覆盖的内容 |
| 变更理由 | list | 是 | 用户指令、合规要求、原创性要求、平台规则要求 |
| 修正前 | string/object | 是 | 原内容或原结构 |
| 修正后 | string/object | 是 | 建议修正内容 |
| 影响范围 | list | 是 | 受影响的镜头、旁白、封面、标签、平台字段 |
| 需人工确认项 | list | 是 | 修正后仍需人工确认的事项 |

## 约束规则

1. `锁定内容` 不得自动覆盖。
2. 修改范围不清楚时，先输出澄清项，不做全局改写。
3. 涉及素材、配音、封面、发布标签时，只输出字段需求，不生成真实资产。
4. 修正后仍是待复核草案，不是最终文案。
5. 修改命令不能改变生成放行、真实渲染放行或发布放行状态。
