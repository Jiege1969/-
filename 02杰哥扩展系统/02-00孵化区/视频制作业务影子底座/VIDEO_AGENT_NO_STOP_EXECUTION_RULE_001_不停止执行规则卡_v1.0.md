# VIDEO_AGENT_NO_STOP_EXECUTION_RULE_001 不停止执行规则卡 v1.0

- 资产类型：连续施工规则卡
- 施工等级：W1/R0
- 适用范围：视频制作线影子施工
- 状态：草案

## 要纠正的问题

历史问题不是缺少用户授权，而是把“阶段性总结、下一步建议、自检通过”误处理成等待确认点，导致连续施工中断。

## 执行规则

1. 用户已明确给出连续施工授权时，完成一轮后不得停在“是否继续”的确认问题。
2. 每轮开始必须先只读当前施工面板和一键接续施工包。
3. 每轮只做 W1/R0 低风险影子施工，并限定在视频制作业务影子底座内。
4. 每轮完成后必须自检并生成对齐回传记录。
5. 回传记录不是停点；若未触发红线，应自动选择下一项低风险候选继续。
6. 遇到红线时只登记阻断，不实施。
7. 若缺少素材、账号、真实配置或用户内容，自动生成缺口卡、待复核问题或占位模板，不向真实系统推进。

## 允许自动继续的任务类型

- 影子契约草案。
- 人工复核清单。
- 状态枚举和状态一致性检查。
- 放行缺口卡。
- 风险阻断登记模板。
- 企业微信回执草案模板。
- 影子索引草案和本线资产清单。
- 本地自检报告和对齐回传记录。

## 必须暂停并登记阻断的任务类型

- 接真实模型 API。
- 接 MoneyPrinterTurbo、HappyHorse、Qwen-TTS、PostBot 等真实执行器。
- 读取真实素材、真实账号或平台 Cookie。
- 真实渲染、上传、发布、外发。
- 修改 n8n、服务脚本、端口、总管文件、公共组件或正式库。

## 回合边界说明

在单个工具执行回合内，应连续推进多个低风险小任务。若系统交互机制要求返回用户消息，则返回时必须说明已完成的施工与已排好的下一步候选，而不是把“继续施工”作为需要用户再次确认的问题。
