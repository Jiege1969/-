# VIDEO_AGENT_MANAGER_DECISION_RETURN_INTAKE_CARD_001 总管判断返回视频线影子接收卡

- 版本：v1.0
- 日期：2026-05-08
- 所属业务线：视频制作系统
- 所属层级：W1/W2 影子接收卡
- 当前状态：草案

## 1. 定位

本接收卡用于在未来总管对话框给出判断后，视频制作线如何以影子方式接收判断结果。

本卡不主动读取总管文件，不写总管，不调用企业微信，不触发真实发布。

## 2. 接收前提

| 前提 | 要求 |
|---|---|
| 来源明确 | 必须标明来自总管对话框或人工负责人 |
| 任务ID明确 | 必须绑定视频任务ID |
| 判断范围明确 | 必须说明是生成、渲染、发布、素材、合规还是企业微信路由 |
| 是否仍需复核明确 | 默认仍需视频线人工复核 |
| 是否允许真实执行明确 | 未单独写明时一律视为不允许 |

## 3. 接收字段

| 字段 | 说明 |
|---|---|
| 接收卡ID | 视频线本地编号 |
| 来源 | 总管对话框/人工负责人 |
| 来源记录摘要 | 不复制敏感内容，只写摘要 |
| 关联任务ID | VF-YYYYMMDD-序号 |
| 判断类型 | 生成/渲染/发布/素材/合规/路由 |
| 总管判断摘要 | 只记录判断结论摘要 |
| 视频线下一步 | 待人工复核/生成问题清单/保持阻断 |
| 禁止自动动作 | 默认全部禁止 |

## 4. 默认处理规则

1. 总管判断返回不等于视频线自动执行。
2. 若判断涉及真实渲染、真实发布、企业微信真实外发或 n8n，本线只能登记“需另行执行授权”。
3. 若判断只允许继续影子复核，则进入待人工复核清单。
4. 若判断信息不完整，则退回缺口卡，不进入执行。

## 5. 边界声明

本接收卡只定义未来回流字段，不读取总管真实文件，不改总管面板，不触发企业微信。

本接收卡不调用真实模型、不读取真实素材、不渲染、不上传、不发布、不触发 n8n。
