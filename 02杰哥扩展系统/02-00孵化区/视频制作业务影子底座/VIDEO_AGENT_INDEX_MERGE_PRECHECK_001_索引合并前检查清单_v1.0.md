# VIDEO_AGENT_INDEX_MERGE_PRECHECK_001 索引合并前检查清单 v1.0

- 资产类型：影子检查清单
- 施工等级：W1/R0
- 适用范围：视频制作业务影子底座内索引草案合并前的人工核对
- 状态：草案

## 定位

本清单只用于判断影子索引草案是否具备提交总管或人工整合的条件，不直接修改任何总管索引、孵化区总索引或正式视频制作系统索引。

## 合并前检查项

| 编号 | 检查项 | 通过标准 | 未通过处理 |
|---|---|---|---|
| IMC-001 | 写入范围 | 所有新增资产均位于视频制作业务影子底座 | 停止合并，登记越界风险 |
| IMC-002 | 文件配对 | 每个关键资产同时具备 md 与 json，或明确说明为何单文件存在 | 补齐配对文件或登记缺口 |
| IMC-003 | JSON 可解析 | JSON 能通过本地只读解析检查 | 修复格式后再提交 |
| IMC-004 | 风险等级 | 资产标注为 W1/R0 或明确低风险影子施工 | 升级为待总管判断 |
| IMC-005 | 红线隔离 | 不包含真实模型、真实渲染、真实发布、n8n、企业微信真实外发的实施指令 | 只保留阻断登记，删除实施表述 |
| IMC-006 | 门禁拆分 | 生成放行、真实渲染放行、发布放行保持分开 | 退回补拆分 |
| IMC-007 | 人工复核 | 每个进入下一阶段的资产都有人工复核或待复核承接字段 | 补复核字段 |
| IMC-008 | 结论口径 | 不把影子草案表述为正式结论 | 改为草案或待复核表述 |

## 合并建议输出

合并前应输出：

1. 拟合并资产清单。
2. 不合并资产及原因。
3. 需要总管整合的事项。
4. 红线阻断事项。

## 边界

- 不修改总管文件。
- 不修改公共组件。
- 不触发企业微信真实外发。
- 不接 n8n。
- 不触发真实渲染或发布。
