# 共享政策证据只读调用样例 VIDEO 002：平台规范真实来源调用

> 版本：v1.0  
> 日期：2026-05-07  
> 资产身份：视频制作系统只读规范证据调用影子样例  
> 风险等级：W1  
> 边界：只读样例，不读取真实素材，不连接平台账号，不剪辑、不渲染、不上传、不发布、不外发、不接 n8n。  

## 一、调用意图

视频制作系统在生成脚本、分镜、素材清单或发布前检查草案时，可以只读调用平台规范来源卡，获得规则线索、风险提示和待复核问题。本样例只验证“真实来源卡进入草案前置检查”，不生成平台合规结论。

## 二、调用输入

| 字段 | 内容 |
|:---|:---|
| requesting_system | 视频制作业务 |
| query_intent | 平台规范证据/发布风险前置检查 |
| topic_keywords | B站、用户协议、活动规则、原创性、版权、发布风险 |
| expected_evidence_level | 官方用户协议、官方活动规则、当前投稿规范待补 |
| source | `VIDEO_PLATFORM_RULE_SOURCE_BILIBILI_20260507` |
| business_context | 待补；需用户明确目标视频类型、发布平台、素材来源和授权范围 |

## 四、视频制作系统可生成的草案

| 输出 | 边界 |
|:---|:---|
| 平台规范待复核清单 | 可以 |
| 素材授权待补清单 | 可以 |
| 脚本/分镜风险提示 | 可以，仅作草案 |
| 发布前人工检查问题 | 可以 |
| 平台合规结论 | 不可以 |
| 版权安全结论 | 不可以 |
| 自动上传/发布 | 不可以 |

## 五、人工复核问题

1. 目标视频是否发布到 B站，还是多平台分发？
2. 目标内容属于普通投稿、活动投稿、直播切片还是商业宣传？
3. 当前使用的平台规则链接是否为最新页面？
4. 活动规则是否仍在有效期内？
5. 素材是否原创、授权、可二次剪辑、可商业使用？
6. 是否包含人物肖像、客户信息、账号截图、地址、电话等敏感信息？

## 六、结论

视频制作系统现在可以读取一张真实平台规范来源卡，并把它转成发布风险前置检查草案。但在投稿规范、分区规则、素材授权和用户目标未补齐前，系统仍不得输出“可发布”“平台合规”“版权安全”等确定结论。
