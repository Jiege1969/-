## 一、用途

本清单把四条只读调用样例连接到人工复核回执或复核字段，确保共享政策证据调用可以被人工复核、纠偏和沉淀，而不是只停留在“读到了证据”。

## 三、统一复核字段

| 字段 | 说明 |
|:---|:---|
| sample_id | 只读调用样例编号 |
| reviewing_business_line | 复核业务线 |
| evidence_used | 使用了哪些政策/规范/事件证据 |
| evidence_level_checked | 是否保留依据层级 |
| validity_status_checked | 是否保留有效状态 |
| source_checked | 是否保留来源链接或本地路径 |
| forbidden_use_checked | 是否保留禁止用途 |
| conclusion_overreach | 是否出现证据被写成业务结论 |
| missing_items | 仍缺哪些证据 |
| human_feedback | 人工复核意见 |
| next_action | 继续补证、修改样例、进入进化候选或关闭 |

## 四、复核结果分层

| 结果 | 含义 | 处理 |
|:---|:---|:---|
| pass_shadow | 影子样例结构通过 | 可继续影子演练 |
| pass_with_notes | 有问题但不越界 | 补待补事项 |
| fail_boundary | 出现越权结论或边界问题 | 立即纠偏 |
| need_more_evidence | 证据不足 | 补资料，不升级 |
| evolution_candidate | 多次复核形成可复用经验 | 进入进化候选，不自动改正式规则 |

## 六、硬边界

- 人工复核意见不得自动修改正式规则。
- 复核通过不等于正式业务结论。
- 股票线复核不得引入交易建议。
- 税务线复核不得生成正式税务意见。
- 视频线复核不得生成可发布或版权安全结论。
- 本职工作线复核不得替代审批。
