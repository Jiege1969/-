# 人工复核到进化候选操作卡

> 版本：v1.0
> 状态：人工操作卡，不是自动进化流程
> 边界声明：不接 n8n，不接企业微信，不写正式库，不触发真实业务动作。

## 适用场景

某个影子样例经过用户或人工复核后，需要判断是否进入进化候选。

## 操作步骤

1. 读取人工复核回执通用模板。
2. 记录通过、修改后通过、驳回或待补。
3. 读取影子样例复盘字段清单。
4. 标注错误类型、人工修正摘要、可复用模式和不可复用原因。
5. 如果具备跨任务复用价值，填写影子到进化候选记录模板。
6. 推荐去向只能写候选：策略锚点 / 规则库 / 母本模板 / 业务线模板 / 暂不沉淀。
7. 真正写入策略锚点库或规则库前，必须另行确认风险等级。

## 禁止动作

- 不自动新增策略锚点。
- 不自动修改规则库。
- 不把一次样例复核升级为通用规则。
- 不把候选记录写成系统已学会。

## 输出

```text
进化候选判断：
- 来源样例：
- 人工修正：
- 可复用模式：
- 推荐去向：
- 是否需要人工确认：
```
