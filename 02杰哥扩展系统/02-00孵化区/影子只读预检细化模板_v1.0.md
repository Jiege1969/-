# 影子只读预检细化模板

> 版本：v1.0
> 状态：孵化区只读预检模板，不是生产脚本
> 边界声明：不接 n8n，不接企业微信，不写正式库，不触发真实业务动作。

## 用途

用于新增或补充影子资料前，先做只读检查，明确是否可以继续进入影子草案。

## 通用预检项

| 检查项 | 方法 | 输出 |
|:---|:---|:---|
| 目标目录 | 只读确认目录是否存在 | 存在/缺失 |
| 重复资产 | 只读查找同名或同主题文件 | 重复/未重复 |
| 索引入口 | 只读确认是否有线内索引 | 有/无 |
| 边界声明 | 只读检查文件是否声明影子状态 | 有/无 |
| 禁止动作 | 只读检查是否出现上线、外发、真实处理等词 | 命中/未命中 |
| 待补字段 | 只读检查是否保留待补/待复核 | 有/无 |

## 业务线预检

| 业务线 | 额外检查 |
|:---|:---|
| 税收 | 是否涉及申报、退税、备案、开票、电子税务局 |
| 本职工作 | 是否涉及OA、ERP、财务、人事、审批、盖章 |
| 视频制作 | 是否涉及真实素材、剪辑、转码、渲染、发布 |

## 结论格式

```text
影子只读预检：
- 目录：
- 重复资产：
- 索引入口：
- 边界声明：
- 禁止动作命中：
- 结论：继续 / 待补 / 暂停
```
