# 共享政策证据只读调用样例 OFFICE 001：涉税资料清单

> 版本：v1.0  
> 日期：2026-05-07  
> 资产身份：本职工作系统只读政策证据调用影子样例  
> 风险等级：W1  
> 边界：只读样例，不替代审批，不替代专业税务意见，不写政策库，不外发。  

## 一、调用意图

本职工作系统可能需要整理某项涉税业务的资料准备清单。它可以只读查询税收政策知识库，拿到政策依据和资料缺口线索，但不能生成税务结论或替代内部审批。

## 二、调用输入

| 字段 | 内容 |
|:---|:---|
| requesting_system | 本职工作业务 |
| query_intent | 涉税资料清单/合规准备线索 |
| topic_keywords | 软件产品、增值税、即征即退、资料要求 |
| expected_evidence_level | 国家级政策依据、待核验地方口径 |
| source | `SHARED-POLICY-EVIDENCE-001` 税收政策知识库/政策证据底座 |

## 三、只读证据返回

| 字段 | 内容 |
|:---|:---|
| policy_basis | 财税〔2011〕100号 |
| source_level | 国家级主管机关政策/规范性文件 |
| validity_status | 以官方政策法规库展示为准，待人工逐条复核 |
| related_guide | 国家税务总局软件产品即征即退政策指引 |
| evidence_gap | 地方材料要求、检测证明、产品登记或替代材料、收入拆分、测算字段 |

## 四、本职工作系统可生成的草案

| 输出 | 边界 |
|:---|:---|
| 资料准备清单 | 仅为待复核工作清单 |
| 待补材料问题 | 需要用户或专业人员确认 |
| 流程提醒 | 不替代审批、不替代税务判断 |

## 五、禁止输出

- 不写“该业务一定适用”。
- 不写“可以享受优惠”。
- 不给确定金额。
- 不生成可外发正式意见。
- 不替代内部审批或盖章流程。
