# 影子资料接入操作卡

> 版本：v1.0
> 状态：人工操作卡，不是自动入口工具
> 边界声明：不接 n8n，不接企业微信，不写正式库，不触发真实业务动作。

## 适用场景

用户提供一份资料、链接、模板、样例或素材说明，希望进入某条影子业务线时使用。

## 操作步骤

1. 判断业务线：税收 / 本职工作 / 视频制作 / 其他。
2. 读取孵化区影子底座总索引。
3. 读取对应业务线线内索引。
4. 填写影子资料登记卡通用模板。
5. 标注来源、授权、敏感性、依据层级和人工复核状态。
6. 如果资料未授权、含敏感信息或来源不清，标为待确认，不进入影子样例。
7. 如果资料可进入影子，继续创建影子样例。

## 禁止动作

- 不主动扫描用户未指定目录。
- 不复制真实敏感资料。
- 不把资料登记当作正式采用。
- 不触发外发、申报、审批、渲染、发布。

## 输出

```text
资料接入结论：
- 业务线：
- 来源：
- 授权：
- 敏感性：
- 可进入影子：是/否/待确认
- 下一步：
```
