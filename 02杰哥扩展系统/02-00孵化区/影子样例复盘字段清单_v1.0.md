# 影子样例复盘字段清单

> 版本：v1.0
> 状态：复盘字段草案，不是正式账本
> 边界声明：不接 n8n，不接企业微信，不写正式库，不触发真实业务动作。

## 用途

用于规范影子样例完成一次人工复核后的复盘字段，帮助判断是否值得进入进化候选。

## 字段清单

| 字段 | 说明 | 状态 |
|:---|:---|:---|
| sample_id | 影子样例编号 | 必填 |
| review_id | 人工复核回执编号 | 必填 |
| original_draft_summary | 原草案摘要 | 待填 |
| correction_summary | 人工修正摘要 | 待填 |
| error_type | 缺资料 / 依据层级错 / 风险边界漏 / 输出格式差 / 其他 | 待判 |
| reusable_pattern | 可复用模式 | 待判 |
| non_reusable_reason | 不可复用原因 | 待补 |
| affected_template | 可能影响的模板 | 待补 |
| promotion_risk | 沉淀风险 | 待补 |
| next_action | 补模板 / 补样例 / 入候选 / 暂不处理 | 待判 |

## 复盘边界

- 复盘不是正式账本。
- 复盘不自动修改模板。
- 复盘不自动产生新规则。
- 复盘不覆盖人工最终判断。
