## 一、当前方案

当前采用：

```text
扩展系统内部轻量只读调配优先
总管只登记能力和边界
n8n 后置
```

政策知识库由税收业务系统维护，其他扩展系统只在需要政策证据时少量只读查询。查询结果只作为证据输入，必须回到本业务系统自己的分析契约里解释。

## 四、禁止调用关系

| 禁止项 | 原因 |
|:---|:---|
| 其他系统写入税收政策知识库 | 防止污染政策证据底座 |
| 视频工厂写回共享证据或平台规范来源卡 | 防止把内容草案、平台经验或发布判断反写为证据 |
| 税收政策库直接返回业务结论 | 证据库不是结论库 |
| 调用方省略 validity_status | 会把待核验证据误用为确认依据 |
| 调用方省略 evidence_level | 会混淆国家政策、地方口径、解释材料和人工经验 |
| 用 n8n 自动转发查询结果 | 当前属于 W3，尚未确认 |
| 企业微信或外发调用共享证据 | 当前属于 W3，尚未确认 |

## 五、轻量调用步骤

1. 调用方确认只需要政策证据，不需要正式结论。
2. 调用方读取本清单，确认允许查询范围。
3. 调用方读取对应证据源索引或样例文件。
4. 调用方保留 `evidence_level`、`validity_status`、`source_url/source_path`、`risk_flags`。
5. 调用方在本业务系统内输出待复核草案。
6. 若要写正式配置、接 n8n、接企业微信、外发或自动调度，暂停确认。

## 七、验收标准

| 验收项 | 标准 |
|:---|:---|
| 轻量 | 不建服务、不建 n8n、不写生产配置 |

| 保真 | 保留来源、层级、有效状态和风险标记 |
| 不越权 | 不把证据写成正式结论 |
| 可后置扩展 | 若未来高频稳定，再评估 n8n |
