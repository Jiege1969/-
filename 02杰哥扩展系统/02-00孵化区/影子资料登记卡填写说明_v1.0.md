# 影子资料登记卡填写说明

> 版本：v1.0
> 状态：填写说明，不是正式资料采集流程
> 边界声明：不接 n8n，不接企业微信，不写正式库，不触发真实业务动作。

## 填写顺序

1. 先填业务线。
2. 再填资料名称和资料类型。
3. 填来源类型和来源位置。
4. 判断授权状态。
5. 判断敏感性。
6. 判断依据层级。
7. 判断是否可进入影子。
8. 填人工复核状态。

## 关键字段说明

| 字段 | 填写口径 |
|:---|:---|
| authorization_status | 不确定就填“待确认”，不要猜 |
| sensitivity | 涉财务、人事、合同、客户、素材版权、账号等均需标敏感或待判 |
| basis_level | 不确定层级时填“待判”，不要把经验写成制度 |
| can_enter_shadow | 未授权或未脱敏时填“否”或“待确认” |
| forbidden_actions | 写清楚不能做的真实动作 |

## 示例占位

```text
card_id: MATERIAL_CARD_OFFICE_001
business_line: 本职工作
authorization_status: 待确认
sensitivity: 待判
can_enter_shadow: 待确认
human_review_status: 待复核
```

## 禁止

- 不填真实敏感内容。
- 不把“待确认”改成“已授权”。
- 不用登记卡替代人工授权。
