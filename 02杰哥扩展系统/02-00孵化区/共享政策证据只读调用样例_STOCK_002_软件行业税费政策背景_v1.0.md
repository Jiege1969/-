# 共享政策证据只读调用样例 STOCK 002：软件行业税费政策背景

> 版本：v1.0  
> 日期：2026-05-07  
> 资产身份：股票系统只读税费政策证据调用影子样例  
> 风险等级：W1  
> 边界：只读样例，不改股票正式配置，不改L3评分契约，不生成买卖建议，不生成税务结论，不外发，不接 n8n。  

## 一、调用意图

股票研究系统研究软件行业或软件相关上市公司时，可能需要了解税费政策背景，例如软件产品增值税即征即退政策。

本样例只演示“税收政策证据如何作为行业研究背景进入股票分析”，不把税务适用结论套进股票评分，也不对具体公司是否享受优惠作税务判断。

## 四、行业研究解释

| 项目 | 解释 |
|:---|:---|
| 可作为 | 软件行业政策背景、公司收入结构研究提示、财税优惠风险提示 |
| 不可作为 | 公司已享受优惠的确认、税务适用结论、利润增厚确定结论、买卖建议 |
| 需要补证 | 公司软件产品收入占比、是否自行开发、是否满足材料要求、实际享受情况、财报披露 |
| 风险反例 | 政策存在不等于公司一定受益；受益强度取决于收入结构、纳税身份、资料条件、实际税负、地方办理口径 |

## 五、传入股票研究的边界字段

| 字段 | 内容 |
|:---|:---|
| evidence_type | tax_policy_background |
| industry_tags | 软件、企业服务、增值税、税费优惠 |
| evidence_level | 国家级主管机关政策/官方指引 |
| validity_status | 候选有效状态，待官方页面和人工复核 |
| allowed_use | 行业政策背景、研究证据提示 |
| forbidden_use | 不得直接提高评分，不得替代公司财报和业务证据，不得输出交易建议 |
| confidence | draft / pending_review |

## 六、人工复核问题

1. 目标公司是否有软件产品销售收入？
2. 软件产品收入占比是多少？
3. 公司公告或财报是否披露享受即征即退政策？
4. 收入是否属于自行开发生产的软件产品？
5. 政策影响是否已反映在利润、现金流或递延收益等科目？
6. 是否存在政策变化、地方口径或材料不满足风险？

## 七、结论

税收政策知识库可以为股票系统提供软件行业税费政策背景，但股票系统只能把它作为研究证据线索。它不能直接改变股票评分，不能替代财报证据，不能生成税务结论，也不能生成买卖建议。
