# 影子样例命名与编号规则草案

> 版本：v1.0
> 状态：命名规则草案，不是全系统强制规则
> 边界声明：不接 n8n，不接企业微信，不写正式库，不触发真实业务动作。

## 用途

用于孵化区影子样例、资料登记卡、人工复核回执的命名建议，降低后续接续时的查找成本。

## 编号前缀

| 前缀 | 含义 | 示例 |
|:---|:---|:---|
| TAX_SHADOW | 税收影子样例 | `TAX_SHADOW_001_软件即征即退_影子样例_v1.0.md` |
| OFFICE_SHADOW | 本职工作影子样例 | `OFFICE_SHADOW_001_制度流程梳理_影子样例_v1.0.md` |
| VIDEO_SHADOW | 视频制作影子样例 | `VIDEO_SHADOW_001_短视频脚本拆解_影子样例_v1.0.md` |
| MATERIAL_CARD | 资料登记卡 | `MATERIAL_CARD_TAX_001_增值税政策_v1.0.md` |
| REVIEW_RECEIPT | 人工复核回执 | `REVIEW_RECEIPT_OFFICE_001_v1.0.md` |

## 命名建议

```text
业务前缀_三位序号_主题_资产类型_v版本.md
```

示例：

```text
VIDEO_SHADOW_001_平台规范来源_影子样例_v1.0.md
```

## 使用边界

- 本规则先作为孵化区草案，不反向要求旧文件重命名。
- 发现旧命名不一致时，只记录，不顺手清理。
- 若未来升级为强制规则，必须另行确认风险等级和验收通道。
