# 本职工作工作流梳理

> 版本：v1.0
> 状态：影子工作流草案，不是自动化流程
> 边界声明：不开正式链路，不外发，不接真实办公系统，不触发 n8n 或企业微信。

## 影子工作流

```text
用户提出任务
-> 判断任务类型
-> 收集授权资料
-> 判断依据层级
-> 识别风险边界
-> 生成待复核草案
-> 用户人工修正
-> 沉淀为进化样本
```

## 节点说明

| 节点 | 输入 | 输出 | 人工确认点 |
|:---|:---|:---|:---|
| 任务类型判断 | 用户描述 | 场景标签、待补问题 | 任务不清时必须确认 |
| 授权资料收集 | 用户提供文件或公开来源 | 资料清单、来源记录 | 涉敏资料必须确认 |
| 依据层级判断 | 法律法规、单位制度、流程经验 | 层级排序、冲突提示 | 冲突无法判断时必须确认 |
| 风险边界识别 | 任务目标、输出去向、系统动作 | 禁止动作、人工闸口 | 涉外发/提交/审批必须确认 |
| 待复核草案生成 | 已确认资料、模板、约束 | 草案、依据、待补项 | 草案采用前必须确认 |
| 人工修正沉淀 | 用户修改意见 | 修正样本、经验条目 | 是否沉淀为规则需确认 |

## 默认禁止动作

- 不自动读取未授权目录。
- 不接入 OA、ERP、财务、人事、邮件、企业微信等真实系统。
- 不替用户提交审批、报送、发布、盖章或对外承诺。
- 不把人工经验直接升级为系统规则。

## 第一阶段验收

- 每个节点都有输入、输出和人工确认点。
- 工作流明确为影子草案。
- 不包含脚本、计划任务、n8n 工作流或真实系统接入。
