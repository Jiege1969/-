# 本职工作制度流程资料模板

> 版本：v1.0
> 状态：影子资料模板，不是正式制度库
> 边界声明：不开正式链路，不外发，不接真实办公系统，不触发 n8n 或企业微信。

## 用途

用于登记用户后续提供的单位制度、科室流程、岗位职责和表格模板，形成可复核的资料索引。

## 模板

| 字段 | 内容 |
|:---|:---|
| 资料名称 | 待补 |
| 资料类型 | 单位制度 / 科室流程 / 岗位职责 / 表格模板 / 历史案例 |
| 来源位置 | 待用户提供 |
| 版本或日期 | 待补 |
| 适用范围 | 待补 |
| 上位依据 | 待补 |
| 下位流程 | 待补 |
| 涉及岗位 | 待补 |
| 涉及敏感信息 | 是/否/待判 |
| 可否进入影子样例 | 待确认 |
| 人工复核意见 | 待填写 |

## 使用边界

- 未经用户授权，不主动读取真实办公目录。
- 科室流程不得反向覆盖单位制度或上位依据。
- 涉及人事、财务、合同、客户等敏感资料时，必须先确认授权和脱敏。
