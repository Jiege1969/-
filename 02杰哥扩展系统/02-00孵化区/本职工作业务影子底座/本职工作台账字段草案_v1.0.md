# 本职工作台账字段草案

> 版本：v1.0
> 状态：影子字段草案，不写正式台账
> 边界声明：不开正式链路，不外发，不接真实办公系统，不触发 n8n 或企业微信。

## 用途

用于预先梳理本职工作场景中可能复用的台账字段，后续由用户结合真实工作确认。

## 通用字段

| 字段 | 说明 | 状态 |
|:---|:---|:---|
| item_id | 条目编号 | 待确认 |
| task_type | 工作事项类型 | 待确认 |
| source_doc | 来源资料 | 待确认 |
| basis_level | 依据层级 | 待确认 |
| responsible_role | 责任岗位 | 待确认 |
| input_materials | 输入材料 | 待确认 |
| output_draft | 输出草案 | 待确认 |
| risk_flags | 风险标记 | 待确认 |
| human_gate | 人工确认点 | 待确认 |
| review_status | 复核状态 | 待确认 |
| archive_note | 归档说明 | 待确认 |

## 禁止项

- 不直接写正式台账。
- 不登记真实个人敏感信息。
- 不把字段草案当作单位正式表格。
