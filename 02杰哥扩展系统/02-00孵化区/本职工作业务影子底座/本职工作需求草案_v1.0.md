# 本职工作业务影子底座需求草案

> 版本：v1.0
> 状态：待复核草案，不是正式业务方案
> 边界：只做影子底座，不上线、不外发、不接真实系统
> 边界声明：不开正式链路，不外发，不接真实办公系统，不触发 n8n 或企业微信。

## 目标

让系统先学会整理本职工作场景中的依据、流程、资料和输出草案，形成可复核、可追溯、边界清楚的影子底座。

## 第一阶段范围

- 建立资料来源清单。
- 建立数据源清单。
- 梳理高频工作事项草案。
- 明确哪些动作必须人工确认。
- 标注待补资料和待复核项。

## 暂不做

- 不自动办理真实业务。
- 不接 OA、ERP、财务、人事、邮件或企业微信。
- 不生成正式制度解释。
- 不提交审批、报送、发布或盖章。
- 不处理未授权敏感资料。

## 高频事项候选

当前仅作为候选，等待用户确认：

| 候选事项 | 输入 | 输出 | 当前状态 |
|:---|:---|:---|:---|
| 制度依据整理 | 制度文件、流程说明 | 依据层级摘要 | 待确认 |
| 工作流程梳理 | 科室流程、岗位职责 | 流程草案和风险点 | 待确认 |
| 台账字段设计 | 表格模板、历史台账 | 字段清单草案 | 待确认 |
| 材料草稿生成 | 历史模板、任务说明 | 待复核草稿 | 待确认 |
| 复盘经验沉淀 | 已办结案例、人工修正 | 经验样本 | 待确认 |

## 验收标准

- 文件均位于孵化区影子底座目录。
- 所有输出明确标注待复核。
- 不确定资料均标注待补。
- 高风险真实动作均列入禁止或人工确认。
- 后续正式开工前重新执行扩展系统开工五问。
