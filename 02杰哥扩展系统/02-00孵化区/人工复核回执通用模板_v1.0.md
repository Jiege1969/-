# 人工复核回执通用模板

> 版本：v1.0
> 状态：孵化区通用人工复核模板，不是审批单
> 边界声明：不接 n8n，不接企业微信，不写正式库，不触发真实业务动作。

## 用途

用于记录用户或人工复核者对影子样例、草案、字段模板、资料登记卡的复核意见。

该回执只用于影子孵化和进化样本候选，不替代正式审批、正式业务确认或对外承诺。

## 模板

| 字段 | 内容 |
|:---|:---|
| review_id | 待生成 |
| related_asset | 待补 |
| business_line | 税收 / 本职工作 / 视频制作 / 总管策略 / 其他 |
| review_type | 通过 / 修改后通过 / 驳回 / 待补 |
| reviewer | 用户 / 人工复核者 |
| review_date | 待补 |
| accepted_parts | 待补 |
| correction_points | 待补 |
| rejected_parts | 待补 |
| missing_materials | 待补 |
| can_enter_evolution | 是 / 否 / 待判 |
| next_action | 继续影子 / 补资料 / 暂停 / 进入人工确认 |

## 使用规则

- 回执不能写成正式审批。
- 回执不能触发自动发布、外发、申报、渲染或真实系统接入。
- 复核意见进入进化系统前，需确认是否为可复用经验。
- 被驳回内容不得继续作为默认模板使用。

## 最小自检

```text
关联资产明确
-> 修改点明确
-> 是否可沉淀明确
-> 下一步动作明确
-> 未触发真实业务动作
```
