# 共享政策证据只读调用样例 VIDEO 001：平台规范与素材授权待补

> 版本：v1.0  
> 日期：2026-05-07  
> 资产身份：视频制作系统只读政策/规范证据调用影子样例  
> 风险等级：W1  
> 边界：只读样例，不读取真实素材，不连接平台，不剪辑、不渲染、不发布、不外发、不接 n8n。  

## 一、调用意图

视频制作系统可能需要查询平台规范、版权政策、素材授权要求等证据，以辅助生成待复核视频方案。

当前视频线尚未登记真实平台规范来源卡，也未登记真实素材授权卡。因此本样例的重点是：当证据不足时，系统应返回待补项，不得生成“可发布”“版权安全”“平台合规”等确定结论。

## 二、调用输入

| 字段 | 内容 |
|:---|:---|
| requesting_system | 视频制作业务 |
| query_intent | 平台规范/素材授权/版权风险证据 |
| topic_keywords | 平台规范、素材授权、版权、发布风险 |
| expected_evidence_level | 官方平台规范、用户授权材料、人工复核 |
| source | 视频平台规范来源卡模板、视频素材授权字段模板 |

## 三、只读证据状态

| 证据 | 当前状态 | 处理 |
|:---|:---|:---|
| 平台规范来源卡 | 只有模板，未登记真实平台 | 返回待补，不生成平台规则结论 |
| 素材授权字段 | 只有模板，未登记真实素材授权 | 返回待补，不生成授权结论 |
| 官方版权政策 | 未登记 | 返回待补，不生成版权安全结论 |
| 用户发布要求 | 未提供 | 返回待补，不替代平台规则 |

## 四、可返回字段

| 字段 | 内容 |
|:---|:---|
| evidence_id | VIDEO-EVIDENCE-PENDING-001 |
| title | 视频平台规范与素材授权证据待补 |
| evidence_level | 待补 |
| validity_status | 待核验 |
| source_path | `视频平台规范来源卡模板_v1.0.md`; `视频素材授权字段模板_v1.0.md` |
| risk_flags | 未登记真实平台规范、未登记素材授权、未登记版权政策 |
| allowed_use | 生成待补资料清单、人工复核问题 |
| forbidden_use | 不得输出可发布、版权安全、平台合规、可商用等确定结论 |

## 五、视频系统可生成的草案

| 输出 | 边界 |
|:---|:---|
| 平台规范待补清单 | 可以 |
| 素材授权待补清单 | 可以 |
| 发布风险提示 | 可以 |
| 分镜/脚本建议 | 仅在不使用真实素材、不发布前提下作为草案 |
| 平台合规结论 | 不可以 |
| 版权安全结论 | 不可以 |
| 自动发布 | 不可以 |

## 六、人工复核问题

1. 目标发布平台是什么？
2. 是否已有官方平台规范链接或用户提供规范文件？
3. 素材来源分别是什么？
4. 哪些素材可剪辑、可发布、仅参考或禁止使用？
5. 是否含个人、客户、地址、账号等敏感信息？
6. 授权期限和使用范围是什么？

## 七、结论

视频系统当前可以接入共享证据调配机制，但只能得到“证据待补”和“复核问题”。在没有真实平台规范和素材授权证据前，不应输出可发布或版权安全结论。
