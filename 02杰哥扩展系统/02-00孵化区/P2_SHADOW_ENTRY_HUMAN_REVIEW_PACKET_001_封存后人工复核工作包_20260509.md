# P2-S10 封存后人工复核工作包

> 状态：空白工作包模板与只读预演依据，不是放行单。
> 日期：2026-05-09
> 边界：不读取真实材料，不写影子入口，不触发外部动作。

## 目的

P2-S9 已把映射结果分成待复核影子封存、缺口封存和红线阻断封存。P2-S10 把这些封存项转成可人工复核的工作包，明确复核问题、允许动作和禁止动作。

## 工作包分组

### 待复核影子封存

适用：税收、本职工作、视频、共享政策证据四条业务线。

复核目标：

- 材料是否已脱敏或授权。
- 目标业务线是否正确。
- 目标入口是否仍为空白或待复核状态。
- 是否只生成待复核草案或预填建议。
- 是否仍保持不写正式库、不外发、不触发 n8n。

允许动作：

- 人工读取脱敏材料。
- 人工决定是否填写影子入口。
- 人工补充缺口字段。

禁止动作：

- 自动填写影子入口。
- 自动生成正式业务结论。
- 自动发送、上传、申报、交易、渲染或发布。

### 缺口封存

适用：未脱敏、来源不清、授权不明、条件不足。

复核目标：

- 缺口是否真实存在。
- 是否可以通过补充脱敏材料解决。
- 是否需要继续暂停。

允许动作：

- 记录缺口。
- 请求补充材料或授权。

禁止动作：

- 用猜测补齐缺口。
- 生成业务结论。

### 红线阻断封存

适用：真实执行请求、未授权敏感材料、明确要求外发或正式办理。

复核目标：

- 红线命中是否准确。
- 是否需要升级给总管或人工确认。
- 是否必须保持阻断。

允许动作：

- 记录阻断事实。
- 进入问题回收。

禁止动作：

- 绕过红线继续推进。
- 转入任何业务入口。

## 使用顺序

P2-S4 -> P2-S6 -> P2-S8 -> P2-S9 -> P2-S10 -> 人工复核 -> 影子入口填写候选。
