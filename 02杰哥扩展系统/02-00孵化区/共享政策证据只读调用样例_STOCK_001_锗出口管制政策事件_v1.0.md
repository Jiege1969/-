# 共享政策证据只读调用样例 STOCK 001：锗出口管制政策事件

> 版本：v1.0  
> 日期：2026-05-07  
> 资产身份：股票系统只读政策证据调用影子样例  
> 风险等级：W1  
> 边界：只读样例，不改股票配置，不改政策事件库，不触发前台、不外发、不交易。  

## 一、调用意图

股票研究系统需要读取政策事件证据，辅助判断锗相关公司或行业的政策催化背景。

本样例只演示“证据如何被读取和保真传递”，不生成新的股票评分，不修改 L3 契约，不输出买卖建议。

## 二、调用输入

| 字段 | 内容 |
|:---|:---|
| requesting_system | 股票研究系统 |
| query_intent | 政策事件/行业监管证据 |
| topic_keywords | 锗、出口管制、半导体材料、稀有金属 |
| expected_evidence_level | 官方政策事件 |
| source | `SHARED-POLICY-EVENT-001` 股票政策事件库 |

## 三、只读证据摘录

| 字段 | 内容 |
|:---|:---|
| event_id | POL-2023-001 |
| title | 商务部 海关总署公告2023年第23号 关于对镓、锗相关物项实施出口管制的公告 |
| source_name | 商务部、海关总署 |
| source_level | official |
| publish_date | 2023-07-03 |
| effective_date | 2023-08-01 |
| status | superseded_active |
| industry_tags | 稀有金属、半导体材料、出口管制、锗 |
| impact_direction | 利好 |
| event_confidence | 0.95 |
| source_url | `https://dcj.mofcom.gov.cn/article/zcfb/zcdwmy/202307/20230703419666.shtml` |

## 四、业务内解释边界

股票系统可以把该证据作为政策事件和行业背景，但必须保留以下限制：

| 项目 | 要求 |
|:---|:---|
| allowed_use | 政策事件证据、行业政策背景、研究报告证据链 |
| forbidden_use | 不得直接生成买卖建议，不得替代财报/行情/技术结构证据 |
| risk_counterpoint | 政策利好不等于盈利兑现；需求、价格、许可执行节奏和替代材料均需继续跟踪 |
| output_state | 只能进入研究草案或结构化评分证据，不触发外发和交易 |

## 五、对税收政策知识库的启发

本样例说明：跨系统调用不一定要上 n8n。对于低频政策证据，只要保留来源、状态、层级、风险反例和禁止用途，就可以先用轻量只读调配支撑影子验证。
