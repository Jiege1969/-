# 影子源头优先治理规则草案

> 版本：v1.0
> 状态：孵化区影子规则草案，不是清债规则
> 边界声明：不接 n8n，不接企业微信，不写正式库，不触发真实业务动作。

## 用途

用于影子底座新增资料、样例或模板前，先确认来源、授权、依据层级和复核状态。

## 源头优先检查

| 检查项 | 问题 | 不满足时处理 |
|:---|:---|:---|
| 来源 | 资料从哪里来？ | 标待补 |
| 授权 | 用户是否明确授权？ | 标待确认 |
| 依据层级 | 属于哪个层级？ | 标待判 |
| 有效状态 | 是否仍有效？ | 标待核验 |
| 敏感性 | 是否含敏感内容？ | 标待脱敏 |
| 复核 | 是否经过人工确认？ | 标待复核 |

## 禁止绕行

- 不因“看起来有用”就写入样例。
- 不因“之前这么做过”就升级为规则。
- 不因为已有影子资料就默认来源可靠。
- 不顺手清理旧资料。

## 输出格式

```text
源头检查：
- 来源：
- 授权：
- 层级：
- 有效状态：
- 敏感性：
- 复核状态：
- 结论：可进入影子 / 待补 / 暂停
```
