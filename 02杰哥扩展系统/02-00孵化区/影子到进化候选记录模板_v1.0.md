# 影子到进化候选记录模板

> 版本：v1.0
> 状态：进化候选模板，不是正式进化规则
> 边界声明：不接 n8n，不接企业微信，不写正式库，不触发真实业务动作。

## 用途

用于记录某个影子样例或人工复核意见是否具备进入进化系统的候选价值。

本模板只产生候选记录，不自动写入策略锚点库、规则库或正式样本库。

## 模板

| 字段 | 内容 |
|:---|:---|
| candidate_id | 待生成 |
| source_asset | 待补 |
| business_line | 税收 / 本职工作 / 视频制作 / 总管策略 / 其他 |
| trigger_context | 待补 |
| human_correction | 待补 |
| reusable_lesson | 待补 |
| applies_to | 待补 |
| not_applies_to | 待补 |
| evidence | 待补 |
| risk_if_promoted | 待补 |
| recommended_destination | 策略锚点 / 规则库 / 母本模板 / 业务线模板 / 暂不沉淀 |
| reviewer_decision | 待复核 |

## 判断标准

- 是否来自真实人工修正或明确复核意见。
- 是否具有跨任务复用价值。
- 是否有足够证据。
- 是否会造成文档膨胀或规则冲突。
- 是否需要先进入待评估队列。

## 禁止项

- 不自动新增策略锚点。
- 不自动修改施工铁律。
- 不把单个案例直接升级为通用规则。
- 不把未复核内容写成“系统已学会”。
