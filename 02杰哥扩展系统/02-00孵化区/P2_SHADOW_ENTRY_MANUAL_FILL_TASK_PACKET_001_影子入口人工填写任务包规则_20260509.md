# P2-S14 影子入口人工填写任务包规则

> 状态：人工填写任务包规则，不是填写结果，不是写入器。
> 日期：2026-05-09
> 边界：不读取真实材料，不写影子入口，不触发外部动作。

## 目的

P2-S13 已生成影子入口填写差异预览。P2-S14 将差异预览压缩成 4 份人工填写任务包，让人工清楚知道：

- 哪些字段可以基于真实脱敏或授权材料填写。
- 哪些字段必须保持 false。
- 哪些字段必须保持待复核或不变。
- 填完后必须回到哪道只读闸口复验。

## 任务包硬规则

- 任务包不是填写结果。
- 任务包不是放行单。
- 任务包不得自动写入目标入口。
- 任务包不得生成正式业务结论。
- 任务包不得触发 n8n、企业微信、正式库或真实业务动作。
- 每份任务包必须保留目标入口路径和复验脚本。

## 复验要求

人工完成填写后，不得直接进入业务草案或真实执行。必须先走：

1. JSON 解析检查。
2. 红线字段保持 false 检查。
3. 目标入口状态与业务线一致性检查。
4. 只读回归或对应业务线影子检查。
