# 影子资料登记卡通用模板

> 版本：v1.0
> 状态：孵化区通用影子模板，不是正式资料库
> 边界声明：不接 n8n，不接企业微信，不写正式库，不触发真实业务动作。

## 用途

用于三条影子线统一登记资料来源、授权状态、适用范围、风险边界和人工复核结论。

## 模板

| 字段 | 内容 |
|:---|:---|
| card_id | 待生成 |
| business_line | 税收 / 本职工作 / 视频制作 / 其他 |
| material_name | 待补 |
| material_type | 政策 / 制度 / 流程 / 素材 / 模板 / 样例 / 平台规范 / 其他 |
| source_type | 官方公开 / 用户提供 / 历史样例 / 人工经验 / 待核验 |
| source_path_or_url | 待补 |
| collected_date | 待补 |
| effective_status | 有效 / 失效 / 待核验 / 不适用 |
| authorization_status | 已授权 / 仅参考 / 禁止使用 / 待确认 |
| sensitivity | 无敏感 / 财务 / 人事 / 合同 / 客户 / 素材版权 / 账号 / 待判 |
| basis_level | 法律 / 行政法规 / 部门规章政策 / 单位制度 / 科室流程 / 人工经验 / 不适用 |
| can_enter_shadow | 是 / 否 / 待确认 |
| forbidden_actions | 待补 |
| human_review_status | 待复核 |
| review_note | 待填写 |

## 使用规则

- 未授权资料只登记待确认，不进入样例处理。
- 敏感资料必须先脱敏，再进入影子样例。
- 人工经验不得直接升级为系统规则。
- 资料登记不代表正式采用。

## 最小自检

```text
来源有记录
-> 授权有状态
-> 敏感性有判断
-> 是否可进影子有结论
-> 人工复核状态明确
```
