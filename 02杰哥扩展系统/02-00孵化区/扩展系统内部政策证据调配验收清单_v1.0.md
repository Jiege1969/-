# 扩展系统内部政策证据调配验收清单

> 版本：v1.0  
> 日期：2026-05-07  
> 资产身份：扩展系统内部轻量调配验收草案  
> 风险等级：W1  
> 边界：验收草案，不是生产监控，不接 n8n，不自动调度。  

## 一、验收目标

验证扩展系统内部政策证据轻量调配是否真正可用，并确认没有把影子证据调用做成正式工作流。

## 二、必检项

| 验收项 | 标准 |
|:---|:---|
| 只读 | 调用样例不得写入、覆盖、删除任何政策库或业务库 |
| 不接 n8n | 当前阶段不得建立 n8n 工作流或自动调度 |
| 不外发 | 不触发企业微信、邮件、发布平台或其他外发 |
| 保留来源 | 输出必须保留 source_url 或 source_path |
| 保留层级 | 输出必须保留 evidence_level 或说明待补 |
| 保留状态 | 输出必须保留 validity_status 或 pending_review |
| 证据不等于结论 | 不得写“确定适用”“可发布”“买入卖出”“审批通过”等结论 |
| 待核验不升级 | pending/draft/待核验不得被调用方改成 confirmed |
| 业务内解释 | 调用方必须在本业务契约里解释证据 |
| 人工复核 | 涉及专业判断时必须保留 review_questions 或人工复核点 |

## 三、当前样例覆盖

| 调用方 | 样例 | 覆盖结论 |
|:---|:---|:---|
| 税务业务分析助手 | TAX 001 软件产品即征即退 | 证据可传入分析契约，不给确定金额 |
| 股票研究系统 | STOCK 001 锗出口管制政策事件 | 政策事件可作研究证据，不触发交易 |
| 本职工作业务 | OFFICE 001 涉税资料清单 | 可生成待补资料清单，不替代审批 |
| 视频制作业务 | VIDEO 001 平台规范与素材授权待补 | 证据不足时返回待补，不生成发布/版权结论 |

## 四、升级到 n8n 前条件

只有同时满足以下条件，才讨论 n8n：

1. 至少 3 个业务系统有稳定、重复的政策证据调用需求。
2. 调用字段稳定，包括 source、level、status、risk、forbidden_use。
3. 只读调用样例至少通过 3 轮人工复核。
4. 没有把证据误写成业务结论的案例。
5. 用户明确要求进入自动化编排。
6. 走 W3 确认和验收。

## 五、当前结论

当前不具备上 n8n 的必要性。扩展系统内部轻量只读调配已经足够支撑影子验证，后续应继续补样例和复核，而不是提前建设自动化工作流。
