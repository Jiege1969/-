# 影子样例创建操作卡

> 版本：v1.0
> 状态：人工操作卡，不是自动样例生成器
> 边界声明：不接 n8n，不接企业微信，不写正式库，不触发真实业务动作。

## 适用场景

资料已完成登记，且确认可进入影子样例时使用。

## 操作步骤

1. 读取影子样例统一结构模板。
2. 按业务线选择编号前缀：TAX_SHADOW / OFFICE_SHADOW / VIDEO_SHADOW。
3. 填写业务线、场景、输入摘要、来源资料、风险标记和禁止动作。
4. 输出草案必须标注“待复核”。
5. 保留人工复核结果字段。
6. 如果涉及真实动作、外发、敏感资料或依据冲突，立即闭口并转人工闸口。
7. 样例完成后，更新线内索引或待补表。

## 禁止动作

- 不写真实敏感数据。
- 不把样例写成正式结论。
- 不自动进入进化系统。
- 不触发真实业务动作。
