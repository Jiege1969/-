# 影子失败闭口规则草案

> 版本：v1.0
> 状态：孵化区影子规则草案，不是施工铁律
> 边界声明：不接 n8n，不接企业微信，不写正式库，不触发真实业务动作。

## 用途

用于影子底座中处理资料缺失、依据冲突、授权不明、风险边界不清等情况。

## 失败闭口条件

| 条件 | 处理 |
|:---|:---|
| 输入来源不明 | 标待补，不生成结论 |
| 授权状态不明 | 标待确认，不进入样例处理 |
| 依据层级冲突 | 标冲突待复核，不采用下位口径 |
| 涉真实动作 | 暂停影子输出，转人工闸口 |
| 输出用途不明 | 只给问题清单，不给方案 |
| 敏感资料未脱敏 | 不处理内容，只登记待脱敏 |

## 输出格式

```text
失败闭口：
- 闭口原因：
- 缺失资料：
- 可继续动作：
- 必须人工确认：
```

## 边界

失败闭口只约束影子草案，不修改正式业务流程。
