# 税收资料元数据字段

> 版本：v1.0  
> 状态：影子底座字段草案  
> 用途：把税收政策资料从“文件”转成可检索、可复核、可推理的结构化卡片

---

## 基础字段

| 字段 | 说明 | 是否必填 |
|:---|:---|:---|
| document_id | 系统内部编号 | 是 |
| title | 文件标题 | 是 |
| document_number | 文号 | 是 |
| issuing_authority | 发布机关 | 是 |
| publish_date | 发布日期 | 是 |
| effective_date | 生效日期 | 待核实 |
| validity_status | 现行有效/废止/部分失效/待核实 | 是 |
| source_url | 官方来源链接 | 是 |
| source_level | 国家级/省级/地市级/基层流程/人工案例 | 是 |
| tax_type | 税种 | 是 |
| business_scenario | 适用业务场景 | 是 |
| legal_level | 法律/行政法规/部门规章/规范性文件/办税指南/实务案例 | 是 |
| hierarchy_rank | 依据层级排序：0宪法/根本原则、1法律、2行政法规、3部门规章/规范性文件/主管机关政策、4地方口径/单位制度、5科室流程/人工经验 | 是 |
| source_scope | 国家级/省级/地市级/单位/科室/人工经验 | 是 |
| conflict_with_higher_level | 是否可能与上位依据冲突 | 是 |

| related_documents | 相关文件 | 否 |
| replaced_by | 废止或替代文件 | 否 |
| local_scope | 地区适用范围 | 否 |
| verification_status | 未核验/人工已核验/需复核 | 是 |
| reviewer | 核验人 | 否 |
| review_time | 核验时间 | 否 |
| notes | 备注 | 否 |

## 可信等级

| 等级 | 含义 | 可用于草案依据 |
|:---|:---|:---|
| A | 国家级官方来源，状态可核验 | 可以 |
| B | 地方官方来源，地区适用范围明确 | 可以，但需标地区 |
| C | 基层流程或办税指南 | 可以作为流程参考 |
| D | 人工经验或案例 | 只能作为提示，不作为正式依据 |
| X | 来源或状态待核实 | 不得作为正式依据 |

---

## 依据层级

所有政策、指南、流程和人工经验入库前必须先判断依据层级：

```text
宪法/根本原则
> 法律
> 行政法规
> 部门规章、规范性文件、主管机关政策
> 地方口径、单位/企业制度
> 职能科室工作流程、操作SOP、人工经验
```

用户主链：

```text
宪法 > 法律 > 部门规章制度 > 单位企业制度 > 职能科室工作流程
```

冲突时以上位依据为准；下位依据只作风险提示、地区口径、流程参考或待复核事项。

---

## 输出使用规则

- A/B/C 级资料可进入候选依据，但必须展示来源和状态。
- D 级资料只能作为风险提示或实务提醒。
- X 级资料只能列入待核实事项。
- 任何资料状态不明时，不得包装成确定依据。
- 下位流程、单位制度或人工经验不得反向覆盖上位法律政策。
- 若存在层级冲突，草案必须标记“依据冲突/待复核”，不得输出确定结论。
