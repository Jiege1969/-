# 税收政策顾问影子版运行检查清单

> 版本：v1.0  
> 日期：2026-05-07  
> 资产身份：税收政策顾问影子版运行检查清单  
> 风险等级：W1  
> 边界：运行检查只约束影子草案输出，不接真实税务系统，不外发，不写正式库。  

## 一、运行前检查

| 检查项 | 通过标准 |
|:---|:---|
| 问题类型 | 属于政策咨询、涉税业务分析、资料清单、适用条件或测算前置 |
| 非目标排除 | 不是申报、退税、开票、外发、正式意见 |
| 输入字段 | 至少有 business_question、business_scenario、requested_output |
| 敏感信息 | 未包含密码、登录信息、未脱敏客户隐私 |
| 依据来源 | 优先使用已登记官方来源、元数据卡、指引卡和字段化样例 |

## 二、证据检查

| 字段 | 要求 |
|:---|:---|
| policy_evidence | 必须列标题、文号或证据编号 |
| evidence_level | 必须写法律、行政法规、规范性文件、官方指引或待补 |
| validity_status | 必须写全文有效、现行有效待复核、废止、失效或待核验 |
| official_source | 必须写官方链接、本地卡路径或待补 |
| extracted_conditions | 必须拆主体、事项、期间、地区、材料、排除或风险 |
| evidence_gap | 不得为空；未知项写待补 |

## 三、输出检查

| 输出项 | 要求 |
|:---|:---|
| 分析对象 | 明确税种、政策、事项、地区、期间；未知写待补 |
| 分析结论 | 必须是待复核草案，不写最终结论 |
| 适用条件 | 已知、待证明、不适用风险分开 |
| 资料缺口 | 必须列出 |
| 测算字段 | 只列字段和口径，不给未经复核金额 |
| 风险提示 | 包含时效、地方口径、资料、外发边界 |
| 人工复核问题 | 至少3条，指向可补资料或可复核事实 |
| 下一步 | 只能是补证据、补资料、人工复核或沉淀样例 |

## 四、红线检查

输出中不得出现以下正向结论：

- 一定适用。
- 可以直接享受。
- 应退金额为确定数。
- 已确认无风险。
- 可直接申报。
- 可直接外发。
- 已通过税务机关确认。

如必须提及这些词，只能出现在“禁止输出”或“风险提示”语境。

## 五、状态判定

| 状态 | 使用条件 |
|:---|:---|
| draft | 证据或业务事实明显不足 |
| evidence_ready | 证据链较完整，但未人工复核 |
| pending_review | 草案已形成，等待用户或专业人员确认 |
| human_reviewed | 人工已复核并留回执；仍不自动写正式规则 |

## 六、运行后记录

每次试用结束后，记录：

```text
[试用记录: 主题=xxx, 状态=draft/evidence_ready/pending_review, 主要缺口=xxx, 是否越界=false, 下一步=xxx]
```

如出现用户要求申报、退税、开票、外发、接系统、n8n或企业微信，立即暂停并标注 W3。
