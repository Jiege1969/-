# 税收业务影子底座：开工五问校准

> 版本：v1.0
> 状态：影子底座补充，不是正式税收业务系统
> 边界声明：不开正式链路，不外发，不接真实申报或办公系统，不触发 n8n 或企业微信。

## 1. 需求

建立税收业务影子底座，用于整理公开税收政策、资料来源、元数据字段、政策卡、测算前置字段和待复核草案。

当前只支持政策资料整理和影子样例验证，不提供正式申报、自动测算、自动报送或税务结论确认。

## 2. 输入

- 国家税务总局、财政部等公开官方政策来源。
- 用户明确提供的税收业务资料、企业情况、历史样例或表格模板。
- 已登记的政策元数据卡、政策指引卡、影子样例和测算前置字段。

当前待补：

- 地方税务机关口径。
- 企业实际业务和财务数据。
- 可用于复核的历史申报或测算样例。

## 3. 输出

- 税收资料来源清单。
- 税收数据源清单。
- 政策元数据卡和政策指引卡。
- 影子样例和待复核需求草案。

所有输出均为待复核材料，不作为正式申报依据或税务意见。

## 4. 风险

- 不登录电子税务局或企业财税系统。
- 不读取未授权财务、发票、合同、人员或客户资料。
- 不自动计算可退税额、应纳税额或申报金额。
- 不提交申报、报送、备案、开票或外发通知。
- 下位流程、地方经验和人工口径不得反向覆盖上位税收依据。

## 5. 验收

第一阶段只验收影子底座：

- 五问、需求草案、数据源清单、来源清单、元数据字段和索引齐备。
- 所有结论标注待复核或待补。
- 不接正式系统、不触发外发、不写正式库。
- 正式税收业务系统开工前必须重新执行扩展系统开工五问。
