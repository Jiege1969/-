# 税收地方口径待补模板

> 版本：v1.0
> 状态：影子待补模板，不是正式税务结论
> 边界声明：不开正式链路，不外发，不接真实申报或办公系统，不触发 n8n 或企业微信。

## 用途

用于登记某一税收主题在地方税务机关、办税指南、窗口口径或历史执行经验中的待补差异。

## 模板

| 字段 | 内容 |
|:---|:---|
| 主题名称 | 待补 |
| 上位依据 | 待补 |
| 地方来源 | 待补 |
| 来源链接或文件 | 待补 |
| 发布机关 | 待补 |
| 发布/更新日期 | 待补 |
| 有效状态 | 待核验 |
| 与上位依据关系 | 细化 / 差异 / 冲突待复核 |
| 适用地区 | 待补 |
| 适用对象 | 待补 |
| 关键口径 | 待补 |
| 风险提示 | 待补 |
| 人工复核结论 | 待复核 |

## 使用边界

- 地方口径不得反向覆盖法律、行政法规、部门规章或主管机关政策。
- 未核验有效状态时，只能作为待补资料。
- 涉及申报、退税、备案、开票等真实动作时，必须另走人工确认。
