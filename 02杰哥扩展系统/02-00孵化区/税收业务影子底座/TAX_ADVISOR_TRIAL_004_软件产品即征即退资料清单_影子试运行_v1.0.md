## 四、待收集资料清单

| 分组 | 资料或字段 | 用途 | 当前状态 |
|:---|:---|:---|:---|
| 主体资料 | 增值税一般纳税人身份资料或可核验证明 | 判断主体条件 | 待用户提供 |
| 主体资料 | 企业基本信息、纳税人识别号、主管税务机关 | 确定地区和主管口径 | 待用户提供 |
| 软件产品资料 | 软件著作权、软件产品登记、检测证明或当地替代材料 | 判断软件产品条件和资料完整性 | 待用户提供 |
| 软件产品资料 | 软件产品名称、版本、销售对象、交付方式 | 判断是否属于软件产品销售 | 待用户提供 |
| 研发生产资料 | 自行开发生产说明、研发流程、源代码或研发资料目录 | 判断自研或本地化改造属性 | 待用户提供 |
| 销售收入资料 | 合同、发票、收入明细、会计科目归集 | 判断软件产品销售收入 | 待用户提供 |
| 收入拆分资料 | 软件、硬件、服务、维护、培训、第三方软件收入拆分表 | 防止混同收入导致误判 | 待用户提供 |
| 税额资料 | 销项税额、可抵扣进项税额、应纳税额 | 仅用于后续测算前置，不在本样例中计算 | 待用户提供 |
| 期间资料 | 所属期、申报期、收入确认期间、政策适用期间 | 判断期间匹配 | 待用户提供 |
| 地方口径资料 | 当地备案、资料清单、办理程序或主管机关要求 | 判断地方执行差异 | 待补 |
| 复核资料 | 人工复核回执、专业人员意见、主管机关沟通记录 | 承接后续修正和复盘 | 待补 |

## 五、地方口径缺口

| 缺口 | 处理 |
|:---|:---|
| 主管税务机关资料要求不明 | 使用地方口径资料登记卡补齐，不得用经验替代 |
| 软件产品材料是否仍需登记或可用替代材料不明 | 标注待复核，以当地最新口径为准 |
| 办理程序、备案节点、留存备查要求不明 | 只列问题，不输出办理建议 |
| 企业所属期和业务发生地不明 | 不判断适用，也不进入金额测算 |

## 六、输出限制

本样例可以输出：

1. 待用户补充的资料清单。
2. 每类资料服务于哪个判断字段。
3. 地方口径和主管机关待补项。
4. 人工复核问题。

本样例不得输出：

- “可以享受即征即退”的确定结论。
- 退税金额、申报金额或办理建议。
- 主管税务机关最终资料口径。
- 正式税务意见或可外发文本。

## 七、人工复核问题

1. 企业是否已经确认为增值税一般纳税人？
2. 软件产品收入是否能与硬件、服务、维护、培训收入分开核算？
3. 软件著作权、检测证明、登记材料或当地替代材料是否齐备？
4. 当前所属期、申报期和政策有效期间是否一致？
5. 主管税务机关是否有额外资料、备案或留存备查要求？
6. 是否涉及嵌入式软件、受托开发、代理销售或进口软件本地化改造？
