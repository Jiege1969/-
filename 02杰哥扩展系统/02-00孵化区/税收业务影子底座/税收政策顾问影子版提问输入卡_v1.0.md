# 税收政策顾问影子版提问输入卡

> 版本：v1.0  
> 日期：2026-05-07  
> 资产身份：税收政策顾问影子版提问输入卡  
> 风险等级：W1  
> 边界：输入卡只帮助整理问题，不采集敏感原文，不连接真实系统，不外发。  

## 一、填写方式

用户提问时，可以按下面字段填写；没有的信息写“待补”，不要编造。

| 字段 | 内容 |
|:---|:---|
| business_question | 待填 |
| requested_output | 政策分析 / 资料清单 / 适用条件 / 测算前置字段 / 待复核报告 |
| tax_type | 待填或待补 |
| business_scenario | 待填 |
| entity_profile | 企业类型、纳税人身份、行业、业务模式；可脱敏 |
| region | 国家层 / 省市 / 待补 |
| period | 所属期、发生日期、申报期；待补也可 |
| amount_or_scale | 金额、收入规模或业务规模；没有则待补 |
| provided_materials | 已有合同、发票、账务、资质、证明、公告等清单 |
| known_policy | 已知政策文号或政策名称 |
| special_risk | 嵌入式软件、混合销售、外购转售、关联交易、跨地区等 |

## 二、最简提问模板

```text
我想做一份待复核税务分析草案。
问题：{business_question}
业务场景：{business_scenario}
税种：{tax_type或待补}
地区：{region或待补}
期间：{period或待补}
已有资料：{provided_materials或待补}
希望输出：{requested_output}
```

## 三、软件产品即征即退专用字段

| 字段 | 内容 |
|:---|:---|
| 是否一般纳税人 | 待补 |
| 软件产品收入 | 待补 |
| 硬件/服务/维护培训收入是否拆分 | 待补 |
| 是否自行开发生产 | 待补 |
| 是否嵌入式软件 | 待补 |
| 是否有软件著作权/检测证明/登记材料 | 待补 |
| 销项税额 | 待补 |
| 进项税额 | 待补 |
| 实际税负测算资料 | 待补 |
| 地方主管税务机关材料要求 | 待补 |

## 四、输入安全规则

- 不粘贴未脱敏的客户隐私、身份证号、完整账号、密码、税控盘信息。
- 不提供电子税务局登录信息。
- 不要求系统直接申报、退税、开票或外发。
- 不把“待补”改写成“已确认”。
- 涉及金额时，只允许先列测算字段和口径。

## 五、输入不足时的处理

| 缺失 | 处理 |
|:---|:---|
| 缺政策 | 查已登记政策卡或标为政策待补 |
| 缺地区 | 按国家层政策分析，地方口径标待补 |
| 缺期间 | 政策时效标待核验 |
| 缺企业资料 | 只列资料缺口，不做适用结论 |
| 缺金额字段 | 只列测算前置字段，不给金额 |
