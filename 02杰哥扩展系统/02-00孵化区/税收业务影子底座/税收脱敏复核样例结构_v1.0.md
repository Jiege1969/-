# 税收脱敏复核样例结构

> 版本：v1.0
> 状态：影子样例结构，不读取真实财税数据
> 边界声明：不开正式链路，不外发，不接真实申报或办公系统，不触发 n8n 或企业微信。

## 用途

用于后续承接用户人工提供的脱敏税收案例，帮助系统学习字段结构、适用条件、待补资料和人工修正意见。

## 样例结构

| 字段 | 说明 | 示例状态 |
|:---|:---|:---|
| sample_id | 脱敏样例编号 | 待生成 |
| tax_topic | 税收主题 | 待补 |
| source_policy | 政策依据 | 待补 |
| taxpayer_type | 纳税人类型 | 脱敏 |
| business_description | 业务描述 | 脱敏 |
| required_fields | 测算或判断所需字段 | 待补 |
| provided_fields | 已提供字段 | 待补 |
| missing_fields | 缺失字段 | 待补 |
| preliminary_assessment | 影子初步判断 | 待复核 |
| human_correction | 人工修正 | 待填写 |
| final_shadow_note | 影子复盘说明 | 待填写 |

## 禁止项

- 不写真实纳税人名称、税号、账号、合同、发票或金额明细。
- 不给出未经人工复核的确定申报金额。
- 不把样例结论扩展为通用税务规则。
