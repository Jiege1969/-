# 税收业务报告工作流草案

> 版本：v1.0  
> 日期：2026-05-07  
> 资产身份：涉税业务分析专家助手影子工作流草案  
> 来源参照：股票分析报告样本与工作流 v1.0 的通用方法链  
> 边界：待复核草案，不是正式税收业务系统；申报、退税、开票不是本系统目标；不外发、不接 n8n、不写正式库。  

## 一、定位

本草案把股票系统已经验证的“对象识别、证据调取、判断生成、前台输出、后台报告、复盘进化”抽象为涉税业务分析工作流。

税务业务系统的定位是政策顾问和涉税业务分析专家助手：依据国家政策和可信资料，分析具体税收业务的政策依据、适用条件、业务风险、资料缺口和待复核结论。它只迁移股票系统的分析方法，不迁移股票行情、交易、价位、券商接口等专用逻辑。

## 二、目标功能和非目标

| 类别 | 内容 |
|:---|:---|
| 目标功能 | 涉税业务分析、政策顾问式问答、政策依据整理、政策有效性核验、适用条件判断、业务事实拆解、资料清单生成、测算前置字段梳理、地方口径待补标注、待复核分析报告生成、人工修正沉淀 |
| 非目标 | 申报、退税、开票、登录电子税务局、连接财税软件、外发正式意见、替代专业人员签字确认 |

## 三、标准链条

```text
用户提出涉税业务问题
-> 意图识别：政策咨询 / 涉税业务分析 / 适用条件判断 / 测算前置字段 / 地方口径待核 / 资料清单生成 / 待复核分析报告
-> 对象解析：税种、政策文号、业务事项、企业事实、所属地区、所属期
-> 证据调取：法律、行政法规、部门规章、政策文件、官方问答、地方口径、企业资料、历史复核样本
-> 依据分层：上位依据优先，下位口径只作执行参考或待复核事项
-> 分析生成：政策匹配、适用条件、证据摘要、业务风险、缺口摘要、人工确认点
-> 前台草案：对象、结论级别、依据、适用条件、待补材料、风险提示、下一步人工复核
-> 后台报告：证据链、来源链接、版本状态、测算字段、地方差异、复核记录
-> 复盘进化：人工修正、口径差异、样例沉淀、经验候选
```

## 四、意图路由

| 用户说法 | 系统识别 | 影子处理 | 硬边界 |
|:---|:---|:---|:---|
| “软件产品即征即退怎么判断” | 适用条件梳理 | 生成待复核条件草案 | 不给最终税务结论 |
| “这笔业务按什么政策分析” | 涉税业务分析 | 匹配政策依据、拆解业务事实和适用条件 | 不替代专业签字确认 |
| “这个政策现在有效吗” | 政策查询 | 查已登记政策卡和有效状态 | 不替代官方复核 |
| “需要准备哪些资料” | 资料清单生成 | 按依据和事项列待收集资料 | 不替代内部审批 |
| “测算需要哪些字段” | 测算前置字段 | 列字段、公式口径、缺口 | 字段不足不给确定金额 |
| “我们当地能不能办” | 地方口径待核 | 标注地方口径待补 | 不把地方经验写成正式结论 |
| “生成一份待复核说明” | 待复核分析报告 | 输出依据、条件、缺口、风险和人工复核点 | 不作为正式外发意见 |

## 五、排除项处理

| 说法 | 处理方式 |
|:---|:---|
| “帮我申报” | 说明本系统不做申报，只能整理依据、资料清单和待复核说明 |
| “帮我退税” | 说明本系统不执行退税，只能梳理政策适用条件和测算前置字段 |
| “帮我开票” | 说明本系统不处理开票，只能整理相关依据和风险提示 |

这些排除项只是安全边界，不是建设目标。

## 六、前台草案字段

| 顺序 | 字段 | 说明 |
|:---|:---|:---|
| 1 | 分析对象 | 税种、政策文号、业务事项、地区和所属期，未知则写待补 |
| 2 | 分析结论 | 只写待复核分析结论，不写最终确定意见 |
| 3 | 上位依据 | 法律、行政法规、部门规章、规范性文件等来源 |
| 4 | 适用条件 | 已确认条件和待确认条件分开写 |
| 5 | 资料缺口 | 企业资料、地方口径、所属期、产品范围等缺口 |
| 6 | 风险事项 | 依据冲突、口径差异、资料不完整、时效不明等 |
| 7 | 人工复核 | 需要用户或专业人员确认的问题 |
| 8 | 下一步 | 只给资料补齐、人工复核、影子样例更新建议 |

## 七、后台报告骨架

| 模块 | 作用 |
|:---|:---|
| 对象解析 | 记录税种、政策文号、业务事项、地区、所属期 |
| 依据链 | 按依据层级列出证据来源和有效状态 |
| 业务事实拆解 | 把具体业务拆为主体、事项、金额/数量口径、期间、地区、材料状态 |
| 适用条件 | 把已满足、待证明、不适用条件拆开 |
| 测算字段 | 只列前置字段、公式口径和缺口，不给未经复核金额 |
| 地方差异 | 标记地方执行口径待补或待核实 |
| 风险提示 | 标出依据冲突、口径差异、资料缺口、时效不明或不可外发的原因 |
| 复核记录 | 连接人工复核回执、修正样本和进化候选 |

## 八、验收标准

| 验收项 | 标准 |
|:---|:---|
| 对象明确 | 输出必须说明政策文号、税种、业务事项；未知项写待补 |
| 业务分析明确 | 输出必须围绕具体涉税业务展开，不只堆政策原文 |
| 依据分层 | 上位依据优先，下位口径不得反向覆盖 |
| 缺口显式 | 地方口径、企业资料、所属期、政策有效状态缺失时必须写明 |
| 不越权 | 不生成正式外发意见，不进入申报、退税、开票等非目标功能 |
| 可复核 | 每个判断必须能回到来源、缺口或人工复核项 |
| 可进化 | 人工修正只进入样本或候选，不自动改正式规则 |
