# 税收政策下载筛选规程

> 版本：v1.0  
> 状态：影子底座操作规程  
> 来源：用户纠偏意见吸收  
> 核心修正：不能先下载后凭印象判断有效；应在国家税务总局政策法规库页面先用筛选项勾选有效状态，再登记或下载。

---

## 一、适用范围

适用于从国家税务总局政策法规库、税务总局官网、财政部官网及地方税务局公开页面登记或下载政策文件的操作。

本规程属于税收影子知识库建设的绿灯机制：只要使用公开官方来源、只做R0筛选和影子元数据登记，就应直接推进，不得因“税收业务系统尚未正式上线”而延后。

---

## 二、正确操作顺序

```text
进入官方政策库
-> 输入关键词或文号
-> 使用页面筛选项
-> 勾选“全文有效”或等价有效状态
-> 再打开政策页面
-> 核对标题、文号、发布机关、发布日期、有效状态
-> 再登记元数据卡或下载原文
```

可使用R0只读辅助工具先做候选检索：

```powershell
& 'D:\杰哥智能化系统\00杰哥系统总管\02脚本\R0只读工具\R0_国家税务总局政策库_全文有效检索.ps1' -SearchWord '即征即退'
```

该脚本只返回候选政策元数据，不下载附件，不写正式库。

---

## 三、必须记录的筛选证据

每张政策元数据卡必须尽量记录：

| 字段 | 说明 |
|:---|:---|
| search_portal | 从哪个官方入口检索 |
| search_keyword | 检索关键词或文号 |
| validity_filter | 是否已勾选有效状态 |
| validity_label_seen | 页面展示的有效状态文字 |
| source_url | 最终政策页面链接 |
| download_status | 已下载/未下载/无需下载 |
| manual_review_status | 人工已复核/待复核 |

---

## 四、有效状态口径

优先级：

1. 页面筛选项中勾选“全文有效”或等价有效状态。
2. 政策页面正文或列表展示的有效状态。
3. 废止、部分失效、条款失效等状态必须单独记录，不得混入有效依据。
4. 无有效状态展示时，标记为“待复核”，不得作为正式依据。

---

## 五、禁止做法

- 不先筛选有效状态就批量下载。
- 不把搜索结果第一页默认当成有效文件。
- 不凭发布日期或文件名推断有效。
- 不把失效、部分失效、条款失效文件当作当前有效依据。
- 不把“影子样例可用”理解为“政策有效性已复核通过”。

---

## 六、对现有影子底座的影响

当前已登记的财税〔2011〕100号、增值税法、软件产品即征即退政策指引，均保留为影子候选依据。

下一轮应补充：

1. 在政策法规库中按文号或关键词检索。
2. 使用有效状态筛选。
3. 将筛选状态回填到对应元数据卡。
4. 必要时下载原文并登记下载状态。

---

## 七、安全边界

- 本规程不自动下载文件。
- R0辅助脚本不自动下载文件。
- 遵守网站公开访问规则和技术限制。
- 不写正式税收库。
- 不输出可直接执行的税务处理意见。
