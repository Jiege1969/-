# 软件产品即征即退测算前置字段清单

> 版本：v1.0  
> 状态：影子底座字段清单  
> 来源：并行只读核实意见吸收  
> 用途：明确“能退多少”类测算问题进入草案前必须补哪些字段  
> 边界：本清单不进行税额测算，不输出正式税务处理结论。

---

## 一、为什么需要本清单

当前软件产品即征即退影子样例已经可以演示“可信输入 -> 候选依据 -> 待复核草案 -> 人工修正”的链条。

但用户问题中包含“如果可以，能退多少”，这类问题涉及测算。测算不能只依赖销售收入和政策名称，还需要申报期、地区、税率、销项税额、进项税额、应纳税额、收入拆分、材料状态等字段。

因此，测算类草案必须先检查本清单。

---

## 二、测算前置字段

| 字段 | 说明 | 缺失时处理 |
|:---|:---|:---|
| tax_period | 纳税所属期/申报期 | 列入待核实事项 |
| local_tax_authority | 主管税务机关及地区 | 列入待核实事项 |
| applicable_vat_rate | 现行适用税率及依据 | 不直接测算 |
| software_sales_amount_excl_vat | 软件产品不含税销售额 | 可做样例假设，必须标注 |
| output_vat | 当期软件产品销项税额 | 缺失则不能得出准确退税额 |
| input_vat_creditable | 可抵扣进项税额 | 缺失则不能得出准确退税额 |
| vat_payable | 当期软件产品应纳税额 | 缺失则只能给测算公式 |
| income_split | 软件、服务、硬件、第三方软件收入拆分 | 缺失则提示拆分风险 |
| input_vat_allocation_method | 进项税额分摊方式 | 缺失则提示核算风险 |
| software_certificate_status | 软件著作权证书或登记材料状态 | 缺失则提示条件风险 |
| embedded_software_flag | 是否嵌入式软件 | 缺失则提示适用差异 |
| commissioned_development_flag | 是否受托开发或转让著作权 | 缺失则提示定性风险 |
| local_filing_requirement | 当地备案/申报材料要求 | 缺失则提示咨询主管机关 |

---

## 三、输出规则

字段不足时，系统只能输出：

1. 政策适用可能性分析。
2. 测算公式或测算思路。
3. 待补字段清单。
4. 风险提示。

不得输出：

- 未经复核的具体退税金额。
- 最终税务处理意见。
- 申报建议。
- 替代当地主管税务机关口径的判断。

---

## 四、影子样例当前缺口

当前 `软件产品即征即退_影子样例_v1.0.md` 已包含：

- 公司身份。
- 软件销售收入。
- 软件著作权证书。
- 候选政策依据。

仍缺：

- 纳税所属期/申报期。
- 主管税务机关及地区。
- 现行适用税率及依据。
- 销项税额、可抵扣进项税额、应纳税额。
- 软件、服务、硬件、第三方软件收入拆分。
- 进项税额分摊方式。
- 软件产品登记或现行替代材料状态。
- 是否嵌入式软件、是否受托开发或转让著作权。
- 当地备案/申报材料要求。

---

## 五、验收口径

如果影子样例写“模板通过”，只代表：

> R0静态结构通过。

不代表：

- 政策有效性已完全复核。
- 材料完整。
- 测算金额准确。
- 可以申报。
- 可以作为最终税务处理结论。
