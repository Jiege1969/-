# 涉税业务分析契约草案

> 版本：v1.0  
> 日期：2026-05-07  
> 资产身份：涉税业务分析专家助手影子契约草案  
> 风险等级：W1  
> 边界：不是正式税务结论规则，不写正式库，不接电子税务局、财税软件、n8n、企业微信或外发通道。  

## 一、定位

本契约用于约束涉税业务分析助手的输出结构。它借鉴股票分析系统“契约先行、证据结构化、缺口显式、置信度分层、人工复核沉淀”的方法，但不迁移股票 L3 权重、行情指标、交易术语或股票研究口径。

税务业务系统的目标不是办税执行，而是依据国家政策和可信证据，对具体涉税业务形成政策顾问式待复核分析。

## 二、输入字段

| 字段 | 说明 | 必填 |
|:---|:---|:---|
| business_question | 用户提出的涉税业务问题 | 是 |
| tax_type | 税种，如增值税、企业所得税等；未知则待补 | 否 |
| business_scenario | 具体业务场景，如软件产品收入、研发费用、资产处置等 | 是 |
| entity_profile | 主体信息，如企业类型、纳税人身份、地区；可脱敏 | 否 |
| period | 所属期或政策适用期间 | 否 |
| region | 地区口径，如国家层、某省市；未知则待补 | 否 |
| provided_materials | 用户已提供资料清单 | 否 |
| requested_output | 用户希望得到的输出，如政策分析、资料清单、测算字段、待复核报告 | 是 |

## 三、证据字段

| 字段 | 说明 |
|:---|:---|
| policy_evidence | 法律、行政法规、部门规章、规范性文件、财税文件等政策依据 |
| evidence_level | 依据层级：法律、行政法规、部门规章/规范性文件、地方口径、企业资料、人工经验 |
| validity_status | 全文有效、已修改、废止、失效、尚未生效、待核验 |
| official_source | 官方来源链接或登记来源 |
| effective_period | 生效期间、适用期间或待核验 |
| extracted_conditions | 适用主体、适用事项、关键条件、排除条件、所需资料 |
| local_practice | 地方口径或执行差异，必须标注地区和待核验状态 |
| evidence_gap | 缺失证据、时效不明、附件未解析、资料不足等 |

## 四、分析输出字段

| 字段 | 说明 |
|:---|:---|
| analysis_object | 本次分析对象：税种、政策、业务事项、地区、期间 |
| policy_match | 匹配到的政策依据和依据层级 |
| business_fact_breakdown | 主体、事项、期间、地区、材料、金额/数量口径等事实拆解 |
| applicability_analysis | 已满足条件、待证明条件、不适用风险 |
| material_checklist | 后续需要补充或核验的资料 |
| calculation_prerequisites | 若涉及测算，只列字段、公式口径、缺口，不给未经复核确定金额 |
| risk_points | 依据冲突、口径差异、时效不明、资料缺口、不可外发等风险 |
| missing | 当前不能下判断的缺口 |
| confidence | draft / evidence_ready / pending_review / human_reviewed |
| review_questions | 需要人工复核的问题 |
| next_action | 建议补资料、补证据、人工复核或沉淀样例 |

## 五、状态分层

| 状态 | 含义 | 可输出内容 |
|:---|:---|:---|
| draft | 初步草案，证据或业务事实不完整 | 只能输出方向、依据候选、待补项 |
| evidence_ready | 证据链较完整，但未人工复核 | 可输出待复核分析结论 |
| pending_review | 已形成分析报告，等待人工确认 | 可输出复核问题和风险点 |
| human_reviewed | 人工已复核并留下回执 | 可作为样例沉淀，不自动升级为正式规则 |

税务场景不使用 `confirmed_conclusion` 作为默认状态，避免误解为正式税务结论。

## 六、硬规则

| 规则 | 要求 |
|:---|:---|
| 依据先于判断 | 没有政策依据或证据层级时，不输出强结论 |
| 缺口必须显式 | missing 不得为空壳；未知项必须写待补或待核验 |
| 地方口径不越级 | 地方口径、窗口经验、历史做法不得覆盖国家政策 |
| 金额不强算 | 字段不足或未经复核时，不给确定金额 |
| 人工复核不过界 | 人工修正进入样例或候选，不自动改正式规则 |
| 非目标硬隔离 | 不申报、不退税执行、不开票、不外发正式意见 |

## 七、可迁移方法与不可迁移内容

| 类别 | 内容 |
|:---|:---|
| 可迁移 | 契约先行、结构化证据、evidence/missing/confidence、状态分层、前后台分层、人工复核沉淀 |
| 不可迁移 | 股票 L3 权重、K线、均线、MACD、RSI、承接区、转强线、风险线、股票代码、行情源、交易语义 |

## 八、验收标准

| 验收项 | 标准 |
|:---|:---|
| 分析对象明确 | 能看出分析的是哪类涉税业务、哪项政策或哪组事实 |
| 证据链可追溯 | 每个主要判断能回到政策证据或缺口 |
| 缺口不掩盖 | 资料、地区、期间、政策有效性缺失时明确列出 |
| 状态不误导 | 不把 draft 或 pending_review 写成正式结论 |
| 输出服务人工 | 结果能交给用户或专业人员复核，而不是替代复核 |
