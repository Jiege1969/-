# 税收政策顾问影子版试用验收清单

> 版本：v1.0  
> 日期：2026-05-07  
> 资产身份：税收政策顾问影子版试用验收清单  
> 风险等级：W1  
> 边界：只验收影子试用输出质量，不批准正式上线，不输出正式税务意见，不接 n8n，不外发。  

## 一、用途

本清单用于判断税收政策顾问影子版是否可以进入“日常影子试用”。它验收的是草案质量、证据完整度、边界和复核可用性，不是正式税务系统上线许可。

## 二、单次试用验收项

| 验收项 | 通过标准 | 结果 |
|:---|:---|:---|
| 输入完整 | 至少包含 business_question、business_scenario、requested_output | 待验 |
| 对象明确 | 输出写明税种、政策、业务事项、地区、期间；未知写待补 | 待验 |
| 依据可追溯 | 有政策标题、文号、层级、有效状态和来源 | 待验 |
| 条件拆解 | 已知、待证明、不适用风险分开 | 待验 |
| 缺口显式 | 资料、地区、期间、金额字段、地方口径缺口清楚 | 待验 |
| 测算克制 | 只列字段和口径，不给未经复核确定金额 | 待验 |
| 风险提示 | 有政策时效、地方口径、资料不足、不可外发提示 | 待验 |
| 复核问题 | 至少3条，能指导用户补资料或人工复核 | 待验 |
| 结尾声明 | 明确“影子版待复核草案，不是正式税务意见” | 待验 |
| 红线无触发 | 不申报、不退税、不开发票、不外发、不接 n8n | 待验 |

## 三、连续试用验收门槛

| 阶段 | 标准 | 可进入状态 |
|:---|:---|:---|
| 1个样例通过 | 可读、可复核、不越界 | 单题影子试用 |
| 3个不同主题通过 | 结构稳定、缺口处理一致 | 小范围日常影子试用 |
| 5个以上样例通过 | 错误可复盘、人工修正可沉淀 | 可转正式资产候选 |
| 3轮人工复核通过 | 回执完整、修正进入样本 | 讨论正式配置或只读查询入口 |

## 四、失败处理

| 失败类型 | 处理 |
|:---|:---|
| 缺依据 | 补政策元数据卡或标证据待补 |
| 缺条件 | 补条件字段化样例 |
| 缺资料 | 输出资料缺口，不做结论 |
| 误写结论 | 降级为 draft 并修正模板 |
| 误触正式动作 | 暂停，标 W2/W3，人工确认 |
| 无法复核 | 补复核问题或回执映射 |
