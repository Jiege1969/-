## 五、筛选结果能说明什么

| 能说明 | 解释 |
|:---|:---|
| 来源可信度较高 | 来源为国家税务总局政策法规库 |
| 有效状态较清楚 | 已按“全文有效”筛选 |
| 可作为候选清单 | 可进入政策元数据卡候选、待复核依据线索 |
| 可减少废止误用 | 初步排除全文失效、全文废止、尚未生效等状态 |

## 六、筛选结果不能说明什么

| 不能说明 | 原因 |
|:---|:---|
| 不能说明某企业一定适用 | 还缺主体、业务事实、地区、期间、资料 |
| 不能说明某政策就是核心依据 | 候选政策可能是程序、管理、衔接或解释材料 |
| 不能说明可以申报或退税 | 仍需正文条文、材料要求、地方口径和人工复核 |
| 不能说明金额 | 没有测算字段和业务数据 |

## 七、下一步复核路径

```text
全文有效候选列表
-> 人工打开官方页面
-> 复核标题、文号、发文机关、正文、时效、关联政策
-> 判断政策类型：实体条件 / 办理程序 / 衔接公告 / 解释材料
-> 登记独立政策元数据卡
-> 进入具体业务分析契约
```

## 八、风险提示

- “全文有效”是证据状态，不是业务适用结论。
- 候选政策需要逐条打开正文复核，不能只看标题。
- 即征即退相关政策可能覆盖不同行业、不同优惠、不同办理程序。
- 地方材料和办理口径仍需后续补充。

## 九、人工复核问题

1. 当前具体业务是哪一种即征即退事项？
2. 候选政策是实体适用条件、办理程序，还是衔接公告？
3. 候选政策正文是否仍显示全文有效？
4. 是否存在上位法、后续公告或配套政策需要同时引用？
5. 是否需要为某个候选政策登记独立元数据卡？
