## 一、用户问题

```text
我公司是增值税一般纳税人，自行开发并销售一款企业管理软件，已取得软件著作权证书。本月实现软件销售收入100万元（不含税），开具了增值税专用发票。请问：这笔收入能否享受增值税即征即退优惠？如果可以，能退多少？
```

## 六、待复核分析结论

状态：`draft`

在当前已知事实下，该业务与软件产品增值税即征即退政策存在匹配可能：用户描述包含“增值税一般纳税人”“自行开发并销售软件产品”“软件著作权证书”“软件销售收入”等关键要素。

但现有资料不足以形成确定适用结论，也不足以计算具体金额。当前只能输出待复核分析：该业务应继续核验产品范围、收入拆分、所属期、地区口径、销项税额、进项税额、实际应纳税额和当地材料要求。

## 八、missing

- 纳税所属期/申报期。
- 主管税务机关及地区。
- 现行适用税率及依据。
- 销项税额、可抵扣进项税额、实际应纳税额。
- 软件、服务、硬件、第三方软件收入拆分。
- 软件检测证明、登记材料或当地现行替代材料。
- 地方办理材料和流程口径。
- 政策原文条款逐项适用复核。

## 九、risk_points

- 材料不完整导致适用条件无法确认。
- 收入混合导致软件产品收入口径不清。
- 地方材料和流程差异导致办理口径不同。
- 政策有效状态和条款适用仍需以官方来源及人工复核为准。
- 仅凭100万元销售收入无法计算具体可退金额。

## 十、review_questions

1. 该企业主管税务机关和地区是什么？
2. 该收入所属期是什么？
3. 软件著作权证书、检测证明、产品登记或当地要求材料是否齐全？
4. 100万元收入是否全部为自行开发软件产品收入？
5. 是否包含安装、维护、培训、硬件、第三方软件或受托开发收入？
6. 当期销项税额、可抵扣进项税额、实际应纳税额分别是多少？
7. 当地税务机关对该事项是否有补充材料或备案要求？
