## 一、为什么补这条机制

本次偏差在于：已经确认国家税务总局政策法规库具备有效性筛选能力，但施工时仍把“政策资料库建立”放进以后处理，导致边搭建边固化的理念没有贯彻。

纠正后口径：

```text
官方公开政策库的只读检索、有效状态筛选、元数据登记、影子知识库建设 = 绿灯动作。
它不是税收业务系统正式上线，不需要等待完整扩展系统方案。
```

## 五、固化后的建库流程

```text
官方政策库
-> 输入关键词/文号
-> 文件时效选择“全文有效”
-> R0返回候选政策
-> 人工打开官方页面复核标题、文号、时效、正文、关联文件
-> 写入影子底座元数据卡
-> 若页面提供下载入口，再登记download_status
-> 进入待复核草案候选依据
```

## 六、边界

- 本演练证明：国家级公开政策资料库建设可以立即推进。
- 本演练不证明：税收业务系统已经正式上线。
- 本演练不输出：可直接采用的税务处理意见。
- 地方口径、基层流程、申报资料细节后续补充，不作为国家级资料库开工障碍。
