# 税收政策顾问日常影子试用接入台账

> 版本：v1.2  
> 更新时间：2026-05-07 23:49:35 +08:00  
> 资产身份：税收政策顾问日常影子试用接入台账  
> 风险等级：W1  
> 边界：只登记脱敏问题、影子草案状态、证据缺口和复核承接；不申报、不退税、不开发票、不外发、不接 n8n，不形成正式税务意见。  

## 一、用途

本台账用于承接首批5题试运行之后的真实问题影子试用。

它不替代 `税收政策顾问影子版提问输入卡_v1.0.md`，而是在每次真实问题进入后记录：

1. 问题是否已脱敏。
2. 输入字段是否满足最小要求。
3. 输出属于政策摘要、资料清单、适用条件、测算前置还是待复核报告。
4. 草案状态和证据缺口。
5. 是否需要人工复核回执或进入进化候选。
6. 是否触发申报、退税、开票、外发、n8n 等红线。

## 二、接入前检查

| 检查项 | 通过标准 | 未通过处理 |
|:---|:---|:---|
| 问题脱敏 | 不含客户姓名、身份证号、完整账号、密码、登录信息、税控信息 | 要求用户重新脱敏 |
| 输出目标 | 属于政策分析、资料清单、适用条件、测算前置字段、待复核报告 | 若要求正式意见或真实办理，暂停 |
| 最小字段 | 至少有 business_question、business_scenario、requested_output | 先让用户补字段 |
| 证据来源 | 优先用已登记政策卡、指引卡、官方来源或待补标记 | 不得编造政策 |
| 金额边界 | 只列字段、公式口径和缺口 | 不输出未经复核金额 |
| 外发边界 | 不生成可直接外发文本 | 外发请求标 W3 暂停 |

## 四、状态口径

| 状态 | 含义 |
|:---|:---|
| 待接入 | 还没有真实问题或问题未脱敏 |
| 输入待补 | 缺业务场景、输出目标、地区、期间或资料 |
| 草案已出 | 已生成待复核草案，但未人工复核 |
| 待人工复核 | 需要用户、专业人员或主管口径确认 |
| 已复核可沉淀 | 有人工回执，可进入复盘或进化候选 |
| 已阻断 | 命中正式意见、申报、退税、开票、外发、接系统等红线 |

## 五、复核承接

每条日常试用结束后，按以下顺序处理：

```text
真实问题
-> 脱敏输入卡
-> 运行检查清单
-> 待复核草案
-> 日常试用台账
-> 人工复核回执
-> 复盘字段清单
-> 进化候选
```

如果没有人工复核回执，只能保留为 `草案已出` 或 `待人工复核`，不得自动进入正式规则或正式税务意见。

## 六、红线动作

以下请求必须暂停并标注 W3：

- 要求系统直接申报。
- 要求系统直接办理退税。
- 要求系统开具发票。
- 要求登录电子税务局、财税软件或第三方系统。
- 要求接 n8n、企业微信或其他外发通道。
- 要求输出正式税务意见或可直接发客户/税局的文本。
