# 税收事项对照表：软件产品即征即退 vs 研发费用加计扣除

- 生成时间：2026-05-08
- 资产身份：税收业务影子底座 W1/R0 事项区分表
- 来源：受控试用阻断修复清单、软件产品即征即退事项匹配纠偏卡
- 定位：用于工作秘书税收入口的影子匹配口径；不是正式税务规则，不输出正式税务意见

## 一、核心结论

“软件产品即征即退”和“研发费用加计扣除”都可能出现在软件企业语境里，但它们不是同一事项。

入口匹配时必须先区分：

- 用户问的是增值税、软件产品销售、税负超过3%、即征即退、退税资料，还是
- 用户问的是企业所得税、研发支出、费用归集、加计扣除、研发项目。

不能因为出现“软件”“研发”“优惠”就自动跳到研发费用加计扣除。

## 二、事项对照

| 维度 | 软件产品即征即退 | 研发费用加计扣除 |
|:---|:---|:---|
| 主要税种 | 增值税 | 企业所得税 |
| 关注对象 | 软件产品销售收入、增值税实际税负 | 研发活动支出、研发费用归集 |
| 常见关键词 | 软件产品、即征即退、增值税、税负超过3%、退税、软件产品证书、嵌入式软件 | 研发费用、加计扣除、研发项目、人员人工、直接投入、费用归集、辅助账 |
| 用户常问 | 能否享受即征即退、需要什么资料、如何测算超3%部分 | 哪些费用能加计扣除、研发费用怎么归集、辅助账怎么做 |
| 输出重点 | 政策依据、适用条件、资料清单、测算前置字段、missing、人工复核问题 | 政策依据、研发活动判断、费用范围、归集资料、missing、人工复核问题 |
| 不能输出 | 确定退税金额、申报结论、正式办理建议 | 确定扣除金额、企业所得税申报结论、正式办理建议 |
| 匹配状态 | 用户明确提到即征即退/软件产品增值税时优先匹配 | 用户明确提到研发费用/加计扣除/研发支出时匹配 |

## 三、入口分流规则

| 输入特征 | 分流结果 | 说明 |
|:---|:---|:---|
| “软件产品即征即退” | 软件产品即征即退 | 明确命中，不得转研发费用 |
| “软件产品退税” | 软件产品即征即退 | 先按增值税即征即退处理，并提示需复核具体业务 |
| “软件产品税负超过3%” | 软件产品即征即退测算前置字段 | 只给字段和公式口径，不给确定金额 |
| “即征即退需要什么资料” | 软件产品即征即退资料清单 | 输出资料缺口和人工复核问题 |
| “研发费用加计扣除” | 研发费用加计扣除 | 明确命中研发费用事项 |
| “研发项目费用怎么归集” | 研发费用加计扣除 | 进入研发费用归集口径 |
| “软件企业有什么税收优惠” | 先澄清 | 可能涉及即征即退、研发费用、高新技术企业等多个事项 |
| “软件开发能不能减税” | 先澄清 | 必须问收入还是费用、增值税还是所得税 |

## 四、澄清优先规则

命中以下模糊表达时，必须先问清楚，不得直接给单一事项结论：

- 软件企业税收优惠。
- 软件开发减税。
- 软件公司能退税吗。
- 软件业务有什么政策。
- 研发软件有什么优惠。

推荐澄清：

1. 你问的是软件产品销售相关的增值税即征即退，还是研发支出相关的企业所得税加计扣除？
2. 当前问题关注的是销售收入、增值税税负，还是研发费用支出？
3. 你需要政策依据、资料清单、适用条件，还是测算前置字段？
