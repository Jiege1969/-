# 税收政策顾问影子版试用入口

> 版本：v1.0  
> 日期：2026-05-07  
> 资产身份：税收政策顾问影子版试用入口  
> 风险等级：W1  
> 边界：只用于生成待复核分析草案，不输出正式税务意见，不申报、不退税、不开发票、不外发、不接 n8n。  

## 一、适用问题

可以试用的问题：

| 问题类型 | 示例 | 输出 |
|:---|:---|:---|
| 政策咨询 | 某政策主要讲什么、现在应怎样理解 | 政策依据摘要、状态和待核验项 |
| 涉税业务分析 | 某项业务按哪些政策分析 | 待复核分析草案 |
| 适用条件判断 | 某业务是否可能满足某政策条件 | 条件字段、已知事实、缺口和复核问题 |
| 资料清单 | 需要准备哪些资料 | 待复核资料清单 |
| 测算前置 | 如果要测算，需要哪些字段 | 字段和口径，不给确定金额 |
| 地方口径 | 当地能不能办、流程怎样 | 标注地方口径待补，不给确定执行结论 |

## 二、禁止问题

| 禁止请求 | 处理 |
|:---|:---|
| 直接申报 | 拒绝执行，只能整理依据和资料 |
| 直接退税 | 拒绝执行，只能列条件和测算字段 |
| 直接开票 | 拒绝执行，只能整理政策依据和风险 |
| 出具正式意见 | 改为待复核草案 |
| 外发给客户或税局 | 不外发 |
| 接电子税务局、财税软件、n8n、企业微信 | 暂停，属于 W3 |

## 四、输入最小要求

一次试用至少需要：

| 字段 | 是否必填 | 说明 |
|:---|:---|:---|
| business_question | 是 | 用户真实问题 |
| business_scenario | 是 | 具体业务事项 |
| requested_output | 是 | 想要政策分析、资料清单、测算字段还是待复核报告 |
| tax_type | 否 | 不知道可写待补 |
| region | 否 | 不知道可写待补 |
| period | 否 | 不知道可写待补 |
| provided_materials | 否 | 已有资料清单 |

## 五、输出标准

每次试用输出必须包含：

1. 分析对象。
2. 草案状态：draft / evidence_ready / pending_review。
3. 政策依据：标题、文号、层级、有效状态。
4. 业务事实拆解。
5. 适用条件：已知、待证明、不适用风险。
6. 资料缺口。
7. 测算前置字段，如涉及金额。
8. 风险提示。
9. 人工复核问题。
10. 下一步。

## 六、当前可直接试用的主题

| 主题 | 可用证据 | 当前能力 |
|:---|:---|:---|
| 软件产品增值税即征即退 | 财税〔2011〕100号、总局指引、条件字段化样例、测算前置字段 | 可做待复核条件分析、资料缺口和测算字段 |
| 增值税基础依据 | 增值税法元数据卡 | 可做依据层级摘要 |
| 全文有效政策候选筛选 | 总局政策库R0检索演练 | 可做候选证据筛选说明 |

## 七、试用结论口径

标准结尾必须写：

```text
本输出为影子版待复核分析草案，不是正式税务意见。涉及申报、退税、开票、外发或正式采用前，必须由人工和专业人员复核。
```
