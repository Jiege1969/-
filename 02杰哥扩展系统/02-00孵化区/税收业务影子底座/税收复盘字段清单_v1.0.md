# 税收复盘字段清单

> 版本：v1.0  
> 日期：2026-05-07  
> 资产身份：涉税业务分析复盘字段影子草案  
> 风险等级：W1  
> 边界：复盘只沉淀样例和经验候选，不自动修改正式规则。  

## 一、定位

本清单用于记录涉税业务分析助手每次输出后的复盘信息。它服务人工复核、错误纠偏和经验沉淀，不直接升级为正式税务规则。

## 二、复盘字段

| 字段 | 说明 |
|:---|:---|
| review_id | 复盘编号 |
| source_question | 原始用户问题 |
| analysis_object | 税种、政策、业务事项、地区、期间 |
| evidence_used | 使用的政策依据和资料 |
| evidence_missing | 当时缺失的证据 |
| system_analysis | 系统生成的待复核分析结论 |
| confidence_state | draft / evidence_ready / pending_review / human_reviewed |
| human_feedback | 人工复核意见 |
| correction_type | 依据错误、适用条件错误、资料缺口遗漏、地方口径遗漏、表达风险等 |
| corrected_analysis | 修正后的分析要点 |
| reusable_lesson | 可复用经验 |
| evolution_candidate | 是否进入进化候选 |
| formal_rule_change | 是否涉及正式规则修改；默认否 |

## 三、复盘处理规则

| 场景 | 处理 |
|:---|:---|
| 单次人工修正 | 进入复盘记录，不自动改规则 |
| 多次同类修正 | 汇总为进化候选，等待人工判断 |
| 依据层级错误 | 优先修正证据分层或政策库字段 |
| 适用条件遗漏 | 补充适用条件字段，不直接生成正式结论 |
| 地方口径差异 | 标注地区和待核验状态，不覆盖国家政策 |

## 四、验收标准

| 验收项 | 标准 |
|:---|:---|
| 可追溯 | 能回到原问题、证据、系统分析和人工反馈 |
| 可纠偏 | 能识别错误类型和修正方向 |
| 不越权 | 不因复盘自动修改正式规则 |
| 可进化 | 同类问题可沉淀为进化候选 |
