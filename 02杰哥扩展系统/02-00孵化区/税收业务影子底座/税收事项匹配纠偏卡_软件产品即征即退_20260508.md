# 税收事项匹配纠偏卡：软件产品即征即退

- 生成时间：2026-05-08
- 资产身份：税收业务影子底座 W1/R0 事项匹配纠偏卡
- 来源：企业微信受控试用验证回传
- 定位：修复税收入口的事项识别口径；不是正式税务规则，不输出正式税务意见

## 一、问题

验证发现：工作秘书税收入口可进入，但内容匹配不通过。用户意图为“软件产品即征即退”，系统返回方向落到了“研发费用加计扣除”。

这是 P0 交付阻断点。修复前，税收业务不能声明为可交付，只能保持“入口安全、业务映射待修复”。

## 二、正确匹配口径

| 用户关键词或意图 | 应匹配事项 | 不得匹配为 |
|:---|:---|:---|
| 软件产品即征即退 | 软件产品增值税即征即退 | 研发费用加计扣除 |
| 软件产品退税 | 软件产品增值税即征即退 | 企业所得税优惠 |
| 即征即退资料 | 软件产品即征即退资料清单 | 研发费用归集 |
| 软件产品税负超过3% | 软件产品即征即退测算前置字段 | 高新技术企业优惠 |
| 软件产品增值税 | 软件产品即征即退或增值税政策链路 | 研发费用加计扣除 |

## 三、无法确定时的澄清口径

如果用户只说“软件税收优惠”“软件企业优惠”“研发软件怎么减税”，不得直接套到某一事项，应先澄清：

1. 你问的是增值税即征即退，还是企业所得税研发费用加计扣除？
2. 涉及的是软件产品销售收入，还是研发费用支出？
3. 你需要政策依据、资料清单、适用条件，还是测算前置字段？

## 四、修复验收样例

| 输入 | 期待输出 |
|:---|:---|
| 软件产品即征即退需要什么资料？ | 进入软件产品即征即退资料清单链路，列 evidence、missing、人工复核问题 |
| 软件产品税负超过3%怎么退？ | 进入软件产品即征即退测算前置字段链路，不给确定金额 |
| 软件企业研发费用怎么扣除？ | 可进入研发费用加计扣除，但必须与即征即退区分 |
| 软件税收优惠有哪些？ | 先澄清，不直接错配 |

## 五、边界

- 不登录电子税务局。
- 不读取真实财税软件。
- 不输出正式税务意见。
- 不给确定退税金额。
- 不生成申报建议。
- 不写正式税收库。

## 六、业务线接续

下一步可以在 W1/R0 范围内继续做：

1. 建立税收事项关键词区分表。
2. 建立软件产品即征即退与研发费用加计扣除对照表。
3. 建立工作秘书税收入口映射验收样例。

以上均只做影子纠偏和验收样例，不改真实企业微信服务。
