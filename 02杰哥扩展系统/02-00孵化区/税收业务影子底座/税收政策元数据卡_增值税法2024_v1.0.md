## 二、对软件产品影子样例的意义

财税〔2011〕100号是软件产品增值税即征即退的专门政策依据；《中华人民共和国增值税法》是增值税基础法律依据。

二者关系：

```text
增值税法
-> 增值税基础纳税义务、税率、征收管理框架
-> 财税〔2011〕100号等具体优惠政策
-> 软件产品即征即退影子样例
```

## 三、使用限制

- 本卡不替代具体优惠政策。
- 本卡不替代地方主管税务机关执行口径。
- 涉及政策衔接、优惠延续、材料要求时，必须同时核验财政部、税务总局后续公告和地方口径。
- 若旧资料引用《增值税暂行条例》，必须提示其已被增值税法替代或需复核当前适用状态。
