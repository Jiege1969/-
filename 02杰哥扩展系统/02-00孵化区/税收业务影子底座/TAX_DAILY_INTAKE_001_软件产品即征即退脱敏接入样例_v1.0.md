# TAX_DAILY_INTAKE_001：软件产品即征即退脱敏接入样例

> 版本：v1.0  
> 更新时间：2026-05-07 23:10:53 +08:00  
> 资产身份：税收政策顾问日常影子试用脱敏接入样例  
> 风险等级：W1  
> 边界：本样例只演示真实问题进入影子试用前如何脱敏和判定可接入；不读取真实财税资料，不申报、不退税、不开发票、不外发、不接 n8n，不输出正式税务意见。  

## 一、用途

本样例用于演示一条真实涉税咨询在进入日常影子试用台账前，应如何完成脱敏、字段补齐、输出目标确认和红线检查。

它不是税务分析结论，也不是软件产品即征即退的适用判断。它只回答：这个问题能不能安全进入影子试用。

## 二、原始问题类型

| 字段 | 内容 |
|:---|:---|
| 原始问题类型 | 用户想判断某软件产品销售业务是否可能享受增值税即征即退，并想知道下一步要补哪些资料 |
| 是否包含真实敏感信息 | 原始问题可能包含企业名称、税号、合同、发票、收入金额、申报期等敏感信息 |
| 处理方式 | 进入影子试用前必须脱敏，只保留判断所需字段类别和非敏感摘要 |

## 三、脱敏后输入卡

| 字段 | 脱敏后内容 |
|:---|:---|
| business_question | 某软件企业销售自行开发的软件产品，想先判断是否可能适用软件产品增值税即征即退，并了解需要准备哪些资料 |
| requested_output | 适用条件初筛 + 资料清单 + 测算前置字段 |
| tax_type | 增值税 |
| business_scenario | 软件产品销售及即征即退政策咨询 |
| entity_profile | 某软件企业；是否一般纳税人待补 |
| region | 省市待补 |
| period | 所属期/申报期待补 |
| amount_or_scale | 具体金额不进入样例；只标注“涉及软件产品收入，金额待用户脱敏后确认范围” |
| provided_materials | 软件著作权或登记材料待补；合同、发票、收入明细、销项税额、进项税额待补 |
| known_policy | 财税〔2011〕100号；国家税务总局软件产品增值税即征即退公开指引 |
| special_risk | 收入拆分、嵌入式软件、外购转售、地方口径均待核实 |

## 四、接入前检查结果

| 检查项 | 结果 | 说明 |
|:---|:---|:---|
| 问题脱敏 | 通过 | 不保留企业名称、税号、账号、合同编号、发票号码、登录信息 |
| 输出目标 | 通过 | 目标为条件初筛、资料清单和测算前置字段，不是正式意见 |
| 最小字段 | 通过 | 已有 business_question、business_scenario、requested_output |
| 证据来源 | 通过 | 可先调用已登记政策卡、指引卡和字段化样例 |
| 金额边界 | 通过 | 不输出金额，只列测算字段和口径 |
| 外发边界 | 通过 | 不生成可直接外发文本 |
| 真实系统接入 | 通过 | 不登录电子税务局、财税软件或第三方系统 |

## 五、可进入的影子试用输出

| 输出类型 | 是否可做 | 边界 |
|:---|:---|:---|
| 政策依据摘要 | 可做 | 必须列依据层级、有效状态和待核验项 |
| 适用条件初筛 | 可做 | 只能写候选匹配、待证明、风险项 |
| 资料清单 | 可做 | 只列待收集资料，不代表主管税务机关最终办理清单 |
| 测算前置字段 | 可做 | 只列字段和公式口径，不输出退税金额 |
| 正式税务意见 | 不可做 | 命中红线 |
| 申报、退税、开票 | 不可做 | 命中红线 |
| 外发客户或税局 | 不可做 | 命中红线 |

## 七、不得保留的信息

- 企业真实名称、统一社会信用代码、纳税人识别号。
- 法人、财务人员、办税人员姓名和证件号码。
- 电子税务局账号、密码、短信验证码、税控盘信息。
- 完整合同编号、发票号码、银行账号。
- 未经授权的客户资料、供应商资料、交易明细。
