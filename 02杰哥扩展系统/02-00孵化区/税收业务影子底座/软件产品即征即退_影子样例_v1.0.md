# 软件产品即征即退影子样例

> 版本：v1.0  
> 状态：影子样例，不是正式税收系统输出  
> 用途：验证税收业务“可信输入 -> 依据匹配 -> 待复核草案 -> 人工修正”的工作链

---

## 用户输入样例

```text
我公司是增值税一般纳税人，自行开发并销售一款企业管理软件，已取得软件著作权证书。本月实现软件销售收入100万元（不含税），开具了增值税专用发票。请问：这笔收入能否享受增值税即征即退优惠？如果可以，能退多少？
```

## 待复核草案样例

《待复核草案》

### 一、事实摘要

- 公司身份：增值税一般纳税人。
- 业务：自行开发并销售企业管理软件。
- 收入：不含税销售收入100万元。
- 已知材料：软件著作权证书。
- 未知材料：检测证明、软件产品登记或当前主管机关要求的其他材料。

### 二、适用领域

- 业务线：税收业务。
- 税种：增值税。
- 场景：软件产品增值税即征即退。

### 三、候选依据

- 候选依据：《财政部 国家税务总局关于软件产品增值税政策的通知》（财税〔2011〕100号）。
- 官方来源：`https://fgk.chinatax.gov.cn/zcfgk/c102416/c5204304/content.html`
- 元数据卡：`税收政策元数据卡_财税2011_100_v1.0.md/json`
- 基础法律背景：《中华人民共和国增值税法》，元数据卡：`税收政策元数据卡_增值税法2024_v1.0.md/json`
- 当前处理：已登记官方来源和元数据卡；条文逐项适用、有效状态、当地材料要求仍需人工复核。

### 四、判断过程

1. 定性：用户描述的业务属于软件产品销售场景。
2. 条件匹配：已提供软件著作权证书，但检测证明、产品登记或当地申报材料要求尚未确认。
3. 测算思路：若符合即征即退条件，通常围绕实际税负超过规定比例的部分测算退税额。
4. 地方口径：具体材料、流程和申报要求需结合当地主管税务机关口径核实。

### 五、初步草案结论

在已知信息下，该业务存在适用软件产品增值税即征即退政策的可能，但当前材料不完整，不能给出最终税务处理结论。

若条件满足，100万元不含税软件销售收入可按相关政策口径进行测算预演；具体金额需结合纳税所属期、主管税务机关地区、现行适用税率、销项税额、可抵扣进项税额、实际应纳税额、收入拆分和当地申报要求复核。

### 六、风险点

1. 材料不完整风险：检测证明、产品登记或当地要求材料未确认。
2. 地方执行差异：不同地区可能有不同申报资料和流程要求。
3. 产品范围风险：若包含第三方软件、服务、维护、培训等收入，需要确认是否可合并适用或需分别核算。

### 七、待核实事项

1. 官方政策文件有效状态和条文逐项适用性。
2. 当地主管税务机关关于软件产品即征即退的申报材料要求。
3. 软件检测证明、产品登记或现行替代材料是否齐全。
4. 收入构成是否包含安装、维护、培训或第三方软件部分。
5. 若需要回答“能退多少”，是否已补齐测算前置字段清单中的关键字段。
