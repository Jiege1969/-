- 非适用场景：正式税务意见、确定退税金额、申报建议、电子税务局办理、读取真实账套或财税系统。

## 一、输入条件清单

### 1. 必填输入

| 序号 | 字段 | 填写要求 | 不足时处理 |
|:---|:---|:---|:---|
| 1 | 问题原意 | 使用脱敏后的自然语言描述真实问题，不粘贴原始企业资料全文。 | 缺失则不进入试用。 |
| 2 | 税收事项 | 明确为“软件产品增值税即征即退”或“软件产品退税/税负超过3%”。 | 若只说“软件企业优惠”，先澄清。 |
| 3 | 税种 | 应为增值税；不得误分流到企业所得税研发费用加计扣除。 | 税种不清则先澄清。 |
| 4 | 所属期间 | 填写年月、季度或年度的脱敏期间范围。 | 缺失则只可列待补字段。 |
| 5 | 地区 | 填写省/市级地区，不填写具体注册地址。 | 缺失则标为地方口径待补。 |
| 6 | 主体类型 | 填写一般纳税人、小规模纳税人、软件企业等脱敏类别。 | 缺失则不作适用判断。 |
| 7 | 产品信息 | 填写软件产品类别、销售方式、是否自研/嵌入式等非敏感概述。 | 缺失则不作事项适用判断。 |
| 8 | 业务背景 | 描述为何提问，例如资料准备、条件自查、测算字段梳理。 | 缺失则只做入口澄清。 |

### 2. 可选但建议补充

| 字段 | 用途 | 安全要求 |
|:---|:---|:---|
| 销售收入区间 | 仅用于判断是否需要列测算前置字段。 | 使用区间或占位，不写精确真实金额。 |
| 销项税额区间 | 仅用于提示测算字段是否齐备。 | 使用区间或占位，不写票据明细。 |
| 进项税额区间 | 仅用于提示测算字段是否齐备。 | 使用区间或占位，不写发票号码或供应商。 |
| 已缴增值税区间 | 仅用于识别“税负超过3%”是否需要人工核算。 | 不给确定退税金额。 |
| 已备资料类型 | 用于列资料缺口，如软件著作权、检测报告、合同、发票汇总。 | 只写资料类别，不贴原件。 |
| 地方办理口径来源 | 用于登记待人工核验事项。 | 只写公开链接或人工待补，不登录系统。 |

### 3. 入口分流规则

1. 出现“软件产品即征即退、软件产品退税、软件产品税负超过3%”时，进入软件产品增值税即征即退链路。
2. 出现“研发费用、加计扣除、研发项目费用归集”时，进入研发费用加计扣除链路，不混入本草案。
3. 只说“软件企业税收优惠、软件开发减税、软件公司能不能退税”时，必须先澄清，不得强行匹配。
4. 命中软件产品即征即退后，只能输出政策依据链、适用条件字段、资料缺口、测算前置字段、风险点和人工复核问题。

## 二、脱敏检查清单

### 1. 必须移除或替换

| 类别 | 示例 | 脱敏方式 |
|:---|:---|:---|
| 企业身份 | 企业全称、统一社会信用代码、纳税人识别号 | 替换为“某软件企业A”“主体A”。 |
| 人员身份 | 法人、财务、联系人姓名、手机号、邮箱 | 替换为“联系人A”“财务负责人”。 |
| 地址账户 | 注册地址、开户行、银行账号、电子税务局账号 | 删除或替换为省/市级概述。 |
| 票据合同 | 发票号码、合同编号、客户/供应商名称 | 只保留资料类别或数量概述。 |
| 精确财务数据 | 精确收入、税额、利润、退税测算数 | 改为区间、占位符或“待人工填充”。 |
| 系统截图 | 电子税务局、ERP、财务软件、账套截图 | 不接收、不读取、不引用。 |

### 2. 可保留的低敏信息

| 类别 | 可保留范围 |
|:---|:---|
| 地区 | 省/市级地区，用于提示地方口径待补。 |
| 期间 | 年月、季度、年度，不附原始申报表。 |
| 主体类别 | 一般纳税人、软件企业、高新技术企业等类别描述。 |
| 产品类别 | 软件产品、嵌入式软件、SaaS服务等概述。 |
| 问题目标 | 资料清单、条件自查、测算字段梳理、风险点识别。 |

### 3. 接入状态判定

| 状态 | 判定条件 | 处理 |
|:---|:---|:---|
| 可接入 | 必填输入齐备，已脱敏，无真实资料附件，无办理要求。 | 可生成待复核草案。 |
| 输入待补 | 税种、期间、地区、主体、背景任一缺失。 | 只返回补充问题。 |
| 需重新脱敏 | 存在企业身份、票据、账号、精确金额或截图。 | 退回重新脱敏，不生成草案。 |
| 已阻断 | 要求登录电子税务局、读取账套、给确定金额、申报建议或正式意见。 | 暂停并交总管裁定。 |
