# 股票政策事件与共享证据反向同步规则草案

> 版本：v1.0  
> 日期：2026-05-07  
> 资产身份：股票政策事件与共享政策证据反向同步影子规则草案  
> 风险等级：W1  
> 边界：只做影子草案，不改股票正式配置，不改L3评分契约，不写股票正式数据目录，不写税收政策库，不接 n8n，不外发，不生成交易建议。  

## 一、用途

本草案用于解决股票系统和共享政策证据底座之间“只读调用之后如何回流经验”的问题。

当前股票系统可以只读调用税收政策知识库，把政策作为行业研究背景。但如果股票研究过程中发现新的政策事件、行业标签、证据缺口或复核问题，不能直接写回税收政策库或股票正式评分规则，只能形成反向同步候选。

## 二、同步方向

| 方向 | 当前允许 | 说明 |
|:---|:---|:---|
| 共享政策证据 -> 股票研究 | 允许，W1只读 | 作为行业政策背景、风险提示、研究证据线索 |
| 股票研究 -> 共享政策证据候选 | 允许，W1草案 | 只能生成候选记录，不写正式库 |
| 股票研究 -> 税收政策库正式条目 | 禁止 | 税收政策库必须由税务证据流程复核 |
| 股票研究 -> 股票L3正式配置 | 禁止 | 不自动改变评分契约、权重或前台输出标准 |
| 股票研究 -> n8n/外发/交易 | 禁止 | 仍保持W3暂停边界 |

## 三、反向同步候选字段

| 字段 | 说明 | 必填 |
|:---|:---|:---|
| candidate_id | 反向同步候选编号 | 是 |
| source_system | 来源系统，固定为股票研究系统 | 是 |
| source_sample | 来源样例或报告路径 | 是 |
| policy_evidence_id | 关联政策证据编号 | 是 |
| policy_title | 政策标题 | 是 |
| evidence_type | policy_background / policy_event / industry_risk / evidence_gap | 是 |
| stock_context | 股票研究上下文，如行业、公司、政策影响假设 | 是 |
| allowed_target | 可进入的目标，如共享证据候选池、税务待核验项、股票复盘候选 | 是 |
| forbidden_target | 禁止进入的目标，如正式规则库、L3契约、交易建议 | 是 |
| missing | 缺口字段 | 是 |
| review_questions | 人工复核问题 | 是 |
| status | draft / pending_review / rejected / human_reviewed | 是 |

## 五、处理规则

1. 反向同步候选只能进入影子候选，不得自动写正式库。
2. 股票系统发现的“政策影响”必须降级为研究线索，不能升格为税务适用结论。
3. 税收政策库只接收政策证据候选和待核验问题，不接收股票评分、涨跌判断、交易语义。
4. 股票L3只接收人工复核后的结构化政策事件或行业风险，不接收税务适用结论。
5. 若需要改股票正式配置、正式脚本或正式数据目录，必须暂停并按 W2/W3 规则确认。

## 六、人工复核问题

1. 该政策是否确实与目标行业或公司业务相关？
2. 政策证据的有效状态是否已经官方复核？
3. 股票研究引用的是政策背景、政策事件，还是具体公司受益判断？
4. 是否有财报、公告、互动易、招股书等公司证据支撑？
5. 是否存在把税务适用条件误写为股票评分加分项的风险？
6. 该候选应进入共享证据候选池、税务待核验项，还是股票复盘候选？

## 七、验收标准

| 验收项 | 标准 |
|:---|:---|
| 不写正式库 | 只生成候选，不写股票或税务正式资产 |
| 不改评分 | 不改变L3权重、评分契约或前台标准 |
| 不混业务 | 税务适用条件不直接变成股票结论 |
| 可追溯 | 保留来源样例、政策编号、缺口和复核问题 |
| 可复核 | 候选状态必须是 draft 或 pending_review |
