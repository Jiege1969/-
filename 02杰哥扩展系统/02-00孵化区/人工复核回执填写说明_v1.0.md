# 人工复核回执填写说明

> 版本：v1.0
> 状态：填写说明，不是审批流程
> 边界声明：不接 n8n，不接企业微信，不写正式库，不触发真实业务动作。

## 填写顺序

1. 填关联资产。
2. 填业务线。
3. 判断复核类型：通过、修改后通过、驳回、待补。
4. 写清楚接受部分。
5. 写清楚修正点。
6. 写清楚驳回部分和缺失材料。
7. 判断是否可进入进化候选。
8. 给出下一步动作。

## 关键字段说明

| 字段 | 填写口径 |
|:---|:---|
| review_type | 有修改意见时不要填“通过”，应填“修改后通过” |
| correction_points | 必须具体到字段、段落、依据或风险边界 |
| can_enter_evolution | 不确定就填“待判” |
| next_action | 只能是继续影子、补资料、暂停、进入人工确认之一 |

## 示例占位

```text
review_id: REVIEW_RECEIPT_VIDEO_001
related_asset: VIDEO_SHADOW_001
review_type: 待补
can_enter_evolution: 待判
next_action: 补资料
```

## 禁止

- 不把回执写成正式审批。
- 不因“通过”就自动外发或上线。
- 不自动写入策略锚点库或规则库。
