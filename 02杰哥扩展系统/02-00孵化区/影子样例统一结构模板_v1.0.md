# 影子样例统一结构模板

> 版本：v1.0
> 状态：孵化区通用影子样例模板，不是正式业务样例库
> 边界声明：不接 n8n，不接企业微信，不写正式库，不触发真实业务动作。

## 用途

用于税收、本职工作、视频制作等影子业务线统一记录一个“可复核样例”的最小结构。

影子样例只用于方法验证、字段校准和人工复核，不代表系统已经具备正式业务能力。

## 模板

| 字段 | 内容 |
|:---|:---|
| sample_id | 待生成 |
| business_line | 税收 / 本职工作 / 视频制作 / 其他 |
| scenario | 待补 |
| source_materials | 待补 |
| input_summary | 待补 |
| output_draft | 待复核 |
| basis_or_reference | 待补 |
| risk_flags | 待补 |
| forbidden_actions | 待补 |
| missing_items | 待补 |
| human_review_required | 是 |
| human_review_result | 待填写 |
| evolution_candidate | 是 / 否 / 待判 |

## 最小要求

- 必须标注业务线。
- 必须标注输入来源。
- 必须标注输出为待复核草案。
- 必须列出禁止动作。
- 必须保留人工复核结果字段。

## 禁止项

- 不写真实敏感数据。
- 不把影子样例作为正式业务结论。
- 不自动进入正式库。
- 不外发、不申报、不审批、不渲染、不发布。
