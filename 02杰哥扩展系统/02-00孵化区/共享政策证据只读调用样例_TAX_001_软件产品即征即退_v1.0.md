# 共享政策证据只读调用样例 TAX 001：软件产品即征即退

> 版本：v1.0  
> 日期：2026-05-07  
> 资产身份：税务分析助手只读政策证据调用影子样例  
> 风险等级：W1  
> 边界：只读样例，不改政策库，不输出正式税务意见，不给确定金额，不外发。  

## 一、调用意图

税务业务分析助手需要读取政策证据，分析“软件产品销售收入是否可能适用增值税即征即退”。

本样例只演示如何从政策证据底座读取证据，并传入涉税业务分析契约。

## 二、调用输入

| 字段 | 内容 |
|:---|:---|
| requesting_system | 税务业务分析助手 |
| query_intent | 涉税业务政策依据和适用条件 |
| topic_keywords | 软件产品、增值税、即征即退、财税〔2011〕100号 |
| expected_evidence_level | 国家级主管机关政策/规范性文件 |
| source | `SHARED-POLICY-EVIDENCE-001` 税收政策知识库/政策证据底座 |

## 三、只读证据摘录

| 字段 | 内容 |
|:---|:---|
| document_id | TAX-DOC-2011-100 |
| title | 财政部 国家税务总局关于软件产品增值税政策的通知 |
| document_number | 财税〔2011〕100号 |
| issuing_authority | 财政部、国家税务总局 |
| source_level | 国家级 |
| tax_type | 增值税 |
| business_scenario | 软件产品增值税即征即退 |
| legal_level | 规范性文件 |
| validity_status | 现行有效状态需以官方政策法规库展示为准 |
| source_url | `https://fgk.chinatax.gov.cn/zcfgk/c102416/c5204304/content.html` |
| verification_status | 已登记官方来源，待人工逐条复核条文 |

## 四、传入分析契约

| 契约字段 | 填入 |
|:---|:---|
| policy_evidence | 财税〔2011〕100号 |
| evidence_level | 国家级主管机关政策/规范性文件 |
| validity_status | 以官方政策法规库展示为准，待人工逐条复核 |
| official_source | 官方政策法规库链接 |
| extracted_conditions | 软件产品、一般纳税人、自行开发生产、即征即退等候选条件 |
| evidence_gap | 地方口径、具体材料要求、条文逐项适用、测算字段 |

## 五、输出边界

| 项目 | 要求 |
|:---|:---|
| allowed_use | 待复核分析草案、资料缺口、测算前置字段 |
| forbidden_use | 不输出正式税务意见，不给确定金额，不生成申报建议 |
| output_state | draft 或 pending_review，不使用 confirmed_conclusion |
