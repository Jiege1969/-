# 知识库系统说明

## 定位

知识库系统负责资料入库、索引、检索、证据引用和可追溯问答支撑。它为文稿、税收、工作资料、复盘和总管查询提供证据基础。

## 目录职责

- `01配置`：资料来源、索引规则、切分规则、证据格式和禁区配置。
- `02脚本`：资料整理、索引构建、检索验证、证据输出。
- `03数据`：文档索引、证据片段、问答样例、验收包。
- `04日志`：入库、检索、异常和质量检查记录。
- `07文档`：使用说明、证据口径、维护手册和交付说明。
- `08可追溯问答框`：可追溯问答前台/证据闭环子模块，承接问题样例、证据片段、回答草案、人工复核和验收包；2026-05-11 已从原并列目录 `02杰哥扩展系统\07知识库可追溯问答框` 归集到本系统下统一管理。

## 安全边界

知识库回答必须尽量带来源，不能把无来源推断当成事实。对政策、财务、法律、投资等高风险问题，只能输出辅助分析和证据，不能替代人工判断。

## 公共来源可信度机制

新增资料、证据卡和可追溯问答输出必须接入 `D:/杰哥智能化系统/02杰哥扩展系统/00公共组件/01配置/信息来源可信度分层规则.json` 与 `D:/杰哥智能化系统/02杰哥扩展系统/00公共组件/02脚本/信息来源智能鉴别器.py`。系统先识别来源可信度等级、来源类型、用途边界和是否需要反向追溯，再结合当前业务系统判断能否进入正式证据链。

可信来源不等于最终答案。国家官方、国家级机构、学术权威、主流媒体和高公信力商业门户都可以被系统识别和分层，但是否能作正式依据，要看资料原始性、适用场景、时效、授权和人工复核要求。

## 维护要求

新增资料需记录来源、时间、适用范围和清理规则。新增检索能力需先做影子问答和可追溯验收，再接入正式助手。
