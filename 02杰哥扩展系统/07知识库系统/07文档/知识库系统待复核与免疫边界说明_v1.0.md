# 知识库系统待复核与免疫边界说明

> 版本：v1.0  
> 生效日期：2026-05-09  
> 所属系统：02杰哥扩展系统 / 07知识库系统  
> 定位：明确知识库系统的回答待复核机制和免疫边界。

## 一、待复核机制

知识库系统输出的回答、证据片段、资料摘要和检索建议，默认都是待复核结果。

待复核含义：

- 不能直接作为正式业务结论。
- 不能替代人工确认。
- 不能替代税收、股票、视频、内容等业务系统的最终判断。
- 必须保留来源路径、证据片段和缺口提示。

## 二、免疫边界

知识库系统必须守住以下免疫边界：

- 不自动写正式向量库。
- 不触发 n8n。
- 不外发正式回答。
- 不覆盖原始资料。
- 不把草案当最终依据。
- 不把下位资料反向覆盖上位依据。

## 三、问题进入修复链

如果出现无证据回答、来源不清、答非所问、旧资料混用、证据过期等问题，应进入：

```text
问题记录 -> 来源复查 -> 检索规则修正 -> 待复核输出 -> 只读复验 -> 进化候选
```
