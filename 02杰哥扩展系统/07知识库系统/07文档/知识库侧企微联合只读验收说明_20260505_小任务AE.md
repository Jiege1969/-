## 一、字段契约

知识库侧供企业微信联合验收读取的证据索引必须包含：

| 字段 | 要求 |
|---|---|
| evidence_id | 唯一证据编号 |
| source_path | 本地来源路径或片段锚点 |
| source_status | exists、missing、stale 等来源状态 |
| answerability | 可回答、缺证不可回答、越界阻断或交易意图降级 |
| evidence_snippets | 可人工复核的短证据片段 |
| citation_paths | 确定性回答必须具备的引用路径 |
| freshness | 时效说明，不能把历史证据包装成正式当前口径 |
| downgrade_reply | 缺证、过旧或越界时的降级语 |
| cannot_answer_boundary | 明确不能回答或不能执行的边界 |
| rollback | 只读候选层回滚说明，正式库无回滚需求 |

## 二、不可回答边界

| 场景 | 处理 |
|---|---|
| 无证据或缺 citation_paths | 不输出确定结论，转降级语或人工复核 |
| 证据过旧 | 只能说明历史证据存在，不能裁定当前正式口径 |
| 要求外发企业微信、触发 response_url/Webhook/n8n | 拒绝执行，仅保留本地只读说明 |
| 要求写正式知识库、向量库、数据库 | 阻断，保留为只读候选或标记驳回 |
| 股票交易意图 | 只做研究分析与风险提示，不给买卖、仓位、目标价、下单建议 |

## 三、回滚口径

- 默认回滚模式：block_all。
- 触发字段：citation_paths_missing、source_status_missing_or_stale_for_formal_claim、formal_store_write_requested、real_send_requested、response_url_present、webhook_requested、n8n_requested、broker_api_requested、auto_trade_requested。
- 回滚动作：阻断影子路由、冻结灰度样本、标记本地候选为 pending_review/rejected、写离线验收记录。
- 正式库回滚：不需要。本轮未写正式知识库、向量库或数据库。

## 四、验收结论

知识库侧已形成企业微信联合只读证据索引，能够支撑路由、证据索引、灰度确认包、不可回答边界和回滚字段的联合验收。该索引仅用于本地可交付前复核，不具备正式写入、外发、自动化触发或交易权限。
