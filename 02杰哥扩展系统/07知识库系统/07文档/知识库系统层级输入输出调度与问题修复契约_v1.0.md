# 知识库系统层级输入输出调度与问题修复契约

> 版本：v1.0  
> 生效日期：2026-05-09  
> 所属系统：02杰哥扩展系统 / 07知识库系统  
> 上级系统：02杰哥扩展系统  
> 边界：知识库系统提供资料检索、证据片段和待复核回答，不自动写正式库、不触发 n8n、不外发正式结论。

## 一、层级服从

知识库系统服从：

```text
杰哥智能系统总目标
> 总管系统边界
> 扩展系统业务边界
> 知识库系统资料与证据规则
> 单次问答和检索结果
```

知识库单次回答不得反向覆盖上位规则、业务边界或正式依据层级。

## 二、输入输出契约

输入：

- 用户问题。
- 文件、政策、资料、记录。
- 上级系统转来的检索请求。

输出：

- 证据片段。
- 来源路径。
- 待复核回答草案。
- 缺口提示。

## 三、调度协同

知识库系统不单独决定业务动作。它向总管、智能系统、税收、股票、视频、内容等系统提供证据支持。业务判断必须回到对应系统。

## 四、问题修复

若出现无证据回答、来源不清、答非所问、旧资料混用等问题，应进入问题修复链：

```text
记录问题 -> 找到来源缺口 -> 修正检索/资料/提示词 -> 只读复验 -> 形成回执 -> 进入进化候选
```

## 五、免疫边界

- 不自动写正式向量库。
- 不触发 n8n。
- 不外发正式结论。
- 不覆盖原始资料。
- 不把草案当最终依据。
