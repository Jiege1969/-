## 一、回答契约

企业微信知识库助手返回必须包含：

| 字段 | 要求 |
|---|---|
| answer_summary | 最短结论，只能来自证据或明确降级 |
| evidence_snippets | 1-3 条证据片段；片段要短，不复制整篇文档 |
| citation_paths | 本地引用路径，含文件路径和分块/章节 |
| source_status | exists、stale、missing、unverified 之一 |
| downgrade_reply | 证据不足、路径缺失、越界时的固定降级回答 |
| cannot_answer_boundary | 不可回答边界 |
| safety_flags | real_send=false、n8n=false、write_db=false、auto_trade=false |

## 三、降级回答模板

| 场景 | 降级语 |

| 没有证据路径 | 我现在没有可追溯来源路径，不能把这个说成确定结论；请提供资料路径或转人工复核。 |

## 四、不可回答边界

- 无证据、无引用路径、无人工复核的内容不能答成确定结论。
- 不能写正式知识库、向量库、数据库或旧系统。
- 不能触发 n8n、Webhook、response_url 或企业微信真实发送。
- 不能调用模型生成“看似有依据”的替代证据。
- 不能输出股票交易执行建议。
- 不能替总管、01智能系统或03进化系统裁定正式口径。
