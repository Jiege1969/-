# 03进化系统：交付候选自动评审审计清单

- 创建日期：2026-05-05
- 格式版本：auto-review-audit-v1
- 使用方式：接入自动评审前只读检查；所有检查项均为阻断项。

| ID | 检查项 | 阻断逻辑 | 失败处理 |
| --- | --- | --- | --- |
| DCA-001 | 总管唯一中枢 | `center_role=rule_deposit_only`，`second_center_created=false`。 | 退回候选包，回收与状态仍交00总管。 |
| DCA-002 | 不新增OpenClaw/Hermes原件 | 不新增原件、运行依赖、源码、凭据、workflow或prompt原文。 | 只保留抽象规则说明。 |
| DCA-003 | 任务契约dry_run优先 | 必填字段完整，`dry_run=true`，真实动作和外部服务请求为false。 | 补齐任务契约并转为干跑。 |
| DCA-004 | Redis升级门槛 | Redis不得成为真实动作队列、权限放行器或进度权威源。 | Redis仅保留影子映射或缓存候选。 |
| DCA-005 | n8n升级门槛 | 不导入、不启用、不触发workflow，不调用webhook。 | 保持`dry_run_only`。 |
| DCA-006 | 真实动作闸门 | 真实动作闸门默认关闭，真实动作数量为0。 | 补充审批、复核、回滚和kill switch后仍只进入候选。 |
| DCA-007 | 股票analysis-only | 股票只允许分析，券商接口、下单和自动交易为false。 | 仅保留分析和复盘。 |
| DCA-008 | 并行小任务回收格式统一 | 00总管并行回收区md/json双文件齐备，格式版本为`parallel-recycle-v1`。 | 按固定字段重写回收报告。 |
| DCA-009 | 进度不得虚高 | 进度依据必须是本地可验证产物，阻断项为0，只读验收通过。 | 不得提高完成度或改系统级进度。 |
| DCA-010 | 外部服务零触发 | n8n、企业微信、Redis服务、券商接口、外部网络调用均未触发。 | 撤销真实动作入口并保留审计记录。 |
| DCA-011 | 安全阻断不按失败处理 | 安全边界关闭是合规要求，不得绕过闸门。 | 重写验收口径。 |
| DCA-012 | 本地证据齐备 | 规则卡、审计清单、反退化样例、证据JSON和验证脚本齐备。 | 补齐证据后重新只读验收。 |

## 固定回收字段

固定回收报告必须包含：任务、目标、产物路径、验收命令、验收结果、真实动作数量、安全边界、阻断项、进度依据、并行协作边界。
