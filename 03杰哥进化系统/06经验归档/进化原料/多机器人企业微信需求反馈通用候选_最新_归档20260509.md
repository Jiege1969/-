# 多机器人企业微信需求反馈通用候选

- 生成时间：2026-05-09 15:14:48
- 定位：企业微信是用户与系统交流的终端，不只是股票机器人入口。
- 状态：候选层，不改运行中公共入口，不触发19310重载。

## 通用闭环
1. 企业微信机器人收到自然语言需求或批评
2. 先判断是否属于当前机器人对应业务；不属于则转交正确机器人
3. 属于业务反馈时，记录原话、来源机器人、业务对象、反馈类型和安全边界
4. 进入对应业务日志和进化候选层
5. 生成影子改版样例和只读验收
6. 通过人工确认后，才允许进入正式规则申请流程

## 机器人覆盖

### 股票分析助手/股票分析专家
- 对应系统：01股票研究系统
- 候选落点：股票反馈日志 -> 进化候选 -> 股票报告影子验收 -> 人工确认 -> 正式规则申请
- 当前进度：股票侧已先行落地反馈识别、可点击链接、改版候选和影子验收。

### 杰哥工作秘书/税收待复核助手
- 对应系统：05税收业务系统
- 候选落点：税收待复核反馈样本 -> 进化候选 -> 税收草案影子验收 -> 人工确认
- 当前进度：只纳入通用候选；不生成正式税务结论，不登录税局，不接财税软件。

### 杰哥视频助理
- 对应系统：02视频制作系统
- 候选落点：视频反馈样本 -> 进化候选 -> 脚本/分镜影子验收 -> 人工确认
- 当前进度：只纳入通用候选；不真实渲染，不上传，不发布。

### 办公/内容处理助手
- 对应系统：03本职工作系统/04内容处理系统

- 当前进度：只作为本地草案/预演能力候选；不输出正式文档，不覆盖原文件。

### 杰哥系统管家
- 对应系统：00杰哥系统总管/公共接入层
- 候选落点：系统反馈样本 -> 进化候选 -> 状态汇报影子验收 -> 人工确认
- 当前进度：只纳入通用候选；不自动改总管面板，不自动改一键接续包。

## 红线
- 不自动写正式规则；不重载19310/19302；不真实发送企业微信；不接券商；不交易；不登录税局；不真实发布视频。
