# 三业务反馈人工确认状态机定义

- 版本：confirmation-state-machine-v1
- 生成时间：2026-05-08 18:18:23
- 候选层停留：true
- 自动生效：false
- 写正式规则：false
- 需总管确认：true

## 状态集合

- 待确认：候选等待人工确认，不能生效
- 已确认待总管复核：人工已确认，但仍需总管复核，不能生效
- 驳回：候选被驳回，不能生效
- 冻结：候选冻结，不能生效
- 可提交正式规则申请草案：只允许形成正式规则申请草案，禁止自动写正式规则

## 允许迁移

- 待确认 -> 已确认待总管复核：人工确认通过；仍停留候选层，等待总管复核
- 待确认 -> 驳回：人工驳回；候选不得生效
- 待确认 -> 冻结：人工冻结；候选不得生效
- 已确认待总管复核 -> 可提交正式规则申请草案：总管复核通过草案；只生成申请草案，不写正式规则
- 已确认待总管复核 -> 驳回：总管复核驳回；候选不得生效
- 已确认待总管复核 -> 冻结：总管复核冻结；候选不得生效
- 驳回 -> 待确认：人工补充后重新提交；重新进入候选确认层
- 驳回 -> 冻结：驳回后冻结；候选不得生效
- 冻结 -> 待确认：总管解冻后重提；重新进入候选确认层
- 可提交正式规则申请草案 -> 冻结：总管要求暂停草案；草案暂停，禁止自动转正式规则
