# 03进化系统：交付候选自动评审接入规则卡

- 创建日期：2026-05-05
- 任务批次：并行小任务J
- 定位：为交付候选进入自动评审前提供只读规则、阻断清单和反退化样例。
- 执行边界：只生成本地规则与验证脚本，不触发外部服务，不放行真实动作。

## 总体原则

| 原则 | 要求 |
| --- | --- |
| 总管唯一中枢 | 状态、回收和系统级进度仍以00杰哥系统总管为唯一中枢，03进化只沉淀规则。 |
| 不新增OpenClaw/Hermes原件 | 只学习抽象任务契约和编排分层思想，不复制原始代码、配置、凭据、workflow或prompt原件。 |
| dry_run优先 | 交付候选必须先提交任务契约JSON，`dry_run=true`，真实动作与外部服务请求为false。 |
| Redis/n8n升级门槛 | Redis只能是影子映射或缓存候选，n8n只能是dry_run门禁定义；不得升级为真实队列或启用workflow。 |
| 真实动作闸门 | 真实发送、正式库写入、外部API、券商接口、下单和自动交易默认关闭。 |
| 股票analysis-only | 股票相关只允许分析、复盘、规则沉淀和只读验收。 |
| 回收格式统一 | 固定md/json回收报告写回00总管并行回收区。 |
| 进度不得虚高 | 只有本地可验证产物和只读验收通过才能支撑进度表述。 |

## 核心规则

| ID | 规则 | 阻断口径 |
| --- | --- | --- |
| ARC-001 | 总管唯一中枢 | 任何第二中枢、绕过00总管的状态放行或回收入口均阻断。 |
| ARC-002 | 不新增OpenClaw/Hermes原件 | 新增原件目录、复制源码/配置/凭据/workflow/prompt原文均阻断。 |
| ARC-003 | 任务契约dry_run优先 | 缺字段、`dry_run=false`、真实动作或外部服务请求为true均阻断。 |
| ARC-004 | Redis升级门槛 | Redis成为真实动作队列、权限放行器或进度权威源均阻断。 |
| ARC-005 | n8n升级门槛 | 导入、启用、触发workflow或调用webhook均阻断。 |
| ARC-006 | 真实动作单线闸门 | 真实动作默认开启、多闸门并行放行、无审批回滚均阻断。 |
| ARC-007 | 股票analysis-only | 券商接口、资金账户、下单、撤单、自动交易或机器消费交易指令均阻断。 |
| ARC-008 | 并行小任务回收格式统一 | 缺固定回收报告、缺安全边界、缺真实动作数量或协作边界均阻断。 |
| ARC-009 | 进度不得虚高 | 未验收、缺证据、阻断项未清零却声称完成或提高进度均阻断。 |

## 任务契约必填字段

`task_id`、`source_system`、`target_system`、`candidate_type`、`scope`、`inputs`、`expected_outputs`、`dry_run`、`real_action_requested`、`external_service_requested`、`safety_boundary`、`rollback_plan`、`acceptance`、`recycle_report_path`、`progress_claim_basis`。

## 安全边界

本包未触发n8n，未导入或启用workflow，未调用webhook，未发送企业微信，未写正式库，未连接Redis服务，未调用券商接口，未下单，未自动交易，未发起外部网络调用，未新增OpenClaw/Hermes原件。
