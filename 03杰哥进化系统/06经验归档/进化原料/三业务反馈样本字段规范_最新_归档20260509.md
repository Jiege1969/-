# 三业务反馈样本字段规范

- 版本：readonly-queue-candidate-v1
- 生成时间：2026-05-08 17:52:29
- 覆盖业务：税收、股票、视频
- 默认不自动吸收：true
- 不转正式规则：true
- 候选需人工确认：true

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| 样本ID | string | true | 本包内唯一的反馈样本编号。 |
| 来源 | string | true | 只读样本来源，必须指向本包示例或人工离线摘录。 |
| 业务线 | enum | true | 允许值：税收、股票、视频 |
| 输入原文 | string | true | 用户反馈原文或离线摘录。 |
| 系统输出摘要 | string | true | 仅记录既有输出摘要，不生成新结论。 |
| 用户判定 | string | true | 用户对输出的判定或复核意见。 |
| 问题类型 | enum | true | 允许值：理解偏差、摘要遗漏、口径不清、风险提示不足、交易化表达、脚本不清、分镜遗漏、预检误判、其他 |
| 建议动作 | string | true | 候选层建议，不得直接改正式规则。 |
| 是否触红线 | boolean | true | 允许值： |
| 是否可自动吸收 | boolean | true | 允许值： |
| 需人工确认 | boolean | true | 允许值： |
