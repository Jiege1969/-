# 问题状态流转说明

| 状态 | 说明 | 下一步 | 需总管确认 |
| --- | --- | --- | --- |
| 发现 | 来自首日观察、每日清单、总巡检或用户反馈 | 登记台账 | False |
| 候选 | 生成低风险候选资产或复验卡 | 只读复验 | False |
| 复验 | 本地只读复验或离线干跑 | 关闭/升级 | False |
| 升级 | 连续问题、影响使用体验或需要外部动作 | 总管确认 | True |
| 暂停 | 触碰红线、服务重载、正式规则或真实外部动作 | 只登记不执行 | True |
| 关闭 | 问题已复验通过且无红线动作 | 保留证据 | False |
