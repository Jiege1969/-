# 常用指令清单

| 场景 | 建议指令 | 预期输出 | 红线 |
| --- | --- | --- | --- |
| 看系统状态 | 系统现在整体状态怎么样 | 总巡检、总回归、交付状态、红线状态摘要 | False |
| 税收资料草案 | 税收业务：软件产品即征即退需要准备哪些资料 | 税收分析助手-待复核草案摘要 | False |
| 股票研究 | 分析天齐锂业 | 研究价值、风险复核、当前操作建议等去交易化内容 | False |
| 视频脚本预检 | 生成一个视频脚本草案并做发布预检 | 脚本/分镜/预检结果，真实渲染和发布保持阻断 | False |
| 看运行日报 | 查看稳定交付版每日运行日报 | 日报、次日待办、问题状态 | False |
| 继续低风险搭建 | 继续 | 只读巡检、候选资产、验收脚本、状态包或回归清单 | False |
| 触碰外部动作 | 真实发送/触发n8n/交易/登录税局/真实渲染/发布/重载服务 | 暂停并登记需总管确认 | True |
