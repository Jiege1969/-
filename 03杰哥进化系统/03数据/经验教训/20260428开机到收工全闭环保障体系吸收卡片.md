## 已吸收内容
- 检测、判断、执行、验证、记录五步闭环。
- 智能等待替代固定延迟，尤其用于 Ollama API 和模型列表。
- Ollama 0.20.5 目录适配：启动前兼容 `/root/.ollama/blobs`、`/root/.ollama/manifests` 与 `/root/.ollama/models`。
- 灰度修复原则：正常不动，功能异常最小修复，未运行则启动，容器不存在才进入受控重建。
- 状态快照机制：新系统写入 `03数据\运行状态\system_health.env`，供 AI 和脚本快速读取。
- 收工固化思想：所有修复动作必须生成 JSON 或 Markdown 记录。

## 优化取舍
- 不照搬旧系统高权限守护，避免自动修复误伤。
- 新系统守护默认只读；只有显式 `-Repair` 时才启动新系统自己拥有的容器。
- 不自动停止旧股票操作系统的 `jiege_*` 容器。
- 不自动发送企业微信、不触发 n8n、不写旧系统、不接交易接口。
