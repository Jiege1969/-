# 运行期问题分级与处置路线

## 问题分级

| 级别 | 名称 | 需总管确认 | 允许自动执行 | 处置 |
| --- | --- | --- | --- | --- |
| P0 | 红线或外部真实动作风险 | True | False | 停止自动施工，登记为需总管确认，只输出可复制确认项 |
| P1 | 稳定运行阻断 | True | False | 只读定位、生成复跑建议和回滚路线；涉及重载或配置改动时升级总管确认 |
| P2 | 普通试运行问题 | False | True | 进入候选任务队列，先本地复现和候选修复，不自动改正式规则 |
| P3 | 文档和流程优化 | False | True | 低风险补充候选文档和验收建议，不触碰运行配置 |

## 问题域路线

| 问题域 | 判断关键词 | 承接方式 | 红线提示 |
| --- | --- | --- | --- |
| 企业微信公共入口 | 工作秘书、系统管家、视频助理、19310、企业微信 | 公共接入层候选任务 | 真实发送或重载必须总管确认 |
| 税收 | 税收、增值税、即征即退、研发费用 | 税收待复核候选任务 | 不登录税局、不接财税软件、不出正式税务结论 |
| 股票 | 股票、个股、研究价值、风险复核 | 股票展示或研究候选任务 | 不接券商、不交易、不输出下单指令 |
| 视频 | 视频、渲染、发布、MoneyPrinterTurbo、ImageMagick | 视频预检或环境候选任务 | 不真实渲染、不自动发布 |
| 智能进化 | 规则、候选、进化、经验 | 进化候选任务 | 不自动转正式规则 |
