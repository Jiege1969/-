# 三业务正式规则申请草案冲突扫描规则

- 版本：three-business-rule-draft-conflict-scan-v1
- 生成时间：2026-05-08 18:49:12
- 默认签收状态：待签收
- 正式生效：false
- 写正式规则：false
- 需总管确认：true

| 冲突类型 | 判定口径 | 处理动作 |
| --- | --- | --- |
| 红线冲突 | 草案内容或签收动作出现外部系统、真实发送、交易、登录、重载等红线动作即命中。 | 阻断签收，退回人工修订，保持正式生效=false。 |
| 跨业务职责冲突 | 税收、股票、视频任一草案越权修改其他业务职责、入口或处置链路即命中。 | 标记待总管确认，并要求拆分业务边界。 |
| 旧口径回潮 | 草案重新引入已被审查否定的旧口径、旧状态或旧默认自动吸收表达即命中。 | 标记为需复核，要求说明新旧口径差异。 |
| 正式规则自动生效 | 草案或台账出现正式生效=true、写正式规则=true、自动转正式规则=true即命中。 | 强制失败，禁止写入正式规则。 |
| 缺少回滚办法 | 草案缺少可执行回滚办法、撤回方式或恢复来源说明即命中。 | 退回补齐回滚办法后重新扫描。 |
| 缺少总管确认 | 草案或签收台账未声明需总管确认=true即命中。 | 保持待签收，不允许进入正式生效链路。 |
