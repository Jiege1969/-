# 使用接管清单

| 编号 | 事项 | 用途 |
| --- | --- | --- |
| HANDOFF-001 | 先看使用者入口导航与常用指令 | 确定从哪个入口发起税收、股票、视频、系统状态问题 |
| HANDOFF-002 | 按稳定版一页操作卡执行 | 用灯号和操作卡判断能用、阻断、需确认 |
| HANDOFF-003 | 每日先跑日常可用版一键只读总回归 | 确认公共入口、职责分流、税收、视频阻断和红线仍正常 |
| HANDOFF-004 | 查看日常可用版自主巡检快照 | 确认所有已吸收验收包仍为 pass |
| HANDOFF-005 | 试运行问题先进本地入账执行器 | 先形成候选台账，不直接改正式规则 |
| HANDOFF-006 | 运行指挥台索引用于找证据 | 定位日报、周报、回滚、反馈、签收和续建材料 |
| HANDOFF-007 | 首周试用结果签收复核 | 复核日常可用版和稳定交付版仍可签收使用 |
| HANDOFF-008 | 遇到红线事项登记为需总管确认 | 不自动放行外部真实动作和正式规则 |
