# 03进化系统轻量任务契约审计清单

创建日期：2026-05-05

适用范围：标准任务单JSON、SQLite影子台账、Redis影子映射、n8n干跑、真实动作闸门、股票分析only边界。

## 检查项

| 检查项ID | 检查名称 | 通过条件 | 阻断 |
| --- | --- | --- | --- |
| CHK-LTC-001 | 不得新增第二中枢 | `center_role=rule_deposit_only` 且 `second_center_created=false` | 是 |
| CHK-LTC-002 | 标准任务单JSON字段完整 | 必填字段齐全，`dry_run=true`，`real_action_requested=false` | 是 |
| CHK-LTC-003 | SQLite仅为影子权威台账 | `sqlite.role=shadow_authoritative_ledger` 且 `official_db_write=false` | 是 |
| CHK-LTC-004 | Redis仅为影子映射增强 | `redis.role=shadow_mapping_enhancement` 且 `real_action_queue=false` | 是 |
| CHK-LTC-005 | n8n仅干跑 | `n8n.mode=dry_run_only` 且 `triggered=false` 且 `webhook_called=false` | 是 |
| CHK-LTC-006 | 真实动作默认关闭并归单线闸门 | `real_actions_enabled=false` 且 `gate.mode=single_line_manual_gate` | 是 |
| CHK-LTC-007 | 股票分析only | `stock_scope=analysis_only` 且 `broker_api_called=false` 且 `auto_trade=false` 且 `order_placed=false` | 是 |
| CHK-LTC-008 | 禁止接口全关闭 | n8n、企微、正式库、券商、交易、外部网络、生产凭据均为false | 是 |

## 阻断项

- 新增或替代00总管的第二中枢。
- 任务单缺少JSON必填字段或隐含真实动作授权。
- SQLite写正式库或驱动真实动作。
- Redis成为真实动作队列或权限放行器。
- n8n webhook调用、工作流启用或生产凭据写入。
- 企业微信真实发送、正式库写入、券商接口调用、下单或自动交易。
- 股票研究输出被机器直接消费为交易指令。
