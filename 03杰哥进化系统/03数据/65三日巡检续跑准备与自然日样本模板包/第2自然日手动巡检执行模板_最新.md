# 第2自然日手动巡检执行模板

## 前置确认

- 当前 59 包已记录自然日数：1
- 当前 59 包三日达标：False
- 本模板不得在第2自然日真实到达前转为样本。

## 手动执行步骤

1. 确认 59 包样本台账仍可读取，并且当前只记录 1 个自然日。
2. 确认第 2/3 自然日没有被提前写入样本台账或模板包。
3. 按 59 包巡检源逐项只读核对产物，不触发企业微信、n8n、券商、税局、财税软件、视频渲染或发布。
4. 记录执行日期、执行人、巡检源状态、失败分级、处置建议和是否需要总管确认。
5. 完成后只把真实自然日样本追加到后续台账，不把模板占位内容计入三日达标。

## 建议记录字段

- 样本日期：yyyy-mm-dd
- 记录时间：yyyy-mm-dd HH:MM:SS
- 自然日序号：2
- 当日状态：pass / blocked
- 巡检源结果：沿用 59 包巡检源编号、名称、路径、通过口径、当前结果、摘要
- 失败分级：L1_observation / L2_regression_blocker / L3_red_line
- 总管确认：无需 / 需要 / 已确认
- 三日达标：仅当 3 个不同自然日样本均 pass 时才可为 true

## 建议文件名

- 三日巡检第2自然日样本记录_yyyy-mm-dd_手动确认.json
- 三日巡检第2自然日样本记录_yyyy-mm-dd_手动确认.md
