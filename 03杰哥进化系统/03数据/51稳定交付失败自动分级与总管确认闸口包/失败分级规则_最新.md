# 失败分级规则

| 级别 | 名称 | 需总管确认 | 允许自动复跑 | 动作 |
| --- | --- | --- | --- | --- |
| L0 | 全部通过 | False | False | 继续自主施工下一批低风险候选包。 |
| L1 | 只读产物缺失或过期 | False | True | 允许自动重建候选资料或复跑只读验收。 |
| L2 | 低风险口径不一致 | False | True | 允许在原业务边界内最小修复，并复跑对应只读验收。 |
| L3 | 运行服务加载异常 | True | False | 停止自动施工，登记重载申请，等待总管确认。 |
| L4 | 真实外部动作风险 | True | False | 立即停止，保留日志，标记红线风险，等待总管确认。 |
| L5 | 正式规则或总管资产风险 | True | False | 立即停止，只形成候选说明，不落正式变更。 |
