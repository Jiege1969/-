# 问题升级矩阵

| 级别 | 触发条件 | 处理 | 需总管确认 |
| --- | --- | --- | --- |
| 观察 | 单日非红线问题，且不影响总巡检/总回归 | 登记首日或当日问题台账，生成候选即可 | False |
| 复验 | 同类问题连续2天出现 | 生成复验任务和只读回归卡 | False |
| 升级 | 同类问题连续3天出现，或影响日常使用体验 | 登记稳定版缺口，等待总管确认是否进入修复 | True |
| 停机确认 | 涉及真实发送、触发n8n、交易、登录、渲染、发布、正式规则、服务重载 | 立即暂停，只登记不执行 | True |
| 正式规则候选 | 一周内多次复验通过且不触碰红线 | 仅生成正式规则候选草案，不自动生效 | True |
