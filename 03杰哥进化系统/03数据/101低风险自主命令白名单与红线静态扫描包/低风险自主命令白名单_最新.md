- 生成时间: 2026-05-08 19:57:08

- 允许: Python 本地只读验收脚本、快照生成脚本、状态包生成脚本。

## 允许族
- python_readonly_acceptance_script: 允许 Python 启动本地只读验收脚本，脚本名必须以 验证 或 只读验证 开头。
- python_snapshot_generator: 允许 Python 启动本地快照生成脚本，脚本名必须以 生成 开头且包含 快照。
- python_status_package_generator: 允许 Python 启动本地状态包生成脚本，脚本名必须以 生成 开头且包含 状态包。

## 明确禁止
- Start-Process 服务重载或后台启动
- 企业微信真实发送
- n8n/webhook/外部 HTTP 接口
- 券商连接、交易、下单
- 税局登录
- 财税软件连接
- 真实渲染发布
- 正式规则写入或自动转正式规则
- 总管面板修改
- 一键接续包修改
