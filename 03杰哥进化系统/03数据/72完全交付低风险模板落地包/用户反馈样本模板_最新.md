# 用户反馈样本模板

- 来源拆单：税收/股票/视频用户反馈样本模板
- 用途：沉淀脱敏用户反馈字段，用于人工复核体验、结果和缺口，不要求登录或连接高风险系统。
- 红线：false

## 输入
- 业务类型
- 用户问题
- 人工复核结果
- 脱敏证据路径
- 是否需要人工复核

## 输出
- 反馈样本记录
- 共用字段字典
- 人工复核标记

## 验收
- 输入、输出、验收、红线字段齐全
- 红线=false
- 不包含登录税局、连接券商、真实渲染发布要求

## 字段

| 字段 | 说明 | 必填 |
| --- | --- | --- |
| 业务类型 | 税收/股票/视频/通用 | 是 |
| 反馈描述 | 用户可读的脱敏反馈 | 是 |
| 脱敏证据路径 | 本地只读证据路径或占位 | 是 |
| 人工复核状态 | 待复核/已复核/不适用 | 是 |
