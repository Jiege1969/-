# 异常样例扩展模板

- 来源拆单：异常样例扩展
- 用途：扩展可演练但不执行外部动作的异常样例，覆盖缺文件、缺字段、依赖缺失、权限未授权等情形。
- 红线：false

## 输入
- 现有异常样例库
- 失败分级规则
- 只读核对输出

## 输出
- 异常样例扩展表
- 只读演练预期结果
- 人工复核备注模板

## 验收
- 每个异常有触发条件、期望提示、恢复建议
- 红线=false
- 不要求真实发送、登录、交易、渲染

## 字段

| 字段 | 说明 | 必填 |
| --- | --- | --- |
| 异常类型 | 缺文件/缺字段/依赖缺失/权限未授权 | 是 |
| 触发条件 | 只读演练条件 | 是 |
| 期望提示 | 用户可读提示 | 是 |
| 恢复建议 | 人工处理建议 | 是 |
