# 长周期样本记录模板

- 来源拆单：长周期样本
- 用途：设计跨自然日、跨异常、跨业务的只读样本记录模板，为后续人工验收提供连续证据。
- 红线：false

## 输入
- 历史只读巡检结果
- 三日巡检样本模板
- 异常恢复日志索引

## 输出
- 7日只读样本计划
- 每日样本记录模板
- 趋势汇总字段定义

## 验收
- 覆盖税收、股票、视频、规则治理等非真实动作样本
- 红线=false
- 每条样本只记录状态和证据路径

## 字段

| 字段 | 说明 | 必填 |
| --- | --- | --- |
| 样本日期 | 自然日 | 是 |
| 业务域 | 税收/股票/视频/规则治理/通用 | 是 |
| 只读状态 | pass/fail/blocked | 是 |
| 证据路径 | 本地只读证据或日志路径 | 是 |
