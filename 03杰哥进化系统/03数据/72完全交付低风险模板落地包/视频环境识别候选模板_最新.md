# 视频环境识别候选模板

- 来源拆单：视频环境识别候选
- 用途：仅记录视频环境候选项和人工确认项，不运行渲染链路，不读取或提交发布账号凭据。
- 红线：false

## 输入
- 本地视频草稿需求
- 素材缺口清单
- 人工确认字段

## 输出
- 视频环境候选表
- 素材与版权确认字段
- 发布前人工闸口清单

## 验收
- 红线=false
- 只登记候选依赖和确认项
- 不调用渲染、发布、账号读取动作

## 字段

| 字段 | 说明 | 必填 |
| --- | --- | --- |
| 候选环境 | 本地工具名或人工填写 | 是 |
| 素材版权状态 | 待确认/已确认/不适用 | 是 |
| 发布账号检查 | 固定为不读取不提交 | 是 |
| 人工闸口 | 发布前必须人工确认 | 是 |
