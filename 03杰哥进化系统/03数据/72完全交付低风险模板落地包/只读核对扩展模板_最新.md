# 只读核对扩展模板

- 来源拆单：只读核对覆盖
- 用途：扩展生成、执行、验证三段产物的只读覆盖矩阵，只检查本地文件存在、字段完整、红线关闭。
- 红线：false

## 输入
- 现有生成包
- 执行只读核对报告
- 验证报告

## 输出
- 只读覆盖矩阵
- 字段完整性清单
- 红线关闭核对项

## 验收
- 覆盖生成/执行/验证三段
- 每项均可只读核对
- 红线=false 且错误数为0时通过

## 字段

| 字段 | 说明 | 必填 |
| --- | --- | --- |
| 核对对象 | 文件或模板名称 | 是 |
| 存在性检查 | pass/fail | 是 |
| 字段完整检查 | pass/fail | 是 |
| 红线检查 | 必须为false | 是 |
