## 流转边

- 待签收 -> 需补正：材料缺项或红线声明不足
- 待签收 -> 总管已确认：人工签收通过并提交总管确认
- 待签收 -> 已驳回：命中不可补正红线
- 需补正 -> 待签收：补正后重新提交人工签收
- 需补正 -> 已驳回：补正失败或拒绝补正
- 总管已确认 -> 可申请正式生效：总管确认且回滚校验通过
- 总管已确认 -> 回滚待确认：总管要求回滚复核
- 总管已确认 -> 已驳回：总管驳回
- 可申请正式生效 -> 回滚待确认：申请前发现需补充回滚证据
- 可申请正式生效 -> 已驳回：申请前发现红线冲突
- 回滚待确认 -> 待签收：回滚材料补齐后重新签收
- 回滚待确认 -> 总管已确认：回滚复核通过并回到总管确认态
- 回滚待确认 -> 已驳回：回滚入口或快照不可确认
