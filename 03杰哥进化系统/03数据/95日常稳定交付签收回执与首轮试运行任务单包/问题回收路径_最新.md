# 问题回收路径

| 问题类型 | 回收路径 | 默认动作 |
| --- | --- | --- |
| 入口/分流异常 | 企业微信公共接入层候选或只读巡检包 | 本地复测 |
| 税收事项识别异常 | 税收业务候选，不生成正式税务结论 | 待复核草案对照 |
| 股票展示口径异常 | 股票前台展示层候选 | 只修展示，不接交易 |
| 视频渲染/发布误放行 | 视频阻断与放行前检查 | 立即 blocked |
| n8n/外部触发诉求 | n8n离线蓝图和禁用态检查 | 不真实触发 |
| 正式规则诉求 | 正式规则申请草案和冲突扫描 | 需总管确认 |
| 服务重载诉求 | 重载确认登记 | 需总管确认 |
