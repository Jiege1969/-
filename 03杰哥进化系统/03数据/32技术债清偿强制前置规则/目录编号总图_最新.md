# 目录编号总图

## 一、总原则

目录编号不是全系统唯一编号，只在同一层级、同一语义域内排序。

读取职责时必须同时看：

1. 完整目录名。
2. 所属父目录。
3. README。
4. 目录角色索引。

## 五、开工前检查

新增目录前必须回答：

- 属于哪个顶层系统。
- 属于系统级七目录、业务线目录还是能力模块目录。
- 是否与已有同层同语义域编号冲突。
- 输出目录在哪里。
- 日志目录在哪里。
- 是否需要 README。
- 是否需要写入目录角色索引。

## 六、禁止项

- 禁止把历史路径 `D:\01杰哥智能系统` 当作当前路径。
- 禁止只看 `01/02/03` 数字判断职责。
- 禁止为美化编号直接移动正式业务目录。
- 禁止没有 README 的新增业务线进入正式施工。
