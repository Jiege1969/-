# 杰哥智能系统搭建与施工规范（完整版）

**版本**：v2.0
**生效日期**：2026-05-10
**来源**：P0-001实战复盘 + P1-001施工复盘 + Sparkle协作审计
**优先级**：最高（覆盖所有其他施工指南）

## 核心施工原则

### 一、永生优先原则
任何新增的后台微服务（如API），在通过功能测试后，必须立即完成双重永生保障：
1. **守护永生**：接入血脉探针的守护逻辑，确保进程意外终止后能自动拉起。
2. **开机永生**：注册为Windows计划任务或系统服务，确保系统重启后能自动上线。
* **验收标准**：手动杀掉服务进程后，一分钟内必须自动恢复。
* **反面教材（2026-05-10）**：5801/5802手动启动三次均丢失，直到注入探针守护才解决。

### 二、本地环路终检原则
任何涉及外部链路（如企业微信）的功能改造，在开放真实测试前，必须先通过127.0.0.1的本地HTTP请求完成全功能验收。禁止用外部工具（如手机微信）作为唯一的排错或测试手段。
* **验收标准**：本地接口返回预期结果。
* **来源**：ChatGPT施工中全程使用Invoke-RestMethod本地验证，效率远高于我们反复发微信消息。

### 三、事实单点原则
任何在施工中发现的、与蓝图不符的配置事实（如Docker端口映射、有效模型名），一旦确认，必须在发现后的半小时内直接修改对应的配置文件或脚本来永久固化。严禁将“修正步骤”停留在操作者的短期记忆或聊天记录里。
* **验收标准**：重启后无需再次手动修正同一配置。
* **反面教材（2026-05-10）**：Ollama端口11434不可用，直到扫描Docker容器才确认是29134。

### 四、施工即样本原则
每次成功的P0/P1级问题施工，必须在任务闭环后，立即将完整的“问题定义-根因分析-解决过程-关键踩坑-验收标准”归档为《工程样本库》中的一个条目。样本的价值在于记录真实踩过的坑，而非复述完美蓝图。
* **验收标准**：样本包含踩坑记录而非仅复述蓝图。
* **已归档样本**：P0-001（机械回复感根治）、P1-001（报警主动推送）。

### 五、原生机制优先原则（2026-05-10新增）
遇到系统级问题时，优先查找操作系统是否已有成熟的解决方案，避免在应用层打补丁。
* **正面案例**：Sparkle用wscript.exe无窗口启动Python脚本，零闪现。
* **反面教材**：我们之前用ctypes注入隐藏窗口代码，窗口先创建再隐藏，会闪一下。
* **延伸**：隐藏窗口用wscript.exe、定时任务用计划任务、守护进程用现有探针——能用系统原生机制解决的，不写代码。

### 六、资产清理触发原则（2026-05-10新增）
资产清理不以存在时间为触发条件，而以正式取代、生产引用解除、证据归档完成或系统版本升级为触发条件。时间只能触发复核提醒，不能直接触发删除。

* **封存归档条件**：历史规则资产被新规则取代、降级为历史先例，或退出当前执行路径时，应优先封存归档，保留证据链和索引。
* **删除清理条件**：只有同时满足以下条件，才可进入删除或不可逆清理：
  1. 已被正式取代：新规则文件明确声明取代旧文件。
  2. 已确认无生产引用：开工索引、计划任务、脚本调用、配置入口均不引用。
  3. 已完成归档证据：旧文件已移至进化系统经验归档目录，或已有等价证据索引。
  4. 已通过人工确认：不可逆删除必须经过人工确认。
* **反面案例（2026-05-10）**：21组规则库双格式资产存在真理来源不清问题。正确处理方式是裁定主从关系、降级旧口径、保留证据链，而非直接删除。

## 施工闭环流程（强制执行）

1. **只读审计**：动手前先全盘扫描，确认目标文件是否被实际调用、配置现状、通道是否可用
2. **独立配置文件**：新增功能优先使用独立配置文件，不修改已有核心配置；删除文件即可回滚
3. **最小改动接入**：采用“前置调用+失败回退”模式，不重写核心逻辑
4. **防骚扰机制**：任何自动推送必须内置冷却期（同类异常N分钟内不重复）
5. **故障注入验收**：主动制造异常验证推送链路，验收标准必须是明确的布尔值
6. **全部验收通过后才报告“完成”**

## 学习对象：Sparkle（ChatGPT实体）的可借鉴方法

经2026-05-10协作审计，以下方法值得系统长期学习：
1. 全盘只读扫描先行：每次施工第一步是扫描，不是凭记忆
2. 独立配置文件：新增功能不修改已有文件，可独立上线、独立回滚
3. wscript.exe包装：用系统原生机制解决弹窗问题，零闪现
4. 端到端干跑巡检：主动制造异常，验证自动捕获、自动推送全链路
5. 最终报告的完整性：包含改动文件清单、行数变化、验收布尔值

## 系统基因（不可动摇）

以下三条由杰哥在系统创始时注入，是所有施工的底层哲学：
1. **诚实**：承认问题，不回避、不粉饰
2. **态度**：勇于承认问题的能力，不自欺、不甩锅
3. **坚持**：遇到困难不退，反复打磨直到闭环
