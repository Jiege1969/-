# 层级协同系统观：派生逻辑与施工规则

> 版本：v1.0  
> 生效日期：2026-05-08  
> 所属系统：03杰哥进化系统 / 规则库  
> 适用范围：00总管、01智能系统、02扩展系统、03进化系统，以及税收、视频、股票、企业微信等业务线  
> 来源：用户关于“命令 A/B 组成高阶系统 C，多个 C 组成 D，循环往复”的系统运行逻辑阐述

## 一、总原则

杰哥智能系统不是功能堆叠，而是层级协同系统。

每个低阶单元都必须先在本层级稳定，再在高一阶系统中被约束、被调度、被补位。低阶单元的局部正确，不自动等于高阶系统稳定；高阶系统的稳定来自多个低阶单元之间的依赖正确、接口匹配、边界清楚、失败可隔离、经验可回收。

这套层级关系既像制度体系中的“宪法、法律、部门制度、下级规章、基层流程”，也像自然系统中的“人体、神经网络、器官组织、细胞、分子、原子、更小组成单位”。在杰哥智能系统中，它对应为“总管智能体系、子系统、业务线、脚本、命令、函数、字段和代码片段”。

因此，系统搭建必须同时看两件事：

- 向上看：当前动作是否服从总目标、底层逻辑、边界和上位规则。
- 向下看：当前规则是否能真正落到脚本、接口、命令、字段和代码。

只有上位法则能统摄下位动作，下位执行又能反馈上位法则，系统才不是散乱文件堆，而是有生命力的递归协同系统。

## 二、由此派生出的底层逻辑

### 1. 单元完整性逻辑

任何命令、脚本、模块、业务线都必须先说明：

- 输入是什么。
- 输出是什么。
- 依赖谁。
- 服务谁。
- 失败时怎么降级。
- 不允许越过什么边界。

没有这些字段的能力，不能直接进入高阶系统。

### 2. 组合契约逻辑

A 和 B 组成 C 时，必须有组合契约：

| 契约项 | 要求 |
|:---|:---|
| 输入契约 | A 的输出能否被 B 正确理解，B 的输出能否被 A 或 C 正确使用 |
| 边界契约 | A/B 各自不能越权替 C 做最终判断 |
| 节奏契约 | 谁先运行，谁后运行，谁等待谁，谁失败时谁跳过 |
| 失败契约 | A 失败时 B 是否继续，B 失败时 C 是否降级 |
| 证据契约 | A/B 的判断必须能被 C 追溯 |
| 进化契约 | A/B 的经验如何进入 C 的复盘，而不是直接改正式规则 |

### 3. 高阶约束逻辑

高阶系统不是低阶系统的附庸。C 对 A/B 有约束权：

- C 可以要求 A/B 降级。
- C 可以要求 A/B 暂停。
- C 可以拒绝 A/B 的输出入账。
- C 可以把 A/B 的失败转入问题回收。
- C 不能被 A/B 的局部成功绑架。

### 4. 协同补位逻辑

低阶单元之间不是互相抢权，而是互相补位：

- 税收系统补政策分析，不补正式办税。
- 股票系统补研究分析，不补交易决策。
- 视频系统补脚本、分镜、复核，不补未授权发布。
- 企业微信入口补输入输出通道，不补业务判断。
- 智能系统补理解和草案，不补人工确认。
- 进化系统补经验沉淀，不补正式规则自动修改。
- 总管系统补边界、调度、接续，不补具体业务结论。

### 5. 局部副作用克制逻辑

低阶系统必须克制自己的副作用：

- 能输出不等于能外发。
- 能调用不等于能触发。
- 能分析不等于能决策。
- 能生成草案不等于能正式执行。
- 能沉淀经验不等于能覆盖规则。
- 能通过一次不等于能宣称稳定。

### 6. 递归进化逻辑

每一层都可以把成功、失败、修正和边界经验上传给更高一层；更高一层再把成熟规则下发给低阶系统。

```text
低阶执行 -> 失败/成功样本 -> 复盘 -> 进化候选 -> 高阶规则 -> 低阶约束
```

这形成循环，但不是无序循环，而是有层级、有闸口、有证据的循环。

## 三、施工规则

后续搭建任何新能力，必须先回答七问：

1. 这个能力属于哪一层？
2. 它的上一级系统是谁？
3. 它依赖哪些前置单元？
4. 它输出给谁使用？
5. 它失败时谁被阻断，谁可以继续？
6. 它有哪些副作用必须被克制？
7. 它的经验如何进入进化系统？

未回答七问的能力，只能作为草案或影子样例，不得进入正式稳定链路。

## 四、验收规则

验收不只看“能不能跑”，还要看：

- 依赖是否按顺序成立。
- 上下游契约是否清楚。
- 失败是否被正确隔离。
- 红线是否保持关闭。
- 输出是否可追溯。
- 局部成功是否被高阶系统正确吸收。
- 低阶系统是否没有反向覆盖高阶规则。

## 五、对当前正式稳定版的应用

正式稳定版验证时，应同时检查：

1. 开机依赖拓扑是否成立。
2. 只读总回归是否通过。
3. 税收、股票、视频、企业微信入口是否各守边界。
4. 总管是否正确吸收回执。
5. 进化系统是否只沉淀经验，不直接改正式规则。
6. 智能系统是否只输出待复核草案，不冒充正式动作。
7. 三个自然日样本是否都能证明这种高阶协同关系稳定。

## 六、总则

```text
单元先自稳，组合再协同；
低阶守边界，高阶给约束；
失败可隔离，经验可回流；
局部不绑架整体，整体不压死局部；
稳定来自层级协同，不来自功能堆叠。
```
