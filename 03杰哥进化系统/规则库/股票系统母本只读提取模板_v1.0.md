# 股票系统母本只读提取模板

> 版本：v1.0  
> 所属系统：03杰哥进化系统 / 规则库  
> 资产身份：母本提取模板  
> 使用方式：只读提取，不修改股票系统，不删除任何文件

---

## 目的

从股票分析系统中提取可复用的成熟能力，服务税收、内容、视频、本职工作等扩展系统。提取的是“成功基因”，不是机械复制目录和脚本。

---

## 提取范围

| 类别 | 提取内容 | 是否可复用 |
|:---|:---|:---|
| 输入治理 | 数据来源、更新时间、可信度、缺失处理 | 通用 |
| 分析链条 | 事实 -> 依据 -> 判断 -> 风险 -> 待复核 | 通用 |
| 人工闸口 | 交易、外发、关键判断前的确认 | 通用 |
| 输出格式 | 候选结论、风险提示、复盘入口 | 通用 |
| 经验沉淀 | 复盘修正、策略调整、案例记录 | 通用 |
| 高频行情 | 盘中刷新、实时行情、交易时段保护 | 股票专有 |
| 券商接口 | 账户、交易、下单、撤单等 | 股票专有且高风险 |

---

## 只读提取步骤

```text
读取股票系统目录结构
-> 识别入口、数据、脚本、输出、日志、复盘位置
-> 提取通用能力
-> 标记股票专有能力
-> 标记不适配场景
-> 形成母本能力清单
```

## 不适配检查

复制任何股票能力前，必须回答：

1. 这个能力是业务通用，还是股票场景专用？
2. 新业务是否需要实时性？
3. 新业务是否允许自动外发或自动执行？
4. 新业务输出是否只能作为待复核草案？
5. 如果不适配，替代机制是什么？

---

## 验收标准

本提取任务完成时，必须至少形成：

- 股票通用能力清单。
- 股票专有能力清单。
- 不适配场景说明。
- 可复用到税收影子底座的能力项。

严禁：

- 修改股票系统文件。
- 运行交易相关脚本。
- 调用券商接口。
- 删除日志或旧文件。
- 把股票结构机械复制到其他业务线。
