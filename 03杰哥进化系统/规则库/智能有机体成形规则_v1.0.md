# 智能有机体成形规则

> 版本：v1.0  
> 生效日期：2026-05-09  
> 所属系统：03杰哥进化系统 / 规则库  
> 定位：把硬件、软件、脚本、接口、模型、数据、规则和回执这些分散部件，组合成有目标、有感知、有调度、有边界、有修复、有记忆、有进化的智能有机体。

## 一、核心判断

杰哥智能系统不能停留在“无机物堆叠”的状态。

硬件、软件、脚本、接口、模型、数据、规则和文档，单独看都是零件。只有当它们围绕同一个系统目标，形成感知、判断、调度、执行、反馈、修复、记忆和进化的闭环时，才开始成为智能有机体。

本规则不是外部施工方法清单，而是系统自身应具备的形态要求。具体内生理念和能力归属，以 `杰哥智能系统内生理念与能力契约_v1.0` 为上位契约。

```text
零件存在 != 系统成形
功能可跑 != 有机协同
文档完整 != 智能运行
一次通过 != 稳定生命
```

## 二、当前已覆盖但仍需补强的底层机制

现有系统已经覆盖了层级、边界、先后、问题递进、进化回流和稳定验证，但还需要把这些机制组合成更像生命体的七个系统。

| 有机体机制 | 系统对应 | 缺失风险 | 落地要求 |
|:---|:---|:---|:---|
| 感知系统 | 开机自检、服务健康、用户反馈、日志、回执、巡检 | 系统不知道自己哪里坏了 | 每个关键入口都要有状态、证据和失败原因 |
| 神经调度系统 | 总管分流、依赖拓扑、任务队列、先后顺序 | 各模块各跑各的，互相打架 | 前置失败时后置跳过，跨系统动作必须有调度依据 |
| 内稳态系统 | 红线、阈值、降级、跳过、只读、影子 | 局部异常拖垮整体 | 异常先隔离，重动作先降级，正式链路先保护 |
| 代谢系统 | 输入、处理、输出、归档、淘汰、清债 | 文件和样本越堆越多，系统变重 | 无用样本归档，旧口径淘汰，未闭环旧债进入清理 |
| 免疫系统 | 权限边界、真实发送禁用、n8n禁用、交易/税务/发布闸口 | 好能力误触发危险动作 | 能生成不等于能执行，能调用不等于能触发 |
| 自我修复系统 | 问题记录、根因分析、修复方案、复验、回执 | 问题只被记录，没有被解决 | P0/P1/P2 必须有原因、办法、责任层级和复验结果 |
| 记忆进化系统 | 规则库、接续包、面板、样本、复盘、验收 | 经验留在当次对话，不能复用 | 经验必须进入规则、模板、检查项或退出归档 |

## 三、智能有机体八问

后续新增能力、修复问题、吸收思想或复用旧资产时，除已有施工七问外，还必须补问：

1. 它增强了系统的哪一种生命机制：感知、调度、内稳态、代谢、免疫、修复、记忆、进化？
2. 它是否让用户更少操心、更少重复提醒、更能稳定使用？
3. 它的输入、输出、反馈和验收是否闭环？
4. 它失败时系统能否知道、隔离、降级和恢复？
5. 它是否会把局部能力误升级成全局权力？
6. 它产生的数据、文件、样本和经验是否有保留、淘汰或归档规则？
7. 它的经验能否被下次运行复用，而不是停在当次对话？
8. 它是否仍然服从系统总目标、根本法则层级秩序和红线边界？

## 四、从零件到有机体的成形链

每个能力从无机零件进入智能有机体，必须经过以下链路：

```text
零件识别
-> 所属层级
-> 输入输出契约
-> 依赖拓扑
-> 边界与免疫
-> 影子/只读验证
-> 用户可感知闭环
-> 问题修复与复验
-> 经验沉淀
-> 下次运行复用
```

缺任何一环，都不能直接称为成熟能力。

## 五、对当前正式稳定交付的应用

当前正式稳定版验证不能只看“命令跑完”或“文件生成”，还要看：

- 感知：开机自检、19310/19302/19300 等入口状态是否真实可读。
- 调度：前置服务失败时，后置只读回归是否正确跳过并记录阻断。
- 内稳态：P1 失败是否被隔离，没有污染日常交付候选和红线边界。
- 代谢：失败样本是否进入问题回收，未入账样本是否不混入通过样本。
- 免疫：真实发送、n8n、交易、税务办理、视频发布是否持续关闭。
- 修复：DUR-001 企业微信公共入口巡检失败是否区分真实路由退化和巡检口径偏差。
- 记忆：修复后的原因、办法和复验结果是否进入面板、接续包、规则或验收项。
- 进化：如果同类问题复发，是否上升为更通用的依赖、路由或巡检规则。

## 六、克制原则

有机体不是越复杂越高级。

```text
能用已有机制表达的，不新增机制；
能用检查项约束的，不急着改脚本；
能只读验证的，不触碰正式动作；
能局部隔离的，不扩大成全局工程；
能通过规则复用的，不依赖人工记忆。
```

## 七、总则

```text
目标是心脏，规则是骨架，数据是血液，调度是神经，边界是免疫，问题修复是愈合，进化记忆是成长。

智能有机体不是由零件数量决定，而是由这些零件能否围绕同一目标稳定协同、感知自身、修复自身、积累经验、克制风险、持续进化决定。
```
