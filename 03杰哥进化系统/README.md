# 03杰哥进化系统

## 定位

本系统负责让 v3 持续变稳、变准、变聪明。

第一阶段只生成建议和草案，不直接修改生产配置。

## 第一批模块

1. `01反馈提炼`
2. `02提示词管理`
3. `03模型评测`
4. `04系统复盘`

## 目录编号说明

本目录存在两类同层编号：

1. 系统级七目录：`01配置`、`02脚本`、`03数据`、`04日志`、`05备份`、`06临时`、`07文档`。
2. 能力模块目录：`01反馈提炼`、`02提示词管理`、`03模型评测`、`04系统复盘`。

这些编号不是全系统唯一编号，只在同一语义域内排序。读取职责时必须看完整目录名和本 README，不得只按数字判断。

`03杰哥进化系统` 的定位是规则、经验、提示词、评测和复盘能力层。它可以沉淀建议、草案、规则和检查项，但不得绕过人工闸口直接改生产配置、生产提示词或生产模型。

## 主要职责

1. 从日志、失败任务、用户反馈中提炼经验。
2. 管理提示词版本、变更记录和回滚记录。
3. 评测不同模型适合的任务类型。
4. 形成系统复盘和升级建议。

## 禁止事项

1. 不自动修改生产提示词。
2. 不自动切换生产模型。
3. 不自动删除旧版本。
4. 不绕过人工确认执行系统升级。
