# 03杰哥进化系统总则

创建日期：2026-04-26

## 一、定位

03杰哥进化系统负责复盘、评测、提示词管理和经验提炼。

它不直接执行生产改造。

## 二、第一阶段原则

1. 只生成建议。
2. 只生成草案。
3. 不自动修改生产提示词。
4. 不自动切换生产模型。
5. 不自动删除历史版本。

## 三、第一批模块

1. 反馈提炼。
2. 提示词管理。
3. 模型评测。
4. 系统复盘。

## 四、输入来源

1. 用户反馈。
2. 任务失败记录。
3. 运维日志。
4. 模型评测结果。
5. 系统变更记录。

## 五、输出结果

1. 用户偏好摘要。
2. 提示词修改建议。
3. 模型路由调整建议。
4. 架构风险提醒。
5. 复盘报告。
