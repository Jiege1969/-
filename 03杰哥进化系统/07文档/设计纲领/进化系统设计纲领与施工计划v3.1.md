# 03杰哥进化系统设计纲领与施工计划v3.1

生成日期：2026-04-30

## 定位

03杰哥进化系统负责把系统运行、搭建、失败、修复、复盘和用户反馈转化为长期能力。它不是单纯存日志，而是做归纳、提炼、分类、复用和升级。

## 核心逻辑

方法是具体问题的解决办法，不能机械照搬；真正要沉淀的是方法背后的逻辑。

进化链路：

问题出现 -> 找到根因 -> 制定具体方法 -> 验证结果 -> 记录经验 -> 归纳分类 -> 提炼通用逻辑 -> 固化为规则、脚本、验收或提醒 -> 下一次更快更稳地处理。
