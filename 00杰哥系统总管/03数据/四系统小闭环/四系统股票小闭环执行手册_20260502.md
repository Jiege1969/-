# 四系统股票小闭环执行手册

生成日期：2026-05-02

## 一、定位

这是股票分析系统作为真实业务样板时，四系统最小闭环的稳定可复用执行手册。

四系统指：

- `00杰哥系统总管`：定方向、边界、计划、验收、接续。
- `01杰哥智能系统`：提供模型、服务、企业微信桥接和运行时底座。
- `02杰哥扩展系统/01股票研究系统`：承载真实业务、报告、前台问答和验收。
- `03杰哥进化系统`：沉淀问题、经验、规则和方法。

## 二、每次开工

1. 读取 `AI施工接续最小包_最新.md`。
2. 读取 `一键接续施工包_最新.md`。
3. 确认当前只推进股票系统，其他扩展业务暂停。
4. 跑股票系统快检：
   - 完全交付最终验收 5/5。
   - C+++ 日常可用总验收 16/16。
   - 日常一键运行失败数 0。
   - `19300` 股票助手健康。
   - `19302` 企微桥接健康。

## 三、每次施工

1. 只处理股票系统真实问题或低风险增量优化。
2. 不触发真实发送、不启用 n8n 自动触发、不调用券商接口、不自动交易。
3. 尽量把问题修复转成脚本、验收、规则或面板。
4. 保持前台输出口径：当前判断、建议策略、参考位置、风险观察线、结论。

## 四、每次验收

推荐优先运行一键执行器：

```powershell
python "D:\杰哥智能化系统\00杰哥系统总管\02脚本\执行四系统股票小闭环.py" --no-open
```

或双击入口：

```text
D:\杰哥智能化系统\00杰哥系统总管\06工具\四系统股票小闭环一键执行.bat
```

一键执行器会依次执行：股票完全交付验收、C+++ 日常可用验收、股票日常快速刷新、企微前台回归、公网回调 ready 检查、四系统状态面板、四系统闭环验收、四系统闭环历史观察。

执行后优先查看：

```text
D:\杰哥智能化系统\00杰哥系统总管\03数据\四系统小闭环\四系统股票小闭环历史观察面板_最新.md
```

该面板用于观察最近执行成功率、失败动作和反复断点，尤其是 `19302`、SSH 反向隧道、公网回调是否反复掉线。

如只需检查四系统闭环，运行：

```powershell
python "D:\杰哥智能化系统\00杰哥系统总管\02脚本\验证四系统股票小闭环.py"
```

必要时补跑股票系统验收：

```powershell
python "D:\杰哥智能化系统\02杰哥扩展系统\01股票研究系统\02脚本\验证股票系统完全交付最终验收.py"
python "D:\杰哥智能化系统\02杰哥扩展系统\01股票研究系统\02脚本\验证股票系统C加加加日常可用总验收.py"
python "D:\杰哥智能化系统\02杰哥扩展系统\01股票研究系统\02脚本\股票系统日常一键运行.py" --skip-closed-loop --no-open
```

## 五、每次收工

1. 更新工作日志。
2. 更新明日工作计划。
3. 更新开工上下文和一键接续包。
4. 如有重要经验，写入进化系统经验卡片。
5. 刷新桌面全系统 AI 无缝接手包。

## 六、判定标准

小闭环可复用成立，必须同时满足：

- 总管能生成闭环状态面板。
- 智能系统健康接口可用。
- 股票系统真实业务验收通过。
- 进化系统有方法或经验沉淀。
- 接续包能让新对话继续施工。
- 安全边界没有被放宽。
