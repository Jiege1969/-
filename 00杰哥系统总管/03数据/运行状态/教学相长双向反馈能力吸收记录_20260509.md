## 一、吸收结论

“教学相长”不是聊天中的比喻，而是杰哥智能系统必须具备的底层学习回路。

系统不能只由设计者单向灌输规则，也不能只由上级系统单向命令下级系统。用户使用中的感受、质疑、提醒，子系统运行中的失败、修复、复验和用户可感知问题，都应成为系统感知输入，并能反向修正方法、规则和能力。

## 二、能力定义

教学相长双向反馈能力包括：

| 方向 | 能力要求 |
|:---|:---|
| 用户到系统 | 用户感受、质疑、提醒进入事实记录、盲点识别、问题分型和经验回流 |
| 系统到用户 | 系统通过解释、回执、面板和验证结果帮助用户理解状态和下一步 |
| 设计者到系统 | 设计原则下沉为规则、检查器、入口行为和验收标准 |
| 系统到设计者 | 运行失败、口径冲突、复验结果反向修正设计方法 |
| 上级到下级 | 总管和进化系统把上位原则下沉为子系统可执行边界 |
| 下级到上级 | 子系统把局部实践、失败类型和有效修复反哺总管规则 |

## 五、后续约束

1. 不能把用户反馈当成外部噪声。
2. 不能只让施工者增长能力，而不让系统增长能力。
3. 不能只由上级系统单向命令下级系统。
4. 子系统实践中验证有效的方法，应能上升为总管规则和进化规则。
5. 上位方法论必须能下沉为子系统可执行的检查、边界、回执或行为。
