## 七、升级窗口规则

| 层级 | 对象 | 规则 |
|---|---|---|
| L4 | Docker、WSL2、GPU 驱动 | 单独窗口，不与任何业务组件同窗升级。 |
| L3 | Python、Node、npm、pip | 只在项目本地环境验证，不动全局环境。 |
| L2 | n8n、Ollama、Redis | 影子容器或并存端口验证，人工确认后才切换。 |
| L1 | 模型文件 | 新旧并存，路由灰度，旧版保留。 |
| L0 | 脚本、提示词、工作流 JSON | 文件备份、验收报告、可回滚。 |

## 八、禁止项

- 禁止使用 `latest` 作为正式运行标签。
- 禁止跨层同时升级。
- 禁止无备份升级。
- 禁止无回滚脚本升级。
- 禁止影子失败后进入正式。
- 禁止在股票/企业微信高频窗口升级。
- 禁止自动升级 Docker、WSL、GPU 驱动、n8n、Ollama、Redis。

## 九、结论

当前正式运行栈已可锁定：`Python 3.14.4 + Node v25.9.0 + Docker 29.3.1 + Compose v5.1.1 + Ollama 0.20.5 + Redis 7.2.5-alpine + n8n 1.123.30`。风险不在“现在不能用”，而在“后续不能随意升级、不能用 latest、不能混用全局环境碰巧可用的依赖”。
