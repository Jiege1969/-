# 目录角色索引

记录时间：2026-05-06 06:00:00 +08:00

## 一、总规则

目录编号不是全系统唯一编号，只在同一层级、同一语义域内排序。读取职责时必须看完整目录名、README 和角色索引，不得只按数字判断。

| 目录 | 角色 |

| `01配置` | 总管配置、规则、注册表 |
| `02脚本` | 总管脚本、巡检、守护、台账生成 |
| `03数据` | 运行状态、接续包、台账、报告 |
| `04日志` | 总管日志、巡检日志、守护日志 |
| `05备份` | 总管本地备份 |
| `06工具` | 长期工具入口和运维入口 |
| `06临时` | 临时材料、候选清理、中间文件 |
| `07文档` | 面板、说明、工作日志 |
