# 视频创作智能体愿景吸收与并行施工指令

- 生成时间：2026-05-08 09:07:15 +08:00
- 资产身份：总管侧 W1/R0 视频创作智能体愿景吸收与并行施工指令
- 来源输入：用户转述的视频制作系统愿景与外部建议
- 适用对象：负责视频制作系统搭建的并行对话框
- 当前定位：影子升级蓝图和并行施工边界，不是正式接入大模型、渲染器、TTS、发布器或企业微信真实外发许可

## 一、总管判断

该愿景方向正确：目标不是单个脚本，而是“能对话、能理解想法、能生成草案、能局部修正、能在人工门禁下逐步进化的视频创作智能体”。

但当前系统阶段必须按以下方式吸收：

```text
先做 W1/R0 影子蓝图、状态结构、意图分类、局部修正契约、引擎适配契约和人工门禁清单；
不直接接入真实大模型 API、不调用 MoneyPrinterTurbo/HappyHorse/Qwen-TTS/PostBot、不真实渲染、不发布、不企业微信真实外发。
```

## 二、与当前系统现状的对齐

| 当前资产 | 可承接什么 | 不承接什么 |
|---|---|---|
| 轮次012总控层 | 任务单、会话字段、合规规则、本地预演 | 不承接真实渲染、发布、n8n、外发 |
| 视频影子复核链路 | 脚本、分镜、素材授权、平台规则、人工复核、修正回执 | 不承接成片生成或发布放行 |
| 企业微信接入层 | 机器人入口和路由登记，视频助理可作为预演入口 | 不承接真实发送或业务判断 |
| 进化系统 | 承接人工回执后的经验候选、多案例验证 | 不直接把单次经验升级正式规则 |
| 总管系统 | 登记边界、收并行回传、判断是否触发暂停 | 不替视频系统做创作判断 |

## 三、对外部建议的分层吸收

| 外部建议 | 当前吸收方式 | 风险边界 |
|---|---|---|
| 对话记忆体 | 先做“会话状态字段契约”和“创作历史索引草案” | 不接真实 LLM 记忆库，不写向量库 |
| 意图路由 | 先做“视频意图分类表”和“路由决策草案” | 不替换现有运行脚本中的逻辑 |
| 动态执行与反馈 | 先做“局部修正请求契约”和“锁定段落/可改段落规则” | 不自动重写正式脚本 |
| 多样性预览 | 先做“3个候选开场/分镜方案输出模板” | 不生成真实图片、音频或视频 |
| MoneyPrinterTurbo | 只做适配器输入输出字段契约 | 不调用引擎、不渲染 |
| HappyHorse | 只登记为片头/精品镜头候选引擎 | 不调用外部服务 |
| Qwen3-TTS | 只做配音需求字段和音色选择草案 | 不合成真实语音、不克隆音色 |
| PostBot | 只做发布适配器边界清单 | 不登录平台、不发布、不模拟规避平台风控 |
