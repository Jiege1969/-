## 二、机器可读字段要求

| 字段 | 必填 | 说明 |
| --- | --- | --- |
| task_id | 是 | 对应 `受控试用任务队列_20260508` 中的任务ID |
| execution_date | 是 | 格式 YYYY-MM-DD |
| executor_window | 是 | 标明哪个并行对话或业务线 |
| business_line | 是 | 税收/股票/视频/企业微信/总管 |
| risk_level | 是 | 默认 W1/R0；出现 W2/W3 必须暂停 |
| input_summary | 是 | 必须脱敏 |
| changed_files | 是 | 文件路径列表，可为空但必须说明 |
| output_summary | 是 | 不贴长文，概括产物 |
| evidence | 否 | 业务线可填 |
| missing | 否 | 业务线可填 |
| confidence | 否 | 业务线可填 |
| boundary_flags | 是 | 所有禁止项必须显式 false |
| needs_manager_ruling | 是 | true 时不得继续扩大施工 |
| self_check_line | 是 | 统一自检行 |

## 三、总管吸收判定

| 判定 | 条件 | 总管动作 |
| --- | --- | --- |
| 可吸收 | W1/R0，边界全 false，无需裁定 | 写入回传吸收记录，必要时更新面板/接续包 |
| 需补资料 | W1/R0，但 evidence/missing 不完整 | 记录为待补事项，不扩大施工 |
| 暂停 | 出现 W2/W3、真实接入、外发、服务变更、删除/移动、规则冲突 | 停止，交回用户或总管裁定 |
| 退回 | 业务线越权改总管、正式库、服务脚本或真实系统 | 标记为不吸收，要求回滚或人工确认 |

## 四、R0 边界声明

- 本模板不触发任何业务脚本。
- 本模板不写正式库。
- 本模板不改变企业微信、n8n、服务脚本或真实业务系统配置。
- 本模板只规范回传记录格式。
