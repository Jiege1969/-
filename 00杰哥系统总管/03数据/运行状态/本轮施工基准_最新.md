# 本轮施工基准

生成时间：2026-05-05 10:45:31 +08:00

## 1. 本轮基准口径

- 本轮身份：只负责 `00杰哥系统总管` 的施工定盘、并行分发边界和结果回收口径。
- 股票系统：阶段性交付完成；剩余有效工时 `0小时`；后续仅保留灰度监控、问题修复和优化。
- 全盘当前进度：`45%-50%`。
- 全盘剩余有效工时：`55-84小时`。
- 下一批主线：`00总管脚本化`、`02扩展/知识库可追溯问答`、`03进化规则沉淀`，并补齐 `01智能系统` 中台能力。
- 暂缓事项：股票新功能、企业微信扩大真实发送、n8n、券商接口、自动交易。
- 进度调整结论：本轮是定盘与分发，不构成新的业务交付完成证据；暂不调整全盘进度和剩余工时。

## 3. 禁止修改边界

- `00总管`：可修改 `D:/杰哥智能化系统/00杰哥系统总管/02脚本`、`03数据`、`07文档`；如需改 `01配置` 必须先备份。不得修改 01/02/03 子系统业务代码。
- `01智能系统`：仅限 `D:/杰哥智能化系统/01杰哥智能系统` 内自身任务文件；不得修改总管接续包、总管进度配置、扩展系统股票核心、进化系统规则代码。
- `02扩展系统`：仅限自身被分配模块；股票系统已阶段性交付完成，核心脚本冻结。不得扩大企业微信真实发送，不得触发 n8n，不得调用外部正式发送接口。
- `03进化系统`：仅做沉淀、候选、只读复盘和验收报告；不得修改正式规则代码，不得反写其他业务系统。
- 共享口径文件：`进度口径规则.json`、`进度回答标准.json`、`四大系统验收读取口径.json`、`当前施工面板.md`、`一键接续施工包_最新.md` 统一由 `00总管` 汇总更新，其他施工框只提交建议和证据。

```text
【验收命令或验收方式】
【验收结果】通过 x/x；失败 x；阻断项 x
【是否触发高风险动作】企业微信真实发送/n8n/券商接口/自动交易/正式库写入：是或否
【进度影响建议】是否建议调整系统进度、剩余工时、原因
【冲突风险】是否与其他框修改同一核心文件、是否与口径冲突
【下一步建议】
```

## 5. 并行启动判断

允许同时启动 `02扩展系统`、`01智能系统`、`03进化系统` 三个施工框，但必须满足：

- 三个框分别在自己的系统目录施工，不互相改文件。
- 不由子系统框直接修改总管共享口径文件，只提交回收格式。
- 不启动高风险动作：企业微信真实发送扩大、n8n、券商接口、自动交易、正式库写入。
- 任一框发现需要跨系统修改，必须停止并回报总管定盘。
- 总管作为唯一回收方，统一读取证据、判断冲突、决定是否调整进度。

结论：`允许启动下一批并行框`。建议并行启动顺序为 `02扩展/知识库可追溯问答`、`01智能系统中台补齐`、`03进化规则沉淀`，同时保留 `00总管` 作为定盘和回收框。
