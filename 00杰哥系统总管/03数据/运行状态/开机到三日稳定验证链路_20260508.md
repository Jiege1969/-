# 开机到三日稳定验证链路

- 生成时间：2026-05-08
- 风险等级：W1/R0
- 目的：把用户提出的“从开机启动自检开始”纳入正式稳定版验证口径。

## 一、验证链路

```text
开机
  -> Windows 计划任务触发开机施工准备自检
  -> 生成 startup_construction_preflight_latest.md/json
  -> 判断机器、Docker、Ollama、Redis、n8n、关键端口是否就绪
  -> Codex 接续读取当前施工面板和一键接续包
  -> 执行日常可用交付版一键只读总回归
  -> 执行红线扫描
  -> 生成当天自然日样本
  -> 三个不同自然日样本全部通过后执行 FS-08
  -> 生成正式稳定交付达标建议书
```

## 二、明天用户怎么做

1. 正常开机。
2. 等桌面右下角开机自检状态提示。
3. 打开 Codex 回到本对话。
4. 说：“继续”或“开始执行 5月9日第二自然日样本”。
5. 我先读取开机自检报告，再执行只读命令清单。

## 三、如果开机自检失败

- 不采自然日样本。
- 不进入正式稳定达标。
- 先记录失败项。
- 按问题级别进入 FS-03 问题回收。

## 四、如果开机自检通过但只读总回归失败

- 当天不计入三日达标。
- 生成问题回收记录。
- 修复后等下一个真实自然日重新采样。

## 五、如果两层都通过

- 生成当天真实自然日样本回执。
- 2026-05-09 计入第二自然日。
- 2026-05-10 计入第三自然日。
- 三日齐备后执行 FS-08。
