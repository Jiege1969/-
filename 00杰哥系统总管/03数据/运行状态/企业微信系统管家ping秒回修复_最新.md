# 企业微信系统管家 ping 秒回修复

生成时间：2026-05-05 19:23

## 问题

手机企业微信对【杰哥系统管家】发送 `ping` 后，先返回“请稍后”，随后返回 `LLM request timed out.`。

判断：入口链路有响应，但 `ping` 没有被锁定为总管确定性健康检查，存在被上游转入 LLM 链路后超时的风险。

## 已修复

1. `19310` 企业微信统一指令本地服务新增 `ping` 快速路径。
2. `ping`、`PING`、`ping一下`、`在吗`、`在线吗` 等输入不再进入模型链路，直接由总管本地健康检查回复。
3. 补齐 `/wecom/system-manager` 路径，使【杰哥系统管家】登记路径可直接进入 `19310`。
4. 路由规则把 `ping`、`在线`、`系统管家` 纳入系统状态类关键词。
5. 启动脚本改为优先使用真实 Python 可执行文件，避免 Windows `python` 别名留下重复壳进程。
6. 停止脚本修复 `$PID` 变量冲突，后续可正常停止 `19310` 服务。

## 验收

- `19310/health`：正常。
- `POST /command text=ping`：约 0.44 秒返回。
- `POST /wecom/system-manager text=ping`：约 0.43 秒返回。
- 当前 `19310` 仅 1 个 Python 服务进程监听。
