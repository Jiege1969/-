# 第二轮并行核实任务书

生成时间：2026-05-06

## 1. 背景

第一轮“摸清家底找差距”已经完成骨架、血脉、基因、证据四线并行核实，并完成 P0 三张台账：

- n8n 工作流总台账。

- F 盘系统备份总台账。

## 2. 本轮并行任务

| 任务 | 核实主题 | 目标 |
|---|---|---|
| E | 公网反向隧道守护 | 判断如何守护企业微信公网回调链路，避免 `18080 -> 19302` 掉线 |
| F | Docker 卷/旧镜像归属 | 判断旧卷、旧镜像、旧资产是否可作为清理候选 |

| H | 版本锁定和依赖风险 | 固化 Python/Node/Docker/n8n/Ollama/Redis 版本治理 |
| I | 目录编号和说明缺口 | 解释 `02扩展`、`03进化` 同层编号冲突，提出低风险说明方案 |

## 3. 边界

本轮只读核实，不做以下动作：

- 不重启服务。
- 不触发 n8n。
- 不发送企业微信真实消息。
- 不调用券商接口。
- 不删除 Docker 卷、镜像、模型、数据库、备份或日志。
- 不搬目录。

## 4. 收口标准

每条线必须输出：

- 当前事实。
- 证据路径或命令。
- 风险判断。
- 是否可直接施工。
- 若可施工，必须说明安全边界和验收口径。
