# 企业微信回调 403 排查

生成时间：2026-05-05 21:14

## 现象

用户在企业微信后台填写工作秘书 URL：`http://43.167.210.211/wecom/work-secretary` 时，企业微信提示：请求 URL 失败，HTTP 返回码 403。

## 判断

公网 URL 普通访问返回 200，说明公网、nginx、SSH 反向隧道和本机 19302/19310 路由均可达。

403 主要发生在企业微信后台 URL 校验阶段：后台会带 `msg_signature/timestamp/nonce/echostr` 请求本机，本机按 Token 和 EncodingAESKey 解密校验。若后台填写的 Token/AESKey 与本机私密配置不一致，本机会按安全规则返回 403。

## 已处理

已生成本机可直接用于后台校验的配置文件：

`C:\Users\Administrator\Desktop\企业微信回调配置_工作秘书_视频助理_请勿外传.txt`

文件内包含工作秘书和视频助理各自的 URL、Token、EncodingAESKey。

## 注意

如果企业微信后台只显示 Bot ID + Secret，没有 URL、Token、EncodingAESKey 配置项，说明该入口是智能机器人长连接模式，不应填公网 URL。

如果后台允许 URL 回调配置，则必须使用本机文件中的 Token/AESKey；如果在后台点击了随机生成 Token/AESKey，必须再同步回本机，否则仍会 403。

## 安全边界

本次只生成本机私密配置提示文件，未触发 n8n，未发送企业微信消息，未调用券商接口，未自动交易，未自动发布视频。
