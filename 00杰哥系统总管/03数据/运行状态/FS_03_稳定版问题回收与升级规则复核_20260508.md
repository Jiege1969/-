# FS-03 稳定版问题回收与升级规则复核

- 生成时间：2026-05-08
- 风险等级：W1/R0
- 用途：正式稳定交付版样本采集期间，如果只读巡检、复验或总回归出现失败，用统一口径回收问题。

## 一、问题分级

| 级别 | 条件 | 处理 |
|:---|:---|:---|
| P0 | 红线命中、正式库写入、真实外发、n8n触发、交易、税务办理、视频发布、服务脚本被改或重启 | 立即暂停正式稳定达标，不计入当日样本 |
| P1 | 只读巡检或总回归失败数大于 0 | 当日不计入通过样本，生成问题回收记录 |
| P2 | 字段缺失、样本来源不清、时间戳不完整 | 补证据后再判断，补不齐则不计入 |
| P3 | 文案口径不一致但不影响只读结果 | 记录修正，不阻断当日样本 |

## 二、P1 细分规则

P1 不得再机械等同处理。先按问题性质拆分，再决定是否允许同日修复后复核：

| 子类 | 条件 | 处理 |
|:---|:---|:---|
| P1-A 真实稳定退化 | 核心依赖不可用、服务持续异常、数据链断裂、红线边界不清、修复需要大范围改造 | 原始样本不入账，修复后等待下一真实自然日 |
| P1-B 局部职责/路由缺口 | 依赖链通过、红线为 0、失败项可定位到单一入口或单一职责分流、修复范围小、复验能覆盖原失败项 | 原始失败保留；允许生成同日修复后复核回执，复核通过后可作为当日候选样本补入账 |
| P1-C 巡检口径偏差 | 业务实际可用，失败来自巡检期望口径过严、字段命名或文案口径不一致 | 原始失败保留；校准巡检口径并复验，复验通过后可作为当日候选样本补入账 |
| P1-D 证据不足 | 不能证明问题边界、修复范围或复验覆盖 | 不入账，补证据后再判断 |

同日修复后复核必须同时满足：

1. 不改写原始失败回执。
2. 问题根因明确，且不是红线、交易、税务办理、正式库、n8n、真实外发、视频发布。
3. 修复动作有回执，修复范围可追溯。
4. 复验覆盖原失败项和总回归。
5. 复验结果为 pass，失败数为 0。
6. 红线扫描为 0。
7. 不用同日多次复跑冒充多个自然日，只允许同一自然日形成一个候选样本。
8. 复核回执必须明确说明：这是“同日修复后复核入账”，不是删除或覆盖原始失败。

## 三、升级规则

1. 任一 P0：直接暂停正式稳定版达标流程，必须人工确认后再继续。
2. 任一 P1：先按 P1-A/B/C/D 分型；P1-A 和 P1-D 不入账并等待下一真实自然日；P1-B 和 P1-C 可按同日修复后复核机制判定是否补入账。
3. 任一 P2：允许补证据；补证据不得补未来样本。
4. P3：可在当天修正口径，但不得改写原始巡检事实。

## 四、回收记录必要字段

- 问题编号
- 发现日期
- 来源样本
- 问题级别
- P1 子类
- 失败项或冲突项
- 是否红线
- 是否影响当日样本计入
- 处理建议
- 人工确认状态
- 是否允许同日修复后复核
- 同日复核结论
