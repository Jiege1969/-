# 企业微信系统管家公网桥接打通

生成时间：2026-05-05 19:50

## 触发问题

手机企业微信对【杰哥系统管家】发送 `系统状态` 后仍返回 `LLM request timed out.`。

## 判断

`19310` 本地系统管家入口在 19:42 未收到访问记录，说明手机端消息没有进入本地总管。

进一步检查发现：

- 股票机器人公网链路正常，云端 `18080` 通过 SSH 反向隧道转到本机 `19302`。
- 云端 nginx 原先只配置了 `/wecom/message` 和 `/wecom-bot/message`。
- 云端原先没有 `/wecom/system-manager`，因此系统管家公网路径未打通。

## 已处理

1. 本机 `19302` 股票企业微信桥接入口新增 `/wecom/system-manager` 代理。
2. 代理目标为本机 `19310/wecom/system-manager`。
3. 云端 nginx 新增 `/wecom/system-manager` 路由，仍走现有 `18080 -> 19302` 隧道。
4. nginx 配置已 `nginx -t` 通过并 reload。
5. 云端备份已移至 `/etc/nginx/jiege-backups/`，避免被 nginx 当作启用配置读取。

## 验收

- `http://43.167.210.211/wecom/system-manager?text=ping`：通过，返回 `system-manager-ping`。
- `POST http://43.167.210.211/wecom/system-manager text=系统状态`：通过，返回 `system-manager-status`。
- 股票公网回归 `POST /wecom-bot/message text=300502`：通过，股票分析正常。
- 本机 `19302`：正常监听。
- 本机 `19310`：正常监听。

## 注意

如果手机端【杰哥系统管家】仍返回 `LLM request timed out`，说明企业微信后台里这个机器人仍未配置到：

```text
http://43.167.210.211/wecom/system-manager
```

公网和本机服务已准备好，剩余就是企业微信后台机器人入口绑定问题。
