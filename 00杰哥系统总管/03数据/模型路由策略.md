# 模型路由策略

创建日期：2026-04-26

## 一、目标

让系统根据任务类型、响应速度、显存占用和稳定性自动选择合适模型。

模型路由不是追求所有任务都调用最大模型，而是在稳定运行前提下充分发挥 RTX 3090 24GB 的优势。

## 二、模型分层

| 层级 | 代表模型 | 用途 |
|---|---|---|
| 快速模型 | `qwen2.5:7b`、`deepseek-r1:7b` | 状态解释、短问答、低风险任务 |
| 日常模型 | `qwen3:14b` | 日常对话、知识库问答、普通总结 |
| 深度模型 | `qwen3:30b`、`deepseek-r1:32b` | 深度分析、复杂推理、策略复盘 |
| 代码模型 | `qwen3-coder:30b` | 代码分析、脚本生成、系统维护建议 |
| 视觉模型 | `gemma3:27b` | 图片理解、截图分析、图文任务 |
| 金融模型 | `mychen76/Fin-R1:Q5`、`finance-llama-8b` | 股票研究补充解释 |

## 三、任务路由建议

| 任务类型 | 首选路线 | 兜底路线 |
|---|---|---|
| 健康检查 | 规则引擎直接输出 | 快速模型解释 |
| 普通聊天 | 日常模型 | 快速模型 |
| 深度分析 | 深度模型 | 日常模型 |
| 股票单股分析 | 股票服务 + 日常模型 | 股票服务 + 金融模型 |
| 股票批量筛选 | 股票服务批处理 + 队列 | 结果摘要用日常模型 |
| 知识库问答 | 检索 + 日常模型 | 检索 + 深度模型 |
| 视频总结 | 语音识别 + 日常模型 | 语音识别 + 深度模型 |
| 代码维护 | 代码模型 | 深度模型 |
| 图片理解 | 视觉模型 | 人工确认 |

## 四、显存策略

1. 30B 级模型默认不并发。
2. 显存占用高时，大任务进入队列，普通任务降级到 7B 或 14B。
3. 显存长期空闲超过 50% 时，系统可建议提升默认模型。
4. 模型切换必须记录任务类型、模型名、耗时和是否成功。
5. 不允许多个业务模块各自绕过模型路由直接调用大模型。

## 五、v3 第一阶段策略

第一阶段先实现静态规则路由，不做复杂自动学习。

后续由 `03杰哥进化系统\03模型评测` 定期生成模型效果建议，再人工确认是否调整默认策略。
