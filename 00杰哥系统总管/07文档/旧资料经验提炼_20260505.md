# 旧资料经验提炼

生成日期：2026-05-05

本文件是旧资料清理后的唯一学习材料。原“历史经验”“旧系统退役”“D盘瘦身”和旧 WSL2 专项资料不再作为施工输入，已按用户要求归集提炼后删除。

## 当前口径

- 当前系统唯一正式根目录是 `D:\杰哥智能化系统`。
- `D:\01杰哥智能系统` 和 `/mnt/d/01杰哥智能系统` 是已禁用、已清理的旧路径，不得作为运行路径、脚本输入、挂载来源或新系统参考骨架。
- 系统搭建以当前机器上的配置、脚本、运行状态报告和实时只读验收为准；历史文档不能替代当前检查。
- 旧资料如需学习，只吸收方法，不复用旧命令、旧路径、旧容器名、旧端口和旧挂载。

## 提炼经验

1. 删除目录前先查 Docker 容器定义和 bind mount；已退出容器也可能在再次创建或启动时自动补建宿主目录。
2. 文件系统存在性、Docker 元数据、运行中容器健康状态要一起验收，不能只看目录是否存在。
3. 旧路径资料如果继续留在当前文档树，会被误读为现行规则，应提炼成少量原则后删除原件。
4. 正式系统目录、v3 容器、镜像、卷和运行服务是边界对象；清理旧资料不能影响它们。
5. 旧资料中的模型、数据库、备份和密钥线索不得自动迁入当前系统。

## 保留安全规则

- 不创建 `D:\01杰哥智能系统`。
- 不恢复旧 `ollama`、`n8n` 容器定义。
- 不把旧系统退役报告、D盘瘦身报告、历史经验白皮书作为后续搭建依据。
- 不停止 `jiege_v3_ollama`、`jiege_v3_redis`、`jiege_v3_n8n`。
- 不重启 `19300/19302`，不触发 n8n，不发送企业微信，不写正式库，不调用券商接口，不自动交易。

## 后续使用

后续如果再次发现旧资料或旧路径引用，处理顺序为：

1. 判断是否为当前审计日志；审计日志只作历史记录，不作为施工输入。
2. 判断是否为可执行脚本、设计纲领、施工面板、索引或规则；这些位置如含旧路径，应立即修正或删除。
3. 必要经验补入本文件或新的当前口径规则，再删除原旧资料。
