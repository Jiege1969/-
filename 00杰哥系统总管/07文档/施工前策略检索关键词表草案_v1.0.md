# 施工前策略检索关键词表草案

> 版本：v1.0
> 状态：设计草案，不是生产规则
> 边界声明：不修改生产脚本，不接自动调用，不写正式库，不触发 n8n 或企业微信。

## 1. 用途

本表用于预研“施工前策略检索”函数的关键词匹配口径。它只描述未来检索应该关注哪些词、命中后提醒什么，不直接改变总管入口规则。

## 2. 风险关键词

| 类别 | 关键词 | 初判风险 | 提醒动作 |
|:---|:---|:---|:---|
| 删除清理 | 删除、清掉、清理、移除、覆盖、替换原文件 | W2/W3待判 | 检查是否清债；缺源头审计、资产分类、写入风险评估时只允许R0 |
| 批量文件 | 全部、所有、整个D盘、超过30天、批量 | W2/W3待判 | 要求分目录或资产类型许可，禁止直接批量删除 |
| 服务变更 | 重启、停止服务、端口、Docker、计划任务、环境变量 | W3 | 暂停，人工确认 |
| 外发动作 | 发送、推送、企业微信、邮件、发布、通知、报送 | W2/W3待判 | 触发人工闸口，不得自动外发 |
| 正式业务 | 上线、正式库、接入真实系统、启用、投产 | W3待判 | 触发开工五问或方向校准 |
| 金融交易 | 买入、卖出、下单、仓位、券商接口、目标价 | W3 | 禁止自动执行，人工确认 |
| 税务真实动作 | 申报、退税、备案、开票、电子税务局 | W3待判 | 只允许影子草案，正式动作暂停确认 |
| 办公真实动作 | OA、ERP、人事、财务系统、审批、盖章 | W3待判 | 不接真实办公系统，人工确认 |

## 3. 绿灯关键词

| 类别 | 关键词 | 初判风险 | 提醒动作 |
|:---|:---|:---|:---|
| 只读核查 | 读取、查看、核对、扫描、统计、审计 | R0 | 可直接推进，输出只读结果 |
| 总结归纳 | 总结、归纳、梳理、提炼、说明 | R0/W1 | 可直接推进，注意不写正式规则 |
| 草案设计 | 草案、预研、设计、方案、影子、样例 | W1 | 可推进，标明不是生产代码或正式业务 |
| 文档补充 | 补说明、补缘由、补索引、补待补项 | W1/W3待判 | 若改治理规则则升W3，否则作为文档草案处理 |

## 4. 扩展系统关键词

| 业务线 | 关键词 | 命中后读取 |
|:---|:---|:---|
| 税收 | 税收、税务、增值税、即征即退、政策、申报、退税 | 依据层级规则、税收影子底座、开工锚点 |
| 本职工作 | 本职工作、制度、流程、台账、材料、岗位、科室 | 依据层级规则、本职工作影子底座、开工锚点 |
| 视频 | 视频、转码、剪辑、字幕、封面、渲染、发布 | 开工锚点、母本反适配、真实动作边界 |
| 企业微信非股票 | 企业微信、主动消息、回调、可信IP | 人工闸口、开工锚点、真实外发边界 |

## 5. 冲突关键词

| 表达 | 冲突点 | 建议提醒 |
|:---|:---|:---|
| “只读修改一下” | 只读与修改冲突 | 以写入动作重新判级 |
| “影子底座上线” | 影子与上线冲突 | 暂停，执行开工五问 |
| “不用确认直接W3” | 授权与铁律冲突 | W3仍需人工确认 |
| “顺手清理” | 搭建轮次与清债冲突 | 只记录待清队列，不顺手清 |

## 6. 输出建议

命中关键词后不应输出长篇规则摘抄，只给施工执行者一个轻提醒：

```text
命中：删除/批量/日志
初判：清债风险，写入级别待判
边界：缺三份材料只允许R0
下一步：先做只读源头审计
```
