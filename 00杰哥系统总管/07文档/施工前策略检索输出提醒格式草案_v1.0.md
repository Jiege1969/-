# 施工前策略检索输出提醒格式草案

> 版本：v1.0
> 状态：设计草案，不是生产规则
> 边界声明：不修改生产脚本，不接自动调用，不写正式库，不触发 n8n 或企业微信。

## 1. 输出目标

施工前策略检索的输出应当轻、短、可执行。它不是替用户审批，而是帮助施工执行者快速知道：

- 当前请求属于绿灯、黄灯还是红灯。
- 初判风险等级是什么。
- 命中了哪些规则或锚点。
- 哪些边界不能碰。
- 下一步应该直接推进、先问用户，还是只读审计。

## 2. 字段草案

| 字段 | 含义 | 示例 |
|:---|:---|:---|
| request_type | 请求类型 | 影子草案 / 清债 / 正式开工 / 外发动作 |
| traffic_light | 三色判断 | 绿灯 / 黄灯 / 红灯 |
| risk_level | 初判风险 | R0 / W1 / W2 / W3 / 待判 |
| matched_rules | 命中规则 | 施工铁律v3.1、SA-005、母本模板 |
| boundary | 必须守住的边界 | 不外发、不接正式库、不自动删除 |
| next_step | 建议下一步 | 直接推进 / 先做五问 / 暂停确认 / R0审计 |
| user_questions | 需要用户确认的问题 | 资料来源是否授权？是否进入正式系统？ |

## 3. Markdown模板

```text
策略检索提醒
- 请求分类：{request_type}
- 三色判断：{traffic_light}
- 初判风险：{risk_level}
- 命中规则：{matched_rules}
- 必须边界：{boundary}
- 建议下一步：{next_step}
- 待确认问题：{user_questions}
```

## 5. 三色样例

### 绿灯

```text
策略检索提醒
- 请求分类：只读核查
- 三色判断：绿灯
- 初判风险：R0
- 命中规则：只读优先、施工铁律R0定义
- 必须边界：不写入、不删除、不触发外部系统
- 建议下一步：直接只读扫描并报告结果
- 待确认问题：无
```

### 黄灯

```text
策略检索提醒
- 请求分类：影子底座草案
- 三色判断：黄灯
- 初判风险：W1
- 命中规则：扩展系统开工五问、母本模板反适配
- 必须边界：影子状态，不上线，不接n8n，不外发
- 建议下一步：轻提醒边界后推进草案
- 待确认问题：是否需要进入正式业务系统
```

### 红灯

```text
策略检索提醒
- 请求分类：正式接入/真实动作
- 三色判断：红灯
- 初判风险：W3
- 命中规则：人工闸口、施工铁律W3定义、扩展系统开工锚点
- 必须边界：暂停执行，人工确认，不自动接入
- 建议下一步：汇总风险并请用户确认
- 待确认问题：是否正式开工？输入输出风险和验收是否已明确？
```

## 6. 人工确认触发条件

- 初判为 W2 或 W3。
- 命中删除、清债、批量覆盖、正式库、外发、真实系统接入。
- 命中规则冲突或依据层级冲突。
- 请求中同时出现“影子”和“上线”等互相冲突表述。
- 输入、输出、风险、验收任一项不明确。
