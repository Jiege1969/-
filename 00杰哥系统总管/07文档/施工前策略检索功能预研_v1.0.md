> 版本：v1.0
> 状态：只读设计草案，不是生产代码
> 边界声明：不修改生产脚本，不接自动调用，不写正式库，不触发 n8n 或企业微信。

## 1. 目标

在施工前，根据用户请求自动检索相关治理规则、策略锚点、母本模板和当前接续状态，输出轻量提醒，帮助施工执行者先判定风险、边界和下一步动作。

本预研只定义未来函数应该读什么、怎么匹配、输出什么，不实现生产代码。

## 3. 关键词匹配建议

| 关键词类型 | 示例关键词 | 命中后提醒 |
|:---|:---|:---|
| 清债/删除 | 清掉、删除、清理旧日志、覆盖、移动 | 切换清债许可判断；缺三份材料只允许 R0 |
| 正式开工 | 搭建系统、上线、接入、启用、正式库 | 触发扩展系统开工五问或人工确认 |
| 外发/真实动作 | 企业微信、发送、发布、申报、报送、审批 | 触发人工闸口；禁止自动执行 |
| 服务变更 | 端口、Docker、重启、计划任务、环境变量 | 判断为 W3；暂停确认 |
| 文档/影子 | 草案、影子底座、样例、资料整理 | 黄灯或绿灯推进，保持影子边界 |
| 策略/规则 | 施工铁律、JSON配置、总管规则、母本模板 | 判断是否规则变更，必要时 W3 |
| 税收依据 | 税收、政策、申报、退税、增值税、即征即退 | 读取依据层级规则和税收影子底座边界 |
| 本职工作 | 制度、流程、台账、材料、岗位、科室 | 读取依据层级规则和本职工作影子边界 |

## 4. 输出格式建议

```text
策略检索提醒
- 请求分类：绿灯/黄灯/红灯
- 初判风险：R0/W1/W2/W3
- 命中规则：文件 + 条目
- 必须边界：禁止动作/人工确认点
- 建议下一步：直接推进/先问用户/只读审计/进入开工五问
- 待补问题：需要用户确认的最小问题
```
