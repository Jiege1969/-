# 建议新增模型下载命令

## 推荐命令

```powershell
ollama pull bge-m3
ollama pull qwen3-embedding:4b
ollama pull sam860/qwen3-reranker:0.6b-Q8_0
```

## 用途说明

- `bge-m3`：知识库向量检索、中文政策文件检索、多语言资料检索。
- `qwen3-embedding:4b`：高质量向量检索，作为 `bge-m3` 的增强或备选。
- `sam860/qwen3-reranker:0.6b-Q8_0`：对初步召回的资料进行重排序，提高知识库问答证据命中率。

## 安全边界

本文件只记录下载命令。模型下载由用户手动执行；系统不自动拉取模型、不删除模型、不切换生产配置。
