# 命名规范

创建日期：2026-04-26

## 一、中文可读优先

面向用户和运维人员的目录、Markdown 文档，优先使用中文命名。

示例：

```text
服务注册表.md
模型路由策略.md
股票研究系统设计.md
```

## 二、机器读取优先 ASCII

脚本和机器读取配置，优先使用 ASCII 文件名和 ASCII 脚本主体。

原因：

PowerShell 5 对无 BOM UTF-8 中文脚本可能误读，导致语法错误。

示例：

```text
machine/service_registry.json
machine/health_rules.json
```

## 三、编号规则

系统和模块使用数字编号：

```text
00杰哥系统总管
01杰哥智能系统
02杰哥扩展系统
03杰哥进化系统
09迁移暂存
```

业务模块：

```text
01股票研究系统
02视频制作系统
03本职工作系统
04内容处理系统
```

## 四、脚本规则

PowerShell 脚本：

1. 文件名可以中文。
2. 脚本主体尽量 ASCII。
3. 中文说明放 Markdown。
4. 中文 HTTP 路径使用 URL 编码。
5. 中文路径优先通过相对路径推导。

## 五、禁止事项

1. 禁止使用含义不明的临时命名，例如 `new1`、`test2`。
2. 禁止同级目录出现功能重复名称。
3. 禁止用 `final_final`、`备份2` 这类不可追溯命名。
4. 禁止机器配置文件混用多个命名风格。
