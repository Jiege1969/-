## 一、当前脚本

### 只读状态检查.ps1

路径：

`D:\杰哥智能化系统\00杰哥系统总管\02脚本\只读状态检查.ps1`

作用：

1. 只读采集磁盘、GPU、Docker、端口、HTTP 健康检查、v3 文件统计。
2. 将状态快照写入 v3 自己的 `03数据\状态快照`。
3. 将简要日志写入 v3 自己的 `04日志\状态检查`。

不做的事：

1. 不停止服务。
2. 不重启服务。
3. 不修改旧系统。
4. 不读取密钥。
5. 不迁移模型或数据库。

执行方式：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File "D:\杰哥智能化系统\00杰哥系统总管\02脚本\只读状态检查.ps1"
```

## 二、脚本编码规范

PowerShell 5 在无 BOM UTF-8 脚本中容易误读中文字符串。

因此 v3 第一阶段规定：

1. PowerShell 脚本主体尽量使用 ASCII。
2. 中文说明优先写入 Markdown 文档。
3. 需要访问中文目录时，优先用脚本相对路径推导，不在脚本中硬编码中文路径。
4. HTTP 中文路径使用 URL 编码。
