# 操作安全规范

创建日期：2026-04-26

## 一、低风险操作

以下操作可直接执行：

1. 在 `D:\杰哥智能化系统` 内新增空目录。
2. 在 `D:\杰哥智能化系统` 内新增说明文档。
3. 只读查看服务状态、端口、磁盘、GPU、Docker 容器。
4. 只读查看非密钥文档。

## 二、需要谨慎但可评估后执行的操作

以下操作必须先输出影响评估：

1. 复制旧系统文档到 v3。
2. 复制非密钥配置模板到 v3。
3. 新建只读检查脚本。
4. 新建未接入生产的测试脚本。
5. 新增不启动的 docker-compose 草案。

## 三、必须等待用户确认的操作

以下操作必须等待用户明确确认：

1. 删除文件或目录。
2. 覆盖已有文件。
3. 移动模型、数据库、n8n 数据。
4. 停止、重启、删除容器或服务。
5. 修改开机自启、计划任务、systemd 服务。
6. 读取或复制 `.env`、密钥、API Token。
7. 清理 Docker 资源。
8. 修改任何 05备份 目录。

## 四、操作前置评估格式

执行中高风险操作前必须说明：

1. 操作目标
2. 受影响路径
3. 当前状态只读检查
4. 风险点
5. 回滚方案
6. 验证方法
7. 是否需要用户确认
