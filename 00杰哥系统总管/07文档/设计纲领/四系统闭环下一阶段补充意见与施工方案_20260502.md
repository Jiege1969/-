# 四系统闭环下一阶段补充意见与施工方案

生成时间：2026-05-02 21:18

## 一、阶段定位

下一阶段的目标不是继续堆功能，而是把四个子系统形成稳定、可复用、可交接的最小闭环。

当前样板业务只选择股票分析系统，不展开税收、本职工作、内容处理、视频制作等其他扩展业务。

四系统闭环标准链路：

```text
00总管定方向、边界和验收
-> 01智能系统保障模型、服务、企业微信桥接和运行时
-> 02扩展系统/股票承载真实业务、报告、前台问答和验收
-> 03进化系统沉淀问题、经验、规则和方法
-> 00总管更新日志、接续、计划和下一轮任务
```

## 二、必须补充的口径

### 1. 机器自动闭环和人工闭环分开

机器可以自动执行：

- 开工状态检查。
- 日常一键刷新。
- 完全交付、C+++、企微回归、四系统小闭环验收。
- 状态面板、日报、证据入口、复盘提醒、接续记录生成。

人工必须参与：

- 公司概况、事件风险、行业景气证据核验。
- 判断复盘到期后的真实验证结果填写。
- 是否正式导入证据。
- 是否真实发送企业微信。
- 是否调整规则、评分、排序或前台策略口径。

### 2. 股票系统是唯一真实样板场

当前不做“全业务铺开”。股票系统跑顺后，再把方法沉淀为全系统通用规则。

### 3. 验收口径固定

每次阶段完成至少确认：

- 股票完全交付最终验收：5/5。
- C+++ 日常可用总验收：当前最新 21/21。
- 企微前台交互回归：37/37。
- 日常一键运行：失败 0。
- 四系统股票小闭环：4/4 环节通过，失败 0。
- 19300、19302 监听正常，公网回调 ready。

### 4. 进化系统必须沉淀为规则

每个真实问题修复后，至少沉淀：

- 问题现象。
- 根因判断。
- 防复发验收项。
- 可复用经验卡片或方法文件。

### 5. 接续包刷新节奏

小步骤只更新日志、接续卡片和必要面板。

阶段收工、关键交接、准备换对话、用户明确要求时，再刷新桌面全系统 AI 无缝接手包。

## 三、下一阶段施工顺序

1. 固化四系统闭环分工和人工闸口。
2. 围绕股票系统继续推进证据链人工核验：189 入口 -> 190 单股工作包 -> 172/175/178 人工填写 -> 173/176/179 预览 -> 181 导入闸口。
3. 到 2026-05-07 后处理首批 T5 判断复盘：188 清单 -> 人工验证结果 -> 复盘学习状态面板。
4. 每轮施工后跑 C+++、企微回归、四系统小闭环。
5. 把新增规则写回总管接续和进化经验。

## 四、安全边界

未经用户明确确认，不得执行：

- 删除或迁移大目录。
- 覆盖正式档案。
- 写正式库。
- 真实企业微信发送。
- 启用 n8n 自动触发。
- 重启公网隧道或影响正式服务。
- 调用券商接口。
- 自动交易。

股票系统永远是研究辅助系统，不是自动交易系统。
