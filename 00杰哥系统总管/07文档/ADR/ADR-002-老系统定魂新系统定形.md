# ADR-002：老系统定魂，新系统定形

日期：2026-04-26

## 状态

已采纳。

## 背景

老系统沉淀了宪章、纲领、白皮书、踩坑经验和四系统架构思想。

当前 `D:\杰哥智能体操作系统` 已经跑通网关、大脑、股票服务、语音服务、Ollama、PostgreSQL、Redis、n8n 等工程能力。

## 决策

v3 不推倒重来，也不原样照搬旧系统。

采用：

```text
老系统定魂，新系统定形
```

## 后果

1. 老系统文档作为历史经验副本纳入 v3。
2. 当前新系统作为 v2.5 工程验证区，后续分模块吸收。
3. 旧脚本不直接执行，必须重新评估路径、容器名、端口和风险。
