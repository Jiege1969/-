# ADR-005：模型路由是核心能力

日期：2026-04-26

## 状态

已采纳。

## 背景

本机硬件具备 RTX 3090 24GB 显存和 64GB 内存，适合运行多档本地模型。

固定调用单一模型会浪费硬件优势，也会导致长任务阻塞普通任务。

## 决策

v3 必须建设模型路由能力。

不同任务调用不同模型：

1. 快速任务用 7B。
2. 日常任务用 14B。
3. 深度任务用 30B/32B。
4. 代码任务用 coder 模型。
5. 图片任务用视觉模型。
6. 股票任务可结合金融模型。

## 后果

1. 业务模块不得绕过模型路由直接调用大模型。
2. 30B 级模型默认不并发。
3. 模型策略由 03 模型评测模块持续提出建议，但生产切换必须人工确认。
