# 扩展系统开工锚点

> 版本：v1.0  
> 生效日期：2026-05-07  
> 适用范围：税收、视频、本职工作、企业微信非股票业务及其他扩展系统  
> 定位：正式开工前的硬性提醒，不是系统自动开发能力声明
> 来源锚点：策略锚点库 SA-005《扩展系统开工五问》

## 1. 核心规则

凡涉及扩展系统从“预留 / 影子 / 样例”进入“正式搭建 / 可用功能 / 上线联动”时，当前施工执行者必须暂停直接施工，先与用户完成需求、输入输出、风险边界、阶段目标和验收标准讨论。

总管系统当前只负责记录和提醒，不具备独立开发、独立批准或自动施工能力。

## 2. 触发场景

以下表达均触发本锚点：

- 开始搭建税收系统、税务系统、本职工作系统、视频制作系统等扩展系统。
- 将影子样例变成正式可用功能。
- 接入 n8n、企业微信、正式库、外发链路或自动化链路。
- 对非股票业务启用通知、发布、申报、渲染、转码、抓取等真实动作。
- 将股票系统母本经验迁移到新业务线。

## 3. 开工五问

正式搭建前必须讨论清楚：

1. 需求：这个系统要解决什么具体问题？
2. 输入：数据从哪里来？格式是什么？是否有授权或来源限制？
3. 输出：产物给谁用？保存在哪里？是否外发或入库？
4. 风险：哪些动作绝对不能自动做？哪些必须人工确认？
5. 验收：第一阶段做到什么程度算完成？什么情况必须降级或闭口？

五问没有明确答案，只允许 R0 只读调研、目录预留、理念沉淀，不允许正式搭建。

## 4. 股票母本使用边界

股票系统是成熟母本，但不是扩展系统的模板套壳。

允许复用：

- 只读预检。
- 人工闸口。
- 失败闭口。
- 接续包。
- 回滚意识。
- 证据链与复核。

禁止机械照搬：

- 高频刷新。
- 企业微信实时推送。
- n8n自动触发。
- 硬 fail-closed 到所有内容场景。
- 真实业务动作默认放行。

## 5. 当前扩展样例定性

前期税收、内容、视频相关产物统一定性为：

> 影子样例 / 方法验证材料 / 非正式业务能力。

它们可以作为讨论材料和母本适配参考，但不能被视为已经正式搭建完成。

## 6. 施工执行者约束

当用户提出扩展系统正式搭建请求时，当前施工执行者不得直接进入文件创建、脚本编写、链路接入或功能上线。必须先进入讨论，形成开工五问答案和阶段方案。

本规则约束施工执行者和总管入口提示，不声称当前系统具备独立开发能力。
