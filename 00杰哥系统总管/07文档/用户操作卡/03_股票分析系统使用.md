# 股票分析系统使用

股票系统现在定位为分析系统，只做研究、问答、报告、风险提示和复盘。不连接券商接口，不下单，不自动交易，不生成交易委托。

手机端用法：

- 对【杰哥股票分析助手】发：`分析 股票代码`，例如 `分析 300502`。
- 也可以发股票名称，例如 `分析 新易盛`。
- 系统会返回短回复，必要时带图文详情入口。

看报告时重点看四块：

1. 当前判断：是否推荐、观察或谨慎。
2. 参考价位：承接区、转强线、风险线。
3. 成交标准：是否达到活跃或明显活跃。
4. 风险提示：哪些条件不成立就不能追。

不要把系统回复理解成买卖指令。含“买入、卖出、下单、仓位、券商、交易”等表达会被硬闸门拦截。允许问“观察条件、风险线、转强条件、失效条件”，但最终决策必须人工判断。
