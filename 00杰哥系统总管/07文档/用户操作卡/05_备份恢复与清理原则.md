# 备份恢复与清理原则

清理原则：能判断的旧启动项要果断处理；不能判断的数据目录先做证据包，不直接删。

可以直接清理：

- `__pycache__`。
- 打包缓存 `build`、临时 `spec`。
- 空日志、失效 pid。
- 明确的启动验证临时日志。

不能直接清理：

- `.venv`。
- 模型目录。
- Docker 数据目录。
- n8n、Redis、数据库数据。
- 股票正式数据、正式报告、备份归档。
- 旧系统容器挂载数据。

旧 `jiege_*` Docker 容器目前是退出态，不影响当前系统运行，但挂载数据仍有历史引用。下一步应生成“旧容器退役候选包”：先列容器、镜像、挂载、引用证据，再区分容器可删、数据保留、数据可归档三类。

恢复时先确认当前主线：`D:\杰哥智能化系统`。不要把旧目录 `D:\杰哥智能体操作系统` 当成当前主线恢复。
