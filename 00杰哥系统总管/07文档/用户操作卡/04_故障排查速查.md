# 故障排查速查

如果企业微信没反应：

1. 先对【杰哥系统管家】发 `ping`。
2. 如果系统管家也没回，看公网回调和反向隧道。
3. 如果系统管家回、股票不回，看 `19302` 和 `19300`。
4. 如果工作秘书或视频助理不回，看 `/wecom/work-secretary`、`/wecom/video-assistant` 和 `19310`。

如果回复很慢：

1. 看 Ollama 是否可用：`http://127.0.0.1:29134/api/tags`。
2. 看是否正在加载大模型。
3. 看电脑是否正在剪视频、打游戏、跑批处理或占用 GPU。

如果开机弹黑窗口：

当前主线任务不应弹黑窗口。优先检查是否又出现旧启动项、桌面启动文件夹脚本、注册表 Run 项或旧系统任务。

如果磁盘空间紧张：

优先清理缓存、打包中间产物、过期临时日志。不要直接删模型、Docker 数据、n8n 数据、Redis 数据、股票正式数据和备份归档。
