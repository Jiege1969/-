# 企业微信机器人使用

当前企业微信机器人统一走公网 URL 回调，不再使用长连接。

常用机器人：

- 【杰哥系统管家】：问系统状态、自检、进度、故障。常用：`ping`、`系统状态`、`自检`。
- 【杰哥股票分析助手】：问单股分析。常用：`分析 300502`、`分析 新易盛`。
- 【杰哥工作秘书】：问材料整理、文稿处理、知识库问答。
- 【杰哥视频助理】：问视频脚本、素材整理、发布计划。

如果机器人没回话，先不要重启一堆服务。按链路判断：

1. 企业微信后台是否仍填当前公网 URL。
2. 云服务器 Nginx 是否能访问。
3. 反向隧道 `43.167.210.211:80 -> 云端127.0.0.1:18080 -> 本机127.0.0.1:19302` 是否通。
4. 本机 `19302` 和 `19310` 是否健康。

本次经验：手机没回话不一定是大模型慢。2026-05-05 晚上发生过企业微信请求已到公网，但 云端 `18080` 反向隧道短时断开，Nginx 返回 502。以后优先按这条链路查。
