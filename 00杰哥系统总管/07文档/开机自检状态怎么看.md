# 开机自检状态怎么看

开机后系统会在后台自动做自检，不弹黑色终端窗口。

自检完成后，桌面右下角会出现一个小状态动画卡。成功时显示：

`杰哥，您好！智能系统已经为您准备好了！`

- 绿色：启动成功，几秒后自动关闭。
- 黄色：自检完成但有项目需要查看。
- 红色：没有读到自检报告或启动异常。

你要确认是否启动成功，只看这个文件：

`D:\杰哥智能化系统\00杰哥系统总管\03数据\开机施工准备\startup_construction_preflight_latest.md`

打开后看三项：

- `Ready for Codex construction: True`：说明总管开机自检通过。
- `V3 AI base healthcheck: True`：说明 Docker、Ollama、Redis、n8n 等基础链路已就绪。
- `Warnings: none`：说明没有需要你处理的警告。

如果看到 `False` 或 `Warnings` 下面有内容，就先不要开真实动作。把这份文件和同目录的 `startup_construction_preflight_latest.json` 留作排查证据。

正常情况下你不用打开任何终端，也不用看后台窗口。系统只写报告，并用小状态卡提示是否启动成功。
