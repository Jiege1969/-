# 目录规范

创建日期：2026-04-26

## 一、顶层目录

v3 顶层固定为：

```text
D:\杰哥智能化系统
├── 00杰哥系统总管
├── 01杰哥智能系统
├── 02杰哥扩展系统
├── 03杰哥进化系统
└── 09迁移暂存
```

## 二、标准七目录

除 `09迁移暂存` 外，每个系统和业务模块原则上采用：

```text
01配置
02脚本
03数据
04日志
05备份
06临时
07文档
```

## 三、目录职责

| 目录 | 职责 |
|---|---|
| 01配置 | 配置、配置模板、机器可读规则 |
| 02脚本 | 自动化脚本、只读检查、辅助工具 |
| 03数据 | 业务数据、状态快照、索引 |
| 04日志 | 运行日志、检查日志、操作日志 |
| 05备份 | 本系统备份，不自动清理 |
| 06临时 | 可清理临时文件 |
| 07文档 | 设计、说明、日志、ADR、验收 |

## 四、业务模块目录

业务模块位于：

```text
D:\杰哥智能化系统\02杰哥扩展系统
```

第一批模块：

```text
01股票研究系统
02视频制作系统
03本职工作系统
04内容处理系统
```

## 五、进化模块目录

进化模块位于：

```text
D:\杰哥智能化系统\03杰哥进化系统
```

第一批模块：

```text
01反馈提炼
02提示词管理
03模型评测
04系统复盘
```

## 六、禁止事项

1. 禁止在 v3 根目录随意堆放临时文件。
2. 禁止把业务代码放进 `00杰哥系统总管`。
3. 禁止把模型、数据库直接放进 `00杰哥系统总管`。
4. 禁止跨模块直接写入其他模块的 `03数据`。
5. 禁止把密钥放入文档目录。
