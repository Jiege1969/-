# 杰哥智能化系统 v3 架构蓝图草案

创建日期：2026-04-26

## 一、定位

本目录是杰哥智能化系统 v3 的新骨架。

当前阶段只作为架构落地区，不承载生产服务，不接管旧系统，不迁移模型，不迁移数据库。

## 二、总原则

1. 继承老系统的四系统架构、七目录骨架、版本锁定、复用优先、稳定优先原则。
2. 吸收当前新系统中已经跑通的网关、大脑、股票服务、语音服务、Ollama、PostgreSQL、Redis、n8n 等工程成果。
3. 所有迁移动作必须先盘点、再复制、再验证、再备案，最后才讨论清理。
4. 不触碰其他独立系统，尤其不触碰 `D:\杰哥智能系统`。

## 三、四系统职责

### 00杰哥系统总管

负责全局治理：

- 系统宪章
- 架构蓝图
- 服务注册表
- 端口分配表
- 健康检查
- 备份记录
- 迁移记录
- 禁止触碰清单

### 01杰哥智能系统

负责基础底座：

- 智能体网关
- 智能体大脑
- 模型服务
- 模型路由
- 数据库
- 缓存
- 知识库
- 工作流中心
- 统一消息出口

### 02杰哥扩展系统

负责业务能力：

- 股票研究
- 视频制作
- 本职工作
- 内容处理

所有业务模块复用 01 主系统基础能力，不重复部署 Ollama、Redis、数据库和消息出口。

### 03杰哥进化系统

负责维护升级：

- 反馈提炼
- 提示词管理
- 模型评测
- 系统复盘

进化系统第一阶段只生成建议和草案，不直接修改生产配置。

## 四、迁移原则

1. 先迁移文档副本，不迁移运行数据。
2. 先做只读检查，不启用自动修复。
3. 先建立服务注册表和端口分配表，再迁移 Compose。
4. 先保留旧模型库和新模型库，不合并、不删除。
5. 任何删除、覆盖、重装、清理都必须单独确认。
