# 健康检查规则说明

创建日期：2026-04-26

## 一、定位

健康检查规则用于指导 v3 总管如何判断系统状态。

第一阶段只检查，不修复。

## 二、严重级别

| 级别 | 含义 |
|---|---|
| P0 | 阻断，v3 基础不可用 |
| P1 | 核心能力异常 |
| P2 | 业务能力异常或风险提醒 |
| P3 | 信息记录 |

## 三、当前重点

1. v3 目录是否存在。
2. 当前新系统核心服务是否健康。
3. 新 Ollama 是否可用。
4. n8n 是否可用。
5. v3 智能体大脑测试服务是否可用。
6. 旧 Ollama 是否仍绑定 `0.0.0.0:11434`。

## 四、边界

健康检查不等于自愈。

任何自动修复动作必须等 v3 接管策略明确后再设计。

## 五、v3测试服务补充

`v3智能体大脑测试服务` 已纳入健康检查，地址为 `http://127.0.0.1:28100/health`。该检查只代表第一阶段测试服务状态，不代表 v3 已接管生产流量。
