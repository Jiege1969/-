# ripgrep 本地独立版使用说明

## 安装原因

Codex 桌面应用自带的 `rg.exe` 位于 `C:\Program Files\WindowsApps\OpenAI.Codex_...\app\resources\rg.exe`，当前 PowerShell 环境启动它时会报 `Access is denied`。

为避免影响系统环境，本目录放置独立版 ripgrep，不修改全局 PATH，不替换系统文件。

## 当前可用路径

`D:\杰哥智能化系统\00杰哥系统总管\06工具\ripgrep\15.1.0\rg.exe`

## 使用方式

后续搜索优先使用完整路径：

```powershell
& 'D:\杰哥智能化系统\00杰哥系统总管\06工具\ripgrep\15.1.0\rg.exe' -n '关键词' 'D:\杰哥智能化系统'
```

## 安全边界

- 未修改全局 PATH。
- 未覆盖 Codex 自带 `rg.exe`。
- 未删除或移动现有系统文件。
- 不影响 n8n、企业微信、Ollama、Redis、数据库或股票业务脚本。
