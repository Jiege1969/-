# 00杰哥系统总管

## 定位

本系统负责 v3 的全局治理。

它不承载具体业务，不直接执行股票、视频、本职工作等任务。

## 主要职责

1. 维护宪章、蓝图、服务注册表、端口分配表。
2. 维护禁止触碰清单和迁移路线图。
3. 建立健康检查、状态汇总、备份索引。
4. 记录工作日志、迁移记录、风险清单。

## 目录编号说明

本系统存在历史例外：`06工具` 与 `06临时` 同层双 `06`。

- `06工具` 是人工入口、运维入口、可视化工具和辅助工具区。
- `06临时` 是中间文件、候选清理、短期试验和可删除前复核区。

短期不搬目录，避免破坏既有脚本、计划任务和报告引用。后续如需重构，应先建立新路径、兼容旧路径、全量引用检查，再分批迁移。

## 禁止事项

1. 不直接存放业务代码。
2. 不直接存放模型文件。
3. 不直接存放数据库。
4. 不绕过用户确认执行删除、覆盖、重启、清理等动作。

当前允许自动执行的动作仅限低风险只读巡检、状态采集、日志记录、已配置的隐藏守护任务；删除、覆盖、正式升级、真实外发、n8n 正式执行、券商接口和自动交易仍保持硬闸门。
